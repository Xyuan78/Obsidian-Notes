## 1.JS写在哪里
### 1.1写在script标签中

```html
<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <title>JavaScript 示例</title>
  </head>
  <body>
    <h1>JavaScript 示例</h1>

    <script>
      alert("页面已加载");
      console.log("JavaScript 正在运行");
    </script>
  </body>
</html>
```
说明：`<script>` 可以放在 `head`、`body` 或页面中的其他位置，但实际编写时要考虑代码什么时候使用页面元素。
### 1.2写在外部.js文件中
在HTML中引用

```html
<script src="./js/js-demo.js"></script>
```
`js/js-demo.js`：

```js
alert("来自外部 JavaScript 文件");
console.log("外部 JS 文件加载成功");
```

建议写在独立的js文件里面，以便于以后的JavaScript只负责行为

### 1.3.script放的位置
如果脚本需要操作页面元素，而元素还没有被浏览器解析出来，脚本可能找不到元素。因此课堂中推荐：

```html
<body>
  <h1 id="title">页面标题</h1>

  <script src="./js/main.js"></script>
</body>
```

现代写法也可以使用 `defer`：

```html
<head>
  <script src="./js/main.js" defer></script>
</head>
```

`defer` 表示先继续解析 HTML，等文档解析完成后再按顺序执行脚本，适合需要操作 DOM 的普通外部脚本。

### 1.4页面加载时立即执行与按钮触发时执行

页面加载就执行的代码：

```html
<script>
  console.log("页面加载时执行");
</script>
```

用户点击后才执行的代码：

```html
<button onclick="showMessage()">显示提示</button>

<script>
  function showMessage() {
    alert("按钮被点击");
  }
</script>
```

课堂中的原则是：

- 页面显示前就要使用的脚本，需要提前引入。
- 只有用户交互时才使用的代码，可以等需要时再执行。
- 外部脚本放在 `body` 末尾有助于先显示页面内容，再执行脚本。

## 2.三个输出
### 2.1alert()
```js
alert("Hello World");
```

`alert()` 会弹出提示框，并且会暂停页面继续执行，直到用户点击“确定”。

### 2.2console.log()
```js
console.log("Hello World");
console.log(5 + 6);
```

浏览器中按 `F12` 打开开发者工具，切换到 **Console（控制台）** 查看结果。

### 2.3document.write()
```js
document.write("<h1>直接写入页面</h1>");
document.write("<p>这是一段文本</p>");
```

课程演示发现：如果页面已经加载完成后再执行 `document.write()`，可能重写整个页面，把原来显示的内容覆盖掉。
## 3.基本语法
### 3.1数据类型
常见原始类型：

- `string`：字符串。
- `number`：数字，包括整数、小数和 `NaN`。
- `boolean`：布尔值 `true` / `false`。
- `undefined`：声明但未赋值。
- `null`：主动表示“没有对象值”。
- `symbol`：唯一符号。
- `bigint`：大整数。

常见对象类型：

- `Object`：普通对象。
- `Array`：数组。
- `Date`：日期时间对象。
- `Function`：函数也是对象。
### 3.2注释
单行注释：

```js
// 这是单行注释
```

多行注释：

```js
/*
  这是多行注释
  可以写多行说明
*/
```

### 3.3分号
```js
let name = "张三";
console.log(name);
```

分号在部分情况下可以省略，但推荐一行只写一条语句，并保持统一风格。
## 4变量
### var，let，const
```js
var oldName = "旧式变量";
let count = 1;
const siteName = "Frontend Notes";
```

- `var`：课程常用写法，函数作用域，存在变量提升，现代项目通常不再优先使用。
- `let`：块级作用域，变量值可以重新赋值。
- `const`：块级作用域，声明后不能重新绑定；对象内部属性仍可修改。

## 5.typeof
用于查看值的类型，可以写括号，也可以不写括号
```js
const name = "张三";
let score = 100;

console.log(typeof name);  // "string"
console.log(typeof score); // "number"
```
## 6.undifined和null
```js
let a;
console.log(a); // undefined

let list = ["ss", "nn"];
list = null; // 主动释放对象引用
```

- `undefined` 常表示变量已声明但还没有值。
- `null` 常表示程序主动设置的“空”。
- `typeof null` 的结果是 `"object"`，这是历史遗留行为。
- `typeof undefined` 的结果是 `"undefined"`。
- `NaN` 的类型是 `number`。
- 数组和日期的 `typeof` 结果都是 `"object"`。

## 7.TS和JS注解的区别
```ts
let age: number = 18;
const name: string = "张三";

function add(a: number, b: number): number {
  return a + b;
}
```

```js
let age = 18;
const name = "张三";

function add(a, b) {
  return a + b;
}
```

- JavaScript 变量不需要写类型。
- TypeScript 可以为变量、函数参数、函数返回值和对象增加类型。
- TypeScript 是建立在 JavaScript 基础上的语言，需要编译或转换后运行。
- TypeScript 中数字类型使用 `number`，不是 Java 中的 `int`。
- 函数没有返回值时，TypeScript 可以把返回类型写成 `void`。
- 当前课程先学习 JavaScript，之后再把类型系统自然迁移到 TypeScript。

## 9.类型转换
### 9.1 隐式转换
```js
console.log("5" + 1); // "51"
console.log("5" - 1); // 4
console.log(1 + true); // 2
```

`+` 遇到字符串时通常会拼接，其他算术运算通常会尝试把值转换成数字。隐式转换容易造成错误，关键代码应显式转换。

### 9.2 数字转字符串

```js
const number = 100;

const text1 = String(number);
const text2 = number.toString();
const text3 = number + "";

console.log(text1, text2, text3);
```
### 9.3 字符串转数字
```js
const number1 = Number("100");       // 100
const number2 = parseInt("100");    // 100
const number3 = parseFloat("15.8"); // 15.8
```

课程重点讲解了 `parseInt()` 的进制参数：

```js
console.log(parseInt("110", 2));  // 6，二进制
console.log(parseInt("FF", 16));  // 255，十六进制
console.log(parseInt("123abc"));  // 123，遇到非法字符停止
console.log(parseInt("abc"));     // NaN
```
说明：
- 第二个参数表示按什么进制解析。
- 没有传入进制时，实际项目中建议养成显式写十进制的习惯，例如 `parseInt(value, 10)`。
- 遇到无法解析的内容时会得到 `NaN`。
### 9.4 NaN
```js
const result = Number("abc");
console.log(result);       // NaN
console.log(typeof result); // "number"
```

`NaN` 表示 **Not a Number（不是一个有效数字）**，但它的数据类型仍然是 `number`。
```js
console.log(Number.isNaN(NaN)); // true
```
### 9.5 布尔值转换

以下值通常转换为 `false`：
```js
Boolean(false);
Boolean(0);
Boolean("");
Boolean(null);
Boolean(undefined);
Boolean(NaN);
```

## 10. 流程控制

### 10.1 if...else
```js
const score = 85;

if (score >= 90) {
  console.log("优秀");
} else if (score >= 60) {
  console.log("及格");
} else {
  console.log("不及格");
}
```

### 10.2 switch
```js
const today = new Date().getDay();

switch (today) {
  case 0:
    console.log("星期日");
    break;

  case 1:
    console.log("星期一");
    break;

  case 6:
    console.log("星期六");
    break;

  default:
    console.log("工作日");
}
```
- `getDay()` 返回 `0` 到 `6`。
- `0` 表示星期日。
- `switch` 中不要忘记 `break`，否则可能继续执行后续分支。
- 所有分支都不匹配时执行 `default`。
- JavaScript 的 `switch` 可以使用数字和字符串。

### 10.3 for循环
```js
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
```
### 10.4 for... in

```js
const student = {
  name: "张三",
  age: 18,
};

for (const key in student) {
  console.log(key, student[key]);
}
```
数组中使用 `for...in` 时，得到的是下标：

```js
const colors = ["red", "green", "blue"];

for (const index in colors) {
  console.log(index, colors[index]);
}
```

现代代码遍历数组值时，更推荐 `for...of`：

```js
for (const color of colors) {
  console.log(color);
}
```
### 10.5while
```js
let count = 1;

while (count <= 5) {
  console.log(count);
  count++;
}
```

条件为真时执行循环体，条件为假时停止。
### 10.6 do...while

```js
let count = 1;

do {
  console.log(count);
  count++;
} while (count <= 5);
```

`do...while` 先执行一次循环体，再判断条件，所以至少执行一次。

### 10.7 break 和 continue

```js
for (let i = 1; i <= 10; i++) {
  if (i === 5) {
    break;
  }

  console.log(i);
}
```

`break` 用于跳出整个循环。

```js
for (let i = 1; i <= 5; i++) {
  if (i === 3) {
    continue;
  }

  console.log(i);
}
```

`continue` 用于跳过本轮剩余代码，进入下一轮循环。
