## 1.函数
### 1.1 函数声明
```js
function add(a, b) {
  return a + b;
}

const result = add(10, 20);
console.log(result); // 30
```
- `function`：函数关键字。
- `add`：函数名。
- `(a, b)`：参数列表。
- `{ ... }`：函数体。
- `return`：返回结果并结束函数。

JavaScript 函数不需要写返回类型。是否返回值取决于函数体中有没有 `return`。
```js
function printMessage(message) {
  console.log(message);
}

console.log(printMessage("你好")); // 先输出"你好"，再输出 undefined
```
### 1.2 函数表达式
```js
const add = function (a, b) {
  return a + b;
};

console.log(add(1, 2));
```
函数可以作为值赋给变量，也可以作为参数传给其他函数。
### 1.3 箭头函数（Lambda表达式）

```js
const add = (a, b) => {
  return a + b;
};

const square = (number) => number * number;
const sayHello = () => "Hello";
```
简写规则：

- 只有一个参数时，可以省略参数括号。
- 函数体只有一条返回表达式时，可以省略 `return` 和花括号。
- 需要多行逻辑时，仍然使用完整花括号。
```js
const greet = (name) => `你好，${name}`;
console.log(greet("张三"));
```
### 1.4 函数也是一种对象

函数也可以被赋值，传递和调用
```js
const runTask = function () {
  console.log("执行任务");
};

const anotherTask = runTask;

anotherTask();
```
## 2. 对象
### 2.1 数组也是对象
#### 2.1.1 数组的创建和访问
```js
const scores = [100, 120, 50];

console.log(scores[0]); // 100
console.log(scores[1]); // 120
console.log(scores.length); // 3
```
#### 2.1.2 类型可以混合

```js
const studentInfo = ["张三", 18, true, null];
```
#### 2.1.3 数组的类型
```js
const scores = [100, 120, 50];

console.log(typeof scores);          // "object"
console.log(Array.isArray(scores)); // true
```
#### 2.1.4 数组的遍历
```js
const scores = [100, 120, 50];

for (let i = 0; i < scores.length; i++) {
  console.log(scores[i]);
}
```

```js
for (const score of scores) {
  console.log(score);
}
```
### 2.2 对象的创建
- 对象由键值对组成。
- 可以通过点语法或方括号读取属性。
- 方括号适合属性名包含特殊字符或从变量动态获取时使用。
- `for...in` 可以遍历对象键名。
#### 2.2.1 点语法

```js
console.log(student.name);
console.log(student.scores[0]);
```
#### 2.2.2 方括号语法
```js
console.log(student["name"]);
```
当属性名放在字符串中，或属性名需要通过变量动态确定时，方括号语法更合适：
```js
const key = "age";
console.log(student[key]);
```
