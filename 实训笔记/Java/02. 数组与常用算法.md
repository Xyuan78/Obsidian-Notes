## 1. 数组基础

数组用于保存**多个相同类型**的数据，元素在内存中连续存放。数组是引用类型。

```java
int[] numbers = {10, 20, 30, 40};
```

推荐声明方式：

```java
数据类型[] 数组名;
```

创建固定长度数组：

```java
int[] scores = new int[5];
```

创建并初始化：

```java
int[] numbers = new int[]{10, 20, 30};
int[] values = {10, 20, 30};
```

> [!warning] 创建数组时，不能同时写长度和初始化列表。
> `int[] a = new int[3]{1, 2, 3};` 是错误的。

### 1.1 下标与长度

```java
int[] array = {10, 20, 30};

System.out.println(array[0]);      // 10
System.out.println(array.length);  // 3
```

- 下标从 `0` 开始。
- 有效下标范围是 `0` 到 `array.length - 1`。
- 数组长度固定，创建后不能直接增加或减少。

### 1.2 默认值

| 元素类型 | 默认值 |
|---|---|
| `byte`、`short`、`int`、`long` | `0`、`0L` |
| `float`、`double` | `0.0F`、`0.0D` |
| `char` | `'\u0000'` |
| `boolean` | `false` |
| 对象引用 | `null` |

## 2. 遍历数组

### 2.1 普通 for

```java
int[] array = {10, 20, 30};

for (int i = 0; i < array.length; i++) {
    System.out.println(array[i]);
}
```

需要下标、修改元素或从后向前遍历时使用普通 `for`。

### 2.2 foreach

```java
for (int value : array) {
    System.out.println(value);
}
```

foreach 只适合顺序读取全部元素，不能在遍历时方便地修改原数组元素的位置。

## 3. 动态创建数组

```java
import java.util.Scanner;

public class ScoreDemo {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.print("人数：");
        int count = input.nextInt();

        double[] scores = new double[count];
        for (int i = 0; i < scores.length; i++) {
            System.out.print("第" + (i + 1) + "个成绩：");
            scores[i] = input.nextDouble();
        }

        for (double score : scores) {
            System.out.println(score);
        }
    }
}
```

## 4. 常见统计算法

### 4.1 最值、和、平均值

```java
int[] array = {34, 56, 6, 7, 8, 1879, 567, 2345, 245, 677};

int max = array[0];
int min = array[0];
int sum = 0;

for (int value : array) {
    sum += value;
    if (value > max) {
        max = value;
    }
    if (value < min) {
        min = value;
    }
}

double average = sum * 1.0 / array.length;
```

> [!tip] 为什么 `max` 初始化为 `array[0]`
> 如果初始化为 `0`，当数组全是负数时，最大值会错误地保持为 0。

## 5. 排序算法

### 5.1 冒泡排序

思想：相邻两个元素比较，逆序则交换。每轮把一个最大或最小的元素放到正确位置。

```java
int[] array = {34, 56, 6, 7, 8, 1879, 567, 2345, 245, 677};

for (int i = 0; i < array.length - 1; i++) {
    for (int j = 0; j < array.length - 1 - i; j++) {
        if (array[j] > array[j + 1]) {
            int temp = array[j];
            array[j] = array[j + 1];
            array[j + 1] = temp;
        }
    }
}
```

易错点：

- 外层比较轮数通常是 `length - 1`。
- 每一轮已经排好的尾部元素不再参与比较。
- 交换时必须借助临时变量。

### 5.2 选择排序

每一轮从未排序区间选出最小值，与未排序区间的第一个元素交换。

```java
for (int i = 0; i < array.length - 1; i++) {
    int minIndex = i;
    for (int j = i + 1; j < array.length; j++) {
        if (array[j] < array[minIndex]) {
            minIndex = j;
        }
    }
    int temp = array[i];
    array[i] = array[minIndex];
    array[minIndex] = temp;
}
```

### 5.3 插入排序

思想：把当前元素插入到前面已经有序的区间中。

```java
for (int i = 1; i < array.length; i++) {
    int current = array[i];
    int j = i - 1;

    while (j >= 0 && array[j] > current) {
        array[j + 1] = array[j];
        j--;
    }
    array[j + 1] = current;
}
```

课件中“在固定长度数组中插入一个新值”的练习不是完整的排序，而是先在有序数组中寻找插入位置，再把后面的元素整体向后移动。

## 6. 查找算法

### 6.1 线性查找

逐个比较，数组是否有序都可以使用，时间复杂度为 `O(n)`。

```java
int target = 30;
int index = -1;

for (int i = 0; i < array.length; i++) {
    if (array[i] == target) {
        index = i;
        break;
    }
}
```

### 6.2 二分查找

二分查找要求数组必须有序，每次排除一半区间，时间复杂度为 `O(log n)`。

```java
int left = 0;
int right = array.length - 1;
int target = 30;
int index = -1;

while (left <= right) {
    int mid = left + (right - left) / 2;

    if (array[mid] == target) {
        index = mid;
        break;
    } else if (array[mid] < target) {
        left = mid + 1;
    } else {
        right = mid - 1;
    }
}
```

> [!warning] 二分查找前必须先排序。
> 如果数组无序，二分判断方向的前提不成立。

## 7. 二维数组

二维数组可以理解为“数组的数组”。

```java
int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6}
};

System.out.println(matrix[1][2]); // 6
```

遍历：

```java
for (int i = 0; i < matrix.length; i++) {
    for (int j = 0; j < matrix[i].length; j++) {
        System.out.print(matrix[i][j] + "\t");
    }
    System.out.println();
}
```

### 7.1 不规则二维数组

```java
int[][] triangle = new int[5][];

for (int i = 0; i < triangle.length; i++) {
    triangle[i] = new int[i + 1];
}
```

### 7.2 杨辉三角

```java
int n = 6;
int[][] triangle = new int[n][];

for (int i = 0; i < n; i++) {
    triangle[i] = new int[i + 1];

    for (int j = 0; j <= i; j++) {
        if (j == 0 || i == j) {
            triangle[i][j] = 1;
        } else {
            triangle[i][j] = triangle[i - 1][j]
                    + triangle[i - 1][j - 1];
        }
    }
}
```

规律：每一行首尾为 1，其余元素等于上一行同列元素与上一行前一列元素之和。

## 8. 方法

### 8.1 定义与调用

```java
public static int add(int a, int b) {
    return a + b;
}

public static void main(String[] args) {
    int result = add(10, 20);
    System.out.println(result);
}
```

格式：

```java
访问修饰符 返回类型 方法名(参数列表) {
    方法体
}
```

- `void` 表示没有返回值。
- 有返回值的方法必须保证所有分支都能返回对应类型的值。
- 调用方法时传入的称为实参；定义方法时声明的称为形参。

### 8.2 方法返回值

```java
public static int[] createArray(int n) {
    int[] array = new int[n];
    return array;
}
```

### 8.3 参数传递

Java 中只有值传递：

- 基本类型传入的是数值副本，方法内重新赋值不会影响调用方。
- 对象或数组传入的是“引用值的副本”。方法通过该引用修改对象内容，调用方能看到变化；若给形参重新赋值为另一个对象，调用方变量仍指向原对象。

```java
public static void change(int value) {
    value = 100; // 不影响调用方
}

public static void fill(int[] array) {
    array[0] = 100; // 会影响调用方看到的数组内容
}
```

> [!important] 课件所称“引用传递”
> 应改用 Java 的正式说法：传递对象引用的副本。这个区别在方法内部重新给形参赋值时尤其重要。

## 10. 易错清单

- [ ] 数组越界：访问了下标 `length` 或更大的位置。
- [ ] 混淆 `array.length` 和字符串的 `str.length()`。
- [ ] `new int[5]` 的合法下标是 0 到 4。
- [ ] 数组变量保存的是引用，直接赋值 `b = a` 不会复制数组。
- [ ] 二分查找前没有排序。
- [ ] 交换两个变量时缺少临时变量，导致其中一个值被覆盖。
