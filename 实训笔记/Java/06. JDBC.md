## 1. JDBC 是什么
JDBC（Java Database Connectivity）是 Java 访问关系型数据库的标准 API。它定义了一套统一接口，具体数据库差异由各厂商提供的 JDBC 驱动实现。
- Java 程序面向 `java.sql` 标准接口编程。
- 更换数据库时，通常只需替换驱动和连接配置。
- SQL、事务和结果集处理方式保持一致。
## 2. 核心接口与类

| 类型                  | 作用                 |
| ------------------- | ------------------ |
| `Driver`            | 数据库驱动接口，由数据库厂商实现   |
| `DriverManager`     | 管理驱动并创建连接          |
| `Connection`        | 表示一次数据库连接和事务上下文    |
| `Statement`         | 执行静态 SQL           |
| `PreparedStatement` | 执行带参数的预编译 SQL，优先使用 |
| `CallableStatement` | 调用存储过程             |
| `ResultSet`         | 保存查询结果，提供行游标       |
| `SQLException`      | JDBC 操作异常          |
#### 主要是三个接口，一个类
- Connection  连接接口，与对应的数据库建立连接
- Statement  数据操作接口，对数据进行增删改（int 变量，表示影响的行数，） 查。
- ResultSet  结果集接口，只用于查询，获得相应的结果集（查询结构），
- 
- DriverManager 驱动管理类，mysql--加载mysql驱动

### 3.2 六个操作步骤
**（1）载入JDBC驱动程序：**

首先要在应用程序中加载驱动程序driver，使用Class.forName()方法加载特定的驱动程序，每种数据库管理系统的驱动程序不同，由数据库厂商提供。

**（2）定义连接URL，建立数据库连接对象：**

通过DriverManager类的getConnection()方法获得表示数据库连接的Connection类对象。

**（3）创建Statement对象**

获取Connection对象以后，可以用Connection对象的方法创建一个Statement对象的实例。

**（4）执行查询或更新：**

Statement对象可以执行SELECT语句的executeQuery()方法或执行INSERT、UPDATE、DELETE语句的executeUpdate()方法。

**（5）操作结果集：**

利用ResultSet对象对数据库操作返回的结果进行处理。ResultSet包含一些用来从结果集中获取数据并保存到Java变量中的方法。主要包括next()方法，用于移动结果集游标，逐行处理结果集，getString()、getInt()、getDate()、getDouble()等方法，用于将数据库中的数据类型转换为Java的数据类型。

**（6）释放资源：**

使用与数据库相关的对象非常耗内存，因此在数据库访问后要关闭与数据库的连接，同时还应该关闭ResultSet、Statement和Connection等对象。可以使用每个对象自己的close()方法完成。

public static void main(String[] args) throws SQLException,ClassNotFoundException {

```java 
封装增删改
package com.elm.manager.test;  
  
import java.sql.*;  
  
public class DBUtil {  
    static final String URL="jdbc:mysql://127.0.0.1:3306/erlemang?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=UTC";  
    static final String USER_NAME="root";  
    static final String PWD="Ks5639605518@";  
    static final String DRIVER="com.mysql.cj.jdbc.Driver";  
//    static Connection connection = null;  
//    static PreparedStatement preparedStatement=null;  
//    static ResultSet resultSet = null;  
  
	//获取连接
    public static Connection getConnection() throws SQLException,ClassNotFoundException {  
        Connection connection = null;  
        //加载驱动  
        if(connection==null || connection.isClosed()){  
            Class.forName(DRIVER);//加载驱动  
            connection = DriverManager.getConnection(URL,USER_NAME,PWD);  
        }  
  
        return connection;  
    }  
  
	  //关闭连接
    public static void closeAll(Connection connection,PreparedStatement preparedStatement,ResultSet resultSet) throws SQLException{  
        if(resultSet!=null){  
            resultSet.close();  
        }  
        if(preparedStatement!=null){  
            preparedStatement.close();  
        }  
        if(connection != null && !connection.isClosed()){  
            connection.close();  
        }  
    }  
  
    /**  
     *        执行数据库的增删改操作  
     * @param sql  要执行的sql语句  
     * @param objs 参数的数据  
     * @return     返回影响的行数  
     * @throws SQLException  
     * @throws ClassNotFoundException  
     */    public static int executeUpdate(String sql,Object[] objs) throws SQLException,ClassNotFoundException{  
        //获得连接  
        Connection conn = getConnection();//获得连接  
        PreparedStatement preparedStatement=conn.prepareStatement(sql);//预格式化sql，通过参数的方式填入数据，效率高  
        if(objs!=null && objs.length>0){  
            //sql的参数化  
            for (int i = 0; i <objs.length ; i++) {  
                //preparedStatement.setObject(index,value);  
                preparedStatement.setObject(i+1,objs[i]);  
            }  
        }  
        //执行sql  
        int count = preparedStatement.executeUpdate();  
  
  
        //关闭连接  
        closeAll(conn,preparedStatement,null);  
        //返回对应的处理结果  
        return count;  
  
    }  
  
}
```
