## 1. 类与对象

类：一组具有相同属性和共同行为的对象的集合，类是抽象的，是不可以被描述的，类是对象的抽象。 泛指 
对象：客观存在的，可以被描述的一切事物，统称为对象。
对象是具体的，是可以被描述的，
对象是类 的实例。特指 
从对象中抽象出类：找出对象中的相同属性和共同行为，去掉对应的值

### 1.1 定义类

```java
public class Person {
    private String name;
    private int age;

    public Person() {
    }

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public void introduce() {
        System.out.println("我是" + name + "，今年" + age + "岁");
    }
}
```

- 类是对一类事物的抽象。
- 对象是类创建出来的具体实例。
- 属性描述状态，方法描述行为。

### 1.2 创建对象

```java
Person person = new Person("张三", 18);
person.introduce();
```

`new` 的步骤：

1. 分配对象空间。
2. 初始化成员变量默认值。
3. 调用构造器。
4. 返回对象引用。

### 1.3 成员变量默认值

成员变量即使不手动赋值，也有默认值：

| 类型 | 默认值 |
|---|---|
| 整数类型 | `0` |
| 浮点类型 | `0.0` |
| `boolean` | `false` |
| `char` | `'\u0000'` |
| 引用类型 | `null` |

局部变量没有默认值，使用前必须显式赋值。

### 1.4 构造器

构造器特点：

- 名称与类名相同。
- 没有返回类型，也不写 `void`。
- 主要用于初始化对象。
- 可以重载。
- 如果未定义任何构造器，编译器自动生成无参构造器。
- 一旦定义了有参构造器，默认无参构造器不会再自动生成。

```java
public Person() {
}

public Person(String name) {
    this.name = name;
}
```

### 1.5 this

`this` 表示当前对象。

```java
public void setName(String name) {
    this.name = name;
}
```

同名变量冲突时，`this.name` 表示成员变量，`name` 表示参数。

### 1.6 封装
属性私有化，通过公共的方法去访问getter setter。主要是为了保护数据

```java
public class Student {
    private String name;

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }
}
```

封装的作用：

- 隐藏内部实现细节。
- 通过方法控制读写规则。
- 便于修改内部实现而不影响调用方。
#### 访问修饰符
- **default** (即默认，什么也不写）: 在同一包内可见，不使用任何修饰符。使用对象：类、接口、变量、方法。
    
- **private** : 在同一类内可见。使用对象：变量、方法。 **注意：不能修饰类（外部类）**
    
- **public** : 对所有类可见。使用对象：类、接口、变量、方法
    
- **protected** : 对同一包内的类和所有子类可见。使用对象：变量、方法。 **注意：不能修饰类（外部类）**。

## 2. 重载与重写
### 2.1 重载Overload

重载：同一个类中，方法名相同，参数列表不同，与返回值无关

 不同方式:(1)个数不同，（2）类型不同（3）参数的类型顺序不同
```java
public int add(int a, int b) {
    return a + b;
}

public double add(double a, double b) {
    return a + b;
}

public int add(int a, int b, int c) {
    return a + b + c;
}
```

仅返回值类型不同不能构成重载。

### 2.2 重写

在继承条件下，子类重写父类方法，方法（除访问修饰符外，其他都要相同）父类方法的访问修饰符不能大于子类的访问修饰符
子类重新实现父类方法：

```java
class Animal {
    public void move() {
        System.out.println("动物在移动");
    }
}

class Bird extends Animal {
    @Override
    public void move() {
        System.out.println("鸟在飞");
    }
}
```

重写要求：

- 方法名和参数列表相同。
- 访问权限不能比父类更严格。
- 返回值类型必须兼容。
- 父类 `private` 方法、构造器不能被重写。
- `final` 方法不能被重写。

## 3. 继承

### 3.1子类继承父类

- Java 类只能单继承，一个子类只能有一个直接父类。
- 子类继承父类可访问的成员。
- 构造子类对象前，会先执行父类构造过程。
- `super(...)` 调用父类构造器，必须是子类构造器中的第一条有效语句。
- `super.method()` 调用父类版本的方法。

```java
class Animal {
    protected String name;

    public void eat() {
        System.out.println("动物在吃");
    }
}

class Bird extends Animal {
    public void fly() {
        System.out.println("鸟在飞");
    }
}
```

### 3.2super 示例

```java
class Animal {
    public Animal(String name) {
        System.out.println(name);
    }
}

class Bird extends Animal {
    public Bird() {
        super("Bird");
    }
}
```

## 4. 多态

多态指同一个父类引用在运行时可以指向不同子类对象，并调用子类重写后的方法。

```java
Animal animal1 = new Bird();
Animal animal2 = new Dog();

animal1.move(); // 执行 Bird.move()
animal2.move(); // 执行 Dog.move()
```

向上转型

```java
Animal animal = new Bird();
```
向下转型

```java
Animal animal = new Bird();
Bird bird = (Bird) animal;
bird.fly();
```
