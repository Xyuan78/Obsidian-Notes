## 1. 不需要写构造方法

### 再pom.xml中
加入之后，不需要写构造方法
```java
<dependency>
    <groupId>org.projectlombok</groupId>
    <artifactId>lombok</artifactId>
    <version>1.18.36</version>
</dependency>
```
### 再开头加入
```java
import lombok.AllArgsConstructor;
import lombok.Data;
import lombok.NoArgsConstructor;
import lombok.experimental.Accessors;
import lombok.ToString;//生成ToString方法
import java.io.Serializable;//实现序列化接口

@Data //自动添加getter与setter
@AllArgsConstructor //所有参数的构造
@NoArgsConstructor //空构造，默认构造
@Accessors(chain = true) //链式编程

//举个例子
public class Student implements Serializable {

    private String stuName;//姓名
    private String stuNo;//学号
    private int stuId; //自动增长列
}

```

| 注解                    | 作用                                                |
| --------------------- | ------------------------------------------------- |
| `@Data`               | 生成 getter、setter、`toString`、`equals`、`hashCode` 等 |
| `@NoArgsConstructor`  | 生成无参构造器                                           |
| `@AllArgsConstructor` | 生成包含全部字段的构造器                                      |
