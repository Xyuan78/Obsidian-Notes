# 实训笔记索引

> [!info] 这个文件夹是什么
> 实训课堂上跟着讲师的原始笔记，按上课顺序记录（Java → JavaScript → Vue）。它和主库 `Java/`、`前端/` 下的笔记是**两套并行的记录**：这里是课堂现场版，主库是课后整理版。

读完这套笔记，应该能做到：

- 用 Java 定义类与对象、写数组和方法，看懂重载 / 重写 / 多态的代码。
- 用 JavaScript 写函数与对象，分清 `let`/`const`、`==` 与 `===`、隐式类型转换和流程控制。
- 用 Vite 建 Vue 3 项目，写模板语法、指令、`ref`、事件绑定、`v-model` 与路由。

## 学习主线

1. **Java**：项目初始化（Lombok）→ 基础语法 → 数组与常用算法 → 面向对象。这四篇内部有强依赖，按 `00 → 01 → 02 → 03` 读。
2. **JavaScript**：基础与输出 → 函数和对象 → Bootstrap 集成与组件化（转入 Vue 的过渡）。
3. **Vue**：创建项目与目录结构 → 基础语法（模板 / 指令 / ref / 事件 / v-model）→ Router 与生命周期。

> [!tip] 阅读建议
> 每篇末尾都有「相关笔记」段落，它同时给出**本文件夹的上下篇**和**主库里的对照笔记**。遇到课堂版写得简略的地方，直接跳到主库那一条。
