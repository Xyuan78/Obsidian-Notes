## 2.模板语法
### 1. 插值
```vue
<span style="color:rgb(192, 0, 0)"><script setup></span>
const title = "Vue 学习笔记";
const count = 3;
</script>

<template>
  <h1>{{ title }}</h1>
  <p>当前数量：{{ count + 1 }}</p>
</template>
```
双大括号 `{{ }}` 会把表达式结果转换为文本。适合简单表达式，不适合放复杂逻辑。
注：必须要加setup
### 2.指令 
指令以 `v-` 开头：
```vue
<img v-bind:src="imageUrl" alt="示例图片" />
<button v-on:click="increase">增加</button>
```
常用简写：

```vue
<img :src="imageUrl" alt="示例图片" />
<button @click="increase">增加</button>
```
- `:` 是 `v-bind:` 的简写，用于绑定属性。
- `@` 是 `v-on:` 的简写，用于绑定事件。动态绑定函数
- `v-model` 用于表单双向绑定。
- `v-if` / `v-show` 用于条件显示。
- `v-for` 用于列表渲染。
### 3. 条件判断
#### 1. v-if
v-if 如果条件是false，不会渲染该控件，适用于页面启动时控件是否被加载

```vue
<script setup>
import { ref } from "vue";

const isLoggedIn = ref(false);
</script>

<template>
  <p v-if="isLoggedIn">欢迎回来</p>
  <p v-else>请先登录</p>
</template>
```

多分支：

```vue
<p v-if="status === 'loading'">加载中</p>
<p v-else-if="status === 'error'">加载失败</p>
<p v-else>加载完成</p>
```

`v-if` 为假时，元素不会创建或会从 DOM 中移除。
#### 2. v-show
```vue
<p v-show="isVisible">这段内容通过 CSS 隐藏</p>
```
#### 3. 两者区别
- v-if 如果条件是false，不会渲染该控件，适用于页面启动时控件是否被加载 

- v-show 如果条件是false，渲染该控件，给了一个样式是隐藏，适用于，页面控件反复显示或隐藏
### 4. 数组
#### 1. 遍历对象
```vue
<script setup>
const student = {
  name: "张三",
  age: 18,
  address: "南京",
};
</script>

<template>
  <ul>
    <li v-for="(value, key, index) in student" :key="key">
      {{ index }} - {{ key }}：{{ value }}
    </li>
  </ul>
</template>
```
数组通常使用 `(item, index)`，对象使用 `(value, key, index)`。
### 使用数值范围

```vue
<p v-for="i in 9" :key="i">
  <span v-for="j in i" :key="j">{{ j }} × {{ i }} = {{ i * j }}</span>
</p>
```

### 5.ref 
`ref` 适合保存字符串、数字、布尔值、数组和对象：
```vue
<script setup>
import { ref } from "vue";

const count = ref(0);
const user = ref({
  name: "张三",
  age: 18,
});

function increase() {
  count.value++;
}

function changeName() {
  user.value.name = "李四";
}
</script>

<template>
  <p>{{ count }}</p>
  <p>{{ user.name }}</p>
  <button @click="increase">增加</button>
</template>
```
在 JavaScript 中通过 `.value` 读写；在模板中，Vue 会自动解包顶层 `ref`，通常不需要写 `.value`。

#### 1.动态绑定属性
```vue
<script setup>
import { ref } from "vue";

const userName = ref("张三");
const isActive = ref(true);
const hasError = ref(false);
const styleObject = {
  color: "red",
  fontSize: "20px",
};
</script>

<template>
  <input :value="userName" :data-name="'user-' + userName" />

  <p
    :class="{
      active: isActive,
      error: hasError,
      card: true,
    }"
  >
    动态类名
  </p>

  <p :style="styleObject">动态样式</p>
</template>
```
`v-bind` 的简写是 `:`。除了 `class` 和 `style`，也可以绑定 `value`、`disabled`、`src`、`data-*` 等属性。

### 6.事件绑定
```vue
<script setup>
function sayHello(name) {
  console.log(`你好，${name}`);
}
</script>

<template>
  <button @click="sayHello('张三')">点击</button>
  <button @click="sayHello($event.type)">查看事件类型</button>
</template>
```

`$event` 是原生事件对象，常用于读取事件信息或阻止默认行为。

### 7. 事件修饰符
```vue
<form @submit.prevent="submitForm">
  <button type="submit">提交</button>
</form>

<button @click.once="buy">只能点击一次</button>

<div @click="outer">
  <button @click.stop="inner">阻止冒泡</button>
</div>
```

常见修饰符：

- `.prevent`：调用 `event.preventDefault()`。
- `.stop`：调用 `event.stopPropagation()`。
- `.once`：事件只触发一次。
- `.self`：只有事件目标是自己时触发。
- `.capture`：使用捕获阶段。
- `.passive`：优化滚动等场景，不能与 `.prevent` 混用。
```vue
<button @click.right="openMenu">右键菜单</button>
<button @mousedown.middle="openLink">中键</button>
<input @keyup.enter="submit" />
<a @click.stop.prevent="handleClick">阻止冒泡和默认行为</a>
```

- `.left`：鼠标左键。
- `.right`：鼠标右键。
- `.middle`：鼠标中键。
- `.enter`：回车键。
- `.capture`：使用捕获阶段监听，不是说“阻止捕获”。
- 修饰符可以链式组合，顺序会影响执行逻辑。
### 8.v-model
#### 1. 双向绑定
```vue
<script setup>
import { ref } from "vue";

const username = ref("");
const agreed = ref(false);
</script>

<template>
  <label>
    用户名
    <input v-model="username" />
  </label>

  <label>
    <input v-model="agreed" type="checkbox" />
    同意协议
  </label>

  <p>{{ username }}</p>
</template>
```

`v-model` 把表单控件的值和响应式数据连接起来。
#### 2. 修饰符

```vue
<input v-model.trim="username" />
<input v-model.number="age" type="number" />
<input v-model.lazy="keyword" />
```

- `.trim`：自动移除首尾空格。
- `.number`：尝试把输入转换为数字。
- `.lazy`：在 `change` 事件后同步，而不是每次输入都同步。
#### 3. v-model对不同控件的处理
`v-model` 会根据控件类型选择对应的属性和事件：

- `text`、`textarea`：使用 `value` 和 `input` 事件。
- `checkbox`、`radio`：使用 `checked` 和 `change` 事件。
- `select`：使用 `value` 和 `change` 事件。

```vue
<input v-model="message" type="text" />
<textarea v-model="message"></textarea>
<input v-model="checked" type="checkbox" />
<input v-model="selected" type="radio" value="A" />
<select v-model="city">
  <option value="beijing">北京</option>
</select>
```

对于单选按钮和带 `value` 的复选框，最终绑定的是控件对应的 `value`。复选框绑定数组时会收集多个选中值。
## 3. Router

### 3.1安装和添加依赖
Vue 路由允许我们通过不同的 URL 访问不同的内容。
创建项目时可以选择 Router 和 Pinia：

```bash
npm create vue@latest
```

```js
//在main.js中引入 
import { createApp } from 'vue' //导入组件 
import App from '@/App.vue' 
import router from '@/router/index'//引入路由 
import store from '@/store' 
createApp(App) //创建vue对象 .use(store) //使用导入的组件 
.use(router)//把路由加入到vue上（使用路由组件） .mount('#app')//绑定，id是app的网页控件上
```

### 3.2 使用router
#### 3.2.1 在标签中使用
```js
<script src="https://unpkg.com/vue/dist/vue.js"></script>
<script src="https://unpkg.com/vue-router/dist/vue-router.js"></script>
 
<div id="app">
  <h1>Hello App!</h1>
  <p>
    <!-- 使用 router-link 组件来导航. -->
    <!-- 通过传入 `to` 属性指定链接. -->
    <!-- <router-link> 默认会被渲染成一个 `<a>` 标签 -->
    <router-link to="/foo">Go to Foo</router-link>
    <router-link to="/bar">Go to Bar</router-link>
  </p>
  <!-- 路由出口 -->
  <!-- 路由匹配到的组件将渲染在这里 -->
  <router-view></router-view>
</div>
```

```js
// 0. 如果使用模块化机制编程，导入 Vue 和 VueRouter，要调用 Vue.use(VueRouter)
 
// 1. 定义（路由）组件。
// 可以从其他文件 import 进来
const Foo = { template: '<div>foo</div>' }
const Bar = { template: '<div>bar</div>' }
 
// 2. 定义路由
// 每个路由应该映射一个组件。 其中"component" 可以是
// 通过 Vue.extend() 创建的组件构造器，
// 或者，只是一个组件配置对象。
// 我们晚点再讨论嵌套路由。
const routes = [
  { path: '/foo', component: Foo },
  { path: '/bar', component: Bar }
]
 
// 3. 创建 router 实例，然后传 `routes` 配置
// 你还可以传别的配置参数, 不过先这么简单着吧。
const router = new VueRouter({
  routes // （缩写）相当于 routes: routes
})
 
// 4. 创建和挂载根实例。
// 记得要通过 router 配置参数注入路由，
// 从而让整个应用都有路由功能
const app = new Vue({
  router
}).$mount('#app')
 
// 现在，应用已经启动了！
```
