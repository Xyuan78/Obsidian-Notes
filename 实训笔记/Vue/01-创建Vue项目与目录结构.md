```bash
node --version
npm --version
```
## 2. 创建项目
###### 1.使用管理员终端打开需要创建项目的文件夹，使用命令

```bash
npm create vue@latest
```

##### 3.进入项目安装依赖
1.进入项目
```bash
cd vue-notes-app
```
![[Pasted image 20260917091104.png]]
2.安装依赖
```bash
npm install
```
出现下面这个之后代表完成
![[Pasted image 20260917091414.png]]

3.启动开发服务器
```bash
npm run dev
```
