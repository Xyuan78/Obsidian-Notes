# Vim 常用命令速查

## 模式切换

- `i`：进入输入模式
- `Esc`：切换到普通模式 / 命令模式

## 普通模式下的命令

| 命令 | 说明 |
|------|------|
| `i` | 切换到输入模式 |
| `dd` | 剪切当前行 |
| `yy` | 复制当前行 |
| `p` | 粘贴 |
| `u` | 撤销上一次操作 |
| `:w` | 保存文件 |
| `:wq` | 保存并退出 |

## 输入模式

- `Esc`：退出输入模式，回到普通模式
