# Linux 基础命令

## 1. 查看命令帮助信息

| 命令 | 说明 |
|------|------|
| `man ls` | 查看 ls 命令的帮助信息 |
| `ls --help \| more` | 分页显示 ls 命令的选项信息 |

> 按 `q` 键退出帮助页面

## 2. 中断 Shell 命令

```
Ctrl + C   中断正在执行的命令
```

## 3. 显示当前路径

```bash
pwd
```

## 4. 显示当前目录中的子目录及文件

```bash
ls
```

## 5. `ls` 命令选项

| 选项 | 说明 |
|------|------|
| `-a` | 显示所有文件和子目录，包括 `.` 开头的隐藏文件 |
| `-l` | 显示文件和子目录的详细信息 |
| `-d` | 如果是目录，则只显示目录信息，不显示其中的文件 |
| `-h` | 以易读的方式显示文件大小 |
| `-R` | 递归显示指定目录下的文件和子目录 |

## 6. 创建文件夹

```bash
mkdir 文件夹名    # 在当前目录下创建文件夹
```

## 7. 目录切换

```bash
cd /root/exam              # 切换到 /root/exam 子目录
cd ..                      # 返回上级目录
```
> 自动补全：输入命令开头一个或几个字母，按 `Tab` 键自动补全，再按一次显示所有符合条件的命令

## 8. [[vim]] 和 vi 编辑器

### vi 的三种模式

1. **输入模式（文本编辑模式）**：在命令模式下按 `i` 键进入
2. **命令模式**：用户输入单键命令的模式。在其他模式中按 `ESC` 键进入
3. **末行模式**：从命令模式输入 `:` 进入，可输入复杂命令（通常是文件操作命令）

![[Pasted image 20260312090329.png|403]]

### 在末行模式下的操作

| 命令 | 说明 |
|------|------|
| `set nu` | 显示行号 |
| `set nonu` | 不显示行号 |
| `n1,n2 co n3` | 将 n1~n2 的所有行复制到 n3 行之后 |
| `n1,n2 m n3` | 将 n1~n2 的所有行移动到 n3 行之后 |
| `n1,n2 d` | 删除 n1~n2 的所有行 |
| `n1,n2 s/字符串1/字符串2/g` | 将 n1~n2 行的所有字符串1替换为字符串2 |

### 在命令模式下的操作

| 命令 | 说明 |
|------|------|
| `dd` | 删除光标所在行 |
| `ndd` | 从光标所在行开始删除 n 行 |
| `yy` | 复制整行 |
| `nyy` | 复制 n 行 |
| `p` | 粘贴 |

### 保存文件

**命令模式：**
- `ZZ`：存盘退出
- `ZQ`：不存盘退出

**末行模式：**
- `:w`：保存文件，不退出 vi
- `:w 文件名`：保存为指定文件（另存为）
- `:q!`：不保存文件，直接退出 vi
- `:wq`：保存文件并退出 vi
- `:wq!`：强制保存文件并退出 vi（仅文件所有者或 root 有权限）
