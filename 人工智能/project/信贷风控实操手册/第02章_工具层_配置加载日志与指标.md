| KP-PY-03 | 单例模式 | 一个类全程序只创建一个实例 | 配置读一次就够，重复读盘既慢又可能读到不同版本 | `ConfigLoader._instance` | 必懂 |
| KP-PY-04 | `__getattr__` | 让对象支持"点"取属性 | 才能写出 `config.model` 这种自然写法 | `AttrDict` | 知道即可 |
| KP-PY-05 | 正则替换 | 用模式匹配批量替换文本 | 把 `${DEEPSEEK_API_KEY}` 换成真 Key | `_interpolate_env_vars` | 知道即可 |

| KP-EV-05 | 混淆矩阵 | 真阳/假阳/真阴/假阴四格表 | 看清模型具体错在哪一类 | `get_confusion_matrix` | 知道即可 |
| KP-EN-09 | 日志分级 | DEBUG < INFO < WARNING < ERROR | 排查时调低级别看细节，上线时调高减少噪音 | `logger.py` | 知道即可 |

### 展开讲 1：AUC 到底在说什么

假设你面前有一堆客户，其中有些会违约（坏），有些不会（好）。你随机抽出**一个坏客户和一个好客户**，让模型给两人打分。**模型给坏客户的分比好客户高的概率，就是 AUC。**

- AUC = 0.5 → 跟抛硬币一样，模型没学到东西
- AUC = 0.75 → 75% 的情况下能正确排序，实际项目里算"能用"
- AUC = 0.9 → 很强，通常意味着数据里有强特征，或者……你泄漏了
- AUC < 0.6 → 大概率代码有 bug，不是模型不行

它有个好处：**不受阈值影响**。你先看排序能力，再决定阈值切在哪。

### 展开讲 2：为什么单例模式在这里会咬人

`ConfigLoader` 只初始化一次，全程序共享。好处是快。

但它有个副作用：**你在同一个 Python 进程里改了 YAML 文件，读到的还是旧的**。测试时尤其明显——第 1 个测试改了配置，第 2 个测试拿到的是被改过的配置。

解决办法：

```python
configs = ConfigLoader("./configs")
configs.reload()      # 强制重新读盘
```

本项目的正式训练流程每次都启动新进程，所以不受影响。但你在 Jupyter 里反复调试时会遇到，记住 `reload()`。

**【目标】** 一次读入 5 个 YAML，支持点访问和环境变量插值。

**【文件】** `src/utils/config_loader.py`（新建）

**【完整代码】**

```python
"""
配置加载器
=========
统一加载所有 YAML 配置，支持点访问与环境变量插值。
"""
from __future__ import annotations

import os
import re
from pathlib import Path
from typing import Any, Dict, Optional

import yaml
from dotenv import load_dotenv


class ConfigLoader:
    """配置加载器（单例）。"""

    _instance: Optional["ConfigLoader"] = None
    _configs: Dict[str, "AttrDict"] = {}

    def __new__(cls, config_dir: str = "./configs"):
        if cls._instance is None:
            instance = super().__new__(cls)
            try:
                instance._initialize(config_dir)
            except Exception:
                # 初始化失败时不要把半成品留成单例，
                # 否则后续调用会拿到一个 _configs 为空的假实例
                cls._instance = None
                raise
            cls._instance = instance
        return cls._instance

    def _initialize(self, config_dir: str) -> None:
        load_dotenv()
        self.config_dir = Path(config_dir).resolve()

        if not self.config_dir.exists():
            raise FileNotFoundError(
                f"配置目录不存在: {self.config_dir}\n"
                f"提示: 请在项目根目录运行，或确认 --config-dir 参数"
            )
        if not self.config_dir.is_dir():
            raise NotADirectoryError(
                f"配置路径不是目录: {self.config_dir}\n"
                f"正确写法: --config-dir ./configs"
            )

        yaml_files = list(self.config_dir.glob("*.yaml"))
        if not yaml_files:
            files_in_dir = [f.name for f in self.config_dir.iterdir()]
            raise FileNotFoundError(
                f"配置目录 {self.config_dir} 下没有 *.yaml 文件。\n"
                f"现有内容: {files_in_dir}\n"
                f"提示: Windows 用户检查扩展名是否被隐藏成了 .yaml.txt"
            )

        for yaml_file in yaml_files:
            # model_config.yaml -> "model"
            config_name = yaml_file.stem.replace("_config", "")
            self._configs[config_name] = self._load_yaml(yaml_file)

    def _load_yaml(self, file_path: Path) -> "AttrDict":
        with open(file_path, "r", encoding="utf-8") as f:
            content = f.read()
        content = self._interpolate_env_vars(content)
        data = yaml.safe_load(content)
        return AttrDict(data) if data else AttrDict({})

    @staticmethod
    def _interpolate_env_vars(content: str) -> str:
        """
        支持两种写法：
            ${VAR_NAME}            -> 不存在则保留原文
            ${VAR_NAME:-default}   -> 不存在则用 default
        """
        pattern = re.compile(r"\$\{([^}^{]+)\}")

        def replacer(match):
            expr = match.group(1)
            if ":-" in expr:
                var_name, default = expr.split(":-", 1)
                return os.environ.get(var_name.strip(), default.strip())
            return os.environ.get(expr.strip(), match.group(0))

        return pattern.sub(replacer, content)

    def get(self, name: str) -> "AttrDict":
        if name not in self._configs:
            raise KeyError(f"配置 '{name}' 不存在，可用配置: {list(self._configs.keys())}")
        return self._configs[name]

    def reload(self) -> None:
        self._configs = {}
        self._initialize(str(self.config_dir))

    def __repr__(self) -> str:
        return f"ConfigLoader(dir={self.config_dir}, configs={list(self._configs.keys())})"


class AttrDict(dict):
    """支持属性访问的字典。d.a.b 等价于 d["a"]["b"]。"""

    def __init__(self, data: Optional[Dict] = None):
        super().__init__()
        if data:
            for key, value in data.items():
                self[key] = self._wrap(value)

    @staticmethod
    def _wrap(value: Any) -> Any:
        if isinstance(value, dict):
            return AttrDict(value)
        if isinstance(value, list):
            return [AttrDict._wrap(item) for item in value]
        return value

    def __getattr__(self, key: str) -> Any:
        if key in self:
            return self[key]
        raise AttributeError(f"配置项 '{key}' 不存在")

    def __setattr__(self, key: str, value: Any) -> None:
        self[key] = self._wrap(value)


def load_configs(config_dir: str = "./configs") -> ConfigLoader:
    """便捷函数。"""
    return ConfigLoader(config_dir)


if __name__ == "__main__":
    loader = ConfigLoader("./configs")
    print("已加载:", list(loader._configs.keys()))
    print("XGBoost 学习率:", loader.get("model").xgboost.params.learning_rate)
```

**【逐块讲解】**

| 代码段 | 做什么 | 小白要点 |
|---|---|---|
| `__new__` | 控制"创建对象"这一步 | 第一次调用才真初始化，之后直接返回同一个对象 |
| `except: cls._instance = None` | 初始化失败时清空单例 | 不加这句，失败一次后所有后续调用都会拿到空配置 |
| `glob("*.yaml")` | 扫目录下所有 YAML | 加一个 YAML 文件就自动多一个配置块，不用改代码 |
| `stem.replace("_config","")` | 文件名变键名 | `model_config.yaml` → `"model"` |
| `_interpolate_env_vars` | 正则替换 `${...}` | `:-` 前面是变量名，后面是默认值 |
| `AttrDict._wrap` | 递归包装嵌套字典 | 所以 `.xgboost.params.max_depth` 能一路点下去 |
| `__getattr__` | 拦截"点访问" | 找不到时抛 `AttributeError` 而不是 `KeyError`，报错更清晰 |

**【完整代码】**

```python
"""
日志工具
========
基于 loguru 的统一日志接口，文件 + 控制台双输出。
"""
from __future__ import annotations

import sys
from pathlib import Path

from loguru import logger as _loguru_logger


def get_logger(
    name: str = "credit_risk",
    log_dir: str = "./logs",
    level: str = "INFO",
    rotation: str = "10 MB",
    retention: str = "14 days",
):
    """
    获取配置好的 logger。

    参数:
        name: 模块名，会显示在日志里，方便定位是谁打的
        log_dir: 日志目录
        level: DEBUG / INFO / WARNING / ERROR
        rotation: 单文件多大时切分
        retention: 保留多久
    """
    log_path = Path(log_dir)
    log_path.mkdir(parents=True, exist_ok=True)

    # 先清空默认 handler，否则会重复输出两遍
    _loguru_logger.remove()

    # 控制台
    _loguru_logger.add(
        sys.stderr,
        format="<green>{time:HH:mm:ss}</green> | <level>{level: <8}</level> | "
               "<cyan>{name}</cyan>:<cyan>{function}</cyan>:<cyan>{line}</cyan> - "
               "<level>{message}</level>",
        level=level,
        colorize=True,
    )

    # 文件（按天 + 按大小切分）
    _loguru_logger.add(
        log_path / f"{name}_{{time:YYYY-MM-DD}}.log",
        format="{time:YYYY-MM-DD HH:mm:ss} | {level: <8} | {name}:{function}:{line} - {message}",
        level=level,
        rotation=rotation,
        retention=retention,
        encoding="utf-8",
        enqueue=True,
    )

    return _loguru_logger.bind(name=name)


# 默认实例，导入即可用
default_logger = get_logger()
```

**【逐块讲解】**

| 参数 | 作用 |
|---|---|
| `_loguru_logger.remove()` | loguru 自带一个默认输出，不清掉会每条日志打两遍 |
| `<green>{time}</green>` | 用标记给日志上色，只影响屏幕不影响文件 |
| `{name}:{function}:{line}` | 打出"哪个文件、哪个函数、第几行"，定位问题的关键 |
| `rotation="10 MB"` | 单个文件超 10MB 自动切新文件 |
| `retention="14 days"` | 14 天前的自动删除，防止磁盘被日志吃满 |
| `enqueue=True` | 多进程安全，Streamlit 场景必须 |

### 步骤 2.3　写 `src/utils/metrics.py`

**【目标】** 一套统一的指标计算，重点实现 AUC 和 KS。

**【文件】** `src/utils/metrics.py`（新建）

**【完整代码】**

```python
"""
评估指标模块
============
AUC、KS、混淆矩阵、ROC/PR 曲线、Lift。
"""
from __future__ import annotations

from dataclasses import dataclass, asdict
from typing import Dict, Tuple

import numpy as np
from sklearn.metrics import (
    accuracy_score,
    confusion_matrix,
    f1_score,
    log_loss,
    precision_recall_curve,
    precision_score,
    recall_score,
    roc_auc_score,
    roc_curve,
)


@dataclass
class EvalResult:
    """评估结果。"""
    auc: float = 0.0
    ks: float = 0.0
    accuracy: float = 0.0
    precision: float = 0.0
    recall: float = 0.0
    f1: float = 0.0
    log_loss: float = 0.0
    threshold: float = 0.5

    def to_dict(self) -> Dict:
        return asdict(self)

    def __repr__(self) -> str:
        return (f"EvalResult(AUC={self.auc:.4f}, KS={self.ks:.4f}, "
                f"F1={self.f1:.4f} @ threshold={self.threshold:.2f})")


class Evaluator:
    """统一指标计算器。"""

    def __init__(self, threshold: float = 0.5):
        self.threshold = threshold

    def evaluate(
        self,
        y_true: np.ndarray,
        y_pred_proba: np.ndarray,
        threshold: float = None,
    ) -> EvalResult:
        """
        参数:
            y_true: 真实标签 (n,)
            y_pred_proba: 预测概率，一维 (n,)
            threshold: 分类阈值，不传则用构造时的值
        """
        y_pred_proba = np.asarray(y_pred_proba).ravel()   # 兼容 (n,1)
        threshold = threshold if threshold is not None else self.threshold
        y_pred_label = (y_pred_proba >= threshold).astype(int)

        return EvalResult(
            auc=float(roc_auc_score(y_true, y_pred_proba)),
            ks=self.calculate_ks(y_true, y_pred_proba),
            accuracy=float(accuracy_score(y_true, y_pred_label)),
            precision=float(precision_score(y_true, y_pred_label, zero_division=0)),
            recall=float(recall_score(y_true, y_pred_label, zero_division=0)),
            f1=float(f1_score(y_true, y_pred_label, zero_division=0)),
            log_loss=float(log_loss(y_true, np.clip(y_pred_proba, 1e-15, 1 - 1e-15))),
            threshold=threshold,
        )

    @staticmethod
    def calculate_ks(y_true: np.ndarray, y_pred_proba: np.ndarray) -> float:
        """
        KS = max(|TPR - FPR|)，越大说明模型把好坏客户分得越开。
        经验值：>0.3 可接受，>0.5 优秀。
        """
        fpr, tpr, _ = roc_curve(y_true, y_pred_proba)
        return float(np.max(np.abs(tpr - fpr)))

    @staticmethod
    def find_best_threshold(
        y_true: np.ndarray,
        y_pred_proba: np.ndarray,
        method: str = "youden",
    ) -> float:
        """找最优阈值。youden = 让 TPR-FPR 最大；f1 = 让 F1 最大。"""
        if method == "youden":
            fpr, tpr, thresholds = roc_curve(y_true, y_pred_proba)
            return float(thresholds[np.argmax(tpr - fpr)])

        if method == "f1":
            precisions, recalls, thresholds = precision_recall_curve(y_true, y_pred_proba)
            f1_scores = 2 * precisions * recalls / (precisions + recalls + 1e-10)
            # thresholds 比 precisions 少一个元素
            return float(thresholds[np.argmax(f1_scores[:-1])])

        raise ValueError(f"不支持的方法: {method}")

    @staticmethod
    def get_confusion_matrix(
        y_true: np.ndarray,
        y_pred_proba: np.ndarray,
        threshold: float = 0.5,
    ) -> np.ndarray:
        y_pred = (np.asarray(y_pred_proba).ravel() >= threshold).astype(int)
        return confusion_matrix(y_true, y_pred)

    @staticmethod
    def get_roc_curve(y_true, y_pred_proba) -> Tuple[np.ndarray, np.ndarray, np.ndarray]:
        return roc_curve(y_true, np.asarray(y_pred_proba).ravel())

    @staticmethod
    def get_pr_curve(y_true, y_pred_proba):
        return precision_recall_curve(y_true, np.asarray(y_pred_proba).ravel())

    @staticmethod
    def calculate_lift(y_true, y_pred_proba, n_bins: int = 10) -> Dict:
        """按预测概率分成 n 组，看每组的违约率是平均值的几倍。"""
        y_true = np.asarray(y_true)
        y_pred_proba = np.asarray(y_pred_proba).ravel()
        sorted_idx = np.argsort(-y_pred_proba)
        y_sorted = y_true[sorted_idx]

        baseline = float(y_true.mean())
        bin_size = len(y_true) // n_bins
        lifts = []

        for i in range(n_bins):
            start = i * bin_size
            end = (i + 1) * bin_size if i < n_bins - 1 else len(y_true)
            bin_rate = float(y_sorted[start:end].mean())
            lifts.append({
                "bin": i + 1,
                "size": int(end - start),
                "default_rate": bin_rate,
                "lift": float(bin_rate / baseline) if baseline > 0 else 0.0,
            })

        return {"baseline": baseline, "bins": lifts}
```

**【逐块讲解】**

| 代码段 | 做什么 | 小白要点 |
|---|---|---|
| `@dataclass` | 自动生成 `__init__` | 不用手写 8 个参数的构造函数 |
| `np.asarray(...).ravel()` | 把 `(n,1)` 压成 `(n,)` | 上游模型可能返回二维，这里统一处理，避免后面的切片错误 |
| `roc_auc_score` | 直接算 AUC | sklearn 内置，不用自己积分 |
| `calculate_ks` | 从 ROC 曲线取 `TPR-FPR` 的最大值 | ROC 曲线的两个轴正好就是好坏样本的累积分布 |
| `f1_scores[:-1]` | 丢掉最后一个 | `precision_recall_curve` 返回的 thresholds 比 precisions 少一个 |
| `np.clip(proba, 1e-15, 1-1e-15)` | 把概率夹在极小区间内 | 概率正好 0 或 1 时 `log(0)` 会变成 `-inf` |
| `calculate_lift` | 分组看提升度 | 第一组的 lift 通常是 2~3，说明"最可疑的 10% 里违约率是全体的 2~3 倍" |

## 6. 本章错误对照

### 错误 E-02　`evaluate()` 的关键字参数名写错

**出现在**：原文档第 4、5 章调用评估器时

**❌ 原文写法**

```python
result = evaluator.evaluate(y_true=y_val, y_proba=proba)
```

**✅ 修正写法**

```python
result = evaluator.evaluate(y_true=y_val, y_pred_proba=proba)
```

**💥 不修的后果**　训练跑到最后一步评估时中断，前面几十分钟白跑：

```
TypeError: Evaluator.evaluate() got an unexpected keyword argument 'y_proba'
```

**🧠 为什么**　函数定义里形参就叫 `y_pred_proba`。关键字参数是"按名字点菜"，名字差一个字 Python 就找不到这道菜。

**✅ 自查**　全项目搜索 `y_proba=`，凡是不带 `pred_` 的一律改掉。

---

### 错误 E-03　用 `configs.model` 访问顶层配置

**出现在**：原文档附录 B 的 API 速查、以及多处示例

**❌ 原文写法**

```python
configs = ConfigLoader("./configs")
lr = configs.model.xgboost.params.learning_rate
```

**✅ 修正写法**

```python
configs = ConfigLoader("./configs")
lr = configs.get("model").xgboost.params.learning_rate
```

**💥 不修的后果**

```
AttributeError: 'ConfigLoader' object has no attribute 'model'
```

**🧠 为什么**　`ConfigLoader` 只在**返回的 AttrDict 内部**实现了 `__getattr__`，`ConfigLoader` 类本身没有。它只提供 `get(name)`。所以第一步必须用 `get()` 取出配置块，之后才能一路点下去。

**✅ 自查**　看到 `configs.` 后面直接跟配置名（`data`/`model`/`llm`/`feature`/`pipeline`），就缺了 `.get("...")`。

---

### 错误 E-04　以为 `EvalResult` 有 `summary()` 和 `confusion_matrix`

**出现在**：原文档第 4 章的评估示例

**❌ 原文写法**

```python
print(result.summary())
print(result.confusion_matrix)
```

**✅ 修正写法**

```python
print(result)                                  # 已实现 __repr__
print(result.to_dict())                        # 转字典
cm = Evaluator.get_confusion_matrix(y_true, proba, threshold=result.threshold)
```

**💥 不修的后果**

```
AttributeError: 'EvalResult' object has no attribute 'summary'
```

**🧠 为什么**　`EvalResult` 是个 `@dataclass`，只有字段 + `to_dict()` + `__repr__`。混淆矩阵不是它存的字段，要用静态方法现算。

**✅ 自查**　想知道一个对象有什么，直接 `print([m for m in dir(result) if not m.startswith('_')])`。

## 7. 常见坑

| 现象 | 原因 | 解决 |
|---|---|---|
| 单例导致测试互相污染 | 配置读过一次就缓存了 | 测试里先 `configs.reload()`，或每个测试用独立进程 |
| 日志文件没有生成 | `logs/` 目录不存在且没有创建权限 | `logger.py` 里有 `mkdir(parents=True)`，检查是否被异常中断 |
| AUC 算出来是 0.5 以下 | 概率传给 `y_true`、标签传给 `y_score` 反了 | 顺序是 `(真实标签, 预测概率)` |
| KS 算出来大于 1 | 手动实现时取错了绝对值位置 | 必须 `max(|tpr-fpr|)` |
| `to_dict()` 里的 numpy 类型无法 JSON 序列化 | `np.float64` 不是原生 float | 已用 `float()` 包裹；保存时仍失败就加自定义 encoder |

## 8. 本章自测

**1. 为什么 `ConfigLoader` 要设计成单例？有什么副作用？**

<details><summary>点开看答案</summary>

好处：配置只需读一次盘，全程序共享，避免重复 IO 和配置不一致。副作用：改了 YAML 后同一进程内读到的仍是旧值，需要用 `reload()` 强制重读。

</details>

**2. AUC = 0.5 意味着什么？AUC = 0.95 应该先怀疑什么？**

<details><summary>点开看答案</summary>

0.5 意味着模型排序能力和随机猜一样，没学到东西。0.95 要**先怀疑数据泄漏**（比如把目标列也喂进了特征），而不是先高兴。

</details>

**3. KS 和 AUC 都是衡量区分能力的，区别在哪？**

<details><summary>点开看答案</summary>

AUC 看的是**整体**排序能力（所有阈值下的综合表现）；KS 看的是**某一个最优点**上好坏分布差得最开的位置。风控行业习惯同时看，KS 更直观地对应"切一刀能捞回多少坏人"。

</details>

**4. 为什么 `np.clip(proba, 1e-15, 1-1e-15)` 不能省？**

<details><summary>点开看答案</summary>

`log_loss` 内部要算 `log(p)`。如果模型输出正好 0 或 1（在强特征下很常见），`log(0) = -inf`，整个指标变成 `inf` 或 `nan`。夹一下就能避免。

</details>
