### 展开讲 1：为什么要"造"特征

原始字段：`annualIncome=120000`（年收入）、`installment=3000`（月还款）。

单看这两个数，模型很难判断风险——年收入 12 万、月还 3000，压力大不大？要看比例。

于是造一个：

```
installment_to_income_ratio = 3000 / (120000/12) = 0.3
```

30% 的月收入用来还贷。这个数字本身就能说明问题，而且**跨人群可比**——不管他收入 5 万还是 50 万，这个比例都有相同含义。

这就是特征工程的价值：**把"两个绝对值"变成"一个有业务含义的比值"**。

### 展开讲 2：三道筛子各筛什么

```
原始特征 ~60 个
   ↓ 方差筛（去掉几乎不变的）
~55 个
   ↓ 相关性筛（去掉几乎重复的）
~40 个
   ↓ 模型筛（按重要性留 Top 50）
~30 个（不足 50 就全留）
```

为什么不能只用最后一道：模型筛要训一次 XGBoost，如果前面有大量常数列和重复列，这次训练既慢又不准。前面的筛子是"降噪"，让最后一道筛得更准。

## 5. 分步操作

### 步骤 4.1　写 `src/features/builder.py`

**【目标】** 读 YAML 里的公式字符串，算出新列。

**【文件】** `src/features/builder.py`（新建）

**【完整代码】**

```python
"""
特征构造器
==========
按配置中的公式生成衍生特征。

设计要点：规则在 YAML，代码只负责执行。
想加新特征，改配置即可，不动 Python。
"""
from __future__ import annotations

from typing import Dict, List

import numpy as np
import pandas as pd

from src.utils.logger import get_logger

logger = get_logger("features.builder")


class FeatureBuilder:
    """根据配置生成衍生特征。"""

    def __init__(self, config):
        # config 传的是 configs.get("feature")
        self.config = config
        self.derived_cfg = config.derived_features
        self._created_features: List[str] = []

    def build(self, df: pd.DataFrame) -> pd.DataFrame:
        """生成所有配置中定义的衍生特征。"""
        if not self.derived_cfg.enabled:
            logger.info("衍生特征已关闭，跳过")
            return df

        df = df.copy()
        for rule in self.derived_cfg.rules:
            try:
                df = self._apply_rule(df, rule)
                self._created_features.append(rule["name"])
                logger.debug(f"创建衍生特征: {rule['name']}")
            except Exception as e:
                # 单条失败不中断整体
                logger.warning(f"创建特征 {rule['name']} 失败: {e}")

        logger.info(f"成功创建 {len(self._created_features)} 个衍生特征")
        return df

    def _apply_rule(self, df: pd.DataFrame, rule: Dict) -> pd.DataFrame:
        name = rule["name"]
        formula = rule["formula"]

        if name in df.columns:
            logger.debug(f"特征 {name} 已存在，跳过")
            return df

        df[name] = self._safe_eval(formula, df)
        return df

    @staticmethod
    def _safe_eval(formula: str, df: pd.DataFrame):
        """
        受限命名空间的公式求值。

        允许：df / pd / np / 数据框中的列名
        禁止：内置函数（__builtins__ 置空），所以 open()、__import__ 都不可用
        """
        # 先把所有合法列名注入命名空间，这样公式里能直接写 annualIncome
        namespace = {c: df[c] for c in df.columns if isinstance(c, str) and c.isidentifier()}

        # 再覆盖这三个，保证不会被同名数据列顶掉
        namespace.update({
            "df": df,
            "pd": pd,
            "np": np,
            "__builtins__": {},
        })

        return eval(formula, namespace)

    def get_created_features(self) -> List[str]:
        return self._created_features.copy()
```

**【逐块讲解】**

| 代码段 | 做什么 | 小白要点 |
|---|---|---|
| `config.derived_features.rules` | 取规则列表 | 少写 `.rules` 会 `TypeError: not iterable` |
| `try/except` 包住每条规则 | 一条失败不影响其他 | 某些数据里可能没有某个字段，跳过即可 |
| `if name in df.columns: return` | 幂等 | 重复调用 `build()` 不会重复造列 |
| `namespace = {c: df[c] ...}` | **把列名注入** | 配置里写 `annualIncome / 12`，必须有 `annualIncome` 这个变量 |
| `isidentifier()` | 只注入合法变量名 | 列名带空格或横线时不能当变量名 |
| `__builtins__: {}` | 禁掉所有内置函数 | 即使配置被改成 `open('passwd').read()` 也执行不了 |

**【验证】**


### 步骤 4.2　写 `src/features/selector.py`

**【目标】** 三道筛子依次过滤特征。

**【文件】** `src/features/selector.py`（新建）

**【完整代码】**

```python
"""
特征筛选器
==========
方差 → 相关性 → 模型重要性，三道筛子依次过滤。
"""
from __future__ import annotations

from typing import Dict, List, Optional

import numpy as np
import pandas as pd
from sklearn.feature_selection import VarianceThreshold

from src.utils.logger import get_logger

logger = get_logger("features.selector")


class FeatureSelector:
    """特征筛选器。同样遵循 fit / transform。"""

    def __init__(self, config):
        # config 传的是 configs.get("feature")
        self.config = config
        self.selection_cfg = config.feature_selection
        self._selected_features: Optional[List[str]] = None
        self._dropped_features: List[str] = []

    def fit_transform(self, X: pd.DataFrame, y: pd.Series) -> pd.DataFrame:
        return self.fit(X, y).transform(X)

    def fit(self, X: pd.DataFrame, y: pd.Series) -> "FeatureSelector":
        if not self.selection_cfg.enabled:
            self._selected_features = X.columns.tolist()
            return self

        current_cols = X.columns.tolist()
        logger.info(f"开始特征筛选 - 输入特征数: {len(current_cols)}")

        for method_cfg in self.selection_cfg.methods:
            method_name = method_cfg["name"]

            if method_name == "variance":
                current_cols = self._filter_by_variance(X[current_cols], method_cfg)
            elif method_name == "correlation":
                current_cols = self._filter_by_correlation(X[current_cols], method_cfg)
            elif method_name == "model_based":
                current_cols = self._filter_by_model(X[current_cols], y, method_cfg)
            else:
                logger.warning(f"未知的筛选方法: {method_name}")

            logger.info(f"  应用 [{method_name}] 后 - 剩余特征数: {len(current_cols)}")

        self._selected_features = current_cols
        self._dropped_features = [c for c in X.columns if c not in current_cols]
        return self

    def transform(self, X: pd.DataFrame) -> pd.DataFrame:
        if self._selected_features is None:
            return X
        cols = [c for c in self._selected_features if c in X.columns]
        return X[cols]

    # ---------------- 三种筛选 ----------------

    def _filter_by_variance(self, X: pd.DataFrame, cfg: Dict) -> List[str]:
        threshold = cfg.get("threshold", 0.01)
        selector = VarianceThreshold(threshold=threshold)
        selector.fit(X.fillna(0))
        return X.columns[selector.get_support()].tolist()

    def _filter_by_correlation(self, X: pd.DataFrame, cfg: Dict) -> List[str]:
        threshold = cfg.get("threshold", 0.95)
        corr = X.corr().abs()
        upper = corr.where(np.triu(np.ones(corr.shape), k=1).astype(bool))
        to_drop = [col for col in upper.columns if any(upper[col] > threshold)]
        return [c for c in X.columns if c not in to_drop]

    def _filter_by_model(
        self,
        X: pd.DataFrame,
        y: pd.Series,
        cfg: Dict,
    ) -> List[str]:
        model_name = cfg.get("model", "xgboost")
        top_k = cfg.get("top_k", 50)

        if model_name != "xgboost":
            raise ValueError(f"不支持的筛选模型: {model_name}")

        from xgboost import XGBClassifier

        model = XGBClassifier(
            n_estimators=100,
            max_depth=4,
            random_state=42,
            eval_metric="logloss",
            verbosity=0,
        )
        model.fit(X.fillna(0), y)

        importance = pd.Series(model.feature_importances_, index=X.columns)
        return importance.nlargest(top_k).index.tolist()

    @property
    def selected_features(self) -> List[str]:
        return self._selected_features or []

    @property
    def dropped_features(self) -> List[str]:
        return self._dropped_features
```

**【逐块讲解】**

| 代码段 | 做什么 | 小白要点 |
|---|---|---|
| `for method_cfg in ...methods` | 按配置顺序过筛 | 顺序有讲究：先粗筛再细筛 |
| `VarianceThreshold(0.01)` | 方差低于 0.01 的丢掉 | 标准化后方差为 1，0.01 意味着"几乎不变" |
| `np.triu(..., k=1)` | 取相关系数矩阵上三角 | 避免重复计算（A-B 和 B-A 是一回事） |
| `any(upper[col] > 0.95)` | 该列与任何一列高相关就丢 | 注意可能过度删除，见 W-02 |
| `feature_importances_` | 树模型自带的重要性 | 取值是"该特征被用来分裂的总收益"，不是因果 |
| `nlargest(top_k)` | 取重要性最大的 K 个 | 不足 K 个就全给 |

**【验证】**

## 6. 本章错误对照

### 错误 E-07　公式里的裸列名没有注入命名空间

**出现在**：原文档 `_safe_eval`

**❌ 原文写法**

```python
safe_globals = {
    "df": df,
    "pd": pd,
    "np": np,
    "__builtins__": {},
}
return eval(formula, safe_globals)
```

而 YAML 里的公式是：

```yaml
formula: "annualIncome / 12"
```

**✅ 修正写法**

```python
namespace = {c: df[c] for c in df.columns if isinstance(c, str) and c.isidentifier()}
namespace.update({"df": df, "pd": pd, "np": np, "__builtins__": {}})
return eval(formula, namespace)
```

**💥 不修的后果**　5 条规则**全部失败**，但不会中断（因为在 try 里），只在日志里留 5 条警告：

```
WARNING | 创建特征 monthly_income 失败: name 'annualIncome' is not defined
```

最终结果：一个衍生特征都没造出来，模型少了一批最有信息量的列，AUC 明显偏低。**而且程序"正常跑完"，你很难发现。**

**🧠 为什么**　`eval(expr, globals)` 里的表达式只能访问 `globals` 字典里的名字。原代码只放了 `df`、`pd`、`np`，没有 `annualIncome` 这个名字，所以报 `NameError`。注释里写了"自动将裸列名转为 df['col'] 形式"，但这部分逻辑**根本没实现**。

**✅ 自查**　跑完 `build()` 后看日志里"成功创建 N 个衍生特征"，N 应该等于 YAML 里的规则条数。

### 错误 W-02　相关性筛选可能删过头

**出现在**：`_filter_by_correlation`

**❌ 原文逻辑**

```python
to_drop = [col for col in upper.columns if any(upper[col] > threshold)]
```

**问题**　如果 A 与 B 高相关、B 与 C 高相关，但 A 与 C 不相关，这段逻辑会把 B 和 C 都删掉（因为 B 列有 A 的相关性、C 列有 B 的相关性），只留 A。三列里丢两列，可能损失信息。

**✅ 更稳的做法**（可选，不强制）

```python
to_drop = set()
cols = list(upper.columns)
for i, c in enumerate(cols):
    if c in to_drop:
        continue
    for j in range(i + 1, len(cols)):
        other = cols[j]
        if other not in to_drop and upper.iloc[i, j] > threshold:
            to_drop.add(other)      # 每对只丢一个
return [c for c in X.columns if c not in to_drop]
```

**💥 不修的后果**　特征数偏少，模型可能欠拟合。但不会报错，属于"效果损失"而非"程序错误"，所以列为 W 级。

**🧠 为什么**　原逻辑是"列级"判断（这列跟任何列高相关就删），正确思路是"对级"判断（每一对只删一个）。

**✅ 自查**　对比筛完后剩余特征数，如果从 55 掉到 20 以下，就是删过头了。

## 8. 本章自测

**1. 为什么衍生特征要做成"比值"而不是"差值"？**

<details><summary>点开看答案</summary>

比值跨人群可比。收入 5 万月还 1 万，和收入 50 万月还 10 万，差值都是 9 万但压力完全不同；比值都是 20%，含义一致。

</details>

**2. 三道筛子为什么不能只留最后一道模型筛？**

<details><summary>点开看答案</summary>

前面有大量常数列和重复列时，模型筛那次训练又慢又不准（重要性被冗余列稀释）。先降噪再按重要性筛，结果才可靠。

</details>

**3. `__builtins__: {}` 是为了防什么？**

<details><summary>点开看答案</summary>

防配置里的公式执行危险操作。置空后 `open()`、`__import__()`、`eval()` 这些内置函数都不可用，即使 YAML 被恶意改写也执行不了。

</details>

**4. 特征重要性高，能说明这个特征"导致"了违约吗？**

<details><summary>点开看答案</summary>

不能。重要性只说明"模型用它分裂的收益大"，是相关性不是因果。要讲因果得做实验或因果推断。答辩时被问到要注意区分。

</details>
