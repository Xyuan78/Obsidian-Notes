## 4. 本章知识点

| 编号 | 概念 | 一句话解释 | 为什么这里需要它 | 本项目用在哪 | 要求 |
|---|---|---|---|---|---|
| KP-ML-01 | 训练/验证/测试集 | 学知识的 / 调参数的 / 只考一次试的 | 用测试集调参等于泄题，指标不可信 | `DataSplitter` | 必懂 |
| KP-ML-02 | **数据泄漏** | 测试集的信息提前进了训练过程 | 指标虚高、上线暴跌，是本项目最大的方法论坑 | 切分顺序、fit 范围 | 必懂 |
| KP-ML-03 | fit / transform 分离 | 训练集学参数，其他集只套用参数 | 保证线上线下处理一致，杜绝泄漏 | `Preprocessor` | 必懂 |
| KP-ML-04 | 缺失值填充 | 用中位数/众数把空补上 | 模型不接受 NaN | `_fit_imputers` | 必懂 |
| KP-ML-05 | 类别编码 | 把 A/B/C 变成 1/2/3 | 模型只认数字 | `_fit_encoders` | 必懂 |
| KP-ML-06 | 标准化 | 减均值除标准差，让量纲一致 | 神经网络对量纲极敏感 | `_apply_scaler` | 必懂 |
| KP-ML-07 | 异常值截断 | 把极端值压回分位数边界 | 防止个别离群点主导训练 | `_fit_outlier_clips` | 知道即可 |
| KP-BIZ-04 | 违约率 | 样本中违约客户的比例，本数据集约 20% | 决定是否需要处理类别不平衡 | `get_data_summary` | 必懂 |
| KP-PY-06 | 状态持久化 | 把 fit 学到的参数存下来 | 线上预测要复用训练时的参数 | `preprocessor.pkl` | 知道即可 |

### 展开讲 1：三份数据各干什么

| 数据集 | 用途 | 能不能用来调参 | 用几次 |
|---|---|---|---|
| **训练集**（70%） | 模型从它身上学规律 | — | 无数次 |
| **验证集**（10%） | 调超参、早停、选阈值 | 可以 | 很多次 |
| **测试集**（20%） | 最后报告成绩 | **绝对不行** | 只在最终评估用一次 |

为什么必须有验证集：如果你直接用测试集调参，你会不自觉地调到"在这份测试集上最好"，那这个成绩就是假的。留一份从没看过的测试集，才能反映真实水平。

### 展开讲 2：数据泄漏——本项目最容易犯的错

假设你要预测房价，特征里有"是否成交"这一列。模型准确率 99%。为什么？因为成交的房子才挂牌，这一列几乎等价于答案。这就是泄漏。

在信贷场景里，泄漏有两种常见形态：

**形态一：把未来的信息当特征。** 比如用"最终还款状态"预测"是否违约"。
**形态二：在全量数据上 fit 预处理器。** 这是本项目原文档的问题。

```python
# ❌ 错误顺序（原文档的写法）
df = preprocessor.fit_transform(df)      # 在全量数据上学均值/中位数/编码表
df = selector.fit_transform(df, y)       # 在全量数据上学特征重要性
X_train, X_test = split(df)              # 然后才切分

# ✅ 正确顺序（本手册的写法）
X_train, X_val, X_test, y_train, y_val, y_test = split(df)
X_train = preprocessor.fit_transform(X_train)   # 只在训练集上 fit
X_val   = preprocessor.transform(X_val)         # 只 transform
X_test  = preprocessor.transform(X_test)        # 只 transform
```

差别在哪：错误写法里，标准化用的是**全量数据的均值**，这个均值里包含了测试集的信息。测试集的分布"泄漏"进了训练。指标会虚高 1~3 个百分点，上线后掉下来，而且你很难查出原因。

**记住一句话**：`fit` 只配出现在训练集上，`transform` 出现在所有集上。看到 `fit_transform` 作用在 `df`（全量）上，就是错。

### 步骤 3.1　写 `src/data/loader.py`

**【目标】** 两个类：`DataLoader` 读 CSV，`DataSplitter` 切三份。

**【文件】** `src/data/loader.py`（新建）

**【完整代码】**

```python
"""
数据加载与切分
==============
"""
from __future__ import annotations

from pathlib import Path
from typing import Tuple

import pandas as pd
from sklearn.model_selection import train_test_split

from src.utils.logger import get_logger

logger = get_logger("data.loader")


class DataLoader:
    """按配置加载 CSV。"""

    def __init__(self, config):
        # config 传的是 configs.get("data")
        self.config = config
        self.paths = config.paths

    def load_train(self, use_sample: bool = False) -> pd.DataFrame:
        """use_sample=True 读合成数据，False 读真实数据。"""
        if use_sample:
            file_path = Path(self.paths.sample_dir) / self.paths.sample_file
        else:
            file_path = Path(self.paths.raw_dir) / self.paths.train_file
        return self._load_csv(file_path)

    def load_test(self) -> pd.DataFrame:
        file_path = Path(self.paths.raw_dir) / self.paths.test_file
        return self._load_csv(file_path)

    def _load_csv(self, file_path: Path) -> pd.DataFrame:
        if not file_path.exists():
            raise FileNotFoundError(
                f"数据文件不存在: {file_path}\n"
                f"请先运行 `python scripts/generate_sample_data.py` 生成示例数据，"
                f"或把天池真实数据放到 data/raw/ 下"
            )

        loading_cfg = self.config.loading
        file_size_mb = file_path.stat().st_size / (1024 ** 2)
        logger.info(f"加载数据: {file_path} (大小: {file_size_mb:.2f} MB)")

        if file_size_mb > 500:
            logger.info(f"文件较大，启用分块读取（chunk_size={loading_cfg.chunk_size}）")
            chunks = []
            for chunk in pd.read_csv(
                file_path,
                chunksize=loading_cfg.chunk_size,
                encoding=loading_cfg.encoding,
                low_memory=loading_cfg.low_memory,
            ):
                chunks.append(chunk)
            df = pd.concat(chunks, ignore_index=True)
        else:
            df = pd.read_csv(
                file_path,
                encoding=loading_cfg.encoding,
                low_memory=loading_cfg.low_memory,
            )

        logger.info(f"数据加载完成 - shape: {df.shape}")
        return df

    def get_data_summary(self, df: pd.DataFrame) -> dict:
        """数据概览，Web 数据探索页会用。"""
        target_col = self.config.target_column
        summary = {
            "n_samples": len(df),
            "n_features": df.shape[1],
            "memory_mb": float(df.memory_usage(deep=True).sum() / (1024 ** 2)),
            "missing_total": int(df.isnull().sum().sum()),
            "missing_ratio": float(df.isnull().sum().sum() / df.size),
        }
        if target_col in df.columns:
            dist = df[target_col].value_counts(normalize=True).to_dict()
            summary["default_rate"] = float(dist.get(1, 0))
            summary["target_distribution"] = dist
        return summary


class DataSplitter:
    """分层切分：训练 / 验证 / 测试。"""

    def __init__(self, config):
        self.config = config
        self.split_cfg = config.split
        self.target = config.target_column
        self.id_col = config.id_column

    def split(self, df: pd.DataFrame, with_validation: bool = True) -> Tuple:
        drop_cols = [self.target]
        if self.id_col in df.columns:
            drop_cols.append(self.id_col)

        X = df.drop(columns=drop_cols, errors="ignore")
        y = df[self.target]
        stratify = y if self.split_cfg.stratify else None

        # 第一刀：train+val vs test
        X_trainval, X_test, y_trainval, y_test = train_test_split(
            X, y,
            test_size=self.split_cfg.test_size,
            random_state=self.split_cfg.random_state,
            stratify=stratify,
        )

        if not with_validation:
            logger.info(f"切分完成 - 训练: {X_trainval.shape[0]}, 测试: {X_test.shape[0]}")
            return X_trainval, X_test, y_trainval, y_test

        # 第二刀：train vs val
        # validation_size 是相对原始数据的比例，这里要换算
        val_ratio = self.split_cfg.validation_size / (1 - self.split_cfg.test_size)
        stratify2 = y_trainval if self.split_cfg.stratify else None

        X_train, X_val, y_train, y_val = train_test_split(
            X_trainval, y_trainval,
            test_size=val_ratio,
            random_state=self.split_cfg.random_state,
            stratify=stratify2,
        )

        logger.info(
            f"切分完成 - 训练: {X_train.shape[0]}, 验证: {X_val.shape[0]}, 测试: {X_test.shape[0]}"
        )
        return X_train, X_val, X_test, y_train, y_val, y_test
```

**【逐块讲解】**

| 代码段 | 做什么 | 小白要点 |
|---|---|---|
| `Path(...) / filename` | 拼路径 | 比字符串拼接安全，会自动处理斜杠 |
| `file_size_mb > 500` | 大文件走分块 | 80 万行约 150MB，其实一次能读；这个分支是给更大数据准备的 |
| `drop([target, id])` | 特征里去掉标签和 ID | **如果漏了 target，就是最严重的泄漏**：模型直接看到答案 |
| 第一刀 `test_size=0.2` | 切出 20% 测试集 | 分层保证测试集违约率≈20% |
| `val_ratio = 0.1 / (1-0.2) = 0.125` | 换算比例 | 第二刀是在剩下 80% 上切的，要占原始 10% 就得切 12.5% |
| `random_state=42` | 固定随机 | 每次切出来的完全一样，方便复现 |

### 步骤 3.2　写 `src/data/preprocessor.py`

**【目标】** 一个类，`fit` 学参数、`transform` 套参数。

**【文件】** `src/data/preprocessor.py`（新建）

**【完整代码】**

```python
"""
数据预处理器
============
缺失值填充、类别编码、异常值截断、时间列拆解、数值标准化。

核心设计：fit / transform 分离。
    fit        -> 从训练集学参数（中位数、编码表、截断边界、均值方差）
    transform  -> 用学到的参数处理任意数据
训练集用 fit_transform，验证/测试/线上只能用 transform。
"""
from __future__ import annotations

from typing import Dict, List, Optional

import numpy as np
import pandas as pd
from sklearn.preprocessing import LabelEncoder, MinMaxScaler, RobustScaler, StandardScaler

from src.utils.logger import get_logger

logger = get_logger("data.preprocessor")


class Preprocessor:
    """数据预处理器。注意构造要传两个配置。"""

    def __init__(self, data_config, feature_config):
        self.data_cfg = data_config
        self.feature_cfg = feature_config

        # ---- fit 阶段学到的状态 ----
        self._numerical_imputers: Dict[str, float] = {}
        self._categorical_imputers: Dict[str, str] = {}
        self._label_encoders: Dict[str, LabelEncoder] = {}
        self._scaler = None
        self._scaler_cols: List[str] = []     # 记住训练时缩放了哪些列
        self._dropped_cols: List[str] = []
        self._outlier_clips: Dict[str, tuple] = {}

        self._is_fitted = False

    # ================= 对外接口 =================

    def fit_transform(self, df: pd.DataFrame) -> pd.DataFrame:
        return self.fit(df).transform(df)

    def fit(self, df: pd.DataFrame) -> "Preprocessor":
        logger.info(f"开始拟合预处理器 - 输入 shape: {df.shape}")
        df = df.copy()

        self._fit_drop_high_missing(df)
        df = df.drop(columns=self._dropped_cols, errors="ignore")

        self._fit_imputers(df)
        self._fit_encoders(df)
        self._fit_outlier_clips(df)

        self._is_fitted = True
        logger.info(f"预处理器拟合完成 - 移除 {len(self._dropped_cols)} 列")
        return self

    def transform(self, df: pd.DataFrame) -> pd.DataFrame:
        if not self._is_fitted:
            raise RuntimeError("预处理器未拟合，请先调用 fit() 或 fit_transform()")

        df = df.copy()
        df = df.drop(columns=self._dropped_cols, errors="ignore")
        df = self._apply_imputers(df)
        df = self._apply_outlier_clips(df)
        df = self._apply_encoders(df)
        df = self._handle_datetime(df)
        df = self._apply_scaler(df)

        logger.info(f"transform 完成 - 输出 shape: {df.shape}")
        return df

    # ================= fit 阶段 =================

    def _fit_drop_high_missing(self, df: pd.DataFrame) -> None:
        threshold = self.feature_cfg.missing_value.drop_threshold
        missing_ratio = df.isnull().mean()
        self._dropped_cols = missing_ratio[missing_ratio > threshold].index.tolist()
        if self._dropped_cols:
            logger.info(f"高缺失率列将被移除: {self._dropped_cols}")

    def _fit_imputers(self, df: pd.DataFrame) -> None:
        num_strategy = self.feature_cfg.missing_value.numerical_strategy
        cat_strategy = self.feature_cfg.missing_value.categorical_strategy

        num_cols = [c for c in self.data_cfg.columns.numerical if c in df.columns]
        num_cols += [c for c in self.data_cfg.columns.anonymous if c in df.columns]
        for col in num_cols:
            if num_strategy == "mean":
                self._numerical_imputers[col] = df[col].mean()
            elif num_strategy == "median":
                self._numerical_imputers[col] = df[col].median()
            elif num_strategy == "zero":
                self._numerical_imputers[col] = 0
            else:
                self._numerical_imputers[col] = df[col].median()

        cat_cols = [c for c in self.data_cfg.columns.categorical if c in df.columns]
        for col in cat_cols:
            if cat_strategy == "mode":
                mode = df[col].mode()
                self._categorical_imputers[col] = mode.iloc[0] if len(mode) > 0 else "unknown"
            else:
                self._categorical_imputers[col] = "unknown"

    def _fit_encoders(self, df: pd.DataFrame) -> None:
        cat_cols = [c for c in self.data_cfg.columns.categorical if c in df.columns]
        custom = self.feature_cfg.encoding.get("custom", {})

        for col in cat_cols:
            if col in custom:      # 配置了映射的，不需要 fit
                continue
            le = LabelEncoder()
            le.fit(df[col].fillna("unknown").astype(str))
            self._label_encoders[col] = le

    def _fit_outlier_clips(self, df: pd.DataFrame) -> None:
        cfg = self.feature_cfg.outlier
        if cfg.method != "clip":
            return
        for col in cfg.apply_to:
            if col in df.columns:
                lower = df[col].quantile(cfg.lower_quantile)
                upper = df[col].quantile(cfg.upper_quantile)
                self._outlier_clips[col] = (lower, upper)

    # ================= transform 阶段 =================

    def _apply_imputers(self, df: pd.DataFrame) -> pd.DataFrame:
        for col, fill_value in self._numerical_imputers.items():
            if col in df.columns:
                df[col] = df[col].fillna(fill_value)
        for col, fill_value in self._categorical_imputers.items():
            if col in df.columns:
                df[col] = df[col].fillna(fill_value).astype(str)
        return df

    def _apply_outlier_clips(self, df: pd.DataFrame) -> pd.DataFrame:
        for col, (lower, upper) in self._outlier_clips.items():
            if col in df.columns:
                df[col] = df[col].clip(lower=lower, upper=upper)
        return df

    def _apply_encoders(self, df: pd.DataFrame) -> pd.DataFrame:
        custom = self.feature_cfg.encoding.get("custom", {})

        # 1) 自定义映射（如 grade A->1）
        for col, cfg in custom.items():
            if col in df.columns and "mapping" in cfg:
                df[col] = df[col].astype(str).map(cfg["mapping"]).fillna(-1).astype(int)

        # 2) LabelEncoder（未见过的类别映射到第一个已知类别，不崩）
        for col, le in self._label_encoders.items():
            if col in df.columns:
                values = df[col].fillna("unknown").astype(str)
                known = set(le.classes_)
                fallback = le.classes_[0]
                values = values.map(lambda x: x if x in known else fallback)
                df[col] = le.transform(values)

        return df

    def _handle_datetime(self, df: pd.DataFrame) -> pd.DataFrame:
        for col in self.data_cfg.columns.datetime:
            if col not in df.columns:
                continue
            try:
                dt = pd.to_datetime(df[col], errors="coerce")
                df[f"{col}_year"] = dt.dt.year.fillna(0).astype(int)
                df[f"{col}_month"] = dt.dt.month.fillna(0).astype(int)
            except Exception as e:
                logger.warning(f"时间列 {col} 处理失败: {e}")
            df = df.drop(columns=[col], errors="ignore")
        return df

    def _apply_scaler(self, df: pd.DataFrame) -> pd.DataFrame:
        method = self.feature_cfg.scaling.method
        if method == "none":
            return df

        numeric_cols = df.select_dtypes(include=[np.number]).columns.tolist()
        if not numeric_cols:
            return df

        if self._scaler is None:
            # 第一次：在当前（训练）数据上 fit，并记住列名
            if method == "standard":
                self._scaler = StandardScaler()
            elif method == "minmax":
                self._scaler = MinMaxScaler()
            elif method == "robust":
                self._scaler = RobustScaler()
            else:
                return df

            self._scaler_cols = numeric_cols
            df[numeric_cols] = self._scaler.fit_transform(df[numeric_cols])
        else:
            # 后续：只用训练时那批列 transform
            cols = [c for c in self._scaler_cols if c in df.columns]
            if cols:
                df[cols] = self._scaler.transform(df[cols])

        return df
```

**【逐块讲解】**

| 代码段 | 做什么 | 小白要点 |
|---|---|---|
| `__init__(data_config, feature_config)` | 接收**两个**配置 | 少传一个会 `TypeError`，这是原文档常错的地方 |
| `self._numerical_imputers` 等 | 存 fit 的结果 | 这些就是"训练时学到的东西"，将来要存盘 |
| `_is_fitted` | 标记是否学过 | 没 fit 就 transform 会直接报错，避免静默出错 |
| `_fit_drop_high_missing` | 缺失率 >95% 的列丢掉 | 这种列几乎没有信息 |
| `_apply_encoders` 的 `fallback` | 新类别映射到已知值 | 线上来了训练时没见过的类别，不崩 |
| `_handle_datetime` | 日期拆成 _year/_month | 模型不能吃 `2026-05-01` 这种字符串 |
| `self._scaler_cols` | **记住缩放过的列名** | 见下面的 W-01 修正说明 |

## 6. 本章错误对照

### 错误 W-01　`transform` 时标准化没生效（原文档的隐蔽 bug）

**出现在**：原文档 `_apply_scaler` 的 else 分支

**❌ 原文写法**

```python
else:
    # 对齐列
    scaler_cols = [c for c in numeric_cols if hasattr(self._scaler, "mean_")]
    if scaler_cols:
        df[scaler_cols] = self._scaler.transform(df[scaler_cols])
```

**✅ 修正写法**

```python
else:
    cols = [c for c in self._scaler_cols if c in df.columns]
    if cols:
        df[cols] = self._scaler.transform(df[cols])
```

**💥 不修的后果**　不报错，但**验证集/测试集根本没被标准化**。

- 用 `StandardScaler` 时：`mean_` 属性恰好存在，条件为真，**碰巧能用**
- 用 `MinMaxScaler` / `RobustScaler` 时：没有 `mean_` 属性，`scaler_cols` 是空列表，**跳过缩放**

结果：训练集被标准化了、测试集没有。模型在测试集上看到的分布完全变了，AUC 可能掉 5~10 个点。而且**不报任何错**，你会以为是模型不行。

**🧠 为什么**　原代码用"有没有 `mean_` 属性"来判断"这台 scaler 是不是 fit 过"，这个判断依据是错的。正确做法是**自己记住训练时用的是哪些列**（`self._scaler_cols`），transform 时按这份名单来。

**✅ 自查**　训练一段后，打印 `X_train.mean()` 和 `X_test.mean()`，两者都应该接近 0（标准化后）。如果测试集的均值还是原始量级，就中招了。

**❌ 原文写法**

preprocessor = Preprocessor(configs.get("data"))

**✅ 修正写法**

## 7. 常见坑

| 现象 | 原因 | 解决 |
|---|---|---|
| 测试集 AUC 比验证集高很多 | 可能泄漏，或测试集太小 | 先查 fit 是否只用训练集 |
| `SettingWithCopyWarning` | 对切片赋值 | 代码里已用 `df = df.copy()`，若仍报警检查是否有额外切片 |
| 编码后出现 `-1` | 自定义映射表里没有这个类别 | 正常兜底行为，或补全 mapping |
| 日期列拆完后原列还在 | `drop` 失败（列名不匹配） | 看 `f"{col}_year"` 是否生成成功 |
| 内存爆了 | `chunk_size` 太大或没分块 | 调小 `chunk_size` |

## 8. 本章自测

**1. 为什么 `val_ratio = validation_size / (1 - test_size)` 要这么算？**

<details><summary>点开看答案</summary>

第二刀是在"去掉测试集后剩下的 80%"上切的。要让它占**原始数据**的 10%，就得切 `0.1/0.8 = 0.125`。直接传 0.1 会让验证集只占原始的 8%。

</details>

**2. `fit_transform` 和 `transform` 分别该用在哪些数据上？**

<details><summary>点开看答案</summary>

`fit_transform` **只能**用在训练集；`transform` 用在验证集、测试集、线上新数据。用错就是数据泄漏。

</details>

**3. 如果测试集里出现一个训练集没见过的类别（比如新的 `grade` 值），会怎样？**

<details><summary>点开看答案</summary>

`LabelEncoder` 直接 transform 会抛 `ValueError: y contains previously unseen labels`。所以代码里先把未知值映射到 `le.classes_[0]`，保证不崩。

</details>

**4. 本章哪个设计让"线上预测"和"训练时"的处理完全一致？**

<details><summary>点开看答案</summary>

fit/transform 分离 + 状态持久化。`fit` 学到的中位数、编码表、缩放参数都存在对象里，存成 `preprocessor.pkl`，线上加载回来直接 `transform`，保证一致。

</details>
