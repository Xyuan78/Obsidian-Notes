```bash
用 conda（推荐）
conda create -n credit_risk python=3.11
```

# 3. 创建.env.example和 .env

```bash
cd /d E:\PythonCode\project1\credit_risk_system
```

**【操作】** 在项目根目录建两个文件。

先建 `.env.example`（这是模板，可以给别人看）：

```bash
# ===== DeepSeek API 配置 =====
DEEPSEEK_API_KEY=sk-your-api-key-here
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat

# ===== 应用配置 =====
APP_ENV=development
LOG_LEVEL=INFO
DATA_DIR=./data
MODEL_DIR=./data/models

# ===== Streamlit 配置 =====
STREAMLIT_SERVER_PORT=8501
STREAMLIT_SERVER_ADDRESS=0.0.0.0
```

再复制一份改名为 `.env`（这是真身，填真 Key）：

```bat
copy .env.example .env
```

然后用编辑器打开 `.env`，把 `sk-your-api-key-here` 换成你在 https://platform.deepseek.com 申请的真 Key。

**【目标】** 让 `src`、`src.data`、`src.models` 这些目录能被 Python 当成包来 import。

**【操作】** 在项目根目录执行下面这段，一次性建好：

```bat
type nul > src\__init__.py
type nul > src\utils\__init__.py
type nul > src\data\__init__.py
type nul > src\features\__init__.py
type nul > src\models\__init__.py
type nul > src\tuning\__init__.py
type nul > src\explain\__init__.py
type nul > src\llm\__init__.py
type nul > src\llm\agents\__init__.py
type nul > src\pipeline\__init__.py
type nul > app\__init__.py
type nul > app\components\__init__.py
type nul > tests\__init__.py
```

> `type nul >` 是 Windows 下"创建一个空文件"的写法。在 Git Bash 里等价于 `touch 文件名`。

现在把 `src/__init__.py` 打开，写两行（这个可以现在填，因为它不 import 任何东西）：

```python
"""智能信贷风控分析系统 - 源码包"""

__version__ = "1.0.0"
```

其余的 12 个**保持为空**。
