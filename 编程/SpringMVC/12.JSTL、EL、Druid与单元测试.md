# JSTL、EL、Druid 与单元测试

> [!info] 讲义补充
> 本节依据讲义第 6409–7058 行整理。录播未讲到 JSP 标签、Druid 监控与 SSM 测试，属于项目完善部分。

## JSTL 与 EL

JSP 中常用 Expression Language 读取作用域数据：

```jsp
<p>${loginUser.userName}</p>
<p>${pageInfo.total}</p>
```

JSTL 需要在 JSP 顶部导入：

```jsp
<%@ taglib prefix="c" uri="http://java.sun.com/jsp/jstl/core" %>
<%@ taglib prefix="fmt" uri="http://java.sun.com/jsp/jstl/fmt" %>
<%@ taglib prefix="fn" uri="http://java.sun.com/jsp/jstl/functions" %>
```

依赖：

```xml
<dependency>
    <groupId>javax.servlet</groupId>
    <artifactId>jstl</artifactId>
    <version>1.2</version>
</dependency>
```

## 核心标签

### c:if

```jsp
<c:if test="${not empty loginUser}">
    <span>欢迎，${loginUser.userName}</span>
</c:if>
```

### c:choose

```jsp
<c:choose>
    <c:when test="${user.state == 0}">正常</c:when>
    <c:when test="${user.state == 1}">禁用</c:when>
    <c:otherwise>未知状态</c:otherwise>
</c:choose>
```

### c:forEach

```jsp
<c:forEach items="${users}" var="user" varStatus="status">
    <tr>
        <td>${status.count}</td>
        <td>${user.userName}</td>
        <td><fmt:formatDate value="${user.createTime}" pattern="yyyy-MM-dd HH:mm:ss"/></td>
    </tr>
</c:forEach>
```

### c:forTokens

```jsp
<c:forTokens items="1,2,3,4,5" delims="," var="page">
    <a href="/api/user/list.do?pageNum=${page}">${page}</a>
</c:forTokens>
```

## 函数标签 fn

隐藏手机号：

```jsp
${fn:substring(phone, 0, 3)}****${fn:substring(phone, 7, 11)}
```

常用函数：

| 函数 | 作用 |
|---|---|
| `fn:length` | 字符串或集合长度 |
| `fn:substring` | 截取子串 |
| `fn:contains` | 是否包含 |
| `fn:startsWith` | 是否以某串开头 |
| `fn:escapeXml` | 输出转义 |
| `fn:join` / `fn:split` | 拼接/拆分 |

> [!warning] 转义
> 把用户输入直接输出到 HTML 可能产生 XSS。需要时用 `<c:out>` 或 `fn:escapeXml`；不要把所有内容都直接放进 `${...}`。

## 格式化标签

### 数字

```jsp
<fmt:formatNumber value="${amount}" type="currency"/>
<fmt:formatNumber value="${rate}" type="percent" maxFractionDigits="2"/>
<fmt:formatNumber value="${amount}" pattern="#,##0.00"/>
```

### 日期

```jsp
<fmt:formatDate value="${createTime}" type="both"/>
<fmt:formatDate value="${createTime}" pattern="yyyy-MM-dd HH:mm:ss"/>
```

日期格式依赖 JSP locale 与时区。若后端已是 UTC，需要在前端/视图层明确目标时区。

## JSTL 分页

```jsp
<c:forEach begin="1" end="${pageInfo.pages}" var="i">
    <c:choose>
        <c:when test="${i == pageInfo.pageNum}">
            <span class="active">${i}</span>
        </c:when>
        <c:otherwise>
            <a href="/api/user/list.do?pageNum=${i}&pageSize=${pageInfo.pageSize}">${i}</a>
        </c:otherwise>
    </c:choose>
</c:forEach>
```

课堂长示例在此基础上加入了首页、末页、省略号和多个分支，核心仍是使用 `PageInfo` 的页数、当前页和前后页判断。

## 在 JavaScript 中使用 EL

```javascript
const username = "${fn:escapeXml(loginUser.userName)}";
```

> [!danger] 不要直接拼接不受信任的数据
> JSP 字符串进入 JavaScript 时，HTML 转义不等于 JavaScript 转义。包含引号、反斜杠、`</script>` 时可能破坏脚本甚至造成 XSS。更稳妥的方式是把数据写入 `data-*` 属性，或由 API 返回 JSON。

## 接入 Druid 数据源

课堂原先使用 C3P0，后续替换为阿里巴巴 Druid：

```xml
<bean id="dataSource"
      class="com.alibaba.druid.pool.DruidDataSource"
      destroy-method="close">
    <property name="url" value="${mysql.url}"/>
    <property name="username" value="${mysql.username}"/>
    <property name="password" value="${mysql.password}"/>
    <property name="driverClassName" value="${mysql.driver}"/>
    <property name="initialSize" value="5"/>
    <property name="minIdle" value="5"/>
    <property name="maxActive" value="20"/>
    <property name="validationQuery" value="SELECT 1"/>
</bean>
```

参数要结合数据库和并发量调整，不能只复制固定值。

## Druid 监控页

```xml
<servlet>
    <servlet-name>DruidStatView</servlet-name>
    <servlet-class>
        com.alibaba.druid.support.http.StatViewServlet
    </servlet-class>
    <init-param>
        <param-name>allow</param-name>
        <param-value>127.0.0.1</param-value>
    </init-param>
    <init-param>
        <param-name>loginUsername</param-name>
        <param-value>admin</param-value>
    </init-param>
    <init-param>
        <param-name>loginPassword</param-name>
        <param-value>change-me</param-value>
    </init-param>
</servlet>

<servlet-mapping>
    <servlet-name>DruidStatView</servlet-name>
    <url-pattern>/druid/*</url-pattern>
</servlet-mapping>
```

> [!danger] 监控页安全
> 不要把真实账号密码写进仓库；生产环境应限制内网访问、使用强密码并接入统一认证。监控页会暴露 SQL、连接池和运行状态等敏感信息。

## 单元测试分层

### 测试 Mapper

```java
@RunWith(SpringJUnit4ClassRunner.class)
@ContextConfiguration(locations = "classpath:applicationContext.xml")
@Transactional
public class AdminMapperTest {
    @Autowired
    private AdminMapper adminMapper;

    @Test
    public void selectAll() {
        assertNotNull(adminMapper.selectAllAdmin());
    }
}
```

验证：

- XML namespace/id 是否正确。
- SQL 能否执行。
- 结果映射是否正确。
- 参数绑定是否符合预期。

### 测试 Service

```java
@RunWith(SpringJUnit4ClassRunner.class)
@ContextConfiguration(locations = "classpath:applicationContext.xml")
@Transactional
public class AdminServiceTest {
    @Autowired
    private AdminService adminService;

    @Test
    public void getList() {
        MyMessage<List<Admin>> result = adminService.getListAdv();
        assertTrue(result.getSuccess());
        assertNotNull(result.getTag());
    }
}
```

`@Transactional` 测试默认结束后回滚，避免污染数据库；但如果业务代码内部捕获异常，测试仍需验证数据库状态。

### 测试 Controller

```java
@RunWith(SpringJUnit4ClassRunner.class)
@ContextConfiguration(locations = "classpath:applicationContext.xml")
@WebAppConfiguration
public class AdminControllerTest {
    @Autowired
    private WebApplicationContext wac;

    private MockMvc mockMvc;

    @Before
    public void setup() {
        mockMvc = MockMvcBuilders.webAppContextSetup(wac).build();
    }

    @Test
    public void list() throws Exception {
        mockMvc.perform(get("/admin/list.do"))
                .andExpect(status().isOk())
                .andExpect(jsonPath("$.success").value(true));
    }
}
```

MockMvc 验证：

- URL 和请求方法。
- 参数绑定。
- 状态码。
- JSON 字段。
- 视图名。

## 测试中常见问题

- 测试配置加载了错误的环境，误连生产库。
- `@Transactional` 测试看似回滚，实际业务注册了独立事务。
- MockMvc 只测试 MVC 层，不能证明真实浏览器交互。
- 只断言“没抛异常”，没有验证返回值与数据库状态。
- 测试依赖执行顺序或共享可变数据。
