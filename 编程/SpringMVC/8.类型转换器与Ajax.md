# 类型转换器与 Ajax

> [!info] 讲义补充
> 本节来自讲义第 2390–2846 行。录播未完整演示，属于后续补充知识。

## 为什么需要自定义类型转换器

浏览器传来的参数本质上都是字符串。Spring 能自动把 `"18"` 转成 `Integer`，但对于下面这种复合格式没有通用规则：

```text
(123.4,53.8)
```

目标对象：

```java
public class Pointer {
    private Double xpoint;
    private Double ypoint;
}
```

必须明确告诉 Spring 如何把字符串拆成两个坐标。

## Converter<String, Pointer>

```java
public class PointerConverter implements Converter<String, Pointer> {
    @Override
    public Pointer convert(String source) {
        String body = source.substring(1, source.length() - 1);
        String[] parts = body.split(",");
        return new Pointer(
                Double.parseDouble(parts[0]),
                Double.parseDouble(parts[1])
        );
    }
}
```

> [!warning] 示例代码缺少校验
> 实际实现应检查首尾括号、逗号数量、数字格式和空值；否则会抛 `IndexOutOfBoundsException` 或 `NumberFormatException`。转换失败时可抛 `IllegalArgumentException` 或自定义异常，交给统一异常处理。

## 注册转换器

```xml
<bean id="conversionService"
      class="org.springframework.context.support.ConversionServiceFactoryBean">
    <property name="converters">
        <list>
            <bean class="com.elm.converter.PointerConverter"/>
        </list>
    </property>
</bean>

<mvc:annotation-driven conversion-service="conversionService"/>
```

只有注册到 MVC 的 `conversionService`，SpringMVC 的参数绑定才会使用它。

## 自定义日期转换器

```java
public class MyDateConverter implements Converter<String, Date> {
    private String pattern = "yyyy-MM-dd";

    @Override
    public Date convert(String source) {
        try {
            return new SimpleDateFormat(pattern).parse(source);
        } catch (ParseException e) {
            throw new IllegalArgumentException("日期格式错误", e);
        }
    }
}
```

对比：

| 方案 | 适用场景 |
|---|---|
| `@DateTimeFormat` | 单个字段，声明式，最常见 |
| 自定义 `Converter<String, Date>` | 多处共享规则、特殊格式或复杂校验 |

课堂同时演示两种方式，是为了理解底层转换机制；普通日期字段优先用注解，避免重复造轮子。

## Ajax 基础

Ajax 允许页面在后台向服务器发请求，不刷新整个页面。

```javascript
$.ajax({
    url: "/api/user/checkLoginName.do",
    type: "post",
    data: { loginName: value },
    dataType: "json",
    success: function (data, status, xhr) {
        console.log(data);
    },
    error: function (xhr, status, error) {
        console.error(status, error);
    }
});
```

关键参数：

| 参数 | 含义 |
|---|---|
| `url` | 请求地址 |
| `type` | GET/POST/PUT/DELETE |
| `data` | 请求参数 |
| `dataType` | 期望响应类型 |
| `success` | 2xx 且解析成功时调用 |
| `error` | 网络、状态码或解析失败时调用 |

## 用户名异步校验

```javascript
$("#loginName").blur(function () {
    const loginName = $(this).val();
    $.get("/api/user/checkLoginName.do",
          { loginName: loginName },
          function (data) {
              $("#loginNameTip").text(data);
          });
});
```

Controller：

```java
@RequestMapping(value = "/checkLoginName",
                produces = "application/json;charset=UTF-8")
@ResponseBody
public MyMessage<Boolean> checkLoginName(
        @RequestParam("loginName") String loginName) {
    boolean available = !userService.exists(loginName);
    return new MyMessage<Boolean>()
            .setSuccess(available)
            .setMsg(available ? "可用" : "已被占用")
            .setTag(available);
}
```

### 返回字符串与返回 JSON

- 返回 `"exists"` / `"use"` 最简单，但语义弱、扩展性差。
- 返回对象可同时携带 `success`、`msg`、`data`，前端更容易统一处理。
- 无论哪种方式，HTTP 2xx 只说明请求成功，不代表业务一定成功。

## 异步与同步

- 同步：等待前一请求完成再继续。
- 异步：请求发出后，页面仍可响应用户操作。
- Ajax 回调必须检查成功/失败分支，不能只写 `success`。
- 快速连续输入可能产生多个请求，应做防抖和请求竞态处理。

## 易错点

- `dataType: "json"` 要求服务器确实返回可解析 JSON。
- `produces` 的字符集与响应中文乱码有关。
- 前端传 `null`、空串、数字和字符串时，后端绑定行为不同。
- 用户名检查不能只在 Ajax 前端做，注册接口必须再次校验。
- 自定义 Converter 必须注册，否则不会被使用。
