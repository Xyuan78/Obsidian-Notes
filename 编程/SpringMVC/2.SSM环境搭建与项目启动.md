# SSM 环境搭建与项目启动

> [!info] 课堂来源
> 录制 1，约 09:23–25:09；录制 2，约 00:00–08:50。课堂重点是依赖、配置文件、`web.xml`、Tomcat 插件和第一次启动。

## 目标

搭起一个能启动、能加载 Spring、能接收 `*.do` 请求的最小 SSM Web 项目。先确认环境闭环，再学习控制器细节。

```text
pom.xml
  ├─ Spring / SpringMVC / MyBatis / Druid / JSP / Jackson
src/main/resources
  ├─ applicationContext.xml
  ├─ springmvc-config.xml
  ├─ mybatis-config.xml
  ├─ db.properties
src/main/webapp/WEB-INF
  └─ web.xml
```

## Maven 依赖与版本统一

课堂建议先把版本集中到 `properties`：

```xml
<properties>
    <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
    <maven.compiler.source>8</maven.compiler.source>
    <maven.compiler.target>8</maven.compiler.target>
    <spring.version>5.2.10.RELEASE</spring.version>
</properties>
```

核心依赖分组：

- Spring：`spring-core`、`spring-beans`、`spring-context`、`spring-web`、`spring-webmvc`、`spring-jdbc`、`spring-tx`。
- Web：`javax.servlet-api`、`jsp-api`、`jstl`。
- JSON/XML：`jackson-databind`、JAXB 相关依赖（按 JDK 版本决定）。
- 数据：`mybatis`、`mybatis-spring`、MySQL 驱动、Druid。
- 上传：`commons-fileupload`。
- 测试：`junit`、`spring-test`。

> [!tip] 统一版本的意义
> 多个 Spring 模块必须使用同一版本，避免 `NoSuchMethodError`、类加载冲突和 XML 命名空间不一致。

## 打包配置

项目必须是 `war`：

```xml
<packaging>war</packaging>
```

课堂项目还需要把 `src/main/java` 下的 Mapper XML 和 `src/main/resources` 全部打入构建产物：

```xml
<resources>
    <resource>
        <directory>src/main/java</directory>
        <includes><include>**/*.xml</include></includes>
    </resource>
    <resource>
        <directory>src/main/resources</directory>
        <includes><include>**/*.*</include></includes>
    </resource>
</resources>
```

否则运行时可能报 Mapper 绑定语句不存在。

## Tomcat 9 Maven 插件

课堂项目使用：

```xml
<plugin>
    <groupId>org.opoo.maven</groupId>
    <artifactId>tomcat9-maven-plugin</artifactId>
    <version>3.0.1</version>
    <configuration>
        <port>8080</port>
        <path>/api</path>
    </configuration>
</plugin>
```

启动后，控制器 URL 要加上上下文路径 `/api`：

```text
http://localhost:8080/api/admin/helloworld.do
```

若端口被占用：

1. 先停止旧的 Tomcat 进程。
2. 修改 `<port>`，例如 `8081`。
3. 避免使用 1024 以下端口。
4. 重新 `clean` 后启动。

## applicationContext.xml

根配置负责 Spring 容器、数据源、MyBatis 和事务。当前课堂项目的结构是：

```xml
<context:component-scan base-package="com.elm"/>

<context:property-placeholder location="classpath:db.properties"/>

<bean id="dataSource" class="com.alibaba.druid.pool.DruidDataSource"
      destroy-method="close">
    <property name="url" value="${mysql.url}"/>
    <property name="username" value="${mysql.username}"/>
    <property name="password" value="${mysql.password}"/>
    <property name="driverClassName" value="${mysql.driver}"/>
</bean>

<bean id="sqlSessionFactory"
      class="org.mybatis.spring.SqlSessionFactoryBean">
    <property name="configLocation" value="classpath:mybatis-config.xml"/>
    <property name="dataSource" ref="dataSource"/>
    <property name="typeAliasesPackage" value="com.elm.model.entity"/>
</bean>

<bean class="org.mybatis.spring.mapper.MapperScannerConfigurer">
    <property name="basePackage" value="com.elm.mapper"/>
    <property name="sqlSessionFactoryBeanName" value="sqlSessionFactory"/>
</bean>

<bean id="txManager"
      class="org.springframework.jdbc.datasource.DataSourceTransactionManager">
    <property name="dataSource" ref="dataSource"/>
</bean>

<tx:annotation-driven transaction-manager="txManager"/>
```

> [!warning] 课堂简化
> 当前 `applicationContext.xml` 还通过 `<import resource="classpath:springmvc-config.xml"/>` 合并 Web 配置，并且 `web.xml` 中的根容器与 `DispatcherServlet` 都加载 `applicationContext.xml`。这能帮助课堂快速跑通，但会让 Controller 等 Bean 在父子容器中出现重复扫描风险。
>
> 更标准的结构是：根容器加载 Service/Mapper/事务/数据源；`DispatcherServlet` 只加载 Controller、视图解析、消息转换和静态资源映射。

## springmvc-config.xml

负责 Web 层：

```xml
<context:component-scan base-package="com.elm.controller"/>

<mvc:annotation-driven>
    <mvc:message-converters>
        <bean class="org.springframework.http.converter.StringHttpMessageConverter">
            <constructor-arg value="UTF-8"/>
        </bean>
    </mvc:message-converters>
</mvc:annotation-driven>

<bean id="multipartResolver"
      class="org.springframework.web.multipart.commons.CommonsMultipartResolver">
    <property name="maxUploadSize" value="104857600"/>
    <property name="maxInMemorySize" value="4096"/>
    <property name="defaultEncoding" value="UTF-8"/>
</bean>
```

- `annotation-driven` 启用注解映射、参数绑定、消息转换等 MVC 基础设施。
- `multipartResolver` 是文件上传的前置条件。
- 当前课堂配置没有保留 JSP 视图解析器，因此多数示例使用 `@ResponseBody` 返回数据。

## web.xml

```xml
<context-param>
    <param-name>contextConfigLocation</param-name>
    <param-value>classpath:/applicationContext.xml</param-value>
</context-param>

<listener>
    <listener-class>
        org.springframework.web.context.ContextLoaderListener
    </listener-class>
</listener>

<filter>
    <filter-name>characterEncodingFilter</filter-name>
    <filter-class>
        org.springframework.web.filter.CharacterEncodingFilter
    </filter-class>
    <init-param>
        <param-name>encoding</param-name>
        <param-value>UTF-8</param-value>
    </init-param>
</filter>

<servlet>
    <servlet-name>springmvc</servlet-name>
    <servlet-class>
        org.springframework.web.servlet.DispatcherServlet
    </servlet-class>
    <init-param>
        <param-name>contextConfigLocation</param-name>
        <param-value>classpath:/applicationContext.xml</param-value>
    </init-param>
    <load-on-startup>1</load-on-startup>
</servlet>

<servlet-mapping>
    <servlet-name>springmvc</servlet-name>
    <url-pattern>*.do</url-pattern>
</servlet-mapping>
```

### 为什么映射 `*.do`

- 只让以 `.do` 结尾的请求进入 SpringMVC。
- 图片、CSS、JS 等静态资源不会误入 Controller。
- 避免额外配置静态资源释放。
- 代价是 API URL 必须带 `.do`，现代 REST 项目通常会改为 `/` 映射并单独处理静态资源。

## 构建与启动顺序

1. `clean`：删除旧的 `target`。
2. `compile` / `package`：编译并生成 war。
3. 启动 Tomcat 插件。
4. 访问上下文根，看到 `index.jsp` 的 Hello World。
5. 再访问 Controller URL，确认 `*.do` 映射生效。

> [!tip] 提交课堂项目
> 提交前删除 `target`、`.idea` 等本地产物；不要把 IDE 配置和构建缓存当作源码提交。

## 故障定位顺序

| 现象 | 优先检查 |
|---|---|
| 404 | URL、上下文路径、`.do` 后缀、Controller 扫描包 |
| 400 | 参数缺失、参数类型错误、日期格式、请求体格式 |
| 405 | HTTP 方法不匹配 |
| Mapper 绑定异常 | XML 是否被打包、namespace/id 是否匹配 |
| 数据源创建失败 | 驱动类、URL、用户名密码、依赖版本 |
| 中文乱码 | 请求编码过滤器、响应 `charset`、数据库字符集 |
