# 过拟合抑制：Dropout与归一化

深层网络参数多，很容易把训练集背下来。常用的两个手段：Dropout 随机关掉一部分神经元，逼网络不要依赖个别节点；归一化把每层输出拉回稳定分布，让训练更快更稳。

## 1. 过拟合在深度网络里的表现

- 训练集准确率持续上升，验证集提前停滞甚至下降；
- 训练损失一路降，验证损失先降后升。

课上在违约数据集上的要求：网络输入有 47 个特征，原来 4 个神经元的隐藏层太小，要**加大隐藏层神经元数量，并在两层基础上继续加层**，同时用 Dropout 缓解过拟合。

## 2. Dropout

### 2.1 机制

训练时以概率 $p$ 随机把神经元的输出置 0，被丢掉的神经元这一步不参与前向和反向。相当于每次训练一个“更瘦”的子网络，最后集成起来。

```python
class MLP(nn.Module):
    def __init__(self, input_size, hidden_size, output_size, p_drop=0.3):
        super().__init__()
        self.fc1 = nn.Linear(input_size, hidden_size)
        self.bn1 = nn.BatchNorm1d(hidden_size)
        self.drop = nn.Dropout(p_drop)
        self.fc2 = nn.Linear(hidden_size, output_size)

    def forward(self, x):
        x = self.fc1(x)
        x = self.bn1(x)
        x = F.relu(x)
        x = self.drop(x)          # 放在激活之后
        return self.fc2(x)
```

### 2.2 关键事实

| 问题 | 答案 |
|---|---|
| 丢弃比例取多少 | 常用 0.3；不超过 0.5，否则欠拟合 |
| 放在哪 | 通常在 ReLU 之后 |
| 增加参数吗 | 不增加，Dropout 没有权重和偏置 |
| 训练/推理有区别吗 | 有。`model.train()` 时随机丢弃，`model.eval()` 时关闭并按比例缩放 |
| 和 BatchNorm 的关系 | 两者都抑制过拟合，但机制不同，可以一起用 |

> [!warning] 忘记切换 eval 模式
> 如果在评估时仍是 `model.train()`，Dropout 会继续随机丢神经元，同一个输入每次输出都不同，指标会偏低且不可复现。评估前必须 `model.eval()`。

### 2.3 为什么有效

- 防止网络过度依赖某几个神经元，迫使每个节点都学到有用的特征；
- 相当于训练了指数多个共享权重的子网络，推理时做近似集成；
- 和随机森林的“样本/特征随机”是同一类思想：制造多样性，让错误互相抵消。

## 3. 批归一化（BatchNorm）

### 3.1 做什么

对每个 batch 的**每一列特征**（每个隐藏维度）单独做标准化：

$$
\hat{x} = \frac{x-\mu_B}{\sqrt{\sigma_B^2+\epsilon}}, \qquad
y = \gamma\hat{x}+\beta
$$

- $\mu_B,\sigma_B$：当前 batch 在该维度上的均值和标准差；
- $\gamma,\beta$：可学习的缩放和平移参数。

> [!warning] 关于“归一化到 0~1”
> 课上口头说“把输出归一化到 0~1”，这是不严谨的说法。BatchNorm 实际做的是**零均值、单位方差**，输出范围并不限于 0~1，之后再由 $\gamma,\beta$ 调整。数据预处理里的 MinMax 才是压到 0~1。两种“归一化”不要混。

### 3.2 放在哪

常规顺序：

```text
Linear → BatchNorm → ReLU → Dropout
```

部分残差网络会用 `ReLU → BN` 的顺序，但主流仍是先 BN 再激活。

### 3.3 特点

- 让每层输入分布稳定，可以用更大的学习率，收敛更快；
- 有一定正则效果，但**不能替代 Dropout**；
- 引入 $\gamma,\beta$，**会增加参数**；
- 依赖 batch 统计量：batch 太小（如 1、2）时统计不准，效果差；
- 训练时用当前 batch 的均值方差，推理时用训练阶段累积的滑动平均——这也是必须切换 `eval()` 的原因之一。

```python
self.bn1 = nn.BatchNorm1d(hidden_size)   # 全连接层用 1d
# 卷积层用 nn.BatchNorm2d(channels)
```

## 4. 层归一化（LayerNorm）

对**单个样本的所有特征**做归一化，不依赖 batch：

$$
\mu_i = \frac{1}{D}\sum_{d=1}^{D}x_{i,d}, \qquad
\sigma_i^2 = \frac{1}{D}\sum_{d=1}^{D}(x_{i,d}-\mu_i)^2
$$

课上的类比：

- **BatchNorm 按列**：某一门课（一个特征）在全班（一个 batch）上求平均；
- **LayerNorm 按行**：一个学生（一个样本）的所有科目（所有特征）一起求平均。

### 4.1 适用场景

| 场景 | 选哪个 |
|---|---|
| CV、全连接网络，batch 足够大 | BatchNorm |
| NLP/Transformer，序列长度不一、batch 小 | LayerNorm |
| RNN | LayerNorm |

NLP 里一句话的每个字是一个特征位置，句子长度可变，batch 统计不稳定，所以按行归一化更合适。

## 5. BatchNorm vs LayerNorm

| 维度 | BatchNorm | LayerNorm |
|---|---|---|
| 统计范围 | 一个 batch 内、同一特征列 | 单个样本内、所有特征 |
| 方向 | 按列 | 按行 |
| 依赖 batch 大小 | 是 | 否 |
| 训练/推理差异 | 有（滑动平均） | 无 |
| 典型场景 | CNN、MLP | Transformer、RNN |
| 额外参数 | $\gamma,\beta$ | $\gamma,\beta$ |

## 6. 和其他手段的配合

| 手段 | 作用层面 | 备注 |
|---|---|---|
| 数据归一化 | 输入 | 训练前做，测试集用训练集参数 |
| 增加数据 | 数据 | 最根本的解决办法 |
| 早停 | 训练流程 | 验证损失不再下降就停 |
| 权重衰减 | 损失函数 | L2 正则 |
| Dropout | 网络结构 | 训练时随机失活 |
| BatchNorm | 网络结构 | 稳定分布、加速收敛 |
| 减小模型 / 加层 | 结构 | 违约数据 47 维输入需要更大隐藏层，但也不能无限加大 |

> [!tip] 调参顺序
> 先确认数据标准化正确、学习率合理，再加 BatchNorm；仍然过拟合再加 Dropout（0.2–0.3），最后才考虑减层、早停、权重衰减。一次只改一个变量，才知道是谁起了作用。
