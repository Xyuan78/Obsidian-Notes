# 多层感知机与网络构建

多层感知机（MLP）是最基础的神经网络：若干全连接层 + 激活函数堆起来。它的参数量、输入输出形状、`forward` 写法，是读所有更复杂网络的基础。

## 1. 从生物神经元到人工神经元

生物神经元接收信号，累积到阈值后放电。数学抽象：

$$
z = \sum_{i=1}^{n} w_i x_i + b = w^\top x + b
$$

$$
y = f(z)
$$

- $w$：权重，表示每个输入的重要性；
- $b$：偏置，调节激活阈值；
- $f$：激活函数，引入非线性。

单个神经元只能表达线性关系，连 XOR 都分不开。解决办法是**堆多层**。

## 2. MLP 的结构

```text
输入层（不做计算）
   ↓
隐藏层 1：Linear + 激活
   ↓
隐藏层 2：Linear + 激活
   ↓
输出层：Linear（不加激活）
```

| 层 | 作用 |
|---|---|
| 输入层 | 接收特征，只是数据入口 |
| 隐藏层 | 做特征变换，学习抽象表示 |
| 输出层 | 回归输出 1 个值；二分类输出 1 个 logit；多分类输出类别数个 logit |

> [!note] 输出层为什么不加激活
> 多分类用 `CrossEntropyLoss`，它内部已经包含 Softmax；二分类用 `BCEWithLogitsLoss`，内部包含 Sigmoid。输出层再加一次会重复计算，数值也不稳定。

## 3. 全连接层的形状

$$
Y = XW^\top + b
$$

设一个 batch 有 $B$ 个样本，输入维度 $d_{in}$，输出维度 $d_{out}$：

| 张量 | 形状 |
|---|---|
| `X` | $(B, d_{in})$ |
| `W` | $(d_{out}, d_{in})$ |
| `b` | $(d_{out},)$ |
| `Y` | $(B, d_{out})$ |

PyTorch 的 `nn.Linear(in_features, out_features)` 内部权重形状是 `(out_features, in_features)`，所以前向是 $XW^\top$。

## 4. 参数量怎么算

单层参数量：

$$
\text{params} = d_{out} \times (d_{in} + 1)
$$

加 1 是每个输出神经元的偏置。

**例子**：输入 4 维 → 两个隐藏层各 4 个神经元 → 输出 3 类。

| 层 | 计算 | 参数 |
|---|---|---|
| Linear(4, 4) | 4 × (4+1) | 20 |
| Linear(4, 4) | 4 × (4+1) | 20 |
| Linear(4, 3) | 3 × (4+1) | 15 |
| 合计 | | **55** |

这也解释了为什么图像任务参数爆炸：$28\times28=784$ 维输入，接一个 256 神经元的层就有 $256\times785\approx20$ 万参数；$224\times224$ 输入更大。

## 5. 两种搭建方式

### 5.1 nn.Sequential（简单网络）

```python
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(4, 8),
    nn.ReLU(),
    nn.Linear(8, 16),
    nn.ReLU(),
    nn.Linear(16, 3),
)
```

适合层与层严格顺序执行的情况，写起来短，但不方便加分支、残差等结构。

### 5.2 继承 nn.Module（推荐）

```python
import torch
import torch.nn as nn

class MLP(nn.Module):
    def __init__(self, input_size, hidden_size, output_size):
        super().__init__()                    # 必须调用，否则参数无法注册
        self.fc1 = nn.Linear(input_size, hidden_size)
        self.fc2 = nn.Linear(hidden_size, hidden_size)
        self.fc3 = nn.Linear(hidden_size, output_size)
        self.relu = nn.ReLU()

    def forward(self, x):
        x = self.relu(self.fc1(x))
        x = self.relu(self.fc2(x))
        return self.fc3(x)                    # 输出层不加激活

model = MLP(4, 4, 3)
print(model(torch.randn(5, 4)).shape)        # torch.Size([5, 3])
```

要点：

- `__init__` 里只定义层，不写数据流；
- `forward` 定义数据怎么流；
- 调用时写 `model(x)`，PyTorch 会自动转到 `forward`；
- 不调用 `super().__init__()` 会在注册参数时报错。

参数统计：

```python
total = sum(p.numel() for p in model.parameters())
print(total)     # 4→4→4→3 时为 55
```

## 6. 数据加载：Dataset 与 DataLoader

```python
from torch.utils.data import TensorDataset, DataLoader

dataset = TensorDataset(X_tensor, y_tensor)
loader = DataLoader(dataset, batch_size=16, shuffle=True)

for X_batch, y_batch in loader:
    # X_batch: (16, 4)，y_batch: (16,)
    ...
```

- **batch_size**：常用 2 的幂（16、32、128）。越小更新越频繁但噪声大；越大越稳但占显存。
- **shuffle=True**：每个 epoch 打乱顺序，避免模型记住样本顺序。
- 最后一个 batch 可能不足 `batch_size`（例如 120 条、批量 16，最后一批 8 条）。

## 7. 完整训练骨架

```python
model = MLP(input_size=4, hidden_size=8, output_size=3)
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

for epoch in range(10):
    model.train()
    for X_batch, y_batch in loader:
        optimizer.zero_grad()          # 清梯度
        logits = model(X_batch)        # 前向
        loss = criterion(logits, y_batch)
        loss.backward()                # 反向
        optimizer.step()               # 更新
```

鸢尾花数据上的课堂结果：10 轮训练，测试集准确率 90% 以上，评估阶段达到 96.7%。

## 8. 常见错误

| 错误 | 原因 | 解决 |
|---|---|---|
| `mat1 and mat2 shapes cannot be multiplied` | 输入维度与 `in_features` 不一致 | 检查 `X.shape[1]` |
| 参数量对不上 | 把输出层也算错，或漏了偏置 | 用 `d_out*(d_in+1)` 逐层核对 |
| `super().__init__()` 未调用 | 参数没注册，`model.parameters()` 为空 | 构造函数第一行调用 |
| 输出概率不等于 1 | 输出层又加了 Softmax，损失里又算一次 | 输出 logits，交给 CrossEntropyLoss |
