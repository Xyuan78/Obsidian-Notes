# 训练评估与模型保存

训练循环写完只是开始。要正确评估，必须切换 `eval` 模式并关闭梯度；要复用模型，必须知道两种保存方式的区别和加载时的坑。

## 1. 训练模式与评估模式

```python
model.train()     # 训练模式：Dropout 随机失活，BN 用当前 batch 统计
model.eval()      # 评估模式：Dropout 关闭，BN 用滑动平均
```

这两个调用不改变参数，只改变层的行为。忘了切换的后果：

- 评估时还在 `train()`：指标偏低、每次结果不同；
- 训练时误用 `eval()`：Dropout 不生效，BN 统计不对，容易过拟合。

## 2. 完整训练与评估流程

```python
import torch
import torch.nn as nn

model = MLP(input_size=4, hidden_size=16, output_size=3)
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

train_losses, train_accs, test_accs = [], [], []

for epoch in range(10):
    # ---------- 训练 ----------
    model.train()
    total_loss, correct, total = 0.0, 0, 0

    for X_batch, y_batch in train_loader:
        optimizer.zero_grad()
        logits = model(X_batch)
        loss = criterion(logits, y_batch)
        loss.backward()
        optimizer.step()

        total_loss += loss.item()
        pred = logits.argmax(dim=1)
        correct += (pred == y_batch).sum().item()
        total += y_batch.size(0)

    train_losses.append(total_loss / len(train_loader))
    train_accs.append(correct / total)

    # ---------- 评估 ----------
    model.eval()
    correct, total = 0, 0
    with torch.no_grad():
        for X_batch, y_batch in test_loader:
            logits = model(X_batch)
            pred = logits.argmax(dim=1)
            correct += (pred == y_batch).sum().item()
            total += y_batch.size(0)

    test_accs.append(correct / total)
    print(f"epoch {epoch+1}: loss={train_losses[-1]:.4f}, "
          f"train={train_accs[-1]:.4f}, test={test_accs[-1]:.4f}")
```

课堂要求：**训练集准确率也要记录**，不能只画测试集曲线，否则看不出过拟合。课上原始代码只画了测试集，需要在训练循环里补上。

```python
import matplotlib.pyplot as plt

plt.subplot(1, 2, 1)
plt.plot(train_losses)
plt.title("训练损失")

plt.subplot(1, 2, 2)
plt.plot(train_accs, label="train")
plt.plot(test_accs, label="test")
plt.legend()
plt.title("准确率")
plt.show()
```

## 3. 评估阶段的三条纪律

1. **必须用测试集**，不能用训练集或验证集冒充；
2. **必须 `model.eval()`**；
3. **必须 `torch.no_grad()`**，否则会构建计算图，浪费显存。

> [!warning] 标准化的数据泄漏
> 先切分训练/测试，再在**训练集**上 `fit` 标准化器，测试集只 `transform`。如果先对全体数据算均值和方差，测试集信息就泄漏进训练过程，指标会虚高。

## 4. 单样本预测

```python
model.eval()
with torch.no_grad():
    x = torch.tensor([[5.1, 3.5, 1.4, 0.2]], dtype=torch.float32).to(device)
    logits = model(x)
    probs = torch.softmax(logits, dim=1)
    pred = probs.argmax(dim=1)

print(probs)    # tensor([[0.97, 0.02, 0.01]])
print(pred)     # tensor([0])
```

流程：网络输出 logits → Softmax 转概率 → 取最大值的下标作为类别。训练时不要在模型里加 Softmax，因为 `CrossEntropyLoss` 内部已经做了；**推理展示概率时**可以手动加。

## 5. 保存与加载

### 5.1 只保存参数（推荐）

```python
torch.save(model.state_dict(), "iris_model.pth")

loaded = MLP(input_size=4, hidden_size=16, output_size=3)
loaded.load_state_dict(torch.load("iris_model.pth", map_location=device))
loaded.eval()
```

优点：文件小；结构由代码定义，升级模型结构时更可控。

### 5.2 保存整个模型

```python
torch.save(model, "iris_model_full.pth")

loaded = torch.load("iris_model_full.pth", weights_only=False)
loaded.eval()
```

> [!warning] 新版 PyTorch 的 weights_only
> PyTorch 2.6 起 `torch.load` 默认 `weights_only=True`，加载“整个模型”会报错，必须显式写 `weights_only=False`。只加载 `state_dict` 时保持默认即可。加载整个模型依赖保存时的类定义，换项目/改类名容易失败，所以生产环境推荐只存参数。

加载后**一定要 `eval()`**，否则 Dropout/BN 仍处于训练行为。

## 6. 课堂结果与常见问题

鸢尾花数据：120 条训练、30 条测试，batch=16，Adam + CrossEntropy，训练 10 轮，测试准确率 90% 以上，最终评估 96.7%。

| 问题 | 原因 | 处理 |
|---|---|---|
| 准确率一直不变 | 忘记 `optimizer.step()`；标签类型错 | 检查循环四步 |
| 评估指标每次不同 | 没切 `eval()` | `model.eval()` |
| 加载报 `weights_only` 错误 | 加载整个模型 | `weights_only=False` |
| 加载后预测结果很差 | 忘了 `eval()`；设备不一致 | `eval()` + `map_location` |
| 测试集准确率虚高 | 标准化用了全体数据 | 只在训练集 fit |
| 显存爆 | 评估没加 `no_grad` | `with torch.no_grad():` |
