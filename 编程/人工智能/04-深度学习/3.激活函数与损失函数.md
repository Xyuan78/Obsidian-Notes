# 激活函数与损失函数

激活函数决定“神经元怎么响应”，损失函数决定“错得有多严重”。两者配对使用：隐藏层用 ReLU，回归用 MSE，二分类用 BCE，多分类用交叉熵。

## 一、为什么需要激活函数

没有激活函数时，多层线性变换叠起来仍然是线性变换：

$$
W_2(W_1x+b_1)+b_2 = (W_2W_1)x + (W_2b_1+b_2) = W'x+b'
$$

再深的网络也只等价于一个线性模型。激活函数引入非线性，网络才有拟合复杂函数的能力。

## 二、常用激活函数

| 函数 | 公式 | 范围 | 用在哪 | 问题 |
|---|---|---|---|---|
| ReLU | $\max(0,x)$ | $[0,+\infty)$ | 隐藏层默认 | 死亡 ReLU |
| Sigmoid | $\frac{1}{1+e^{-x}}$ | $(0,1)$ | 二分类输出 | 梯度消失 |
| Tanh | $\frac{e^x-e^{-x}}{e^x+e^{-x}}$ | $(-1,1)$ | RNN 隐藏层 | 梯度消失 |
| Softmax | $\frac{e^{z_i}}{\sum_j e^{z_j}}$ | $(0,1)$，和为 1 | 多分类输出 | — |

### 1. ReLU

```python
import torch.nn.functional as F
x = torch.tensor([-3., -1., 0., 1., 3.])
print(F.relu(x))    # tensor([0., 0., 0., 1., 3.])
```

优点：计算快；正区间梯度恒为 1，不像 Sigmoid 那样越深越衰减。
缺点：负数区间梯度为 0，如果某个神经元长期收到负输入，参数再也不会更新，叫“死亡 ReLU”。深层网络里少量神经元死亡反而能抑制过拟合；死亡过多则需要换 PReLU/LeakyReLU。

### 2. Sigmoid 与 Tanh

Sigmoid 把任意实数压到 $(0,1)$，可以解释为概率，适合二分类输出层。但两端导数趋近 0，深层反向传播时梯度连乘会迅速消失。

Tanh 以 0 为中心（$-1$ 到 $1$），比 Sigmoid 好一些，但仍有梯度消失。

### 3. Softmax

把一组 logits 转成概率分布：

$$
p_i = \frac{e^{z_i}}{\sum_j e^{z_j}}
$$

指数运算会放大原本接近的数值差距，让最大类更突出；同时把负数变成正数。多分类输出层用它。

> [!warning] Softmax 的数值稳定性
> 直接对很大的 logits 求 $e^z$ 会溢出。实际实现会先减去最大值，PyTorch 内部已处理。手写时要注意。

## 三、损失函数

### 1. 回归：MSE

$$
\text{MSE} = \frac{1}{n}\sum_{i=1}^{n}(\hat{y}_i-y_i)^2
$$

```python
criterion = nn.MSELoss()
loss = criterion(y_pred, y_true)
```

可导、对大误差惩罚重，是回归的默认选择。单位是原变量的平方，汇报时常用 RMSE。

### 2. 二分类：BCE

$$
\text{BCE} = -\frac{1}{n}\sum_i \left[y_i\log p_i + (1-y_i)\log(1-p_i)\right]
$$

```python
# 输入必须已经过 sigmoid（范围 0~1）
criterion = nn.BCELoss()
loss = criterion(torch.sigmoid(logits), y_true)

# 更常用：内部自带 sigmoid，数值更稳定
criterion = nn.BCEWithLogitsLoss()
loss = criterion(logits, y_true)
```

优先用 `BCEWithLogitsLoss`，少一步 sigmoid，也避免“先 sigmoid 再取 log”的数值问题。

### 3. 多分类：交叉熵

$$
L = -\sum_{k=1}^{K} y_k \log p_k
$$

真实标签是 one-hot 时，只有真实类别那一项为 1，所以等价于：

$$
L = -\log p_{\text{真实类别}}
$$

```python
criterion = nn.CrossEntropyLoss()
logits = torch.tensor([[2.0, 1.0, 0.5],
                       [0.5, 2.5, 0.3]])
labels = torch.tensor([0, 1])       # 必须是 int64，不是 one-hot
loss = criterion(logits, labels)    # tensor(0.3422)
```

> [!warning] PyTorch 的 CrossEntropyLoss 已包含 Softmax
> 网络输出层只输出 logits，不要再加 `nn.Softmax`。加了会重复计算，损失值偏小且梯度不对。Keras 则需要手动加 Softmax 再算交叉熵。

### 4. 手算验证

用上面的 logits：

第 1 个样本 $[2.0,1.0,0.5]$：

$$
e^2=7.389,\quad e^1=2.718,\quad e^{0.5}=1.649
$$

$$
p=\left[\frac{7.389}{11.756},\frac{2.718}{11.756},\frac{1.649}{11.756}\right]\approx[0.6285,0.2312,0.1402]
$$

真实类别为 0，损失 $=-\log 0.6285\approx0.4643$。

第 2 个样本 $[0.5,2.5,0.3]$：$p\approx[0.1086,0.8025,0.0889]$，真实类别为 1，损失 $=-\log0.8025\approx0.2200$。

平均：

$$
\frac{0.4643+0.2200}{2}\approx0.3422
$$

用 PyTorch 实测也是 0.3422，与手算一致。

```python
probs = F.softmax(logits, dim=1)
manual = -torch.log(probs[range(len(labels)), labels]).mean()
```

> [!note] 源文档数字更正
> `文档/多分类交叉熵损失的计算过程.md` 里写 `print(loss) # tensor(0.3018)`、第 0 类概率约 `0.506`，与它自己给的 logits 算出的结果（0.6285、0.3422）不一致。上面用的是实际运行 PyTorch 得到的值。

### 5. 为什么取负对数

- 概率 $p\to0$ 时 $-\log p\to+\infty$，对严重错误重罚；$p\to1$ 时趋近 0，几乎不罚。
- 对数把连乘变连加，避免大量小数相乘下溢。
- Softmax + 交叉熵的梯度极其简洁（见下）。

### 6. 梯度公式

对 logits $z_j$ 求导，最终化简为：

$$
\frac{\partial L}{\partial z_j} = p_j - y_j
$$

- 真实类别 $y_j=1$：梯度 $p_j-1<0$，梯度下降会**增大**该类得分；
- 非真实类别 $y_j=0$：梯度 $p_j>0$，会**减小**该类得分。

如果用 MSE 配 Softmax，梯度里会多出 $p_j(1-p_j)$，在概率接近 0/1 时非常小，训练变慢。这就是分类任务用交叉熵而不是 MSE 的原因。

## 四、配对速查

| 任务 | 输出层 | 损失 |
|---|---|---|
| 回归 | 1 个神经元，无激活 | `MSELoss` |
| 二分类 | 1 个神经元，无激活 | `BCEWithLogitsLoss` |
| 多分类 | 类别数个神经元，无激活 | `CrossEntropyLoss` |
