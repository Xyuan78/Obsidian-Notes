# 反向传播与优化器

前向传播算出预测和损失，反向传播算出每个参数的梯度，优化器按梯度更新参数。三者循环一次，就是一步训练。

## 1. 三个概念

| 概念 | 作用 |
|---|---|
| 梯度 | 损失函数对参数求导，指向损失上升最快的方向；反着走就是下降 |
| 反向传播 | 用链式法则高效求出所有层的梯度 |
| 梯度下降 | 按梯度方向更新参数，让损失变小 |

$$
\theta_t = \theta_{t-1} - \alpha \frac{\partial L}{\partial \theta}
$$

$\alpha$ 是学习率，也就是步长。

## 2. 前向与反向

```text
前向：x → 线性变换 → 激活 → … → 输出 → 损失
反向：损失对输出求导 → 逐层回传 → 每个 W、b 的梯度
更新：W ← W - lr × grad
```

### 2.1 为什么需要反向传播

如果暴力地对每个参数单独求导，深度网络参数量上百万，计算量会爆炸。反向传播利用链式法则，**复用前向传播的中间结果**，从输出层往输入层逐层计算，一次就能得到全部梯度。

链式法则：

$$
\frac{\partial L}{\partial w_1} = \frac{\partial L}{\partial z_3}\cdot\frac{\partial z_3}{\partial z_2}\cdot\frac{\partial z_2}{\partial z_1}\cdot\frac{\partial z_1}{\partial w_1}
$$

### 2.2 PyTorch 自动完成

```python
x = torch.tensor(3.0, requires_grad=True)
w = torch.tensor(2.0, requires_grad=True)
b = torch.tensor(1.0, requires_grad=True)

y = w * x + b
loss = (y - 5) ** 2

loss.backward()      # 反向传播
print(w.grad)        # 12 = 2x(y-5)
print(x.grad)        # 8  = 2w(y-5)
print(b.grad)        # 4  = 2(y-5)
```

手算复核：$y=7$，$\text{loss}=(7-5)^2=4$，$\partial\text{loss}/\partial b=2(7-5)=4$，一致。

## 3. 训练循环的标准写法

```python
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

for epoch in range(epochs):
    model.train()
    for X_batch, y_batch in loader:
        optimizer.zero_grad()        # 1. 清空上一轮梯度
        logits = model(X_batch)      # 2. 前向
        loss = criterion(logits, y_batch)
        loss.backward()              # 3. 反向，累积梯度
        optimizer.step()             # 4. 更新参数
```

顺序不能乱：

- 不清零：梯度会在上一轮基础上累加，更新步子越来越大，训练发散；
- 不 `backward`：没有梯度，`step()` 无事可做；
- 不 `step`：参数永远不变。

> [!warning] 梯度累积是常态
> PyTorch 的 `backward()` 默认把梯度**加到** `.grad` 上而不是覆盖。这就是为什么每个 batch 开头必须 `optimizer.zero_grad()`。

## 4. 梯度下降的三种变体

| 类型 | 每次用多少样本 | 特点 |
|---|---|---|
| 批量梯度下降（BGD） | 全部样本 | 梯度稳，但大数据集上一次更新极慢，且容易快速过拟合 |
| 随机梯度下降（SGD） | 1 个样本 | 更新快，但单个样本噪声大，震荡明显 |
| 小批量梯度下降（Mini-batch） | 32 / 64 / 128 | 兼顾速度和稳定，最常用 |

这也是 `DataLoader` 按 batch 取数的原因：不是不想一次算完，而是一次算完既慢又容易过拟合。

## 5. 常用优化器

| 优化器 | 特点 | 适用 |
|---|---|---|
| SGD | 最简单，固定学习率；可加 momentum | 视觉任务，配合学习率调度 |
| Adam | 动量 + 自适应学习率，收敛快 | 通用首选，初学者 |
| AdamW | Adam + 权重衰减修正 | Transformer/NLP |
| RMSprop | 自适应学习率 | RNN、部分 CNN |

```python
optimizer = torch.optim.SGD(model.parameters(), lr=0.01, momentum=0.9)
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
optimizer = torch.optim.AdamW(model.parameters(), lr=0.001)
```

### 5.1 Adam 和梯度下降的关系

Adam 仍然是梯度下降：先用反向传播拿到梯度，再在更新公式上做改进——用一阶矩（动量）平滑方向，用二阶矩自适应调整每个参数的学习率。本质没变，只是“怎么走”更聪明。

### 5.2 学习率

| 设置 | 现象 |
|---|---|
| 太大 | 损失震荡、爆炸，跨过最优点 |
| 太小 | 收敛极慢，可能停在半路 |
| 合适 | 损失平稳下降 |

经验起点：Adam 用 0.001，SGD 用 0.01；XGBoost 的 learning_rate 常用 0.05–0.1（含义不同，但同样是步长）。

学习率调度器可以按 epoch 衰减，通常每 30–50 个 epoch 调一次；调得太频繁会让步长过早变小，收敛反而变慢。

## 6. 训练中的三类问题

### 6.1 梯度消失

链式求导连乘，每层导数都小于 1 时，越往输入层梯度越接近 0，浅层参数几乎不更新。Sigmoid/Tanh 深层网络最典型。

解决：ReLU、残差连接、BatchNorm、合适的初始化。

### 6.2 梯度爆炸

连乘的导数都大于 1，梯度指数增长，参数更新震荡发散。

解决：梯度裁剪（`torch.nn.utils.clip_grad_norm_`）、权重初始化、减小学习率。

### 6.3 局部极小与鞍点

非凸损失面上可能有局部极小；高维空间里更常见的是**鞍点**（梯度为 0，但在某些方向上升、某些方向下降）。动量类优化器（Adam）有助于越过这些点。

## 7. 梯度检查清单

```python
print(model.fc1.weight.grad)      # 是否为 None？是否全是 0？
print(loss.item())                # 损失是否在下降？
```

| 现象 | 可能原因 |
|---|---|
| 梯度全是 0 | 用了 Sigmoid 且层太深、ReLU 全部死亡、忘记 `backward` |
| 梯度极大 / loss NaN | 学习率太大、没有归一化、梯度爆炸 |
| 参数不变 | 忘记 `optimizer.step()` 或优化器没绑定 `model.parameters()` |
| 每轮梯度翻倍 | 忘记 `zero_grad()` |
