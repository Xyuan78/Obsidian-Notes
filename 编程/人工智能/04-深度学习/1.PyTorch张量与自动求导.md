# PyTorch张量与自动求导

PyTorch 的两个核心：`Tensor` 是能在 GPU 上运算的多维数组；`autograd` 自动记录运算并求梯度。把这两件事弄明白，后面搭网络就只是把层按顺序串起来。

## 1. PyTorch 与 Keras 的定位

| 框架 | 封装程度 | 适合 |
|---|---|---|
| Keras | 高，接口类似 sklearn | 快速搭原型、工业落地 |
| PyTorch | 低，反向传播/梯度都暴露出来 | 理解原理、科研、论文复现 |

课程选 PyTorch，是因为要看清训练过程，而不是只调一个 `fit`。

## 2. 张量是什么

张量 = 多维数组 + GPU 支持 + 自动求导。

| 维度 | 叫法 | 例子 |
|---|---|---|
| 0 | 标量 | `tensor(3.)` |
| 1 | 向量 | `tensor([1., 2., 3.])` |
| 2 | 矩阵 | `tensor([[1., 2.], [3., 4.]])` |
| 3+ | 高维张量 | 一批图片 `(batch, channel, height, width)` |

## 3. 创建张量

```python
import torch

torch.tensor([1, 2, 3])            # 从列表创建，自动推断 dtype
torch.tensor([[1, 2], [3, 4]])     # 二维
torch.Tensor([1, 2, 3])            # 大写 T：总是 float32

torch.zeros((2, 3))                # 全 0
torch.ones((2, 3))                 # 全 1
torch.full((2, 2), 7)              # 全部填 7
torch.arange(0, 10, 2)             # [0, 2, 4, 6, 8]
torch.linspace(0, 1, 5)            # 0 到 1 等距 5 个点
torch.eye(3)                       # 3×3 单位矩阵

torch.randn(2, 3)                  # 标准正态分布
torch.rand(2, 3)                   # [0,1) 均匀分布
torch.randint(0, 10, (2, 3))       # 随机整数

torch.manual_seed(42)              # 固定随机种子，保证可复现
```

### 3.1 与 NumPy 互转

```python
import numpy as np

arr = np.array([1, 2, 3])

t1 = torch.tensor(arr)             # 复制数据，独立内存
t2 = torch.from_numpy(arr)         # 共享内存

arr[0] = 99
print(t2)                          # tensor([99, 2, 3])，跟着变

back = t2.numpy()                  # 转回 NumPy，同样共享
```

> [!warning] 共享内存的副作用
> `from_numpy` 节省显存/内存，但改一边另一边也变。需要独立副本时用 `torch.tensor(arr)` 或 `.clone()`。

## 4. 属性与设备

```python
x = torch.randn(2, 3)

x.ndim        # 2
x.shape       # torch.Size([2, 3])
x.dtype       # torch.float32
x.device      # cpu

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
x = x.to(device)
```

> [!tip] 模型和数据必须在同一设备上
> 模型在 GPU、数据在 CPU 会报 `Expected all tensors to be on the same device`。统一用 `device` 变量管理。

### 4.1 dtype 转换

```python
x = torch.tensor([1, 2, 3])        # int64
x.float()                          # float32
x.double()                         # float64
x.type(torch.float32)
```

深度学习默认 `float32`；`CrossEntropyLoss` 的标签要求 `int64`。

## 5. 索引、切片与形状变换

```python
x = torch.arange(12).reshape(3, 4)

x[0]           # 第一行
x[:, 1]        # 第二列
x[1, 2]        # 单个元素
x[x > 5]       # 布尔索引
x[[0, 2]]      # 花式索引

x.reshape(4, 3)      # 改变形状，可能复制
x.view(4, 3)         # 要求内存连续，否则报错
x.flatten()          # 拉平
x.unsqueeze(0)       # 在第 0 维加一维 → (1,3,4)
x.squeeze()          # 去掉长度为 1 的维度
x.T                  # 二维转置
x.permute(1, 0)      # 任意维度换位

torch.cat([a, b], dim=0)      # 拼接，维度不变
torch.stack([a, b], dim=0)    # 堆叠，增加一维
```

## 6. 运算与广播

```python
a = torch.tensor([[1., 2.], [3., 4.]])
b = torch.tensor([[5., 6.], [7., 8.]])

a + b          # 逐元素
a * b          # 逐元素乘，不是矩阵乘
a @ b          # 矩阵乘法
a.T @ b

a.sum()        # 全部求和
a.sum(dim=0)   # 按列求和
a.mean(dim=1)  # 按行求平均
```

广播规则与 NumPy 一致：从最后一维开始比较，维度相等或其中一个为 1。

## 7. 自动求导（Autograd）

### 7.1 计算图

设置 `requires_grad=True` 后，PyTorch 会记录该张量参与的所有运算，形成计算图：

```python
x = torch.tensor(3.0, requires_grad=True)
w = torch.tensor(2.0, requires_grad=True)
b = torch.tensor(1.0, requires_grad=True)

y = w * x + b          # 7
loss = (y - 5) ** 2    # 4

loss.backward()        # 反向传播，自动求导

print(x.grad)          # 8  = 2w(y-5) = 2×2×2
print(w.grad)          # 12 = 2x(y-5) = 2×3×2
print(b.grad)          # 4  = 2(y-5)   = 2×2
```

手算复核：$\frac{\partial \text{loss}}{\partial x} = 2(y-5)\cdot w = 2\times2\times2=8$，与输出一致。

### 7.2 梯度会累积

```python
x = torch.tensor(1.0, requires_grad=True)
for _ in range(3):
    y = x ** 2
    y.backward()
    print(x.grad)      # 2, 4, 6 —— 不断累加

# 正确做法
x.grad.zero_()         # 每次反向传播前清零
```

实际训练里由 `optimizer.zero_grad()` 统一处理。

### 7.3 推理时关闭求导

```python
with torch.no_grad():
    y = model(x)       # 不构建计算图，省内存、更快
```

评估和预测必须用 `torch.no_grad()`，否则会白白占用显存。
