# TPE与Optuna实战

Optuna 是目前最常用的调参框架，默认采样器是 TPE。TPE 不预测“这组参数效果多少”，而是反过来问“好结果对应的参数长什么样”，因此在混合参数和高维场景下比高斯过程更实用。

## 1. TPE 的换位思考

高斯过程建模 $P(y\mid x)$：给定参数，预测效果。

TPE 建模 $P(x\mid y)$：给定效果，参数是什么分布。

具体做法：

1. 把已完成的 trial 按效果排序，前 25% 标记为“好”，其余为“差”；
2. 对每个参数，分别在好组、差组估计密度 $l(x)$、$g(x)$；
3. 在 $l(x)/g(x)$ 最大的地方采样——好组常见、差组少见；
4. 评估该点，加入历史，重复。

直觉：如果前几次的好结果都集中在 `max_depth 6–8`、`learning_rate 0.03–0.06`，下一次就在这一带附近采样。

> [!note] TPE 和 EI 的关系
> 在 TPE 的假设下，最大化 $l(x)/g(x)$ 与最大化期望提升 EI 是等价的。TPE 不是高斯过程的廉价替代，而是同一目标下的另一种实现。

## 2. 为什么 Optuna 用 TPE

| 能力 | 高斯过程 | TPE |
|---|---|---|
| 连续参数 | 好 | 好 |
| 整数 / 类别参数 | 不擅长 | 原生支持 |
| 高维（5–30 个） | 15 维以上失真 | 表现稳定 |
| 计算开销 | 评估 200 次后很贵 | 拟合两个密度，很便宜 |
| 可记录试验数 | 几百 | 上万 |

典型机器学习模型（XGBoost、LightGBM）正好是 5–15 个混合类型超参数，TPE 是默认且合适的选择。

## 3. Optuna 的三个抽象

| 抽象 | 含义 | 类比 |
|---|---|---|
| Trial | 一次参数组合的尝试 | 一次实验 |
| Objective | 接收 trial、返回分数的函数 | 实验脚本 |
| Study | 一次完整搜索的容器 | 实验记录本 |

```python
study = optuna.create_study(direction="minimize")
study.optimize(objective, n_trials=50)

study.best_value          # 最佳分数
study.best_params         # 最佳参数
study.trials_dataframe()  # 全部试验记录
```

## 4. 最小可用模板

```python
import numpy as np
import optuna
import xgboost as xgb
from sklearn.datasets import fetch_california_housing
from sklearn.model_selection import KFold, cross_val_score

X, y = fetch_california_housing(return_X_y=True, as_frame=True)
cv = KFold(n_splits=5, shuffle=True, random_state=42)

def objective(trial):
    params = {
        "max_depth":        trial.suggest_int("max_depth", 3, 10),
        "learning_rate":    trial.suggest_float("learning_rate", 0.01, 0.3, log=True),
        "subsample":        trial.suggest_float("subsample", 0.5, 1.0),
        "colsample_bytree": trial.suggest_float("colsample_bytree", 0.5, 1.0),
        "reg_lambda":       trial.suggest_float("reg_lambda", 0.1, 10, log=True),
    }
    model = xgb.XGBRegressor(
        **params, n_estimators=300,
        random_state=42, verbosity=0, n_jobs=1, tree_method="hist",
    )
    rmse = -cross_val_score(
        model, X, y, cv=cv,
        scoring="neg_root_mean_squared_error", n_jobs=1,
    ).mean()
    return rmse

study = optuna.create_study(direction="minimize")
study.optimize(objective, n_trials=50, show_progress_bar=True)

print(study.best_value, study.best_params)
```

要点：

- **搜索空间直接写在 `suggest_*` 里**，不需要单独的 `param_grid`；
- `suggest_int` / `suggest_float` / `suggest_categorical` 对应整数、连续、类别；
- `log=True` 用于数量级跨度大的参数（学习率 1e-4 到 1e-1）；
- 目标函数返回**越小越好**的指标，`direction="minimize"`；
- sklearn 的 `neg_root_mean_squared_error` 要取负号才是 RMSE。

课堂对比：

| 方法 | 试验数 | 最佳 RMSE |
|---|---|---|
| 随机搜索 | 60 | 0.4521 |
| Optuna（TPE） | 50 | 0.4509 |

用更少的试验拿到更好的结果，这是“学习历史”的作用。11.19 课堂另一次 50 次搜索得到最佳 MSE 0.438（depth=10，lr=0.04），数值随数据划分和搜索空间变化，不必强行对齐。

## 5. 固定随机种子与参数交互

```python
sampler = optuna.samplers.TPESampler(
    seed=42,             # 可复现
    multivariate=True,   # 建模参数之间的交互
)
study = optuna.create_study(direction="minimize", sampler=sampler)
```

- `seed`：同一份代码跑两遍结果一致，方便论文/作业复现；
- `multivariate=True`：TPE 默认假设参数独立，开启后会考虑联合分布。参数之间有明显交互（如深度与学习率）时建议打开。

## 6. 搜索空间怎么定

| 参数 | 建议范围 | 采样方式 |
|---|---|---|
| `max_depth` | 3–10 | `suggest_int` |
| `learning_rate` | 0.01–0.3 | `suggest_float(..., log=True)` |
| `n_estimators` | 100–2000 | `suggest_int`，配合早停 |
| `subsample` | 0.5–1.0 | `suggest_float` |
| `colsample_bytree` | 0.5–1.0 | `suggest_float` |
| `reg_lambda` | 0.1–10 | `suggest_float(..., log=True)` |
| `gamma` | 0–5 | `suggest_float` |
| `min_child_weight` | 1–30 | `suggest_int` |

范围不要一上来给得过宽：搜索空间越大，需要的 trial 越多。先按经验范围收窄，再逐步调整。

## 8. 什么时候不用 TPE

- 参数少于 5 个、全连续、单次评估极贵：高斯过程可能更省 trial；
- 纯随机基线对照：用 `RandomSampler`；
- 需要严格的网格覆盖：直接 `GridSampler`，但一般不建议。
