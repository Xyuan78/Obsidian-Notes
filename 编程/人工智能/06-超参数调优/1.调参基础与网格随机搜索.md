# 调参基础与网格随机搜索

模型结构定下来之后，超参数决定它到底能发挥几成。网格搜索和随机搜索是最早的系统化方法：把候选值列出来，逐个训练、比较。它们简单可靠，但没有记忆。

## 1. 参数与超参数

| 类型 | 谁决定 | 例子 |
|---|---|---|
| 参数 | 训练算法学出来 | 线性回归的 $w,b$；神经网络的权重 |
| 超参数 | 训练前人为设定 | 树深、学习率、树的数量、正则系数 |

调参调的是超参数。它们不能通过一次 `fit` 得到，只能“试一组、训一次、看指标”。

## 2. 先建立基线

任何调参之前，先用默认参数跑一遍，记录：

- 数据规模、特征数；
- 训练集/验证集指标；
- 训练耗时。

没有基线，就无法判断调参是变好还是变坏。课上在加州房价上先用默认 XGBoost 跑出 RMSE，再开始搜。

## 3. 交叉验证

只切一次验证集，结果受切分随机性影响。K 折交叉验证把训练集分成 K 份，轮流留一份验证，其余训练，取平均：

```python
from sklearn.model_selection import KFold, cross_val_score

cv = KFold(n_splits=5, shuffle=True, random_state=42)
scores = cross_val_score(model, X, y, cv=cv,
                         scoring="neg_root_mean_squared_error")
rmse = -scores.mean()
```

注意：

- sklearn 的 `neg_root_mean_squared_error` 返回负值，因为它的约定是“分数越大越好”；取负号才是 RMSE。
- 交叉验证只在**训练集**内部做，测试集留到最后用一次。

## 4. 网格搜索

把每个参数的可能值列成表，做笛卡尔积，全部跑一遍：

```python
from sklearn.model_selection import GridSearchCV
from xgboost import XGBRegressor

param_grid = {
    "max_depth": [3, 5, 7, 9],
    "learning_rate": [0.01, 0.05, 0.1, 0.2],
    "n_estimators": [100, 300, 500],
}

grid = GridSearchCV(
    XGBRegressor(random_state=42, n_jobs=1),
    param_grid,
    cv=5,
    scoring="neg_root_mean_squared_error",
    n_jobs=-1,
)
grid.fit(X_train, y_train)

print(grid.best_params_)
print(-grid.best_score_)
```

组合数 = $4\times4\times3=48$ 组，每组 5 折，共 240 次训练。

### 4.1 网格搜索的问题

| 问题 | 说明 |
|---|---|
| 组合爆炸 | 参数和取值一多，组合数指数增长 |
| 无记忆 | 第 50 次和第 1 次毫无关系，前面的结果不影响下一步 |
| 算力平均分配 | 小模型几秒、大模型几分钟，但网格对每组一视同仁 |
| 取值离散 | 连续参数只能取有限几个点，最优点可能在点之间 |

## 5. 随机搜索

不再枚举所有组合，而是在每个参数的分布里随机采样，跑固定次数：

```python
from sklearn.model_selection import RandomizedSearchCV
from scipy.stats import loguniform, randint

param_dist = {
    "max_depth": randint(3, 11),
    "learning_rate": loguniform(1e-2, 3e-1),
    "n_estimators": randint(100, 800),
}

search = RandomizedSearchCV(
    XGBRegressor(random_state=42, n_jobs=1),
    param_dist,
    n_iter=60, cv=5,
    scoring="neg_root_mean_squared_error",
    random_state=42, n_jobs=-1,
)
search.fit(X_train, y_train)
```

经验上，同样预算下随机搜索常比网格搜索好：大多数参数只有少数几个真正重要，网格会在不重要的维度上浪费大量组合。

课堂对比（加州房价，RMSE 越小越好）：

| 方法 | 试验数 | 最佳 RMSE |
|---|---|---|
| 随机搜索 | 60 | 0.4521 |
| Optuna（TPE） | 50 | 0.4509 |

## 6. 手工调参的直觉

课上完整演示了人脑调参的过程（RMSE）：

| 轮次 | max_depth | learning_rate | RMSE | 结论 |
|---|---|---|---|---|
| 1 | 6 | 0.1 | 0.48 | 起点 |
| 2 | 8 | 0.1 | 0.46 | 深一点更好 |
| 3 | 10 | 0.1 | 0.49 | 太深过拟合，边界在 8 附近 |
| 4 | 8 | 0.05 | 0.45 | 降学习率更好 |
| 5 | 8 | 0.03 | 0.44 | 继续降 |
| 6 | 8 | 0.01 | 0.46 | 降太多欠拟合 |
| 7 | 7 | 0.04 | 0.43 | 在边界附近精调 |

这个过程说明两件事：

1. 好的调参是**有记忆**的：每一步都参考上一步的结果；
2. 人脑的局限：同时盯两个参数还行，三个以上就乱；能记住的试验也就十来次。

贝叶斯优化就是把这段直觉自动化、扩展到高维（见 [[2.贝叶斯优化原理]]）。

## 7. 调参的纪律

- **测试集只在最后用一次**，调参全程用交叉验证；
- **一次只改一个维度**，否则不知道是谁起的作用；
- **记录每次试验**：参数、分数、耗时，否则无法复盘；
- **先调影响大的参数**：树深、学习率、树数量，再调正则和采样；
- **别在验证集上过拟合**：跑几百次后，最好的验证分数可能只是运气。
