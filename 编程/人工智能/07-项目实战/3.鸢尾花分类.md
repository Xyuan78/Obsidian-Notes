# 鸢尾花分类

鸢尾花是最常用的入门分类数据集：150 个样本、4 个特征、3 个品种。先用 sklearn 的线性/逻辑回归建立直觉，再用 PyTorch 的 MLP 走一遍深度学习完整流程。

## 1. 数据

| 项目 | 内容 |
|---|---|
| 样本数 | 150 |
| 特征 | 花萼长度、花萼宽度、花瓣长度、花瓣宽度（4 维） |
| 类别 | setosa、versicolor、virginica（3 类） |
| 划分 | 训练 120，测试 30 |

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split

iris = load_iris()
X, y = iris.data, iris.target

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42, stratify=y
)
```

## 2. sklearn 基线

### 2.1 线性回归（反面教材）

```python
from sklearn.linear_model import LinearRegression

model = LinearRegression().fit(X_train, y_train)
print(model.score(X_train, y_train), model.score(X_test, y_test))
```

训练/测试约 93%–94%。线性回归把类别当成连续数值，虽然碰巧能分对大部分，但输出的 1.7 这种值没有概率含义，不适合作为分类模型。

### 2.2 逻辑回归

```python
from sklearn.linear_model import LogisticRegression
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
X_train_s = scaler.fit_transform(X_train)
X_test_s = scaler.transform(X_test)

clf = LogisticRegression(max_iter=1000)
clf.fit(X_train_s, y_train)
print(clf.score(X_train_s, y_train), clf.score(X_test_s, y_test))
```

课堂结果：训练集约 99.8%，测试集约 92%。

### 2.3 岭回归与 Lasso 的系数轨迹

```python
import numpy as np
from sklearn.linear_model import Ridge

alphas = np.logspace(-3, 3, 30)
coefs = []
for a in alphas:
    m = Ridge(alpha=a).fit(X_train_s, y_train)
    coefs.append(m.coef_.ravel())
```

鸢尾花上 4 个特征的轨迹：$\alpha$ 到 10 之前基本稳定，之后快速下降，到 20 附近接近 0。Lasso 在 $\alpha\approx5$ 时就有特征归零，说明花瓣宽度等特征贡献最大，可以据此筛特征。

> [!note] 这里的系数是“对类别分数的贡献”
> 多分类逻辑回归/线性模型每个类别都有一组系数。画轨迹前要明确画的是哪个类别的系数，否则曲线对不上。

## 3. PyTorch MLP

### 3.1 预处理

```python
import torch
from torch.utils.data import TensorDataset, DataLoader
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
X_train_s = scaler.fit_transform(X_train)     # 只在训练集 fit
X_test_s = scaler.transform(X_test)

X_train_t = torch.tensor(X_train_s, dtype=torch.float32)
y_train_t = torch.tensor(y_train, dtype=torch.long)
X_test_t = torch.tensor(X_test_s, dtype=torch.float32)
y_test_t = torch.tensor(y_test, dtype=torch.long)

train_ds = TensorDataset(X_train_t, y_train_t)
train_loader = DataLoader(train_ds, batch_size=16, shuffle=True)
```

要点：

- 标准化只在训练集上 `fit`，测试集只 `transform`；
- 标签用 `long`（int64），`CrossEntropyLoss` 要求整数索引；
- batch 取 2 的幂，16 是课堂设置。

### 3.2 模型

```python
import torch.nn as nn

class IrisMLP(nn.Module):
    def __init__(self, input_size=4, hidden_size=8, output_size=3):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(input_size, hidden_size),
            nn.ReLU(),
            nn.Linear(hidden_size, hidden_size),
            nn.ReLU(),
            nn.Linear(hidden_size, output_size),
        )

    def forward(self, x):
        return self.net(x)
```

输出层 3 个神经元对应 3 个类别，不加 Softmax。

### 3.3 训练

```python
model = IrisMLP()
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

train_losses, test_accs = [], []

for epoch in range(10):
    model.train()
    total_loss = 0
    for X_batch, y_batch in train_loader:
        optimizer.zero_grad()
        logits = model(X_batch)
        loss = criterion(logits, y_batch)
        loss.backward()
        optimizer.step()
        total_loss += loss.item()
    train_losses.append(total_loss / len(train_loader))

    model.eval()
    correct = 0
    with torch.no_grad():
        logits = model(X_test_t)
        pred = logits.argmax(dim=1)
        correct = (pred == y_test_t).sum().item()
    test_accs.append(correct / len(y_test_t))
```

课堂结果：10 轮后测试集 90% 以上，最终评估 96.7%。

### 3.4 单样本预测

```python
model.eval()
with torch.no_grad():
    x = torch.tensor([[5.1, 3.5, 1.4, 0.2]], dtype=torch.float32)
    x = torch.tensor(scaler.transform(x.numpy()), dtype=torch.float32)
    logits = model(x)
    probs = torch.softmax(logits, dim=1)
    print(probs, probs.argmax(dim=1))
```

注意新样本也要用训练集的标准化参数。

## 4. 两种实现对比

| 维度 | sklearn 逻辑回归 | PyTorch MLP |
|---|---|---|
| 代码量 | 几行 | 几十行 |
| 可解释性 | 系数清楚 | 黑盒 |
| 小数据表现 | 92% 左右 | 96% 左右 |
| 是否需要标准化 | 是（收敛） | 是（收敛） |
| 适合 | 快速基线 | 理解训练过程 |

在小数据上，MLP 的优势不明显，甚至可能因为参数太多而过拟合。鸢尾花主要用来练流程，不代表深度学习在所有任务上都更好。

## 5. 常见问题

| 问题 | 原因 | 处理 |
|---|---|---|
| 准确率不升 | 标签不是 long、忘记 `zero_grad` | 检查 dtype 和循环四步 |
| 评估波动 | 没切 `eval()` | 评估前 `model.eval()` |
| 新样本预测离谱 | 忘记标准化 | 用训练集的 scaler `transform` |
| 训练集 100%、测试低 | 模型太大/训练太久 | 减层、加 Dropout、早停 |
