# 泰坦尼克生存预测

第一个完整分类项目：用乘客信息预测是否幸存。数据量小、特征直观，适合把预处理、切分、模型对比、过拟合观察串一遍。

## 1. 任务与数据

- 目标：`Survived`，1 = 幸存，0 = 遇难；
- 特征：舱位等级（Pclass）、性别（Sex）、年龄（Age）、兄弟姐妹/配偶数（SibSp）、父母/子女数（Parch）、票价（Fare）、登船口岸（Embarked）；
- 数据量约 891 条，存在缺失值。

> [!warning] 数据量小
> 小样本上测试集准确率的波动很大。一次 80% 不代表模型稳定，换 random_state 可能变成 76%。结论要看趋势，不要抠单个数字。

## 2. 预处理流程

```python
import pandas as pd
from sklearn.model_selection import train_test_split

data = pd.read_csv("titanic.csv")

# 1. 选特征
features = ["Pclass", "Sex", "Age", "SibSp", "Parch", "Fare", "Embarked"]
X = data[features].copy()
y = data["Survived"]

# 2. 缺失值
X["Age"] = X["Age"].fillna(X["Age"].mean())
X["Embarked"] = X["Embarked"].fillna(X["Embarked"].mode()[0])

# 3. 类别编码
X["Sex"] = (X["Sex"] == "female").astype(int)
X["Embarked"] = X["Embarked"].map({"S": 0, "C": 1, "Q": 2})

# 4. 切分
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42, stratify=y
)
```

要点：

- `fillna(mean)` 只是起点，也可以试中位数、众数、按舱位分组填；
- `astype(int)` 把布尔值转成 0/1，模型才认；
- `stratify=y` 保证训练/测试中幸存比例一致；
- 标准化对决策树没影响，对 KNN/SVM 必须做。

## 3. 模型对比（课堂实测）

| 模型 | 训练集 | 测试集 | 说明 |
|---|---|---|---|
| 线性回归 | 36% | 37% | 分类任务用回归，效果差 |
| 逻辑回归 | 78% | 79% | 小样本表现稳定 |
| 决策树（默认） | 96%–97% | 79% | 严重过拟合 |
| 决策树（max_depth=3） | 下降 | 仍不到 80% | 过拟合缓解但欠拟合 |
| KNN（未归一化） | 78% | 69% | 量纲主导距离 |
| KNN（归一化） | 84% | 81% | 明显提升 |
| SVM（未归一化） | 很低 | 很低 | 必须标准化 |

这组数字最有价值的地方不是排名，而是三个现象：

1. **线性回归不能做分类**；
2. **决策树训练集接近 100% 是过拟合信号**；
3. **距离类算法不归一化会崩**。

## 4. 观察过拟合

```python
from sklearn.tree import DecisionTreeClassifier

train_scores, test_scores = [], []
for depth in range(3, 20):
    clf = DecisionTreeClassifier(max_depth=depth, random_state=42)
    clf.fit(X_train, y_train)
    train_scores.append(clf.score(X_train, y_train))
    test_scores.append(clf.score(X_test, y_test))

import matplotlib.pyplot as plt
plt.plot(range(3, 20), train_scores, label="train")
plt.plot(range(3, 20), test_scores, label="test")
plt.legend()
plt.show()
```

训练集一路升到 96%，测试集从 0.8 降到 0.7 左右。这条分叉曲线就是“模型开始背答案”的证据。

## 5. 特征工程

| 方向 | 做法 | 理由 |
|---|---|---|
| 家庭规模 | `SibSp + Parch + 1` | 大家庭和小家庭生存率都低，中间最高 |
| 是否独身 | `(SibSp == 0) & (Parch == 0)` | 独身乘客缺少互助 |
| 年龄分段 | 0–12、13–18、19–35、36–60、60+ | 儿童优先救援，非线性关系更明显 |
| 称呼/头衔 | 从姓名提取 Mr/Mrs/Miss | 隐含性别、婚姻、社会地位 |

特征是否有效，必须用交叉验证对比，不能只看训练集。

## 6. 决策树可视化

```python
from sklearn.tree import plot_tree

clf = DecisionTreeClassifier(max_depth=3, random_state=42)
clf.fit(X_train, y_train)

plt.figure(figsize=(14, 8))
plot_tree(clf, feature_names=features, class_names=["遇难", "幸存"], filled=True)
plt.show()
```

三层树的可读结论：性别是根节点，其次是年龄和舱位；有亲属同行也会提高生存率。

## 7. 经验总结

- 分类问题先用逻辑回归做基线，再看树模型；
- 树模型先限制深度，别用默认参数交作业；
- KNN/SVM 必须归一化，且只能对 `X` 做；
- 特征工程（家庭规模、年龄分段）往往比换模型更有效；
- 小数据集不要反复调参追 1% 的提升，容易过拟合测试集。
