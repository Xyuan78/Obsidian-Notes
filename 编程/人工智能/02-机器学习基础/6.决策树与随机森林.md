# 决策树与随机森林

决策树是“用一系列 if-else 把数据切开”的模型，可解释性最好，但单棵树极易过拟合。随机森林用很多棵不同的树投票，把方差降下来，是最常用的表格数据基线模型之一。

## 一、决策树

### 1. 三个要素

1. **特征选择**：每个节点挑哪个特征来切分；
2. **树的生成**：从根节点递归往下分，直到节点内样本足够纯或达到停止条件；
3. **剪枝**：限制深度或合并节点，防止过拟合。

### 2. 纯度的度量

#### 信息熵

$$
H(D) = -\sum_{k=1}^{K} p_k \log_2 p_k
$$

$p_k$ 是第 $k$ 类在节点中的比例。熵越大，类别越混杂；全部属于一类时熵为 0。前面的负号是为了把 $\log$ 的负值变成正数。

#### 信息增益

$$
\text{Gain}(D, A) = H(D) - \sum_{v} \frac{\lvert D_v\rvert}{\lvert D\rvert} H(D_v)
$$

父节点熵减去按特征 $A$ 切分后各子节点熵的加权平均。增益越大，说明这个特征把数据分得越纯。

#### 基尼不纯度

$$
\text{Gini}(D) = 1 - \sum_{k=1}^{K} p_k^2
$$

含义：从节点里随机抽两个样本，类别不一致的概率。全同类时为 0。**sklearn 默认用基尼**，计算比熵快（不用算 log）。

| 算法 | 分裂标准 |
|---|---|
| ID3 | 信息增益 |
| C4.5 | 信息增益比 |
| CART（sklearn） | 基尼不纯度 |

### 3. 工作示例：天气数据集

14 天里 9 天踢球、5 天不踢球。总基尼：

$$
\text{Gini} = 1 - \left(\frac{9}{14}\right)^2 - \left(\frac{5}{14}\right)^2 = 0.459
$$

按“天气”切分：

| 取值 | 天数 | 踢/不踢 | 基尼 |
|---|---|---|---|
| 晴 | 5 | 2/3 | $1-(2/5)^2-(3/5)^2=0.48$ |
| 阴 | 4 | 4/0 | 0 |
| 雨 | 5 | 3/2 | 0.48 |

加权平均：

$$
\frac{5}{14}\times0.48 + \frac{4}{14}\times0 + \frac{5}{14}\times0.48 = 0.343
$$

基尼增益：

$$
0.459 - 0.343 = 0.116
$$

“温度”的加权基尼为 0.440，增益只有 0.019，小于天气。所以根节点选**天气**。

阴天分支 4 天全部踢球，纯度已满，直接作为叶子“踢球”；晴天和雨天继续在剩余特征里算增益。课上算出晴天分支下湿度的信息增益最大（0.971），于是下一步按湿度分。

> [!tip] 手算技巧
> 先算总纯度，再对每个特征算“各取值的纯度 × 占比”求和，两者相减就是增益。纯度只看节点内各类占比，和特征的名字无关。

### 4. 优缺点

| 优点 | 缺点 |
|---|---|
| 不需要归一化（只看排序和比例） | 极易过拟合 |
| 可解释，能画出来给业务看 | 对数据微小变化敏感，方差大 |
| 能处理数值和类别特征 | 单棵树表达复杂边界能力有限 |
| 训练快 | 类别不均衡时偏向多数类 |

> [!warning] 不要给决策树做归一化
> KNN、SVM 必须归一化，决策树不需要。强行归一化不会提升效果，反而可能改变分裂点的选择，影响结果。

### 5. sklearn 实现

```python
from sklearn.tree import DecisionTreeClassifier, plot_tree

model = DecisionTreeClassifier(
    criterion="gini",     # 或 "entropy"
    max_depth=3,          # 限制深度，防过拟合
    random_state=42,      # 固定随机性，保证结果可复现
)
model.fit(X_train, y_train)

print(model.score(X_train, y_train))
print(model.score(X_test, y_test))

plt.figure(figsize=(16, 8))
plot_tree(model, feature_names=features, class_names=["遇难", "幸存"], filled=True)
plt.show()
```

泰坦尼克数据上的课堂结果：

| 设置 | 训练集 | 测试集 |
|---|---|---|
| 默认参数 | 96%–97% | 79% |
| max_depth=3 | 下降 | 仍不到 80% |

用循环把深度从 3 试到 20，训练集准确率一路升到 96%，测试集反而降到 0.7 左右——这条曲线是过拟合最直观的证据。

```python
train_scores, test_scores = [], []
for depth in range(3, 20):
    clf = DecisionTreeClassifier(max_depth=depth, random_state=42)
    clf.fit(X_train, y_train)
    train_scores.append(clf.score(X_train, y_train))
    test_scores.append(clf.score(X_test, y_test))

plt.plot(range(3, 20), train_scores, label="train")
plt.plot(range(3, 20), test_scores, label="test")
plt.legend()
plt.show()
```

## 二、随机森林

### 1. 怎么来的

单棵树方差大：换一批数据，树的结构就变了。随机森林训练上百棵树，每棵只看数据的一部分，最后投票/平均，错误互相抵消。

随机的两个层次：

1. **样本随机**：`bootstrap=True`，有放回抽样，每棵树拿到的样本不同；
2. **特征随机**：每次分裂只在随机选出的部分特征里挑最优，树与树的“思路”更不一样。

> [!note] 集成的关键前提
> 各棵树的错误必须**不完全相同**，平均才有意义。如果所有树都一样，集成等于没做。这正是要加两层随机的原因。

### 2. 核心参数

| 参数 | 含义 | 建议 |
|---|---|---|
| `n_estimators` | 树的数量，默认 100 | 越多越稳，但线性增加时间 |
| `max_features` | 每次分裂可选的特征数 | 越小树越多样，偏差可能上升 |
| `bootstrap` | 是否有放回抽样 | 默认 True，一般不改 |
| `max_depth` | 单棵树最大深度 | 不设也能靠集成控制方差 |
| `n_jobs` | 并行核数 | `-1` 用满所有 CPU |
| `random_state` | 随机种子 | 项目统一 42 |

```python
from sklearn.ensemble import RandomForestClassifier

rf = RandomForestClassifier(
    n_estimators=100,
    max_features="sqrt",
    n_jobs=-1,
    random_state=42,
)
rf.fit(X_train, y_train)
print(rf.score(X_test, y_test))

# 特征重要性
for name, imp in sorted(zip(features, rf.feature_importances_), key=lambda x: -x[1]):
    print(name, round(imp, 4))
```

### 3. 优缺点

| 优点 | 缺点 |
|---|---|
| 比单棵树稳定，泛化好 | 模型变大，预测变慢 |
| 几乎不用调参就能用 | 可解释性下降（只能看特征重要性） |
| 能输出特征重要性，辅助筛选 | 超高维、稀疏数据上表现差 |
| 对缺失值和异常值较鲁棒 | 回归任务对连续值的外推能力弱 |
