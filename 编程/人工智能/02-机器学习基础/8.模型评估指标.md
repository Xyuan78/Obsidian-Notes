# 模型评估指标

训练完模型，必须用测试集上的数字判断它到底行不行。回归看误差，分类看混淆矩阵和 AUC。指标选错，会把一个没用的模型当成好模型——尤其在不均衡数据上。

## 一、分类任务

### 1. 混淆矩阵

以“正类 = 患病/欺诈/幸存”为例，矩阵按“预测”在上、“实际”在左排列：

|  | 预测正 | 预测负 |
|---|---|---|
| **实际正** | TP（真正例） | FN（假负例，漏报） |
| **实际负** | FP（假正例，误报） | TN（真负例） |

四个格子记住含义比记名字重要：

- TP：该抓的抓到了；
- FN：该抓的漏了；
- FP：不该抓的抓了；
- TN：不该抓的也没抓。

### 2. 四个核心指标

$$
\text{准确率 Accuracy} = \frac{TP+TN}{TP+TN+FP+FN}
$$

$$
\text{精确率 Precision} = \frac{TP}{TP+FP}
$$

$$
\text{召回率 Recall} = \frac{TP}{TP+FN}
$$

$$
F_1 = \frac{2 \times \text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}
$$

| 指标 | 回答的问题 | 分母 |
|---|---|---|
| 准确率 | 整体猜对了多少 | 全部样本 |
| 精确率 | 报出来的正例里有多少是真的 | 预测为正 |
| 召回率 | 真正的正例里抓到了多少 | 实际为正 |
| F1 | 精确率和召回率的调和平均 | — |

精确率和召回率通常此消彼长：阈值调低，召回率上升，精确率下降；阈值调高则相反。F1 用来在两者之间取平衡。

### 3. 不同场景选哪个

| 场景 | 更看重 | 原因 |
|---|---|---|
| 工业质检 | 精确率 | 把次品当良品卖出去，退换货和品牌损失大 |
| 医疗诊断 | 召回率 | 漏诊（FN）会延误治疗，代价远大于误诊 |
| 信贷风控 | 两者兼顾，看 F1/AUC | 既要抓住违约，又不能误伤正常客户 |

> [!warning] 不均衡数据下准确率会骗人
> 1000 个样本里只有 10 个违约。全预测“不违约”也有 99% 准确率，但一个违约都没抓到。这类数据必须看召回率、F1 和 AUC。

### 4. 计算示例

> [!example] 示例（数字为说明用，非课堂原始数据）
> 100 个样本，实际正类 20 个。模型预测正类 25 个，其中 15 个确实是正类。
>
> - TP = 15，FP = 10，FN = 5，TN = 70
> - 准确率 = (15+70)/100 = 85%
> - 精确率 = 15/25 = 60%
> - 召回率 = 15/20 = 75%
> - F1 = 2×0.6×0.75/(0.6+0.75) ≈ 66.7%
>
> 检查：TP+FP=25 与预测正类数一致；TP+FN=20 与实际正类数一致。

### 5. ROC 与 AUC

很多分类器输出的是概率，不是 0/1。取不同阈值，就得到不同的 (FPR, TPR)：

$$
TPR = \frac{TP}{TP+FN} \quad(\text{召回率}), \qquad
FPR = \frac{FP}{FP+TN}
$$

以 FPR 为横轴、TPR 为纵轴，把所有阈值对应的点连起来就是 **ROC 曲线**。

- 曲线越靠近左上角越好：低误报的同时保持高召回；
- 对角线（AUC=0.5）相当于随机猜；
- **AUC** 是曲线下面积，取值 0.5–1。

| AUC | 诊断准确性 |
|---|---|
| 0.5–0.7 | 较低 |
| 0.7–0.9 | 中等 |
| > 0.9 | 较高 |

```python
from sklearn.metrics import roc_auc_score, confusion_matrix, classification_report

proba = model.predict_proba(X_test)[:, 1]
print(roc_auc_score(y_test, proba))
print(confusion_matrix(y_test, model.predict(X_test)))
print(classification_report(y_test, model.predict(X_test)))
```

> [!note] 训练集 AUC 0.99、测试集 0.75 说明什么
> 典型过拟合。训练集上模型几乎完美，换个数据集就掉下来。看到差距这么大，先想防过拟合，而不是继续调参。

## 二、回归任务

| 指标 | 公式 | 说明 |
|---|---|---|
| MAE | $\frac{1}{n}\sum\lvert y_i-\hat{y}_i\rvert$ | 平均绝对误差，单位与原值一致 |
| MSE | $\frac{1}{n}\sum(y_i-\hat{y}_i)^2$ | 均方误差，可导，常作损失 |
| RMSE | $\sqrt{MSE}$ | 均方根误差，单位与原值一致，对大误差敏感 |
| $R^2$ | $1-\frac{SSE}{SST}$ | 拟合优度，越接近 1 越好，可为负 |

泰坦尼克是分类任务，加州房价、Optuna 调参是回归任务，后者主要看 RMSE。

## 三、交叉验证

只切一次训练/测试，结果受这次切分影响大。K 折交叉验证把数据分成 K 份，轮流拿一份做验证、其余训练，最后取平均：

```python
from sklearn.model_selection import cross_val_score

scores = cross_val_score(model, X, y, cv=5, scoring="roc_auc")
print(scores.mean(), scores.std())
```

课程在 Optuna 调参里用的是 5 折，并把每折的 RMSE 取平均作为目标值。

## 四、指标与业务流程的对应

1. 业务先定指标（漏诊多还是误报多），再选模型和阈值；
2. 训练集指标只用于诊断过拟合，对外汇报用测试集/交叉验证；
3. 不均衡数据必须同时看多个指标，不能只报准确率；
4. 阈值不是固定的 0.5，可以按业务成本调整。
