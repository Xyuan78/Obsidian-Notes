# KNN与SVM

这两个算法代表了两种完全不同的分类思路：KNN 靠“看邻居”，SVM 靠“找边界”。它们的共同点是**都依赖距离或数值尺度，必须先做归一化**。

## 一、KNN（K 近邻）

### 1. 核心思想

一个样本的类别，由离它最近的 $k$ 个已知样本决定：

- 分类：$k$ 个邻居投票，票多者胜；
- 回归：$k$ 个邻居取平均（或中位数）。

没有一个“训练”出来的参数模型，训练阶段只是把数据存起来，预测时才计算距离，所以叫**惰性学习**。

### 2. 执行步骤

1. 计算待预测点到所有训练样本的距离；
2. 按距离升序排序；
3. 取前 $k$ 个；
4. 投票或平均，得到结果。

常用距离：

$$
d_{\text{欧式}} = \sqrt{\sum_i (x_i-y_i)^2}, \qquad
d_{\text{曼哈顿}} = \sum_i \lvert x_i-y_i\rvert
$$

默认用欧式距离；数据维度高或噪声大时可以试曼哈顿距离。

### 3. K 值怎么选

- 分类任务取**奇数**，避免 2:2 平票；
- $k$ 太小：对噪声敏感，容易过拟合；
- $k$ 太大：把远处的异类也算进来，欠拟合；
- 通常用交叉验证在几个候选值里选。

### 4. 为什么必须归一化

KNN 完全依赖距离。如果“票价”范围是 0–500，“年龄”范围是 0–80，那么距离几乎由票价决定，年龄再重要也被淹没。归一化后各特征都在同一量级，距离才有意义。

课上在泰坦尼克数据上的对比（课堂实测）：

| 处理 | 训练集 | 测试集 |
|---|---|---|
| 不归一化 | 78% | 69% |
| MinMax 归一化 | 84% | 81% |

```python
from sklearn.preprocessing import MinMaxScaler
from sklearn.neighbors import KNeighborsClassifier

scaler = MinMaxScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)     # 用训练集的参数变换测试集

model = KNeighborsClassifier(n_neighbors=5)
model.fit(X_train, y_train)
print(model.score(X_test, y_test))
```

> [!warning] 归一化只能做在 X 上
> 对标签 `y` 做归一化会把分类任务变成回归任务，结果完全错误。`fit_transform` 只在训练集上调用，测试集用 `transform`。

### 5. 其他用途

KNN 还能填补缺失值：对某列为空的行，在“没有空值的特征列”上找最近的 $k$ 行，用它们的均值/中位数补上。理论上比直接填全体均值更贴近该样本的实际情况。

## 二、SVM（支持向量机）

### 1. 核心思想

在两类数据之间找一个**间隔最大**的分界线（二维是直线，高维是超平面）。决定这条线的只有离它最近的几个点，这些点叫**支持向量**，其余样本删掉也不影响结果。

- 线性可分：直接找最大间隔超平面；
- 线性不可分：允许少量越界，用惩罚参数 $C$ 控制容忍程度；
- 非线性：用核函数把数据映射到高维，在高维里线性可分。

### 2. 核函数

| 核函数 | 特点 | 适用 |
|---|---|---|
| 线性核 | 不升维，最快 | 特征多、文本分类 |
| 多项式核 | 参数有阶数 $d$、系数、常数项；阶数越高越精细也越慢 | 中等非线性 |
| RBF（高斯） | 默认核；只需调 $\gamma$；高维表现好 | 通用 |
| Sigmoid | 非线性，某些场景优于多项式 | 特定数据 |

升维的直觉：二维平面上两个圆圈套在一起，画直线分不开；但如果增加一个“到圆心距离”的特征，就变成一维上的阈值问题，一条线就能分开。核函数就是隐式地做这种特征构造。

### 3. 两个关键参数

- **$\gamma$（gamma）**：RBF 核的宽度。越大，单个样本影响范围越小，边界越曲折，容易过拟合；越小，边界越平滑，可能欠拟合。
- **$C$（惩罚系数）**：对分错的容忍度。$C$ 越大越不容忍错误，容易过拟合；$C$ 越小边界越平滑。

两者要一起调，网格搜索是常用方法。

### 4. 归一化同样关键

SVM 也基于距离/内积，量纲差异会直接破坏超平面。课上记录：未做归一化时准确率只有 0.01–0.05，处理后大幅提升。

> [!warning] 课堂数字口径
> 同一份纪要先写“SVM 提升至 0.4 以上，超越 KNN 的 0.81–0.84”，两组数字互相矛盾，应是转写或记录误差。这里只保留“未归一化时极低、归一化后显著提升”这一结论，具体数值以实际代码输出为准。

### 5. 代码

```python
from sklearn.svm import SVC
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)

model = SVC(kernel="rbf", C=1.0, gamma="scale")
model.fit(X_train, y_train)
print(model.score(X_test, y_test))
```

## 三、对比

| 维度 | KNN | SVM |
|---|---|---|
| 思路 | 看最近的邻居 | 找最大间隔边界 |
| 训练 | 几乎不训练 | 需求解优化问题 |
| 预测 | 慢（要和所有样本算距离） | 快（只看支持向量） |
| 对量纲 | 极敏感 | 极敏感 |
| 非线性 | 靠 $k$ 和距离 | 靠核函数 |
| 可解释性 | 低 | 中（支持向量可看） |
| 大数据 | 慢 | 核方法在样本多时也慢 |

课上提到 SVM 的历史地位：在深度学习普及前，它是机器视觉的主力（HOG + AdaBoost + SVM 做人脸检测），至今在无 GPU 的嵌入式场景仍有使用。
