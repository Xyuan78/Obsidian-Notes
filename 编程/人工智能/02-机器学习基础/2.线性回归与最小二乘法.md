# 线性回归与最小二乘法

线性回归要回答一个问题：给定一组 $(x, y)$ 数据，怎样找一条直线，让所有点到直线的“纵向误差”总和最小。最小二乘法给出了这条直线的解析解，也引出了后面岭回归、逻辑回归、GBDT 残差等一系列概念。

## 1. 模型与残差

一元线性模型：

$$
\hat{y}_i = a + b x_i
$$

真实值 $y_i$ 与预测值 $\hat{y}_i$ 的差叫**残差**：

$$
e_i = y_i - \hat{y}_i
$$

残差是点到回归线在 $y$ 方向上的距离，可正可负。注意区分三个词：

| 概念 | 定义 |
|---|---|
| 残差 | $y_i - \hat{y}_i$，真实值减预测值 |
| 离差 | $x_i - \bar{x}$ 或 $y_i - \bar{y}$，单项减均值 |
| 方差 | 离差平方的平均，衡量数据离散程度 |

## 2. 最小二乘法

直接让残差之和最小不行——正负会抵消。让绝对值之和最小又不好求导。高斯的方法是**平方后求和**：

$$
Q(a, b) = \sum_{i=1}^{n}(y_i - a - b x_i)^2
$$

`Q` 是 `a`、`b` 的二次函数，存在唯一极小值。分别对 `a`、`b` 求偏导并令其为 0：

$$
\frac{\partial Q}{\partial a} = -2\sum (y_i - a - b x_i) = 0
$$

得到

$$
a = \bar{y} - b\bar{x}
$$

再对 `b` 求偏导，代入上式化简，得到离差形式：

$$
b = \frac{\sum_{i=1}^{n}(x_i-\bar{x})(y_i-\bar{y})}{\sum_{i=1}^{n}(x_i-\bar{x})^2}
$$

> [!tip] 记忆方法
> 分子是 $x$ 与 $y$ 的离差乘积和（协方差的上半部分），分母是 $x$ 的离差平方和。算完斜率再回代求截距。

### 工作示例

用课上收入—支出的例子：截距 $a = 200$，斜率 $b = 0.55$。

- 收入为 0 时支出为 200：代表基本刚性消费；
- 收入每增加 1 元，支出增加 0.55 元：新增收入中 55% 用于消费。

拟合优度（训练集上的 $R^2$）课上示例约为 0.90。

### 独立检查

手算一组小数据：$(1,2), (2,4), (3,5)$。

- $\bar{x}=2$，$\bar{y}=11/3$
- 分子：$(-1)(-5/3) + 0 + (1)(4/3) = 5/3 + 4/3 = 3$
- 分母：$1 + 0 + 1 = 2$
- $b = 1.5$，$a = 11/3 - 1.5 \times 2 = 2/3$

代入 $x=3$：$\hat{y} = 2/3 + 1.5 \times 3 = 31/6 \approx 5.17$，与真实值 5 的残差约 $-0.17$。

## 3. 多元线性回归

多个特征时写成矩阵形式：

$$
\hat{y} = X\beta
$$

其中 $X$ 是 $n \times (p+1)$ 的设计矩阵（第一列补 1 对应截距），$\beta$ 是参数向量。损失函数写成范数形式：

$$
L(\beta) = \|y - X\beta\|_2^2 = (y-X\beta)^\top (y-X\beta)
$$

对 $\beta$ 求导并令其为 0：

$$
\frac{\partial L}{\partial \beta} = -2X^\top(y-X\beta) = 0
$$

得到**标准方程**：

$$
\hat{\beta} = (X^\top X)^{-1}X^\top y
$$

对应代码就是 [[2.NumPy数组与矩阵运算]] 里的 `np.linalg.inv(X.T @ X) @ X.T @ y`。

### 3.1 这个解成立的条件

$(X^\top X)$ 必须可逆，等价于 $X$ 满秩：特征之间**不能存在完全的线性关系**。

实际数据里完全共线很少见，但**高度相关**很常见（比如“房间数”和“卧室数”）。这叫多重共线性，后果是：

- 行列式接近 0，求逆数值不稳定；
- 系数估计方差很大，符号可能违背常识（明明正相关却算出负系数）；
- 模型失去可解释性。

处理办法：先看两两相关系数，绝对值大于 0.7 的考虑删掉一列；或者改用岭回归/Lasso（见 [[3.正则化：岭回归与Lasso]]）。

## 4. 评估指标

| 指标 | 公式 | 特点 |
|---|---|---|
| MAE | $\frac{1}{n}\sum\lvert y_i-\hat{y}_i\rvert$ | 单位与原变量一致，对异常值不敏感 |
| MSE | $\frac{1}{n}\sum (y_i-\hat{y}_i)^2$ | 可导，常作损失函数；单位是原变量平方 |
| RMSE | $\sqrt{MSE}$ | 单位和原变量一致，对大误差惩罚重 |
| $R^2$ | $1-\frac{SSE}{SST}$ | 拟合优度，越接近 1 越好，可以为负 |

其中 $SSE=\sum(y_i-\hat{y}_i)^2$，$SST=\sum(y_i-\bar{y})^2$。

$R^2$ 的含义：模型解释了多少比例的方差。测试集上算出来是负数，说明模型比“直接猜平均值”还差。

## 5. sklearn 实现

```python
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error, r2_score

# 特征必须是二维
X = np.array(data[["人均收入"]]).reshape(-1, 1)
y = np.array(data["房屋总价"]).reshape(-1, 1)

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42
)

model = LinearRegression()
model.fit(X_train, y_train)

print(model.coef_)        # 斜率
print(model.intercept_)   # 截距
print(model.score(X_test, y_test))   # R²

pred = model.predict(X_test)
print(mean_squared_error(y_test, pred))
```

可视化：先 `scatter` 画原始点，再用 `model.predict` 的结果画回归线。

```python
pred_all = model.predict(X)
plt.scatter(X, y)
plt.plot(X, pred_all, color="red")
plt.show()
```

> [!warning] 版本差异
> 高版本 Python/sklearn 里，`intercept_` 可能是数组，打印或参与计算前用 `float()` 转换，避免格式报错。

## 6. 线性回归做分类为什么不行

在泰坦尼克生存预测里直接用线性回归，训练集/测试集准确率只有 36%/37%。原因：线性回归输出的是任意实数，而分类需要 0/1 概率；它会把“幸存”拟合成一个连续值，阈值怎么切都不合适。分类要用逻辑回归（见 [[4.逻辑回归]]）。
