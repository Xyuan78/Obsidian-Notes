# 正则化：岭回归与Lasso

多重共线性会让标准方程 $(X^\top X)^{-1}$ 求不出来，或者求出来的系数离谱。岭回归和 Lasso 通过在损失函数里加一个惩罚项，把这个问题修好；Lasso 还额外具备特征选择能力。

## 1. 为什么需要正则化

线性回归的标准方程是 $\hat{\beta}=(X^\top X)^{-1}X^\top y$。当特征高度相关时，$X^\top X$ 接近奇异，逆矩阵数值不稳定，系数会变得非常大、符号乱跳。

最直接的办法是删特征（相关系数 > 0.7 的删一列），但特征很多或样本很少时不好操作。正则化的思路是：**不删特征，而是给系数加一个“惩罚”，不允许它无限变大**。

## 2. 岭回归（Ridge，L2）

损失函数加 L2 惩罚：

$$
L(\beta) = \|y-X\beta\|_2^2 + \lambda\|\beta\|_2^2
$$

求导令零，得到闭式解：

$$
\hat{\beta} = (X^\top X + \lambda I)^{-1}X^\top y
$$

$\lambda I$ 加在对角线上，相当于把矩阵“往单位阵方向拉”，只要 $\lambda>0$，矩阵就一定能求逆。

### 2.1 L2 惩罚的效果

- 系数被**整体压小**，但一般不会恰好等于 0；
- 模型更稳定，代价是训练集上的拟合变差；
- 用一点点准确率换可解释性和数值稳定，这是课程反复强调的“牺牲性能换可解释”。

### 2.2 岭迹图选 alpha

把不同 $\alpha$（即 $\lambda$）下的各特征系数画成折线：

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import Ridge

alphas = np.logspace(-3, 3, 30)   # 10^-3 到 10^3
coefs = []
for a in alphas:
    model = Ridge(alpha=a)
    model.fit(X_train, y_train)
    coefs.append(model.coef_.ravel())

plt.plot(alphas, coefs)
plt.xscale("log")
plt.xlabel("alpha")
plt.ylabel("系数")
plt.show()
```

横轴是 $\alpha$ 的对数，纵轴是各特征权重。选点的原则：

- $\alpha$ 太小：曲线还没稳定，共线性没被压住；
- $\alpha$ 太大：系数整体趋近 0，模型欠拟合；
- 取**曲线从平稳开始明显变化之前**的位置。鸢尾花例子中，$\alpha$ 到 10 之前系数基本稳定，之后急剧下降，到 20 附近接近 0，所以取 10 以内。

> [!note] 岭回归不挑特征
> 岭回归只是把系数压小，不会把某个特征彻底剔除。如果目标是“从 50 个特征里挑出 10 个”，用 Lasso。

## 3. Lasso（L1）

损失函数加 L1 惩罚：

$$
L(\beta) = \|y-X\beta\|_2^2 + \lambda\|\beta\|_1
$$

L1 的几何性质使最优解容易落在坐标轴上，因此**不重要的特征系数会被直接压成 0**，实现自动特征选择。求解通常用坐标下降或最小角回归，而不是普通梯度下降。

```python
from sklearn.linear_model import Lasso

model = Lasso(alpha=0.1)
model.fit(X_train, y_train)
print(model.coef_)        # 部分系数恰为 0
```

鸢尾花案例里，$\alpha$ 增大到 5 左右时就有特征权重归零，可以根据归零顺序判断哪些特征贡献小。

## 4. 两者对比

| 维度 | 岭回归 Ridge | Lasso |
|---|---|---|
| 惩罚项 | L2：$\sum \beta_j^2$ | L1：$\sum \lvert\beta_j\rvert$ |
| 系数 | 整体缩小，不归零 | 部分直接归零 |
| 特征选择 | 不能 | 能 |
| 共线性 | 擅长处理 | 相关特征中只保留一个，结果不稳定 |
| 求解 | 闭式解 | 坐标下降 / 最小角回归 |
| 适用 | 特征都可能有贡献、只想稳住模型 | 特征多、想筛掉无用特征 |

> [!tip] 实际项目怎么选
> 特征数量大（课上提到 40–60 个）时，先用 Lasso 做一轮筛选，缩短训练时间；筛选后再用岭回归或普通线性回归建模。两者不是互斥的，可以串联使用。

## 5. 与局部线性回归的区别

局部线性回归（LOESS 一类）解决的是**非线性**：把数据分段，每段单独拟合一条直线。分段越细，训练集拟合越好，但会把噪声也学进去，过拟合风险很大。它和正则化解决的问题不同：前者处理“曲线不直”，后者处理“系数不稳”。
