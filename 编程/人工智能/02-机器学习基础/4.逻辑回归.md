# 逻辑回归

逻辑回归名字里有“回归”，实际做的是分类：把线性组合的结果压到 0–1 之间，当成“属于正类的概率”。它是理解神经网络输出层和交叉熵损失的前置知识。

## 1. 从线性回归到分类

线性回归输出 $z = w^\top x + b$，取值范围是整个实数轴，没法直接当概率。需要一个函数把 $(-\infty, +\infty)$ 映射到 $(0, 1)$，这就是 Sigmoid：

$$
\sigma(z) = \frac{1}{1 + e^{-z}}
$$

性质：

- $\sigma(0)=0.5$；
- $z \to +\infty$ 时趋近 1，$z \to -\infty$ 时趋近 0；
- 单调递增、连续可导；
- 导数可以用自身表示：$\sigma'(z)=\sigma(z)(1-\sigma(z))$，计算很方便。

预测规则：

$$
\hat{y} =
\begin{cases}
1, & \sigma(z) \ge 0.5 \\
0, & \sigma(z) < 0.5
\end{cases}
$$

由于 $\sigma(z)\ge 0.5 \iff z \ge 0$，本质上就是看线性组合的符号。

## 2. 为什么要用 Sigmoid（Logit 变换）

设正类概率为 $p$，负类概率为 $1-p$。把两者的比值取对数：

$$
\log\frac{p}{1-p} = z = w^\top x + b
$$

左边叫 **Logit**，取值范围是整个实数轴；右边是线性函数，两边范围一致，可以直接建模。反解出 $p$：

$$
p = \frac{1}{1+e^{-z}} = \sigma(z)
$$

所以逻辑回归的假设是：**对数几率是特征的线性组合**。

## 3. 参数估计：极大似然

似然函数是每个样本按预测概率出现的联合概率：

$$
L(w) = \prod_{i=1}^{n} p_i^{y_i}(1-p_i)^{1-y_i}
$$

直接求最大值要处理连乘，取对数变成求和：

$$
\ell(w) = \sum_{i=1}^{n}\left[y_i\log p_i + (1-y_i)\log(1-p_i)\right]
$$

对 $w$ 求偏导令零，**没有闭式解**，要用梯度下降/牛顿法迭代求解。这一点和线性回归不同：线性回归能一步算出来，逻辑回归只能逼近。

> [!note] 这个式子就是交叉熵
> 取负号后就是二分类交叉熵损失。深度学习里的 `BCELoss` 和它是同一个东西，见 [[3.激活函数与损失函数]]。

## 4. 系数的解释：优势比

逻辑回归的系数不能直接说“增加 1 单位，概率增加多少”，因为概率是非线性的。常用**优势比**（odds ratio）：

$$
\text{OR}_j = e^{w_j}
$$

含义：其他变量不变时，$x_j$ 每增加 1 个单位，患病的“优势”（得病概率/不得病概率）变为原来的 $e^{w_j}$ 倍。

课上的食管癌案例：

| 因素 | 优势比 | 解释 |
|---|---|---|
| 抽烟（控制饮酒） | 2.42 | 抽烟者患食管癌的优势是不抽烟者的 2.42 倍 |
| 饮酒（控制抽烟） | 1.69 ≈ $e^{0.53}$ | 饮酒者优势约为 1.69 倍 |

## 5. 代码实现

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import accuracy_score

iris = load_iris()
X, y = iris.data, iris.target

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42, stratify=y
)

scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)

model = LogisticRegression(max_iter=1000)
model.fit(X_train, y_train)

print(model.score(X_train, y_train))
print(model.score(X_test, y_test))
print(model.predict(X_test[:5]))
```

> [!warning] 收敛警告
> 特征量纲差异大时会出现 `ConvergenceWarning: lbfgs failed to converge`。先做标准化，或把 `max_iter` 调大（默认 100）。归一化只能作用在 `X` 上，绝不能对标签 `y` 做。

鸢尾花上的课堂结果：训练集约 99.8%，测试集约 92%。

## 6. 多分类怎么办

二分类用 Sigmoid，多分类用 Softmax：把每个类别的得分转成概率，所有类别概率之和为 1。

$$
p_k = \frac{e^{z_k}}{\sum_{j} e^{z_j}}
$$

sklearn 的 `LogisticRegression` 在多分类数据上会自动改用 Softmax（多项式逻辑回归）。推导和梯度见 [[3.激活函数与损失函数]]。

## 7. 和线性回归的对比

| 维度 | 线性回归 | 逻辑回归 |
|---|---|---|
| 任务 | 回归 | 分类 |
| 输出 | 任意实数 | 0–1 概率 |
| 假设 | $y = w^\top x + b + \varepsilon$ | $\log\frac{p}{1-p}=w^\top x+b$ |
| 参数求解 | 闭式解 | 迭代优化 |
| 损失 | 平方误差 | 交叉熵/对数似然 |
| 泰坦尼克表现 | 36% / 37% | 78% / 79% |
