## 2. 基本数据类型

### 2.1 整型

Python 的整数不是定长，只受内存限制。四种字面量写法：

```python
10      # 十进制
0b1010  # 二进制
0o12    # 八进制
0xa     # 十六进制
```

### 2.2 浮点与复数

```python
3.14
34.        # 等价 34.0
9.34e2     # 科学计数法，934.0

z = 3 + 4j
z.real     # 3.0
z.imag     # 4.0
```

### 2.3 字符串

单引号、双引号、三引号都能定义字符串；三引号可跨行。转义字符里最常用的是 `\n`（换行）、`\t`（制表符）、`\\`（反斜杠本身）。

```python
s = "python"
len(s)          # 6
eval("1 + 2")   # 3，把字符串当 Python 语句执行
```

> [!warning] 中文标点是最常见的“非法字符”
> `SyntaxError: invalid character` 多半是从 PPT/网页复制代码时，双引号或冒号变成了中文全角。肉眼几乎看不出，改回英文标点即可。

### 2.4 布尔

`True` / `False` 本质是 `1` / `0`，可以直接参与运算：

```python
x = False
x + (5 > 4)   # 1
```

## 3. 复合数据类型

| 类型 | 写法 | 有序 | 可变 | 元素可否重复 |
|---|---|---|---|---|
| 列表 list | `[1, 2, 3]` | 是 | 是 | 可以 |
| 元组 tuple | `(1, 2, 3)` | 是 | 否 | 可以 |
| 字典 dict | `{"a": 1}` | 否（3.7+ 保留插入顺序） | 是 | 键不能重复 |
| 集合 set | `{1, 2, 3}` | 否 | 是 | 自动去重 |

```python
a = [1, 2, 3]
a.append(4)      # [1, 2, 3, 4]
a[0] = 9         # 列表可改
a.remove(3)

t = (1, 2, 3)
# t[0] = 9  → TypeError，元组不可改

d = {"name": "tom", "code": 410012}
d["name"]        # 'tom'

s = {"Tom", "Jim", "Tom"}   # {'Tom', 'Jim'}，重复元素被去掉
empty = set()                # 空集合必须用 set()，{} 是空字典
```

> [!tip] 元组常出现在“函数返回多个值”的场景
> `divmod(7, 3)` 返回 `(2, 1)`，`array.shape` 返回 `(行数, 列数)`。看到小括号包着的多个值，基本就是元组。

## 4. 语句结构

```python
# 分支
if score >= 90:
    level = "A"
elif score >= 60:
    level = "B"
else:
    level = "C"

# while：必须先有终止条件
i = 0
while i < 3:
    print(i, end="")
    i += 1

# for：遍历序列或 range
for i in range(0, 6, 2):   # 0 2 4，前闭后开
    print(i)
```

`range(start, end, step)` 的三个参数都可省略：`range(6)` 是 0–5；`range(2, 6)` 是 2–5；`range(0, 6, 2)` 是 0、2、4。**包头不包尾**。

进度条小例子（课堂代码）：

```python
import time

def progress_bar(num):
    for _ in range(num):
        print("█", end="")
        time.sleep(0.1)
    print("\nFinished!")

progress_bar(30)
```

## 5. 函数与模块

```python
def myfun(x, y):
    return x * x + y * y

myfun(3, 4)   # 25
```

模块就是 `.py` 文件。三种导入方式：

```python
import math                 # 用 math.sqrt 调用
from math import sqrt       # 直接用 sqrt
from math import *          # 导入全部，容易和本地同名函数冲突
```

> [!warning] `from 模块 import *` 会覆盖本地同名函数
> 课上的例子：先 `import my_module`，本地又定义 `my_print`，调用 `my_module.my_print` 不受影响；换成 `from my_module import *` 后本地定义被覆盖。正式项目优先用前两种写法。

常用内置函数：`print`、`type`、`id`、`len`、`abs`、`pow`、`round`、`divmod`、`dir`、`help`。

```python
round(5.123, 2)   # 5.12
divmod(7, 3)      # (2, 1)
dir(list)         # 列出 list 的所有属性和方法
```

`random` 模块的四个常用函数：

```python
import random

random.uniform(2, 6)      # 2~6 的随机浮点数
random.randint(1, 8)      # 1~8 的随机整数
random.choice("python")   # 从序列中随机取一个元素
num = [1, 2, 3, 4, 5]
random.shuffle(num)       # 原地打乱，没有返回值
```

## 6. 面向对象

### 6.1 为什么需要类

面向过程写下去，每加一个需求就要改原有函数，容易“牵一发动全身”。面向对象用**继承**把变化隔开：老版本的类不动，新版本写成子类，只覆盖需要改的方法。这就是开闭原则——对扩展开放，对修改关闭。

### 6.2 类与对象

类是模板，对象是按模板创建出来的实例。类里有两部分：**属性**（数据）和**方法**（能修改数据的函数）。

```python
class Person:
    def __init__(self, name, age):
        self.name = name      # 实例属性
        self.age = age

    def introduce(self):
        return f"我是{self.name}，今年{self.age}岁"

p = Person("张三", 20)        # 实例化
print(p.introduce())
```

两个必须记住的语法：

- `__init__` 是构造函数，创建对象时自动执行，前后各两个下划线；
- 所有实例方法的第一个参数固定写 `self`，指向当前对象，相当于 Java/C++ 的 `this`。

面向对象三大特性：

| 特性 | 含义 |
|---|---|
| 封装 | 数据和操作数据的方法放在同一个类里 |
| 继承 | 子类复用父类的属性和方法 |
| 多态 | 同一个方法名，在不同对象上有不同实现 |

### 6.3 继承与重写

```python
class Student(Person):
    def __init__(self, name, age, school):
        super().__init__(name, age)   # 复用父类初始化
        self.school = school

    def introduce(self):              # 重写父类方法
        return super().introduce() + f"，就读于{self.school}"

s = Student("李四", 21, "某大学")
print(s.introduce())
```

创建的是子类对象，调用同名方法时执行子类的版本；创建的是父类对象，就执行父类的版本。同一个方法名在不同对象上表现不同，这就是多态。

### 6.4 继承的代价与设计模式

课堂上特别提醒：继承不是越多越好。每加一个需求就派生一个子类，继承链会越来越长（课上提到有系统堆到七八层），运行变慢、维护变难。更常见的做法是**组合**——把新功能作为成员对象放进去，而不是继承。设计模式（工厂、单例、装饰器）就是对这些经验的总结。

> [!note] 与本课程的关系
> 后面定义 PyTorch 模型时会反复用到继承：`class MLP(nn.Module)` 继承 `nn.Module`，重写 `forward` 方法。理解“子类重写父类方法 + 调用 `super()`”是读懂模型代码的前提。

## 7. 常见错误

| 报错 | 原因 | 处理 |
|---|---|---|
| `invalid character` | 中文引号、中文冒号 | 改成英文标点 |
| `NameError: name 'x' is not defined` | 变量没定义、没 import、或 Jupyter 未运行前面的 cell | 补定义/import，或重启内核按顺序运行 |
| `IndentationError` | Tab 与空格混用 | 统一用 4 个空格 |
| `TypeError: 'tuple' object does not support item assignment` | 修改了元组 | 改用列表，或重新构造元组 |
