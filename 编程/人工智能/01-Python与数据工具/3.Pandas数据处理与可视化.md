# Pandas数据处理与可视化

拿到一份 CSV 之后，第一件事不是训练模型，而是把数据看清楚：多少行、有没有空值、类型对不对、分布是否偏斜、有没有异常值。这篇记录课程里从读取到清洗再到画图的完整流程。

## 1. 两个核心数据结构

| 结构 | 维度 | 说明 |
|---|---|---|
| `Series` | 一维 | 带索引的数组，像 Excel 的一列 |
| `DataFrame` | 二维 | 行索引 + 列索引，像一张表 |

```python
import pandas as pd

s = pd.Series([1, 2, 3], index=["a", "b", "c"])
df = pd.DataFrame({
    "name": ["张三", "李四"],
    "age": [20, 21],
})
```

## 2. 定位：loc 与 iloc

```python
df.loc[0, "age"]      # 按标签取
df.iloc[0, 1]         # 按位置取，第 1 行第 2 列
df.loc[:, ["name"]]   # 所有行、name 列，返回 DataFrame
df.iloc[:, 1]         # 所有行、第 2 列，返回 Series
```

> [!tip] 方括号切片的维度规则
> 行列都带冒号 → 得到 DataFrame；有任何一边不带冒号 → 得到 Series。与 NumPy 的规则一致，做运算前先确认形状。

## 3. 读取与体检

```python
data = pd.read_csv("cali_housing.csv", encoding="utf-8")
data.info()        # 行数、列数、非空数量、dtype
data.describe()    # count/mean/std/min/25%/50%/75%/max
data["房屋年龄"].value_counts()
data.columns = ["人均收入", "房屋年龄", ...]   # 重命名列
```

`info()` 里看三件事：

1. **非空数量**：和总行数不一致就说明有缺失；
2. **dtype**：`int64`/`float64` 能直接算，`object` 是字符串，必须转换；
3. **列名**：英文列名建议改成中文或统一命名，后面写代码不容易错。

`describe()` 里重点看 `mean` 和 `50%`（中位数）：平均值明显大于中位数，说明分布右偏，有极少的高值把均值拉高。课上举的例子：公司平均工资远高于中位数，说明高薪只属于少数高管。

> [!warning] 编码
> 中文 CSV 出现乱码时先试 `encoding="utf-8"`；Windows 上导出的文件常见 `gbk`，两种都试一次。

## 4. 缺失值与类型转换

### 4.1 填充缺失值

```python
data["Age"].fillna(data["Age"].mean(), inplace=True)
```

除了均值，还可以用中位数、众数，或用业务上合理的固定值。没有哪种方式永远最好，要看分布和缺失比例。

### 4.2 字符串转数字

模型只接受数值，类别字段必须编码：

```python
# 性别：female → 1，其余 → 0
data["Sex"] = (data["Sex"] == "female").astype(int)

# 登船口岸：字符串 → 0/1/2
mapping = {v: i for i, v in enumerate(data["Embarked"].unique())}
data["Embarked"] = data["Embarked"].map(mapping)
```

### 4.3 特征选择与衍生

```python
features = ["Pclass", "Sex", "Age", "SibSp", "Parch", "Fare", "Embarked"]
X = data[features]
y = data["Survived"]
```

可以按业务含义组合出新特征，比如“是否独身”（`SibSp == 0 & Parch == 0`）、年龄分段。是否有用要靠训练集/测试集对比验证，不能凭直觉下结论。

## 5. 划分数据集

```python
from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42, stratify=y
)
```

> [!warning] 不要手动按前后切分
> 数据往往按时间或类别排列，直接切前 70% 会让训练集和测试集分布不同。`train_test_split` 随机打乱；分类任务加 `stratify=y`，保证两边的类别比例一致（违约/不违约这类不均衡数据尤其重要）。

## 6. 探索性可视化

```python
import matplotlib.pyplot as plt

# 中文显示
plt.rcParams["font.sans-serif"] = ["KaiTi"]
plt.rcParams["axes.unicode_minus"] = False

# 直方图：看分布
n, bins, _ = plt.hist(data["人均收入"])
plt.show()

# 箱线图：看分位数和异常值
plt.boxplot(data["人均收入"])
plt.show()

# 散点图：看两个变量的关系
plt.scatter(data["小区经度"], data["小区纬度"], alpha=0.1)
plt.xlabel("经度")
plt.ylabel("纬度")
plt.show()
```

### 6.1 三种图的用途

| 图 | 回答的问题 | 关键参数 |
|---|---|---|
| 直方图 `hist` | 数据集中在哪个区间、是否右偏 | `bins` 控制分箱数量 |
| 箱线图 `boxplot` | 中位数、四分位、离群点 | 经验边界 $Q_1-1.5\,IQR$、$Q_3+1.5\,IQR$ |
| 散点图 `scatter` | 两个变量是否相关、空间分布 | `alpha` 透明度、`c` 颜色、`s` 大小、`cmap` 色系 |

加州房价的散点图用经度/纬度作坐标，颜色映射房价、点大小映射人口，可以直观看到旧金山和洛杉矶的高密度区，以及房价与收入在地理上的对应关系。

### 6.2 异常值怎么处理

```python
Q1 = data["人均收入"].quantile(0.25)
Q3 = data["人均收入"].quantile(0.75)
IQR = Q3 - Q1
outliers = data[data["人均收入"] > Q3 + 1.5 * IQR]
```

算出离群点不等于要删除。课上对人均收入的处理是**保留**：数据本身右偏、离群点数量很大（约 681 个），删掉会丢掉真实的高收入群体，反而让模型预测失真。异常值是否删除要结合业务判断。

## 7. 课堂代码要点

```python
# 一元线性回归前，必须把 Series 变成二维数组
medInc = np.array(data["人均收入"]).reshape(-1, 1)
price = np.array(data["房屋总价"]).reshape(-1, 1)

model.fit(medInc, price)
print(model.score(medInc, price))
print(model.intercept_, model.coef_)
```

`reshape(-1, 1)` 是固定写法：`-1` 让行数自动推断，`1` 表示一列。sklearn 的 `fit` 要求 `X` 是二维的。
