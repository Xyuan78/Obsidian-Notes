# MyBatis 环境搭建与快速入门

MyBatis 是半自动的 ORM 框架：它负责把 Java 对象与数据库记录互相映射，但 **SQL 由开发者自己写**，因此比全自动 ORM 更灵活、更可控。

## MyBatis 在技术栈中的位置

源文对 MyBatis 的四句定位：

- ORM 工具将应用程序的增删改查操作与关系数据库相互映射。
- 一张表对应一个对象。
- 允许直接编写 SQL 语句，更灵活。
- **框架基于 JDBC**。

最后一句是关键。MyBatis 并没有取代 JDBC，而是把 JDBC 中重复的部分（加载驱动、获取连接、创建 `PreparedStatement`、遍历 `ResultSet`、关闭资源）封装起来，只把"写什么 SQL"和"结果映射到哪个对象"留给使用者。

> [!info] 与 JDBC 的关系
> 如果把 JDBC 看作"手动挡"，MyBatis 是"自动挡但方向盘仍在你手里"：连接与结果集处理被封装，SQL 与映射关系仍由你决定。
> 前置知识见 [[8.JDBC技术]]。

MyBatis 可以使用简单的 XML 或注解进行配置和原始映射，将接口和 Java 的 POJO 映射成数据库的记录。本笔记走 **XML 路线**；注解路线见 [[9.注解编程、基础CRUD]]。

## 环境搭建六步

源文给出的搭建顺序（数字为源文原有编号）：

### 1. 新建 Maven 项目并加入依赖

```java
<!-- pom.xml -->
<dependencies>
    <!-- mybatis 的 jar 包 -->
    <dependency>
        <groupId>org.mybatis</groupId>
        <artifactId>mybatis</artifactId>
        <version>3.4.6</version>
    </dependency>

    <!-- mysql 8.0.19 的驱动包 -->
    <dependency>
        <groupId>mysql</groupId>
        <artifactId>mysql-connector-java</artifactId>
        <version>8.0.19</version>
    </dependency>

    <!-- 自动注解 getter 与 setter -->
    <dependency>
        <groupId>org.projectlombok</groupId>
        <artifactId>lombok</artifactId>
        <version>1.18.24</version>
        <scope>provided</scope>
    </dependency>
</dependencies>
```

> [!warning] 版本来自源文，不是当前推荐
> `mybatis 3.4.6`、`mysql-connector-java 8.0.19`、`lombok 1.18.24` 是源文写作时使用的版本。照抄可复现源文环境，但不要据此认为它们是最新版本。依赖可在 [mvnrepository](https://mvnrepository.com/) 查询。

### 2. 建立 Maven 目录结构

在 `main` 文件夹下建立：

- `java` 文件夹 —— 写 Java 代码的地方
- `resources` 文件夹 —— 放置配置文件的地方

即 Maven 标准布局 `src/main/java` 与 `src/main/resources`。配置文件必须放在 `resources` 下，否则类路径搜索不到。

### 3. 在 resources 下新建 db.properties

```properties
# db.properties

# 根据 mysql 版本确定驱动
db.mysql.driver = com.mysql.cj.jdbc.Driver
# 连接串：localhost(服务器IP)：3306（mysql端口号）/1181（数据库名）
db.mysql.url = jdbc:mysql://localhost:3306/1181?characterEncoding=utf8&useSSL=false&serverTimezone=UTC&rewriteBatchedStatements=true
# 用户名
db.mysql.username = root
# 密码
db.mysql.password = 123456
```

> [!note] 关于驱动类名与连接参数
> - MySQL 8.x 的驱动类是 `com.mysql.cj.jdbc.Driver`（5.x 时代是 `com.mysql.jdbc.Driver`），写错会报找不到驱动。
> - `serverTimezone=UTC` 用于规避 8.x 驱动的时区报错；`characterEncoding=utf8` 处理中文；`useSSL=false` 关闭 SSL 告警。
> - `root/123456` 是源文本地教学环境的账号密码，保留只为可复现；实际项目请勿把凭证硬编码进版本库。

### 4. 新建实体类

实体类需要符合**驼峰命名映射**：

```java
@Data                // 通过注解的方式给出 getter 与 setter
@NoArgsConstructor   // 不带参数的构造
@AllArgsConstructor  // 带所有参数的构造
public class Student {
    private Integer stuId;
    private String stuNo;
    private String stuName;
    private int stuAge;
    private String stuAddress;
}
```

数据库列名是下划线风格（`stu_id`），Java 字段是驼峰风格（`stuId`）。让二者对上，靠的是全局配置里的 `mapUnderscoreToCamelCase`（见下一步）。

### 5. 建立 log4j.properties

用于打印 MyBatis 执行的 SQL，方便调试。内容与说明见 [[3.全局配置与日志]]。

### 6. 新建 mybatis-config.xml（整体配置文件）

最小可用版本如下，完整逐项说明见 [[3.全局配置与日志]]：

```xml
<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE configuration PUBLIC "-//mybatis.org//DTD Config 3.0//EN"
        "http://mybatis.org/dtd/mybatis-3-config.dtd">
<configuration>
    <properties resource="db.properties" />
    <settings>
        <!-- 设置命名法转化，即下划线分开的单词，改成骆驼命名法 -->
        <setting name="mapUnderscoreToCamelCase" value="true" />
    </settings>
    <typeAliases>
        <!-- 批量设置别名：该包下的 po 类默认别名就是类名（首字母大小写都可以） -->
        <package name="com.neuedu.entity"/>
    </typeAliases>
    <environments default="development">
        <environment id="development">
            <transactionManager type="JDBC" />
            <dataSource type="POOLED">
                <property name="driver" value="${db.mysql.driver}" />
                <property name="url" value="${db.mysql.url}" />
                <property name="username" value="${db.mysql.username}" />
                <property name="password" value="${db.mysql.password}" />
            </dataSource>
        </environment>
    </environments>
    <mappers>
        <mapper resource="com/neuedu/entity/TeacherInfoMapper.xml" />
    </mappers>
</configuration>
```

此文件必须放在类路径根目录（`resources` 下），因为程序用 `Resources.getResourceAsStream("mybatis-config.xml")` 按根查找。

## 建表与第一个映射文件

### 建表 SQL

```mysql
# 创建表
CREATE TABLE t_teacher_info (
    teacher_id INT PRIMARY KEY auto_increment COMMENT '主键，自增',
    teacher_name VARCHAR ( 50 ) NOT NULL COMMENT '教师姓名',
    teacher_login_name VARCHAR ( 50 ) UNIQUE NOT NULL COMMENT '登录账号 unique唯一性',
    teacher_pwd CHAR ( 32 ) NOT NULL COMMENT '密码，MD5的加密',
    teacher_pwd_salt CHAR ( 10 ) NOT NULL COMMENT '密码的加盐加密',
    teacher_pwd_index INT NOT NULL COMMENT '密码加密用到的秘钥'
) ENGINE = INNODB DEFAULT charset = utf8 COMMENT '教师信息表';

# 查看版本
select VERSION();
```

### Mapper 映射文件

```xml
<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "http://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.neuedu.entity.TeacherInfoMapper">
    <!--
    namespace：命名空间，作用是使该 xml 的标签 id 唯一
    如何命名：包.Mapper
    -->
    <!--
    同一个 xml 文件下，所有标签的 id 必须唯一
    resultType = 实体类的别名
    -->
    <select id="selectAll" resultType="TeacherInfo">
        <!-- CDATA 内的字符原样输出，不需要用 &gt; &lt; 转义大于号小于号 -->
        <![CDATA[
            SELECT * from t_teacher_info
        ]]>
    </select>
</mapper>
```

> [!tip] 为什么需要 CDATA
> XML 中 `<` 和 `>` 是标记字符，直接写在 SQL 里会被解析器误认为是标签。两种解法：
> - 用 `&lt;` / `&gt;` 转义 —— 可读性差；
> - 用 `<![CDATA[ ... ]]>` 包裹 —— 内容原样输出，SQL 条件查询里的 `>`、`<` 无需改写。
>
> 源文在此处标注了疑问记号，这里按其本意（原样输出、免转义）说明。

## 执行流程与增删改查

### 三段式骨架

源文中每个测试类的开头都完全相同，这三行就是 MyBatis 的启动流程：

```java
// 1. 查找根目录下的配置文件
InputStream is = Resources.getResourceAsStream("mybatis-config.xml");
// 2. 构建工厂
SqlSessionFactory factory = new SqlSessionFactoryBuilder().build(is);
// 3. 打开 session
SqlSession session = factory.openSession();
```

- `SqlSessionFactory` 是重量级对象，整个应用通常只建一次；
- `SqlSession` 代表一次数据库会话，**用完必须关闭**。

### 新增：注意事务提交

```java
public class Test003 {
    public static void main(String[] args) throws IOException {
        InputStream is = Resources.getResourceAsStream("mybatis-config.xml");
        SqlSessionFactory factory = new SqlSessionFactoryBuilder().build(is);
        SqlSession session = factory.openSession();// 打开 session

        TeacherInfo teacher = new TeacherInfo();
        teacher.setTeacherName("李老师");
        teacher.setTeacherLoginName("lilaoshi");
        teacher.setTeacherPwd("123456");
        teacher.setTeacherPwdSalt("1234567");
        teacher.setTeacherPwdIndex(4);
        System.out.println(teacher);
        System.out.println("==============================================");

        // 命名空间+id 的方式调用
        int insert = session.insert("com.neuedu.entity.TeacherInfoMapper.insertTeacher3", teacher);
        System.out.println(insert);// 如果是 1，代表 1 行受影响

        // 增加，删除，修改的时候，一定要提交，否则数据库不会有变化
        session.commit();// 提交数据
        System.out.println("==============================================");
        System.out.println(teacher);
        session.close();// 用完关闭 session
    }
}
```

### 查询全部与查询单个

```java
// 查询全部
public class Test007 {
    public static void main(String[] args) throws IOException {
        InputStream is = Resources.getResourceAsStream("mybatis-config.xml");
        SqlSessionFactory factory = new SqlSessionFactoryBuilder().build(is);
        SqlSession session = factory.openSession();

        // 查询一个集合
        List<TeacherInfo> infos = session.selectList("com.neuedu.entity.TeacherInfoMapper.selectAll");
        for (TeacherInfo info : infos) {
            System.out.println(info);
        }
        // 因为是查询，不会修改数据库中的数据，所以不需要 commit
        session.close();
    }
}
```

```java
// 通过名称查询一个
TeacherInfo info = session.selectOne(
        "com.neuedu.entity.TeacherInfoMapper.selectOneByName", "张老师");
System.out.println(info);
```

对应的两条 SQL 映射：

```xml
<!-- 查询全部 -->
<select id="selectAll" resultType="TeacherInfo">
    SELECT * from t_teacher_info
</select>

<!-- 查询一个，parameterType 为参数类型，#{value} 取传入的单个参数 -->
<select id="selectOneByName" resultType="TeacherInfo" parameterType="String">
    SELECT * from t_teacher_info where teacher_name=#{value}
</select>
```

`selectList` 返回集合，`selectOne` 返回单个对象；二者都通过 **`namespace + id`** 定位到具体的 SQL 标签。这条"字符串定位"路线其实很脆弱，更推荐的做法是 Mapper 接口代理，见 [[2.结果映射与 Mapper 接口]]。

## 易错点

> [!warning] 必须 `commit`，否则数据不落库
> `openSession()` 默认**不自动提交**。所有 `insert` / `update` / `delete` 之后都必须调用 `session.commit()`，否则程序不报错、但数据库没有任何变化。查询不修改数据，因此不需要 commit。

> [!warning] 必须 `close()` 释放 session
> `SqlSession` 持有数据库连接。不关闭会持续占用连接池资源，高并发下迅速耗尽连接。

其他常见问题：

| 现象 | 原因 |
|---|---|
| 找不到 `mybatis-config.xml` | 配置文件没放在 `resources` 根目录，或 `pom.xml` 未配置对 xml 的打包处理 |
| 找不到驱动 | MySQL 8.x 必须用 `com.mysql.cj.jdbc.Driver` |
| 时区报错 | 连接串缺 `serverTimezone=UTC` |
| 中文乱码 | 缺 `characterEncoding=utf8`；源文另提到可用 `-Dfile.encoding=UTF-8` |
| 字段查出来是 null | 列名下划线 ↔ 字段驼峰未映射，需开启 `mapUnderscoreToCamelCase` |
| 标签 id 冲突 | 同一个 xml 下标签 id 必须唯一；跨 xml 靠 `namespace` 区分 |
