# 后台管理系统常用模式

> [!source] 课程对照
> `vue2026.pdf` 第 48—56、95—146、156—162 页。后端 Java、数据库和框架配置不属于 Vue 核心，本笔记只整理前端模式。

## 整体页面框架

后台系统通常采用“页头 + 侧边栏 + 内容区”的结构：

```vue
<template>
  <el-container class="app-layout">
    <el-header>
      <AppHeader />
    </el-header>

    <el-container>
      <el-aside width="220px">
        <AppMenu />
      </el-aside>

      <el-main>
        <RouterView />
      </el-main>
    </el-container>
  </el-container>
</template>
```

- 页头：系统名称、用户信息、退出登录。
- 侧边栏：一级菜单、二级菜单、路由导航。
- 内容区：通过 `<RouterView />` 展示当前页面。
- 登录页通常使用独立布局，不显示侧边栏。

## 动态菜单

菜单数据可以通过接口返回，再使用 `v-for` 渲染：

```vue
<el-menu router :default-active="$route.path">
  <el-sub-menu
    v-for="menu in menus"
    :key="menu.id"
    :index="String(menu.id)"
  >
    <template #title>
      <el-icon><component :is="menu.icon" /></el-icon>
      <span>{{ menu.name }}</span>
    </template>

    <el-menu-item
      v-for="child in menu.children"
      :key="child.id"
      :index="child.path"
    >
      {{ child.name }}
    </el-menu-item>
  </el-sub-menu>
</el-menu>
```

菜单路径、图标名称和权限标识需要保持稳定。后端返回的菜单用于展示，不能代替后端接口授权。

## 登录流程

典型流程：

1. 用户输入账号、密码和验证码。
2. 前端进行基础格式验证。
3. 请求登录接口。
4. 登录成功后保存服务器返回的认证信息。
5. 获取用户信息和菜单权限。
6. 跳转首页或原始目标页。
7. 刷新页面时恢复登录状态。
8. 退出登录时清除状态并跳转登录页。

```js
async function login() {
  const result = await loginApi({
    username: form.username,
    password: form.password,
  });

  setToken(result.token);
  await loadUserInfo();
  await router.replace(redirectPath);
}
```

## 验证码

验证码通常由服务器生成，前端只负责：

- 请求验证码图片和对应标识。
- 显示图片。
- 点击刷新。
- 把用户输入和服务器签发的验证码标识一起提交。

验证码必须由服务器最终校验。前端从接口获得验证码答案再仅在前端比较，不能形成安全保护。

## Token 与登录状态

可以保存：

- Token。
- 用户基本信息。
- 权限或菜单数据。
- Token 过期时间。

选择存储方式时要考虑：

- `localStorage`：关闭浏览器后仍在，容易被 XSS 读取。
- `sessionStorage`：关闭标签页后清除。
- `HttpOnly Cookie`：JavaScript 无法直接读取，但需要处理 CSRF 和跨域配置。
- Pinia/Vuex：提供组件间响应式共享，但页面刷新后通常会丢失，需要与持久化存储配合。

高敏感系统应优先采用服务器推荐的安全认证方案，不要把密码保存到本地。

## Axios 与认证请求

请求拦截器统一添加认证信息：

```js
service.interceptors.request.use((config) => {
  const token = getToken();

  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }

  return config;
});
```

响应拦截器统一处理：

- 401：登录失效，清除状态并跳转登录页。
- 403：没有权限。
- 500：服务器错误。
- 网络超时。
- 统一业务错误码。

不要在多个组件中重复实现同一套 401 处理。

## 路由权限

```js
router.beforeEach(async (to) => {
  const token = getToken();

  if (to.meta.requiresAuth && !token) {
    return {
      name: "login",
      query: { redirect: to.fullPath },
    };
  }

  return true;
});
```

前端守卫负责页面导航体验，后端接口仍必须验证身份、角色和数据权限。

## 列表页面

后台列表页通常包含：

- 搜索筛选区。
- 操作按钮区。
- 表格。
- 分页。
- 新增或编辑对话框。
- 删除确认。
- 加载状态。
- 空状态和错误状态。

查询条件应集中管理：

```js
const query = reactive({
  keyword: "",
  page: 1,
  size: 10,
  total: 0,
});

async function loadData() {
  const result = await getUserList(query);
  rows.value = result.list;
  query.total = result.total;
}
```

修改筛选条件时通常要重置到第 1 页，否则可能停留在不存在的页码。

## 表格操作

```vue
<el-table-column label="操作">
  <template #default="{ row }">
    <el-button @click="view(row)">查看</el-button>
    <el-button type="warning" @click="edit(row)">编辑</el-button>
    <el-button type="danger" @click="remove(row)">删除</el-button>
  </template>
</el-table-column>
```

删除操作应先二次确认，再调用接口；接口成功后刷新列表或更新当前行。编辑时不要直接修改表格行对象，除非明确采用乐观更新并能回滚。

## 分页

```vue
<el-pagination
  v-model:current-page="query.page"
  v-model:page-size="query.size"
  :page-sizes="[10, 20, 50]"
  :total="query.total"
  layout="total, sizes, prev, pager, next, jumper"
  @size-change="loadData"
  @current-change="loadData"
/>
```

后端分页时，表格只应保存当前页数据。总条数、当前页和每页数量来自请求结果或查询状态。

## 对话框表单

常见流程：

```js
function openCreate() {
  formRef.value?.resetFields();
  dialogVisible.value = true;
}

function openEdit(row) {
  Object.assign(form, row);
  dialogVisible.value = true;
}
```

需要注意：

- 新增和编辑可能使用不同接口。
- 编辑时应复制需要的字段，避免直接引用表格数据。
- 成功后关闭对话框并刷新列表。
- 关闭时清理验证状态。
- 对话框宽度和内容在小屏幕上要适配。

## 文件上传

`el-upload` 常见配置：

- `action`：上传地址。
- `headers`：认证信息。
- `before-upload`：校验文件类型和大小。
- `on-success` / `on-error`：处理结果。
- `show-file-list`：是否显示文件列表。

客户端校验只能改善体验，文件类型、大小、内容和权限必须由服务器验证。

## 树形权限

`el-tree` 适合菜单、部门、分类和权限节点：

- `node-key`：节点唯一标识。
- `show-checkbox`：显示复选框。
- `default-expand-all`：默认展开。
- `getCheckedKeys()`：获取选中节点。
- `setCheckedKeys()`：设置选中节点。
- `setCheckedNodes()`：按节点对象设置选中状态。

树形数据应统一成 `id`、`label`、`children` 等结构，或通过 `props` 字段映射。

## 国际化

后台系统可以支持多语言：

- 使用 Element Plus 的语言包处理组件内置文案。
- 使用 `vue-i18n` 处理项目自己的文案。
- 语言设置可以保存到 `localStorage`。
- 日期、数字和校验提示也要本地化。
- 切换语言后要检查布局是否能容纳更长文本。

## 安全边界

- 前端隐藏按钮只是界面控制，服务器最终决定是否允许操作。
- 登录密码必须通过 HTTPS 传输，服务器使用 bcrypt、Argon2 等安全算法存储。
- 前端 MD5 不能替代服务器端密码哈希。
- 验证码必须在服务器校验。
- Token 应有有效期、刷新和退出失效机制。
- 不把密钥、数据库密码或第三方私钥放到 Vue 前端代码中。

## 常见错误

- 只做前端权限，不做服务器授权。
- 刷新页面后只依赖内存 Store，登录状态丢失。
- 分页、筛选和表格数据状态不一致。
- 删除后不刷新列表或页码超出范围。
- 表单直接引用并修改表格行对象。
- 验证码答案保存在前端并只在前端判断。
- 出现 401 后没有清理旧 Token，页面反复请求失败。
