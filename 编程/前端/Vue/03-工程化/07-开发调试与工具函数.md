# 开发调试与工具函数

> [!source] 课程对照

## 浏览器控制台

```js
console.log("普通日志");
console.info("说明信息");
console.debug("调试信息");
console.warn("警告");
console.error("错误");
```

### 表格输出

```js
console.table([
  { id: 1, name: "张三", age: 18 },
  { id: 2, name: "李四", age: 20 },
]);
```

数组和对象使用 `console.table()` 更便于比较字段。

### 查看对象

```js
console.dir(object);
```

### 性能计时

```js
console.time("load-data");
await loadData();
console.timeEnd("load-data");
```

### 断言

```js
console.assert(count > 0, "count 必须大于 0");
```

只有断言为假时才输出错误，适合开发阶段检查假设。

### 分组日志

```js
console.group("用户请求");
console.log("开始请求");
console.log("请求完成");
console.groupEnd();
```

### 调用次数

```js
console.count("render");
```

### 堆栈跟踪

```js
console.trace("查看调用路径");
```

控制台日志不能代替正式错误监控。生产环境应接入错误上报，并避免打印敏感信息。

## 日期格式化工具

```ts
export function formatDate(
  input?: Date | string | number,
  format = "yyyy-MM-dd HH:mm:ss",
): string {
  const date = input ? new Date(input) : new Date();

  if (Number.isNaN(date.getTime())) {
    throw new Error("无效的日期格式");
  }

  const pad = (value: number) => String(value).padStart(2, "0");
  const year = date.getFullYear();
  const month = date.getMonth() + 1;
  const day = date.getDate();
  const hours = date.getHours();
  const minutes = date.getMinutes();
  const seconds = date.getSeconds();

  const map: Record<string, string | number> = {
    yyyy: year,
    MM: pad(month),
    dd: pad(day),
    HH: pad(hours),
    mm: pad(minutes),
    ss: pad(seconds),
  };

  return Object.entries(map).reduce(
    (result, [key, value]) => result.replaceAll(key, String(value)),
    format,
  );
}
```

使用示例：

```js
formatDate(new Date(), "yyyy-MM-dd");
formatDate("2026-09-17", "MM-dd HH:mm");
```

## 调试接口问题

在浏览器开发者工具中重点检查：

- Network 中请求 URL 是否正确。
- Method、请求头和请求体是否符合后端要求。
- 请求是否跨域。
- 响应状态码和响应数据。
- Token 是否存在、是否过期。
- 前后端字段名是否一致。

## 跨域问题的基本认识

跨域由浏览器同源策略产生。常见解决方式：

- 后端正确配置 CORS。
- 开发环境使用 Vite/Vue CLI 代理。
- 生产环境通过同源网关或反向代理。

不要通过关闭浏览器安全策略来解决开发问题。

## 日期与环境的注意事项

- `getMonth()` 从 0 开始。
- 时区不同会导致同一条时间数据显示不同。
- `new Date("2026-09-17")` 通常按 UTC 解析，纯日期输入要明确业务时区。
- 格式化只用于显示，接口传输优先使用标准格式，例如 ISO 8601。
