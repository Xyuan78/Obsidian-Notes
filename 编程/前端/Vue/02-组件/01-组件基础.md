# 组件基础

## 为什么要拆分组件

组件可以把页面拆成独立、可复用的部分。例如：

```text
App
├── AppHeader
├── SearchBar
├── ProductList
│   └── ProductCard
└── AppFooter
```

拆分后，每部分职责更明确，样式和逻辑更容易维护。

## 创建组件

`src/components/UserCard.vue`：

```vue
<script setup>
const props = defineProps({
  name: {
    type: String,
    required: true,
  },
  age: {
    type: Number,
    default: 0,
  },
});
</script>

<template>
  <article class="user-card">
    <h2>{{ props.name }}</h2>
    <p>年龄：{{ props.age }}</p>
  </article>
</template>

<style scoped>
.user-card {
  padding: 16px;
  border: 1px solid #e2e8f0;
  border-radius: 12px;
}
</style>
```

## 使用组件

父组件中导入后即可在模板中使用：

```vue
<script setup>
import UserCard from "./components/UserCard.vue";
</script>

<template>
  <UserCard name="张三" :age="18" />
</template>
```

使用 `<script setup>` 时，导入的组件会自动暴露给模板，不需要再写 `components` 注册选项。

## Props

- Props 是父组件传给子组件的数据。
- Props 应保持单向流动。
- 子组件不能直接修改 Props。
- 需要修改时，应通过事件通知父组件修改源数据。

```vue
<script setup>
const props = defineProps({
  title: String,
  count: {
    type: Number,
    default: 0,
  },
});
</script>
```

常用类型：

- `String`
- `Number`
- `Boolean`
- `Array`
- `Object`
- `Function`

## 插槽

子组件预留内容位置：

```vue
<template>
  <section class="panel">
    <header>
      <slot name="header">默认标题</slot>
    </header>

    <main>
      <slot>默认内容</slot>
    </main>
  </section>
</template>
```

父组件填充插槽：

```vue
<template>
  <Panel>
    <template #header>
      <h2>用户信息</h2>
    </template>

    <p>这里是正文内容。</p>
  </Panel>
</template>
```

- 默认插槽：没有名称的 `slot`。
- 具名插槽：使用 `name` 和 `#name`。
- 后备内容：父组件没有传内容时显示。
- 作用域插槽：子组件可以把数据传回插槽内容。

## scoped 样式

```vue
<style scoped>
.title {
  color: #2563eb;
}
</style>
```

`scoped` 会限制样式作用范围，减少组件之间的样式污染。全局样式应放在统一的基础样式文件中。

## 组件命名

- 文件名使用 PascalCase，例如 `UserCard.vue`。
- 模板中使用 PascalCase 可读性更好。
- 组件名称应有明确语义，例如 `UserCard`，不要用 `Box1`、`Test`。
- 组件应围绕一个明确职责组织。

## 常见错误

- 直接修改 Props。
- 一个组件承担太多业务和职责。
- 大量复制粘贴，而不是提取可复用组件。
- 样式没有隔离，修改一个组件影响整个页面。
- 组件名称模糊，后续难以定位。
