# 模板语法与响应式数据

## 插值表达式

```vue
<script setup>
const title = "Vue 学习笔记";
const count = 3;
</script>

<template>
  <h1>{{ title }}</h1>
  <p>当前数量：{{ count + 1 }}</p>
</template>
```

双大括号 `{{ }}` 会把表达式结果转换为文本。适合简单表达式，不适合放复杂逻辑。

## 指令

指令以 `v-` 开头：

```vue
<img v-bind:src="imageUrl" alt="示例图片" />
<button v-on:click="increase">增加</button>
```

常用简写：

```vue
<img :src="imageUrl" alt="示例图片" />
<button @click="increase">增加</button>
```

- `:` 是 `v-bind:` 的简写，用于绑定属性。
- `@` 是 `v-on:` 的简写，用于绑定事件。
- `v-model` 用于表单双向绑定。
- `v-if` / `v-show` 用于条件显示。
- `v-for` 用于列表渲染。

## ref

`ref` 适合保存字符串、数字、布尔值、数组和对象：

```vue
<script setup>
import { ref } from "vue";

const count = ref(0);
const user = ref({
  name: "张三",
  age: 18,
});

function increase() {
  count.value++;
}

function changeName() {
  user.value.name = "李四";
}
</script>

<template>
  <p>{{ count }}</p>
  <p>{{ user.name }}</p>
  <button @click="increase">增加</button>
</template>
```

在 JavaScript 中通过 `.value` 读写；在模板中，Vue 会自动解包顶层 `ref`，通常不需要写 `.value`。

## reactive

`reactive` 适合创建对象或数组形式的响应式状态：

```vue
<script setup>
import { reactive } from "vue";

const form = reactive({
  username: "",
  password: "",
});

function resetForm() {
  form.username = "";
  form.password = "";
}
</script>

<template>
  <p>{{ form.username }}</p>
</template>
```

不建议直接解构 `reactive` 对象，否则可能丢失响应性：

```js
// 不推荐
const { username } = form;

// 推荐：需要解构时使用 toRefs
import { toRefs } from "vue";
const { username } = toRefs(form);
```

## ref 与 reactive 怎么选

- 单一值优先使用 `ref`。
- 对象或表单状态可以使用 `reactive`。
- 需要整体替换对象时，`ref` 更方便。
- 团队项目应保持一致，不要为了写法炫技混用。

## 响应式更新的前提

- 数据必须经过 `ref`、`reactive` 或相关 API 转为响应式。
- 直接创建普通变量不会自动触发视图更新。
- 异步回调中修改响应式数据，Vue 会自动安排更新。
- 需要等待更新后的 DOM 时，可以使用 `nextTick()`。

```js
import { nextTick, ref } from "vue";

const visible = ref(false);

async function show() {
  visible.value = true;
  await nextTick();
  console.log("DOM 已更新");
}
```

### v-text、v-html 与插值

```vue
<script setup>
const message = "纯文本内容";
const htmlContent = "<strong>加粗内容</strong>";
</script>

<template>
  <p>{{ message }}</p>
  <p v-text="message"></p>
  <p v-html="htmlContent"></p>
</template>
```

- `{{ }}`：把结果显示为文本。
- `v-text`：覆盖元素文本内容，值作为纯文本处理。
- `v-html`：把字符串作为 HTML 解析，可能引入 XSS，禁止直接渲染用户输入。
- 能使用 `{{ }}` 或 `v-text` 时，不要为了少写几个字符使用 `v-html`。

### 动态绑定属性

```vue
<script setup>
import { ref } from "vue";

const userName = ref("张三");
const isActive = ref(true);
const hasError = ref(false);
const styleObject = {
  color: "red",
  fontSize: "20px",
};
</script>

<template>
  <input :value="userName" :data-name="'user-' + userName" />

  <p
    :class="{
      active: isActive,
      error: hasError,
      card: true,
    }"
  >
    动态类名
  </p>

  <p :style="styleObject">动态样式</p>
</template>
```

`v-bind` 的简写是 `:`。除了 `class` 和 `style`，也可以绑定 `value`、`disabled`、`src`、`data-*` 等属性。

### class 的常见写法

```vue
<p :class="['base', isActive ? 'active' : '']"></p>
<p :class="{ active: isActive, error: hasError }"></p>
```

静态类名可以和动态对象同时存在，Vue 会把结果合并。

### readonly

```js
import { reactive, readonly } from "vue";

const state = reactive({ count: 0 });
const stateCopy = readonly(state);

stateCopy.count = 10; // 不会修改成功，并会产生开发警告
```

`readonly()` 创建只读代理，适合限制子模块或组件直接修改共享状态。只读代理被修改时不会成功，但需要明确设计数据权限。
