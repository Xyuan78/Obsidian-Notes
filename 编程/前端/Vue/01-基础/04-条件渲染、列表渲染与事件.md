# 条件渲染、列表渲染与事件

## v-if 条件渲染

```vue
<script setup>
import { ref } from "vue";

const isLoggedIn = ref(false);
</script>

<template>
  <p v-if="isLoggedIn">欢迎回来</p>
  <p v-else>请先登录</p>
</template>
```

多分支：

```vue
<p v-if="status === 'loading'">加载中</p>
<p v-else-if="status === 'error'">加载失败</p>
<p v-else>加载完成</p>
```

`v-if` 为假时，元素不会创建或会从 DOM 中移除。

## v-show

```vue
<p v-show="isVisible">这段内容通过 CSS 隐藏</p>
```

- `v-if`：按条件创建和销毁元素，适合切换频率低的场景。
- `v-show`：元素始终存在于 DOM 中，通过 `display` 控制显示，适合频繁切换的场景。

## v-for 列表渲染

```vue
<script setup>
import { ref } from "vue";

const fruits = ref(["苹果", "香蕉", "橙子"]);
const users = ref([
  { id: 1, name: "张三" },
  { id: 2, name: "李四" },
]);
</script>

<template>
  <ul>
    <li v-for="fruit in fruits" :key="fruit">
      {{ fruit }}
    </li>
  </ul>

  <ul>
    <li v-for="user in users" :key="user.id">
      {{ user.name }}
    </li>
  </ul>
</template>
```

- `v-for` 可以遍历数组、对象、数字和字符串。
- 使用 `:key` 帮助 Vue 正确复用和移动节点。
- `key` 应稳定且唯一，优先使用数据 ID，不要优先使用数组索引。

## v-for 与 v-if

不要在同一个元素上同时使用 `v-for` 和 `v-if`，因为优先级容易造成误解。先计算过滤后的列表，再渲染。

```vue
<script setup>
import { computed, ref } from "vue";

const products = ref([
  { id: 1, name: "鼠标", active: true },
  { id: 2, name: "键盘", active: false },
]);

const activeProducts = computed(() => products.value.filter((item) => item.active));
</script>

<template>
  <div v-for="product in activeProducts" :key="product.id">
    {{ product.name }}
  </div>
</template>
```

## 事件绑定

```vue
<script setup>
function sayHello(name) {
  console.log(`你好，${name}`);
}
</script>

<template>
  <button @click="sayHello('张三')">点击</button>
  <button @click="sayHello($event.type)">查看事件类型</button>
</template>
```

`$event` 是原生事件对象，常用于读取事件信息或阻止默认行为。

## 事件修饰符

```vue
<form @submit.prevent="submitForm">
  <button type="submit">提交</button>
</form>

<button @click.once="buy">只能点击一次</button>

<div @click="outer">
  <button @click.stop="inner">阻止冒泡</button>
</div>
```

常见修饰符：

- `.prevent`：调用 `event.preventDefault()`。
- `.stop`：调用 `event.stopPropagation()`。
- `.once`：事件只触发一次。
- `.self`：只有事件目标是自己时触发。
- `.capture`：使用捕获阶段。
- `.passive`：优化滚动等场景，不能与 `.prevent` 混用。

## 常见错误

- 列表缺少 `key`，或使用不稳定的索引。
- 事件处理函数写成 `@click="increase()"` 和 `@click="increase"` 不分场景。
- 在模板中堆叠大量条件表达式。
- 用 `v-if` 频繁切换简单显示内容，改用 `v-show` 可能更合适。

### v-for 遍历对象

```vue
<script setup>
const student = {
  name: "张三",
  age: 18,
  address: "南京",
};
</script>

<template>
  <ul>
    <li v-for="(value, key, index) in student" :key="key">
      {{ index }} - {{ key }}：{{ value }}
    </li>
  </ul>
</template>
```

数组通常使用 `(item, index)`，对象使用 `(value, key, index)`。

### 使用数值范围

```vue
<p v-for="i in 9" :key="i">
  <span v-for="j in i" :key="j">{{ j }} × {{ i }} = {{ i * j }}</span>
</p>
```

`v-for="i in 9"` 会生成 1 到 9。

### template 上的 v-for

```vue
<template v-for="item in items" :key="item.id">
  <dt>{{ item.name }}</dt>
  <dd>{{ item.description }}</dd>
</template>
```

`template` 不会渲染成额外元素，适合一次生成多个并列标签。

### 事件修饰符补充

```vue
<button @click.right="openMenu">右键菜单</button>
<button @mousedown.middle="openLink">中键</button>
<input @keyup.enter="submit" />
<a @click.stop.prevent="handleClick">阻止冒泡和默认行为</a>
```

- `.left`：鼠标左键。
- `.right`：鼠标右键。
- `.middle`：鼠标中键。
- `.enter`：回车键。
- `.capture`：使用捕获阶段监听，不是说“阻止捕获”。
- 修饰符可以链式组合，顺序会影响执行逻辑。

### 传递事件对象

```vue
<script setup>
function handleEvent(event) {
  console.log(event.type);
  console.log(event.target);
}
</script>

<template>
  <button @click="handleEvent">查看事件对象</button>
  <button @click="handleEvent($event)">显式传递事件对象</button>
</template>
```

普通事件处理函数默认可以接收事件对象。需要在模板中传入其他参数时，可以显式传入 `$event`。

### 多个处理函数

```vue
<button @click="first($event), second()">执行两个函数</button>
```

Vue 支持在模板中调用多个函数，但事件处理逻辑较多时应封装为一个明确的方法，避免模板变得难读。
