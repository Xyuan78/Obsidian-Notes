# 表单绑定与计算监听

## v-model 双向绑定

```vue
<script setup>
import { ref } from "vue";

const username = ref("");
const agreed = ref(false);
</script>

<template>
  <label>
    用户名
    <input v-model="username" />
  </label>

  <label>
    <input v-model="agreed" type="checkbox" />
    同意协议
  </label>

  <p>{{ username }}</p>
</template>
```

`v-model` 把表单控件的值和响应式数据连接起来。

## 常见表单控件

```vue
<input v-model="name" type="text" />
<textarea v-model="message"></textarea>

<select v-model="city">
  <option value="beijing">北京</option>
  <option value="shanghai">上海</option>
</select>

<input v-model="hobbies" type="checkbox" value="html" />
<input v-model="hobbies" type="checkbox" value="vue" />

<input v-model="gender" type="radio" value="male" />
<input v-model="gender" type="radio" value="female" />
```

- 复选框绑定布尔值或数组。
- 单选按钮绑定选中的值。
- 下拉框绑定选中项的 `value`。
- 多行文本使用 `textarea`。

## v-model 修饰符

```vue
<input v-model.trim="username" />
<input v-model.number="age" type="number" />
<input v-model.lazy="keyword" />
```

- `.trim`：自动移除首尾空格。
- `.number`：尝试把输入转换为数字。
- `.lazy`：在 `change` 事件后同步，而不是每次输入都同步。

## computed 计算属性

```vue
<script setup>
import { computed, ref } from "vue";

const firstName = ref("三");
const lastName = ref("张");

const fullName = computed(() => `${lastName.value}${firstName.value}`);

const total = computed(() => {
  return 0;
});
</script>

<template>
  <p>{{ fullName }}</p>
</template>
```

计算属性适合根据现有响应式数据推导新数据。依赖没有变化时，Vue 会缓存计算结果。

## computed 与方法的区别

- `computed` 有缓存，依赖不变时不会重新计算。
- 普通方法在模板中每次渲染都可能重新执行。
- 复杂逻辑优先使用 `computed`，事件处理使用方法。

## watch 侦听器

```vue
<script setup>
import { ref, watch } from "vue";

const keyword = ref("");
const users = ref([]);

watch(keyword, async (newValue, oldValue) => {
  console.log("旧值：", oldValue);
  console.log("新值：", newValue);

  if (!newValue.trim()) {
    users.value = [];
    return;
  }

  // 请求搜索结果
  // users.value = await searchUsers(newValue)
});
</script>
```

`watch` 适合执行有副作用的操作，例如请求数据、保存本地存储、手动操作 DOM。

## watchEffect

```vue
<script setup>
import { ref, watchEffect } from "vue";

const theme = ref("light");

watchEffect(() => {
  document.documentElement.dataset.theme = theme.value;
});
</script>
```

`watchEffect` 会自动收集函数中访问的响应式依赖，依赖变化后重新执行。

## 选择原则

- 能从现有状态直接推导：使用 `computed`。
- 需要监听变化并执行副作用：使用 `watch`。
- 无需明确列出依赖：使用 `watchEffect`。
- 不要在 `computed` 中修改其他状态。
- 不要把异步请求直接写进 `computed`。

### v-model 对不同控件的处理

`v-model` 会根据控件类型选择对应的属性和事件：

- `text`、`textarea`：使用 `value` 和 `input` 事件。
- `checkbox`、`radio`：使用 `checked` 和 `change` 事件。
- `select`：使用 `value` 和 `change` 事件。

```vue
<input v-model="message" type="text" />
<textarea v-model="message"></textarea>
<input v-model="checked" type="checkbox" />
<input v-model="selected" type="radio" value="A" />
<select v-model="city">
  <option value="beijing">北京</option>
</select>
```

对于单选按钮和带 `value` 的复选框，最终绑定的是控件对应的 `value`。复选框绑定数组时会收集多个选中值。

### 表单初始状态

`v-model` 会忽略普通表单控件自身的初始 `value`、`checked`、`selected` 状态，优先以响应式变量作为数据来源。

```js
const username = ref("");
const agreed = ref(false);
const city = ref("beijing");
```

不要在表单组件中同时依赖 DOM 初始状态和 `v-model` 状态，以免出现数据不一致。
