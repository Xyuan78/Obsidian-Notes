# 字符串、面向对象与接口

> [!info] 资料来源
> 基于语雀《JavaSE核心技术》的 [06.面向对象基础](https://www.yuque.com/neuedu/campus/duhz6q82s7fsi7dt)、[07.面向对象高级特性](https://www.yuque.com/neuedu/campus/ry49n04f7voic3ek)、[09.常见工具类-高级篇](https://www.yuque.com/neuedu/campus/naudgsyggqqm6mml)、[13.JDK新特性](https://www.yuque.com/neuedu/campus/ly1dyeqreptbuxhe) 补充。


## 1. String 基础

### 1.1 `==` 与 `equals`

```java
String s1 = "hello";
String s2 = "hello";
String s3 = new String("hello");

System.out.println(s1 == s2);      // true，指向常量池中的同一个对象
System.out.println(s1 == s3);      // false，地址不同
System.out.println(s1.equals(s3)); // true，内容相同
```

- `==` 用于基本类型时比较值，用于引用类型时比较地址。
- `equals` 的具体行为由对象的类决定。
- 比较字符串内容时，应使用 `equals`。

安全写法：

```java
if ("hello".equalsIgnoreCase(text)) {
    // 即使 text 为 null，也不会抛出空指针异常
}
```

### 1.2 String 的不可变性

`String` 对象创建后内容不能改变。所谓“修改”，通常会产生新字符串。

```java
String s = "a";
s = s + "b";
```

这两行不是修改原字符串，而是让变量 `s` 指向新的字符串对象。

### 1.3 常用方法

```java
String text = "HelloWorld";

text.length();
text.charAt(4);
text.indexOf("Wo");
text.toLowerCase();
text.toUpperCase();
text.startsWith("Hello");
text.endsWith("World");
text.substring(2);
text.substring(2, 5);
text.replace("World", "Java");
text.trim();
text.split("_");
text.contains("World");
text.isEmpty();
```

`substring(start, end)` 的区间是前闭后开：包含 `start`，不包含 `end`。

### 1.4 字符串比较与排序

```java
int result = "abc".compareTo("abd");
```

- 返回负数：前者按字典序在前。
- 返回 0：内容相同。
- 返回正数：前者按字典序在后。

```java
String[] names = {"Tom", "Alice", "Bob"};
java.util.Arrays.sort(names);
```

## 2. StringBuffer 与 StringBuilder

```java
StringBuilder sb = new StringBuilder();

sb.append("Hello");
sb.append(' ');
sb.append("World");

String result = sb.toString();
```

| 类型 | 可变 | 线程安全 | 使用建议 |
|---|---|---|---|
| `String` | 否 | 不可变天然安全 | 内容基本不变 |
| `StringBuffer` | 是 | 是 | 多线程共享且需要同步 |
| `StringBuilder` | 是 | 否 | 单线程频繁拼接，通常首选 |

> [!tip] 频繁循环拼接
> 循环内使用 `result += value` 可能产生大量临时字符串对象，优先使用 `StringBuilder`。

## 3. 正则表达式与 Math

字符串匹配：

```java
String email = "zhangsan@example.com";
boolean valid = email.matches("^\\w+([-+.]\\w+)*@\\w+([-.]\\w+)*\\.\\w+([-.]\\w+)*$");
```

常用正则：

| 表达式 | 含义 |
|---|---|
| `\\d` | 一个数字 |
| `\\w` | 字母、数字或下划线 |
| `+` | 前一项出现一次或多次 |
| `*` | 前一项出现零次或多次 |
| `^` | 字符串开头 |
| `$` | 字符串结尾 |

`Math` 示例：

```java
Math.abs(-10);
Math.max(10, 20);
Math.min(10, 20);
Math.sqrt(16);
Math.random();       // [0.0, 1.0)
Math.pow(2, 3);
```

## 4. 类与对象

### 4.1 定义类

```java
public class Person {
    private String name;
    private int age;

    public Person() {
    }

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public void introduce() {
        System.out.println("我是" + name + "，今年" + age + "岁");
    }
}
```

- 类是对一类事物的抽象。
- 对象是类创建出来的具体实例。
- 属性描述状态，方法描述行为。

### 4.2 创建对象

```java
Person person = new Person("张三", 18);
person.introduce();
```

`new` 的步骤：

1. 分配对象空间。
2. 初始化成员变量默认值。
3. 调用构造器。
4. 返回对象引用。

### 4.3 成员变量默认值

成员变量即使不手动赋值，也有默认值：

| 类型 | 默认值 |
|---|---|
| 整数类型 | `0` |
| 浮点类型 | `0.0` |
| `boolean` | `false` |
| `char` | `'\u0000'` |
| 引用类型 | `null` |

局部变量没有默认值，使用前必须显式赋值。

### 4.4 构造器

构造器特点：

- 名称与类名相同。
- 没有返回类型，也不写 `void`。
- 主要用于初始化对象。
- 可以重载。
- 如果未定义任何构造器，编译器自动生成无参构造器。
- 一旦定义了有参构造器，默认无参构造器不会再自动生成。

```java
public Person() {
}

public Person(String name) {
    this.name = name;
}
```

### 4.5 this

`this` 表示当前对象。

```java
public void setName(String name) {
    this.name = name;
}
```

同名变量冲突时，`this.name` 表示成员变量，`name` 表示参数。

### 4.6 封装

```java
public class Student {
    private String name;

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }
}
```

封装的作用：

- 隐藏内部实现细节。
- 通过方法控制读写规则。
- 便于修改内部实现而不影响调用方。

## 5. 重载与重写

### 5.1 重载 Overload

同一个类中，方法名相同、参数列表不同：

```java
public int add(int a, int b) {
    return a + b;
}

public double add(double a, double b) {
    return a + b;
}

public int add(int a, int b, int c) {
    return a + b + c;
}
```

仅返回值类型不同不能构成重载。

### 5.2 重写 Override

子类重新实现父类方法：

```java
class Animal {
    public void move() {
        System.out.println("动物在移动");
    }
}

class Bird extends Animal {
    @Override
    public void move() {
        System.out.println("鸟在飞");
    }
}
```

重写要求：

- 方法名和参数列表相同。
- 访问权限不能比父类更严格。
- 返回值类型必须兼容。
- 父类 `private` 方法、构造器不能被重写。
- `final` 方法不能被重写。

## 6. 继承

```java
class Animal {
    protected String name;

    public void eat() {
        System.out.println("动物在吃");
    }
}

class Bird extends Animal {
    public void fly() {
        System.out.println("鸟在飞");
    }
}
```

- Java 类只能单继承，一个子类只能有一个直接父类。
- 子类继承父类可访问的成员。
- 构造子类对象前，会先执行父类构造过程。
- `super(...)` 调用父类构造器，必须是子类构造器中的第一条有效语句。
- `super.method()` 调用父类版本的方法。

### 6.1 super 示例

```java
class Animal {
    public Animal(String name) {
        System.out.println(name);
    }
}

class Bird extends Animal {
    public Bird() {
        super("Bird");
    }
}
```

## 7. 多态

多态指同一个父类引用在运行时可以指向不同子类对象，并调用子类重写后的方法。

```java
Animal animal1 = new Bird();
Animal animal2 = new Dog();

animal1.move(); // 执行 Bird.move()
animal2.move(); // 执行 Dog.move()
```

### 7.1 向上转型

```java
Animal animal = new Bird();
```

父类引用只能访问父类中声明的方法；不能直接调用子类特有方法。

### 7.2 向下转型

```java
Animal animal = new Bird();
Bird bird = (Bird) animal;
bird.fly();
```

向下转型前应检查真实类型：

```java
if (animal instanceof Bird) {
    Bird bird = (Bird) animal;
    bird.fly();
}
```

> [!warning] 错误的向下转型会在运行时抛出 `ClassCastException`。

## 8. static 与 final

### 8.1 static

`static` 成员属于类，而不是某个对象：

```java
public class Student {
    public static int count = 0;
    public String name;

    public static void showCount() {
        System.out.println(count);
    }
}
```

```java
Student.count++;
Student.showCount();
```

规则：

- 静态成员推荐使用类名调用。
- 静态方法不能直接访问非静态成员。
- 非静态方法可以访问静态成员。
- 静态代码块在类加载时执行一次。

### 8.2 final

| 修饰位置 | 作用 |
|---|---|
| 类 | 不能再被继承 |
| 方法 | 不能再被重写 |
| 变量 | 只能赋值一次 |
| 引用变量 | 引用不能换，但对象内部状态可能仍可修改 |

```java
public static final int MAX_COUNT = 100;
```

`String` 是 `final` 类，不能被继承。

## 9. 对象数组与综合案例

对象数组保存对象引用：

```java
DVD[] dvds = new DVD[1000];
dvds[0] = new DVD();
```

课件 DVD 管理系统综合了：

- 对象数组保存数据。
- 新增、删除、修改、查询。
- 借出和归还状态管理。
- 使用 `Date` 记录借出时间。
- 计算借出天数与费用。
- 按借出次数排序。
- 使用 getter/setter 访问私有属性。

系统通常拆分为：

| 职责 | 示例类 |
|---|---|
| 实体对象 | `DVD` |
| 数据存储 | `MyData` |
| 业务操作 | `DVDManagement` |
| 程序入口 | `Test` / `Main` |

### 9.1 日期格式化

```java
Date now = new Date();
SimpleDateFormat format = new SimpleDateFormat("yyyy-MM-dd");
String text = format.format(now);
```

- `Date` 表示时间点。
- `SimpleDateFormat` 用于把日期格式化为字符串或解析字符串。
- `SimpleDateFormat` 不是线程安全的，不应在多个线程间共享同一个实例。
- 新项目优先使用 `java.time` 包中的 `LocalDate`、`LocalDateTime` 和 `DateTimeFormatter`。

### 9.2 Lombok

课件使用 Lombok 减少样板代码：

```java
@Data
@NoArgsConstructor
@AllArgsConstructor
public class DVD {
    private String name;
    private int count;
}
```

| 注解                    | 作用                                                |
| --------------------- | ------------------------------------------------- |
| `@Data`               | 生成 getter、setter、`toString`、`equals`、`hashCode` 等 |
| `@NoArgsConstructor`  | 生成无参构造器                                           |
| `@AllArgsConstructor` | 生成包含全部字段的构造器                                      |

使用 Lombok 必须在项目中正确引入依赖，并让 IDE 启用注解处理。

## 10. 抽象类与接口

### 10.1 抽象类

```java
abstract class Teacher {
    public abstract void teach();

    public void sayHello() {
        System.out.println("Hello");
    }
}
```

- 抽象类不能直接实例化。
- 可以包含抽象方法和普通方法。
- 子类要么实现全部抽象方法，要么仍然是抽象类。

### 10.2 接口

```java
interface Payable {
    int calculate(int hours);
}
```

实现接口：

```java
class Worker implements Payable {
    @Override
    public int calculate(int hours) {
        return hours * 50;
    }
}
```

接口特点：

- 一个类可以实现多个接口。
- 接口用于定义能力和规范。
- 接口引用可以指向不同实现类对象，降低代码耦合。
- JDK 8 开始，接口可以包含 `default` 方法和 `static` 方法。

```java
interface Vehicle {
    default void print() {
        System.out.println("我是一辆车");
    }

    static void blowHorn() {
        System.out.println("按喇叭");
    }
}
```

### 10.3 抽象类与接口的选择

| 对比项 | 抽象类 | 接口 |
|---|---|---|
| 关系 | “是什么” | “能做什么” |
| 继承/实现 | 类只能继承一个抽象类 | 类可实现多个接口 |
| 字段 | 可有实例字段 | 通常是公开静态常量 |
| 构造器 | 可以有 | 不能有构造器 |
| 适用场景 | 共享基础实现和状态 | 定义能力、协议、解耦扩展点 |

## 11. 面向接口编程

```java
Teacher teacher = new JavaTeacher();
teacher.teach();
```

调用方依赖接口或父类，运行时传入具体实现：

- 便于替换实现。
- 便于扩展新类型。
- 有利于测试和降低耦合。

打印机组装案例可以抽象为：

```text
Printer(Paper, Ink)
Paper -> A4 / A3 / B5
Ink   -> ColorInk / BlackWhiteInk
```

打印机只依赖 `Paper` 和 `Ink` 接口，不依赖具体材料。

## 12. Lambda 表达式入门

JDK 8 引入 Lambda，用更简洁的写法表示函数式接口的实现。

```java
List<String> names = Arrays.asList("Tom", "Alice", "Bob");

names.forEach(name -> System.out.println(name));
names.sort((a, b) -> a.compareTo(b));
```

语法：

```java
(参数列表) -> 表达式
(参数列表) -> { 语句块; }
```

前提：目标类型必须是函数式接口，即只有一个抽象方法的接口。

## 14. 包、导入与访问权限

包用于组织类并避免类名冲突：

```java
package com.example.student;

import java.util.List;
```

- `package` 必须是源文件中的第一条非注释语句。
- 一个源文件只能声明一个包。
- 导入同包类不需要 `import`。
- `import java.util.*` 只导入当前包中的类型，不会递归导入子包。
- 静态成员可以使用 `import static` 导入。

访问权限从严格到宽松：

| 修饰符 | 同类 | 同包 | 不同包子类 | 任意位置 |
|---|---|---|---|---|
| `private` | 是 | 否 | 否 | 否 |
| 默认（不写） | 是 | 是 | 否 | 否 |
| `protected` | 是 | 是 | 是 | 否 |
| `public` | 是 | 是 | 是 | 是 |

访问权限决定“代码能否访问”，不应只根据属性或方法的功能随意选择。

## 15. 对象内存与匿名对象

创建对象时：

```java
Student student = new Student("张三", 18);
```

可以理解为：

1. 在堆中为对象分配空间。
2. 给成员变量赋默认值。
3. 执行实例初始化代码。
4. 调用构造器。
5. 将对象引用赋给变量。

没有引用变量指向的对象称为匿名对象：

```java
new Printer().print("Hello");
```

匿名对象适合只使用一次的场景，使用后如果没有其他引用，就可能成为垃圾回收候选对象。

## 16. 子类实例化与初始化顺序

创建子类对象时，内存中会同时包含父类部分和子类部分。

初始化顺序通常为：

1. 父类静态成员和静态代码块，按源码顺序执行，且只执行一次。
2. 子类静态成员和静态代码块，按源码顺序执行，且只执行一次。
3. 父类实例成员初始化。
4. 父类构造器。
5. 子类实例成员初始化。
6. 子类构造器。

```java
class Parent {
    static {
        System.out.println("父类静态代码块");
    }

    Parent() {
        System.out.println("父类构造器");
    }
}

class Child extends Parent {
    static {
        System.out.println("子类静态代码块");
    }

    Child() {
        System.out.println("子类构造器");
    }
}
```

子类构造器如果没有显式调用 `super(...)` 或 `this(...)`，编译器会在第一行插入 `super()`。

## 17. 向上转型、向下转型与 instanceof

向上转型是子类对象赋给父类引用：

```java
Animal animal = new Dog();
animal.eat();
```

根据编译时类型，引用只能访问父类声明的成员；根据运行时类型，方法调用发生动态绑定。

向下转型是把父类引用恢复为子类类型：

```java
if (animal instanceof Dog) {
    Dog dog = (Dog) animal;
    dog.bark();
}
```

`instanceof` 在运行时检查对象是否属于指定类型。不要在没有检查的情况下强制转换，否则可能抛出 `ClassCastException`。

> [!warning] 只有对象真实类型满足条件时才能向下转型
> `Animal animal = new Cat();` 不能转型为 `Dog`，因为该对象本来就不是 `Dog`。

## 18. 单例模式

### 18.1 饿汉式

```java
public final class Singleton {
    private static final Singleton INSTANCE = new Singleton();

    private Singleton() {
    }

    public static Singleton getInstance() {
        return INSTANCE;
    }
}
```

饿汉式在类加载时创建对象，简单且线程安全，但可能提前占用资源。

### 18.2 懒汉式与双重检查

```java
public final class LazySingleton {
    private static volatile LazySingleton instance;

    private LazySingleton() {
    }

    public static LazySingleton getInstance() {
        if (instance == null) {
            synchronized (LazySingleton.class) {
                if (instance == null) {
                    instance = new LazySingleton();
                }
            }
        }
        return instance;
    }
}
```

双重检查必须使用 `volatile`，否则其他线程可能看到构造未完成的对象。单例构造器应设为私有，并防止通过反射、反序列化或克隆绕过约束。

## 19. 接口增强与 Lambda 入口

Java 8 之后接口可以有默认方法和静态方法：

```java
public interface Greeting {
    void sayHello();

    default void sayBye() {
        System.out.println("bye");
    }

    static boolean valid(String name) {
        return name != null && !name.trim().isEmpty();
    }
}
```

这不会改变接口的根本定位：接口主要描述能力，默认方法主要用于兼容性演进。

Lambda 是函数式接口的简洁实例化方式：

```java
Runnable task = () -> System.out.println("running");
```

Lambda、函数式接口、方法引用、Stream、Optional 和 `java.time` 的完整内容见 [[10.Java 8 新特性]]。
## 13. 易错清单

- [ ] `String` 内容比较不要用 `==`。
- [ ] 构造器没有返回类型，不能写 `void`。
- [ ] 定义了有参构造器后，需要无参构造器时必须手动补上。
- [ ] 子类重写父类方法时，访问权限不能变严格。
- [ ] 向上转型后不能直接调用子类特有方法。
- [ ] 向下转型前先用 `instanceof` 判断。
- [ ] 静态方法中不能直接访问非静态成员。
- [ ] `final` 修饰引用变量时，引用不可变，不代表对象内容完全不可变。
- [ ] 接口用于定义能力，不要为了“能多继承”而滥用接口。
