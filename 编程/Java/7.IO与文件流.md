# IO 与文件流

> [!info] 资料来源
> 基于语雀《JavaSE核心技术》的 [11.文件与流](https://www.yuque.com/neuedu/campus/giexdpdmi32ztbdw) 整理，并保留原有 `Java基础.pdf` 中关于 `Properties` 的实用内容。

## 1. IO 基本分类

IO 表示输入和输出，参照物通常是运行中的程序：

- **输入流**：外部数据进入程序。
- **输出流**：程序数据写到外部。
- **字节流**：处理字节，适合图片、音频、视频、压缩包和所有二进制文件。
- **字符流**：处理字符，适合文本文件，并负责字符编码转换。

```text
字节输入流：InputStream
字节输出流：OutputStream
字符输入流：Reader
字符输出流：Writer
```

常用实现：

| 场景 | 常用类 |
|---|---|
| 读取文本 | `BufferedReader`、`FileReader` |
| 写出文本 | `BufferedWriter`、`FileWriter` |
| 读取二进制 | `FileInputStream`、`BufferedInputStream` |
| 写出二进制 | `FileOutputStream`、`BufferedOutputStream` |
| 对象序列化 | `ObjectInputStream`、`ObjectOutputStream` |
| 读取配置 | `Properties` |
| 文件和目录元信息 | `File`、`Path`、`Files` |

## 2. File 与 Path

`File` 表示路径或文件系统对象，不会自动打开文件内容。

```java
import java.io.File;

File file = new File("D:/data/demo.txt");

System.out.println(file.exists());
System.out.println(file.isFile());
System.out.println(file.isDirectory());
System.out.println(file.getName());
System.out.println(file.getAbsolutePath());
```

创建目录与文件：

```java
File directory = new File("D:/data");

if (!directory.exists() && !directory.mkdirs()) {
    throw new IllegalStateException("目录创建失败");
}

File file = new File(directory, "demo.txt");

if (!file.exists() && !file.createNewFile()) {
    throw new IllegalStateException("文件创建失败");
}
```

常用方法：

| 方法 | 作用 |
|---|---|
| `exists()` | 路径是否存在 |
| `isFile()` | 是否为普通文件 |
| `isDirectory()` | 是否为目录 |
| `mkdir()` | 创建一级目录 |
| `mkdirs()` | 创建多级目录 |
| `createNewFile()` | 创建空文件 |
| `delete()` | 删除文件或空目录 |
| `length()` | 文件字节数 |
| `listFiles()` | 列出子文件和子目录 |

Java 7 以后还提供了 `Path` 和 `Files`：

```java
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;

Path path = Paths.get("D:/data/demo.txt");
Files.createDirectories(path.getParent());

if (!Files.exists(path)) {
    Files.createFile(path);
}

byte[] bytes = Files.readAllBytes(path);
Files.write(path, "Hello".getBytes("UTF-8"));
```

> [!warning] `File` 不等于文件内容
> `File`、`Path` 主要描述路径和元数据；真正的数据读写由流或 `Files` 完成。打开流后仍要负责关闭资源。

## 3. 字节流

### 3.1 文件复制

```java
import java.io.FileInputStream;
import java.io.FileOutputStream;
import java.io.IOException;

public class FileCopyDemo {
    public static void main(String[] args) {
        try (FileInputStream input = new FileInputStream("source.jpg");
             FileOutputStream output = new FileOutputStream("copy.jpg")) {

            byte[] buffer = new byte[8192];
            int length;
            while ((length = input.read(buffer)) != -1) {
                output.write(buffer, 0, length);
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

`read()` 的返回值：

- 返回正数：本次实际读取的字节数。
- 返回 `-1`：到达输入流末尾。
- 返回 `0`：本次请求长度为零，不是文件结束。

### 3.2 缓冲流

`BufferedInputStream`、`BufferedOutputStream` 在底层流外增加缓冲区，减少频繁系统调用：

```java
try (BufferedInputStream input =
             new BufferedInputStream(new FileInputStream("source.jpg"));
     BufferedOutputStream output =
             new BufferedOutputStream(new FileOutputStream("copy.jpg"))) {

    byte[] buffer = new byte[8192];
    int length;
    while ((length = input.read(buffer)) != -1) {
        output.write(buffer, 0, length);
    }
}
```

> [!important] 二进制文件不能用字符流复制
> 字符流会按编码解释字节，复制图片、音视频或压缩包可能造成数据损坏。

## 4. 字符流

字符流适合文本。字符编码决定字符和字节之间的映射关系，例如 UTF-8、GBK、UTF-16。

### 4.1 读取文本

```java
try (BufferedReader reader =
             new BufferedReader(new FileReader("D:/data/demo.txt"))) {

    String line;
    while ((line = reader.readLine()) != null) {
        System.out.println(line);
    }
}
```

`readLine()` 读到文件末尾时返回 `null`，不包含换行符。

### 4.2 写出文本

```java
try (BufferedWriter writer =
             new BufferedWriter(new FileWriter("D:/data/demo.txt", true))) {

    writer.write("Hello");
    writer.newLine();
    writer.write("World");
}
```

`FileWriter(file, true)` 表示追加，`false` 表示覆盖。

### 4.3 转换流指定编码

`FileReader`、`FileWriter` 使用平台默认编码，跨平台时可能乱码。更稳妥的方式是使用 `InputStreamReader`、`OutputStreamWriter` 显式指定编码：

```java
import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.FileInputStream;
import java.io.FileOutputStream;
import java.io.InputStreamReader;
import java.io.OutputStreamWriter;
import java.nio.charset.StandardCharsets;

try (BufferedReader reader = new BufferedReader(
             new InputStreamReader(
                     new FileInputStream("D:/data/in.txt"),
                     StandardCharsets.UTF_8));
     BufferedWriter writer = new BufferedWriter(
             new OutputStreamWriter(
                     new FileOutputStream("D:/data/out.txt"),
                     StandardCharsets.UTF_8))) {

    String line;
    while ((line = reader.readLine()) != null) {
        writer.write(line);
        writer.newLine();
    }
}
```

## 5. try-with-resources

流、数据库连接、网络连接等资源都应关闭。推荐使用 `try-with-resources`，编译器会自动按相反顺序关闭资源：

```java
try (InputStream input = new FileInputStream("a.txt");
     OutputStream output = new FileOutputStream("b.txt")) {
    // 使用资源
} catch (IOException e) {
    e.printStackTrace();
}
```

要求资源类型实现 `AutoCloseable` 或 `Closeable`。先声明的资源后关闭。

> [!warning] 不要只依赖垃圾回收关闭流
> GC 何时回收对象无法保证。文件描述符、网络连接等资源必须及时显式关闭。

## 6. 对象序列化

序列化把对象状态转换为字节；反序列化把字节恢复为对象。

```java
import java.io.Serializable;

public class Student implements Serializable {
    private static final long serialVersionUID = 1L;

    private String name;
    private int age;

    public Student(String name, int age) {
        this.name = name;
        this.age = age;
    }
}
```

写出对象：

```java
try (ObjectOutputStream output =
             new ObjectOutputStream(new FileOutputStream("student.bin"))) {

    output.writeObject(new Student("张三", 18));
}
```

读取对象：

```java
try (ObjectInputStream input =
             new ObjectInputStream(new FileInputStream("student.bin"))) {

    Student student = (Student) input.readObject();
}
```

要求与注意：

- 被序列化的类必须实现 `Serializable`。
- 对象中的非 `transient` 引用成员也必须可序列化。
- `transient` 成员不会按默认机制序列化。
- `static` 成员属于类，不参与默认序列化。
- 建议显式声明 `serialVersionUID`，降低版本变化导致的兼容问题。
- 反序列化外部不可信数据有安全风险，不应直接处理未知来源内容。

## 7. Properties 配置文件

`Properties` 常用于读取键值对配置。示例 `db.properties`：

```properties
jdbc.driver=com.mysql.cj.jdbc.Driver
jdbc.url=jdbc:mysql://127.0.0.1:3306/school
jdbc.username=root
jdbc.password=your-password
```

从类路径读取：

```java
import java.io.InputStream;
import java.util.Properties;

public class ConfigDemo {
    public static void main(String[] args) throws Exception {
        Properties properties = new Properties();

        try (InputStream input = ConfigDemo.class.getClassLoader()
                .getResourceAsStream("db.properties")) {

            if (input == null) {
                throw new IllegalStateException("找不到 db.properties");
            }

            properties.load(input);
        }

        String url = properties.getProperty("jdbc.url");
        System.out.println(url);
    }
}
```

`getResourceAsStream()` 从类路径查找资源；`new FileInputStream()` 从文件系统路径查找文件，两者的相对路径基准不同。

## 8. 常见错误

- [ ] 文件路径中的反斜杠没有转义，应使用 `/` 或 `\\`。
- [ ] 忘记关闭流，导致文件被占用或文件描述符耗尽。
- [ ] 用字符流复制二进制文件。
- [ ] 使用平台默认编码读写 UTF-8 文本，导致跨环境乱码。
- [ ] 把 `read()` 返回 `0` 误认为文件结束。
- [ ] 序列化对象中存在不可序列化的成员。
- [ ] 把密码等敏感信息直接提交到版本库。
- [ ] 把 `Properties` 的相对路径与类路径资源混为一谈。
