# 数组与常用算法

> [!info] 资料来源
> 基于语雀《JavaSE核心技术》的 [04.数组](https://www.yuque.com/neuedu/campus/cvk3x1mbv26pzeqt)、[05.方法的定义和调用](https://www.yuque.com/neuedu/campus/ywdnangng6nmvxxv) 补充。


## 1. 数组基础

数组用于保存**多个相同类型**的数据，元素在内存中连续存放。数组是引用类型。

```java
int[] numbers = {10, 20, 30, 40};
```

推荐声明方式：

```java
数据类型[] 数组名;
```

创建固定长度数组：

```java
int[] scores = new int[5];
```

创建并初始化：

```java
int[] numbers = new int[]{10, 20, 30};
int[] values = {10, 20, 30};
```

> [!warning] 创建数组时，不能同时写长度和初始化列表。
> `int[] a = new int[3]{1, 2, 3};` 是错误的。

### 1.1 下标与长度

```java
int[] array = {10, 20, 30};

System.out.println(array[0]);      // 10
System.out.println(array.length);  // 3
```

- 下标从 `0` 开始。
- 有效下标范围是 `0` 到 `array.length - 1`。
- 数组长度固定，创建后不能直接增加或减少。

### 1.2 默认值

| 元素类型 | 默认值 |
|---|---|
| `byte`、`short`、`int`、`long` | `0`、`0L` |
| `float`、`double` | `0.0F`、`0.0D` |
| `char` | `'\u0000'` |
| `boolean` | `false` |
| 对象引用 | `null` |

## 2. 遍历数组

### 2.1 普通 for

```java
int[] array = {10, 20, 30};

for (int i = 0; i < array.length; i++) {
    System.out.println(array[i]);
}
```

需要下标、修改元素或从后向前遍历时使用普通 `for`。

### 2.2 foreach

```java
for (int value : array) {
    System.out.println(value);
}
```

foreach 只适合顺序读取全部元素，不能在遍历时方便地修改原数组元素的位置。

## 3. 动态创建数组

```java
import java.util.Scanner;

public class ScoreDemo {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.print("人数：");
        int count = input.nextInt();

        double[] scores = new double[count];
        for (int i = 0; i < scores.length; i++) {
            System.out.print("第" + (i + 1) + "个成绩：");
            scores[i] = input.nextDouble();
        }

        for (double score : scores) {
            System.out.println(score);
        }
    }
}
```

## 4. 常见统计算法

### 4.1 最值、和、平均值

```java
int[] array = {34, 56, 6, 7, 8, 1879, 567, 2345, 245, 677};

int max = array[0];
int min = array[0];
int sum = 0;

for (int value : array) {
    sum += value;
    if (value > max) {
        max = value;
    }
    if (value < min) {
        min = value;
    }
}

double average = sum * 1.0 / array.length;
```

> [!tip] 为什么 `max` 初始化为 `array[0]`
> 如果初始化为 `0`，当数组全是负数时，最大值会错误地保持为 0。

## 5. 排序算法

### 5.1 冒泡排序

思想：相邻两个元素比较，逆序则交换。每轮把一个最大或最小的元素放到正确位置。

```java
int[] array = {34, 56, 6, 7, 8, 1879, 567, 2345, 245, 677};

for (int i = 0; i < array.length - 1; i++) {
    for (int j = 0; j < array.length - 1 - i; j++) {
        if (array[j] > array[j + 1]) {
            int temp = array[j];
            array[j] = array[j + 1];
            array[j + 1] = temp;
        }
    }
}
```

易错点：

- 外层比较轮数通常是 `length - 1`。
- 每一轮已经排好的尾部元素不再参与比较。
- 交换时必须借助临时变量。

### 5.2 选择排序

每一轮从未排序区间选出最小值，与未排序区间的第一个元素交换。

```java
for (int i = 0; i < array.length - 1; i++) {
    int minIndex = i;
    for (int j = i + 1; j < array.length; j++) {
        if (array[j] < array[minIndex]) {
            minIndex = j;
        }
    }
    int temp = array[i];
    array[i] = array[minIndex];
    array[minIndex] = temp;
}
```

### 5.3 插入排序

思想：把当前元素插入到前面已经有序的区间中。

```java
for (int i = 1; i < array.length; i++) {
    int current = array[i];
    int j = i - 1;

    while (j >= 0 && array[j] > current) {
        array[j + 1] = array[j];
        j--;
    }
    array[j + 1] = current;
}
```

课件中“在固定长度数组中插入一个新值”的练习不是完整的排序，而是先在有序数组中寻找插入位置，再把后面的元素整体向后移动。

## 6. 查找算法

### 6.1 线性查找

逐个比较，数组是否有序都可以使用，时间复杂度为 `O(n)`。

```java
int target = 30;
int index = -1;

for (int i = 0; i < array.length; i++) {
    if (array[i] == target) {
        index = i;
        break;
    }
}
```

### 6.2 二分查找

二分查找要求数组必须有序，每次排除一半区间，时间复杂度为 `O(log n)`。

```java
int left = 0;
int right = array.length - 1;
int target = 30;
int index = -1;

while (left <= right) {
    int mid = left + (right - left) / 2;

    if (array[mid] == target) {
        index = mid;
        break;
    } else if (array[mid] < target) {
        left = mid + 1;
    } else {
        right = mid - 1;
    }
}
```

> [!warning] 二分查找前必须先排序。
> 如果数组无序，二分判断方向的前提不成立。

## 7. 二维数组

二维数组可以理解为“数组的数组”。

```java
int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6}
};

System.out.println(matrix[1][2]); // 6
```

遍历：

```java
for (int i = 0; i < matrix.length; i++) {
    for (int j = 0; j < matrix[i].length; j++) {
        System.out.print(matrix[i][j] + "\t");
    }
    System.out.println();
}
```

### 7.1 不规则二维数组

```java
int[][] triangle = new int[5][];

for (int i = 0; i < triangle.length; i++) {
    triangle[i] = new int[i + 1];
}
```

### 7.2 杨辉三角

```java
int n = 6;
int[][] triangle = new int[n][];

for (int i = 0; i < n; i++) {
    triangle[i] = new int[i + 1];

    for (int j = 0; j <= i; j++) {
        if (j == 0 || i == j) {
            triangle[i][j] = 1;
        } else {
            triangle[i][j] = triangle[i - 1][j]
                    + triangle[i - 1][j - 1];
        }
    }
}
```

规律：每一行首尾为 1，其余元素等于上一行同列元素与上一行前一列元素之和。

## 8. 方法

### 8.1 定义与调用

```java
public static int add(int a, int b) {
    return a + b;
}

public static void main(String[] args) {
    int result = add(10, 20);
    System.out.println(result);
}
```

格式：

```java
访问修饰符 返回类型 方法名(参数列表) {
    方法体
}
```

- `void` 表示没有返回值。
- 有返回值的方法必须保证所有分支都能返回对应类型的值。
- 调用方法时传入的称为实参；定义方法时声明的称为形参。

### 8.2 方法返回值

```java
public static int[] createArray(int n) {
    int[] array = new int[n];
    return array;
}
```

### 8.3 参数传递

Java 中只有值传递：

- 基本类型传入的是数值副本，方法内重新赋值不会影响调用方。
- 对象或数组传入的是“引用值的副本”。方法通过该引用修改对象内容，调用方能看到变化；若给形参重新赋值为另一个对象，调用方变量仍指向原对象。

```java
public static void change(int value) {
    value = 100; // 不影响调用方
}

public static void fill(int[] array) {
    array[0] = 100; // 会影响调用方看到的数组内容
}
```

> [!important] 课件所称“引用传递”
> 应改用 Java 的正式说法：传递对象引用的副本。这个区别在方法内部重新给形参赋值时尤其重要。

## 11. 数组内存模型

数组变量保存的是指向数组对象的引用。数组对象在堆中分配，元素在内存中连续排列：

```java
int[] numbers = new int[4];
numbers[0] = 10;
```

![数组内存模型](array-memory.png)

> 图源：语雀《JavaSE核心技术·04.数组》4.5。

- `numbers` 是引用变量。
- `new int[4]` 创建包含 4 个元素的数组对象。
- 默认情况下四个元素的值为 0。
- `numbers[0]` 通过下标访问数组中的第一个元素。

数组变量赋值不会复制数组：

```java
int[] first = {1, 2, 3};
int[] second = first;

second[0] = 100;
System.out.println(first[0]); // 100
```

`first` 和 `second` 指向同一个数组对象。

## 12. 数组复制与工具方法

### 12.1 System.arraycopy

```java
int[] source = {1, 2, 3, 4, 5};
int[] target = new int[5];

System.arraycopy(source, 0, target, 0, source.length);
```

参数依次是：源数组、源起始下标、目标数组、目标起始下标、复制长度。

### 12.2 Arrays.copyOf

```java
import java.util.Arrays;

int[] expanded = Arrays.copyOf(source, 8);
int[] shortened = Arrays.copyOf(source, 3);
```

目标长度大于源长度时，多出的位置使用元素类型默认值；目标长度更小时会截断。

### 12.3 Arrays.sort 与 binarySearch

```java
int[] values = {5, 1, 3, 2, 4};
Arrays.sort(values);

int index = Arrays.binarySearch(values, 3);
```

二分查找前必须先排序，否则结果不可靠。返回非负值表示找到的下标；返回负值表示未找到，负值与插入位置有关。

### 12.4 Arrays.toString 与 deepToString

```java
int[] numbers = {1, 2, 3};
int[][] matrix = {{1, 2}, {3, 4}};

System.out.println(Arrays.toString(numbers));
System.out.println(Arrays.deepToString(matrix));
```

直接打印数组变量通常只得到类似 `[I@...` 的引用信息，不会输出元素。

## 13. 方法分类与重载

方法按返回值和参数可分为四类：

| 类型 | 是否有返回值 | 是否有参数 | 示例场景 |
|---|---|---|---|
| 黑洞方法 | 否 | 否 | 打印固定信息 |
| 消费者方法 | 否 | 是 | 保存数据、修改对象 |
| 生产者方法 | 是 | 否 | 生成随机数、读取时间 |
| 输入输出方法 | 是 | 是 | 计算、查询、转换 |

重载发生在同一个类中：方法名相同，但参数个数、类型或顺序不同。

```java
public static int add(int a, int b) {
    return a + b;
}

public static double add(double a, double b) {
    return a + b;
}

public static int add(int a, int b, int c) {
    return a + b + c;
}
```

仅返回值类型不同不构成重载。编译器在调用时根据实参类型和数量选择最匹配的方法。

## 14. 方法调用栈

方法调用在 JVM 调用栈中保存栈帧。每调用一个方法就压入栈帧，方法返回后弹出；递归过深可能抛出 `StackOverflowError`。

```java
public static int factorial(int n) {
    if (n <= 1) {
        return 1;
    }
    return n * factorial(n - 1);
}
```

递归必须定义终止条件，并确保每次调用都向终止条件靠近。
## 10. 易错清单

- [ ] 数组越界：访问了下标 `length` 或更大的位置。
- [ ] 混淆 `array.length` 和字符串的 `str.length()`。
- [ ] `new int[5]` 的合法下标是 0 到 4。
- [ ] 数组变量保存的是引用，直接赋值 `b = a` 不会复制数组。
- [ ] 二分查找前没有排序。
- [ ] 交换两个变量时缺少临时变量，导致其中一个值被覆盖。
