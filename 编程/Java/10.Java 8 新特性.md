# Java 8 新特性

> [!info] 资料来源
> 基于语雀《JavaSE核心技术》的 [13.JDK新特性](https://www.yuque.com/neuedu/campus/ly1dyeqreptbuxhe) 整理。所有示例均可使用 JDK 8 编译。

## 1. 接口增强

Java 8 允许接口包含：

- 抽象方法
- 默认方法：`default`
- 静态方法：`static`

### 1.1 默认方法

```java
public interface Greeting {
    void sayHello();

    default void sayBye() {
        System.out.println("bye");
    }
}
```

实现类可以不重写默认方法：

```java
public class ChineseGreeting implements Greeting {
    @Override
    public void sayHello() {
        System.out.println("你好");
    }
}
```

默认方法用于在保持二进制兼容的前提下为已有接口增加能力，例如 Java 8 的 `Collection.forEach()`。

如果一个类实现的多个接口提供同名同参数默认方法，编译会冲突，必须在实现类中重写：

```java
@Override
public void run() {
    InterfaceA.super.run();
}
```

### 1.2 静态方法

```java
public interface Validator {
    static boolean isPositive(int value) {
        return value > 0;
    }
}
```

接口静态方法通过接口名调用：

```java
Validator.isPositive(10);
```

接口静态方法不会被实现类继承，也不能通过实现类实例调用。

## 2. Lambda 表达式

Lambda 表达式用于简洁地表示函数式接口的实例。

```java
Runnable task = () -> System.out.println("running");
new Thread(task).start();
```

### 2.1 语法

```text
(参数列表) -> 表达式
(参数列表) -> { 语句块; return 结果; }
```

示例：

```java
Comparator<Integer> comparator = (a, b) -> Integer.compare(a, b);
Function<String, Integer> length = text -> text.length();
Consumer<String> printer = text -> System.out.println(text);
Supplier<String> supplier = () -> "hello";
```

规则：

- 参数类型可以省略，由编译器推断。
- 只有一个参数时，参数列表的括号可以省略。
- 表达式体只有一条语句时，可以省略 `return` 和花括号。
- Lambda 没有自己的 `this`，它捕获的是外层对象的 `this`。
- Lambda 只能访问有效的 `final` 局部变量，即变量初始化后不再改变。

> [!warning] 不是任意接口都能使用 Lambda
> Lambda 的目标类型必须是函数式接口，也就是只有一个抽象方法的接口。可以有多个默认方法或静态方法。

## 3. 函数式接口

```java
@FunctionalInterface
public interface Calculator {
    int calculate(int a, int b);
}
```

使用：

```java
Calculator add = (a, b) -> a + b;
int result = add.calculate(10, 20);
```

`@FunctionalInterface` 让编译器检查是否恰好只有一个抽象方法。

### 3.1 内置函数式接口

| 接口 | 抽象方法 | 含义 |
|---|---|---|
| `Predicate<T>` | `boolean test(T t)` | 判断 |
| `Function<T,R>` | `R apply(T t)` | 转换 |
| `Consumer<T>` | `void accept(T t)` | 消费，无返回值 |
| `Supplier<T>` | `T get()` | 提供结果 |
| `UnaryOperator<T>` | `T apply(T t)` | 同类型一元运算 |
| `BinaryOperator<T>` | `T apply(T a, T b)` | 同类型二元运算 |

组合示例：

```java
Predicate<String> notEmpty = text -> text != null && !text.isEmpty();
Predicate<String> shortText = text -> text.length() <= 10;
Predicate<String> valid = notEmpty.and(shortText);

Function<String, Integer> length = String::length;
Consumer<String> printer = System.out::println;
```

## 4. 方法引用

当 Lambda 只是调用一个已有方法时，可以改写成方法引用。

| 形式 | 示例 |
|---|---|
| 静态方法引用 | `Integer::parseInt` |
| 实例方法引用 | `System.out::println` |
| 特定对象的实例方法引用 | `text::startsWith` |
| 特定类型的任意对象方法引用 | `String::length` |
| 构造器引用 | `ArrayList::new` |

```java
Function<String, Integer> parser = Integer::parseInt;
Supplier<ArrayList<String>> factory = ArrayList::new;
```

方法引用不是新语法概念，而是 Lambda 的简化写法；参数和返回值必须与函数式接口匹配。

## 5. Stream 流式编程

Stream 用于对集合进行声明式处理，不会修改原集合。它表达“做什么”，而不是显式编写每一步循环。

### 5.1 创建流

```java
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);

Stream<Integer> stream1 = numbers.stream();
Stream<Integer> stream2 = Stream.of(1, 2, 3);
Stream<Integer> stream3 = Arrays.stream(new int[]{1, 2, 3}).boxed();
```

### 5.2 中间操作与终止操作

中间操作返回新的 Stream，通常延迟执行；终止操作触发整个流水线执行。

常见中间操作：

| 操作 | 作用 |
|---|---|
| `filter` | 过滤元素 |
| `map` | 一对一转换 |
| `flatMap` | 一对多展开 |
| `distinct` | 去重 |
| `sorted` | 排序 |
| `limit` | 限制数量 |
| `skip` | 跳过前若干元素 |

常见终止操作：

| 操作 | 作用 |
|---|---|
| `forEach` | 遍历 |
| `collect` | 收集结果 |
| `count` | 计数 |
| `anyMatch` / `allMatch` / `noneMatch` | 条件匹配 |
| `findFirst` / `findAny` | 查找元素 |
| `reduce` | 归约 |
| `min` / `max` | 最值 |

示例：

```java
List<String> result = Arrays.asList("Java", "C", "Python", "Go", "Java")
        .stream()
        .filter(name -> name.length() >= 2)
        .distinct()
        .sorted()
        .map(String::toUpperCase)
        .collect(Collectors.toList());

System.out.println(result);
```

流水线只有在遇到终止操作时才真正执行。合理顺序通常是先过滤、再转换，以减少后续处理量：

```java
List<String> names = people.stream()
        .filter(person -> person.getAge() >= 18)
        .map(Person::getName)
        .collect(Collectors.toList());
```

### 5.3 串行流与并行流

```java
long count = numbers.stream()
        .filter(number -> number % 2 == 0)
        .count();

long parallelCount = numbers.parallelStream()
        .filter(number -> number % 2 == 0)
        .count();
```

并行流使用公共 `ForkJoinPool`，并不保证更快。以下情况应谨慎：

- 数据量很小。
- 操作有顺序要求。
- 任务包含阻塞 IO。
- Lambda 修改共享状态，导致线程安全问题。

> [!important] Stream 不是集合
> Stream 是一次性流水线，一个 Stream 通常只能消费一次。重复使用会抛出 `IllegalStateException`。

## 6. Optional

`Optional<T>` 用于显式表达“结果可能不存在”，它不是为了完全替代 `null`。

### 6.1 创建 Optional

```java
Optional<String> empty = Optional.empty();
Optional<String> value = Optional.of("Java");
Optional<String> nullable = Optional.ofNullable(getName());
```

- `Optional.of(null)` 会抛出 `NullPointerException`。
- `Optional.ofNullable(null)` 得到空对象。

### 6.2 常用操作

```java
String name = Optional.ofNullable(getName())
        .map(String::trim)
        .filter(text -> !text.isEmpty())
        .orElse("未知");
```

```java
Optional<String> name = Optional.ofNullable(getName());

name.ifPresent(System.out::println);
String uppercase = name.map(String::toUpperCase).orElse("N/A");
```

> [!warning] 不要把 Optional 当作字段类型或到处传递
> Optional 更适合作为方法返回值，明确告诉调用方结果可能不存在。不要写 `optional.get()` 后立即赌它有值；优先使用 `orElse`、`orElseGet`、`ifPresent`、`map` 链式处理。

## 7. java.time 日期时间 API

旧的 `Date`、`Calendar` 和 `SimpleDateFormat` 可变、线程安全问题较多。Java 8 引入 `java.time`，核心对象通常不可变且更适合并发环境。

### 7.1 创建与获取

```java
LocalDate date = LocalDate.of(2026, 10, 10);
LocalTime time = LocalTime.of(9, 30);
LocalDateTime dateTime = LocalDateTime.of(date, time);

LocalDate now = LocalDate.now();
LocalDateTime current = LocalDateTime.now();
Instant instant = Instant.now();
```

`LocalDate`、`LocalTime`、`LocalDateTime` 不包含时区信息；`Instant` 表示时间轴上的瞬时点。

### 7.2 获取字段

```java
int year = date.getYear();
int month = date.getMonthValue();
int day = date.getDayOfMonth();
DayOfWeek week = date.getDayOfWeek();
```

### 7.3 加减与修改

```java
LocalDate tomorrow = date.plusDays(1);
LocalDate lastMonth = date.minusMonths(1);
LocalDate firstDay = date.withDayOfMonth(1);
```

这些方法返回新对象，不会修改原对象。

### 7.4 格式化与解析

`DateTimeFormatter` 是线程安全的：

```java
DateTimeFormatter formatter =
        DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");

String text = dateTime.format(formatter);
LocalDateTime parsed = LocalDateTime.parse(text, formatter);
```

### 7.5 日期差与时间差

```java
LocalDate start = LocalDate.of(2026, 1, 1);
LocalDate end = LocalDate.of(2026, 10, 10);

Period period = Period.between(start, end);
long days = ChronoUnit.DAYS.between(start, end);

Instant begin = Instant.now();
// 执行任务
Instant finish = Instant.now();
Duration duration = Duration.between(begin, finish);
```

- `Period` 表示日期差，以年、月、日为单位。
- `Duration` 表示时间差，以秒、纳秒为单位。
- 计算两个日期的总天数时，优先使用 `ChronoUnit.DAYS.between()`。

### 7.6 与旧日期类型转换

```java
Date legacyDate = Date.from(instant);
Instant fromLegacy = legacyDate.toInstant();
```

与 `java.sql.Date`、`java.sql.Timestamp` 交互时，应在数据库访问层集中转换，不要在业务代码中扩散旧 API。

## 8. 易错清单

- [ ] 把 Lambda 用在有多个抽象方法的接口上。
- [ ] 在 Lambda 中修改外层可变局部变量。
- [ ] 认为方法引用和普通 Lambda 在所有重载场景下都完全等价。
- [ ] 重复消费同一个 Stream。
- [ ] 在并行流中修改共享集合或计数器。
- [ ] 认为并行流一定比串行流快。
- [ ] 使用 `Optional.get()` 前不判断是否存在。
- [ ] 仍然在并发场景共享 `SimpleDateFormat`。
- [ ] 混淆 `LocalDateTime` 与带时区的 `ZonedDateTime`。
