## 学习主线

1. **建立程序结构**：理解 JVM、JDK、JRE，掌握源文件、类、`main` 方法和编译运行过程。
2. **掌握数据与运算符**：变量保存数据，运算符表达式完成计算，类型转换决定精度和范围。
3. **组织程序逻辑**：选择、循环、数组和方法负责控制流程与复用代码。
4. **建立对象模型**：类与对象描述数据和行为，继承、多态、接口和泛型降低耦合。
5. **处理运行问题**：集合组织内存数据，异常表达失败，IO 和 JDBC 连接外部世界。
6. **进入并发与现代化**：多线程处理并发任务，Java 8 的 Lambda、Stream 和 `java.time` 提供现代写法。

## 必须区分的核心概念

| 概念 | 结论 |
|---|---|
| Java 参数传递 | Java 只有值传递。对象参数传的是引用值的副本；修改对象内容可见，重新给形参赋值不影响调用方 |
| `==` 与 `equals` | `==` 比较基本类型值或引用地址；`equals` 通常比较对象内容，具体行为由类决定 |
| `String`、`StringBuilder`、`StringBuffer` | `String` 不可变；`StringBuilder` 单线程更快；`StringBuffer` 同步但通常更慢 |
| 抽象类与接口 | 抽象类表达“是什么”，可有构造器和实例字段；接口表达“能做什么”，支持多实现 |
| 重载与重写 | 重载在同类中参数列表不同；重写在父子类之间方法签名相同 |
| `HashMap` 与 `Hashtable` | `HashMap` 允许一个 `null` 键和多个 `null` 值；`Hashtable` 不允许 `null` |
| 受检异常与运行时异常 | 受检异常必须处理或声明；运行时异常通常表示编程错误 |
| IO 字节流与字符流 | 字节流适合所有二进制数据；字符流适合文本并负责编码转换 |
| JDBC Statement 与 PreparedStatement | 固定 SQL 可用 `Statement`；含参数 SQL 必须优先使用 `PreparedStatement` |
| 并发与并行 | 并发强调任务在重叠时间内推进；并行强调同一时刻真正执行 |
| `sleep()` 与 `wait()` | `sleep()` 不释放锁；`wait()` 会释放对象锁并进入等待集合 |
| Stream 与集合 | 集合保存数据；Stream 描述一次性流水线，不负责存储 |

## 课件勘误与现代化提示

> [!warning] 使用旧代码时注意
> - “引用传递”不是 Java 的正式术语，应表述为“传递对象引用的副本”。
> - JDK 9 以后 `Class.newInstance()` 已过时，反射创建对象优先使用 `getDeclaredConstructor().newInstance()`。
> - `new Integer(0)` 等包装类构造器已不推荐，应使用 `Integer.valueOf(0)` 或自动装箱。
> - 单线程字符串拼接优先使用 `StringBuilder`，不要机械认为 `StringBuffer` 总是更好。
> - `SimpleDateFormat`、`Calendar` 不是线程安全类型；Java 8 项目优先使用 `java.time`。
> - `DriverManager` 和手工连接适合学习 JDBC 原理，实际项目通常使用连接池和框架。
> - MySQL 8 驱动类名为 `com.mysql.cj.jdbc.Driver`，旧课件中的 `com.mysql.jdbc.Driver` 只适用于旧驱动。
> - 数据库密码不能硬编码或提交到公开仓库。
> - `Hashtable` 是旧同步容器，现代并发场景优先考虑 `ConcurrentHashMap`。
> - 并行流不一定比串行流快，并且不能在 Lambda 中随意修改共享状态。
