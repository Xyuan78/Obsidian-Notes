# Java 核心语法

> [!info] 资料来源
> 基于语雀《JavaSE核心技术》的 [02.变量和运算符](https://www.yuque.com/neuedu/campus/qd0vhu23h3krts7k)、[03.流程控制语句](https://www.yuque.com/neuedu/campus/lys0d4pxasg2l51v) 补充。


## 1. 字面量

作用：告诉程序员数据在程序中的书写格式

| 类型 | 说明 | 写法 |
|------|------|------|
| 整数 | 不带小数点数字 | `666`, `-88` |
| 小数 | 带小数点数字 | `13.14` |
| 字符 | 必须使用单引号，有且仅能一个字符 | `'A'`, `'我'` |
| 字符串 | 必须使用双引号，内容可有可无 | `"HelloWorld"` |
| 布尔值 | 表示真假 | `true`, `false` |
| 空值 | 特殊的值，空置 | `null` |

## 2. 变量

### 2.1 什么是变量？

变量是在程序中临时存储数据的容器，但只能存一个值

### 2.2 变量的格式

```java
数据类型 变量名 = 数据值;
```

> [!warning] 注意
> 变量名不能重复，变量在使用之前要赋值

## 3. 数据类型

### 3.1 分类

- 基本数据类型
- 引用数据类型

### 3.2 基本数据类型的八类

| 数据类型 | 关键字 | 内存占用 | 取值范围 |
|----------|--------|----------|----------|
| 整数 | `byte` | 1 | $-2^{7} \sim 2^{7}-1$（-128~127） |
| | `short` | 2 | $-2^{15} \sim 2^{15}-1$（-32768~32767） |
| | `int` | 4 | $-2^{31} \sim 2^{31}-1$ |
| | `long` | 8 | $-2^{63} \sim 2^{63}-1$ |
| 浮点数 | `float` | 4 | $1.401298e^{-45} \sim 3.402823e^{38}$ |
| | `double` | 8 | $4.9000000e^{-324} \sim 1.797693e^{308}$ |
| 字符 | `char` | 2 | 0~65535 |
| 布尔 | `boolean` | 1 | `true`, `false` |

> [!tip] 取值范围大小
> `double` > `float` > `long` > `int` > `short` > `byte`

## 4. 标识符

一般遵循阿里巴巴的命名规则（见名知意）

- 必须由数字、字母、下划线 `_`、美元符号 `$` 组成
- 数字不能开头
- 不能是关键字
- 区分大小写

### 4.1 小驼峰命名法

适用于变量名和方法名

- 一个单词，全部小写
- 多个单词，从第二个单词开始首字母大写，如 `firstName`, `maxAge`

### 4.2 大驼峰命名法

适用于类名

- 一个单词，首字母大写，如 `Demo`
- 多个单词，每一个单词首字母都要大写，如 `HelloWorld`

## 5. 键盘录入

在 `Scanner` 这个类中

```java
// 1. 导包，找到 Scanner 这个类
import java.util.Scanner;

public class ScannerDemo1 {
    public static void main(String[] args) {
        // 2. 创建对象，申明准备使用 Scanner 类
        Scanner sc = new Scanner(System.in);
        // 3. 接收数据
        System.out.println("请输入一个数字");
        int i = sc.nextInt();
        System.out.println(i);
    }
}
```

## 6. 算术运算符

### `+` `-` `*` `/` `%`

- `/`：整数相除只能得到整数，想得到小数必须有小数参与
- `%`：取模，得到余数

## 7. 隐式转换

把一个取值范围小的数据或变量，赋值给另一个取值范围大的变量，程序自动完成

## 8. 强制转换

把一个取值范围大的数据或变量赋值给另一个取值范围小的变量，必须强制转换

```java
目标数据类型 变量名 = (目标数据类型) 被强转的数据;
```

要转为什么类型，就在小括号中写什么类型

## 9. 字符串 + 操作

- 当 `+` 操作中出现字符串时，此时是字符串的拼接，会拼接前后数据并产生一个新的字符串
- 当连续进行 `+` 操作时，从左到右逐个进行

## 10. 字符的 + 操作

当 `+` 操作中出现了字符，会拿着字符对应的 ASCII 码表中的数字进行计算

```java
char c = 'a';
int result = c + 0;
System.out.println(result); // 97
```

## 11. 自增自减运算符

- `++`：自增
- `--`：自减

放在变量前面：先 ++；放在变量后面：后 ++

## 12. 扩展运算符

`+=`、`-=`、`/=`、`%=`

```java
a += b   // 相当于 a = a + b
```

## 13. 关系运算符

| 符号 | 解释 |
|------|------|
| `==` | 判断左右是否相等，成立为 `true`，否则 `false` |
| `!=` | 判断左右是否不相等，成立为 `true`，否则 `false` |
| `>` | 判断左边是否大于右边 |
| `>=` | 判断左边是否大于等于右边 |
| `<` | 判断左边是否小于右边 |
| `<=` | 判断左边是否小于等于右边 |

## 14. 逻辑运算符

### `&` `|` `!` 的使用

- **`&`（逻辑与）**：两边都为真，结果才为真
- **`|`（逻辑或）**：两边都为假，结果才为假
- **`!`（取反 / 非）**：`false` 取反为 `true`

## 15. 三元运算符

```java
关系表达式 ? 表达式1 : 表达式2;
```

- 如果表达式为真，执行表达式 1
- 如果表达式为假，执行表达式 2

## 17. 程序结构与命名补充

一个 Java 源文件通常由包声明、导入声明和类声明组成：

```java
package com.example;

import java.util.Scanner;

public class Demo {
    public static void main(String[] args) {
        // 程序入口
    }
}
```

标识符用于命名类、变量、方法和包：

- 可以由字母、数字、下划线 `_`、美元符号 `$` 和部分 Unicode 字符组成。
- 不能以数字开头。
- 不能使用 Java 关键字或保留字。
- 区分大小写。
- 类名通常使用大驼峰，变量和方法使用小驼峰，常量使用全大写加下划线。

常见关键字分类：

| 分类 | 示例 |
|---|---|
| 访问控制 | `public`、`protected`、`private` |
| 类型 | `class`、`interface`、`enum`、`void` |
| 流程控制 | `if`、`else`、`switch`、`for`、`while` |
| 异常 | `try`、`catch`、`finally`、`throw`、`throws` |
| 对象与类 | `new`、`this`、`super`、`static`、`final` |
| 包与引用 | `package`、`import`、`instanceof` |

`const` 和 `goto` 是保留字，但 Java 目前没有使用它们。

## 18. 字面量细节

```java
int decimal = 100;
int binary = 0b1010_0001;
int hex = 0xFF;
long large = 10_000_000_000L;
double price = 12.5D;
float rate = 1.5F;
char chinese = '中';
String text = "Java";
```

- 下划线可以出现在数字字面量中，但只能位于数字之间。
- `long` 字面量建议使用 `L`，避免小写 `l` 与数字 `1` 混淆。
- `float` 字面量必须加 `F`，否则 `1.5` 默认是 `double`。
- `char` 使用单引号且只能有一个字符；`String` 使用双引号。
- 浮点数不能精确表示所有十进制小数，金额计算应使用 `BigDecimal`。

## 19. 表达式求值补充

- Java 按运算符优先级和结合性求值；不确定时主动增加括号。
- `&&` 和 `||` 具有短路特点：左侧能确定结果时，右侧不执行。
- `&` 和 `|` 同时是位运算符，用于布尔表达式时不会短路。
- 整数相除会舍去小数部分：`5 / 2` 得到 `2`。
- 整数运算溢出不会自动抛出异常，结果会按二进制补码回绕。
- 自增、自减和复合赋值包含隐式类型转换，可能掩盖精度或溢出问题。

```java
boolean result = false && (10 / 0 > 1); // 右侧不会执行
System.out.println(5 / 2);               // 2
System.out.println(5.0 / 2);             // 2.5
```

## 20. 类型转换补充

自动类型转换满足“范围较小的类型到范围较大的类型”：

```text
byte -> short -> int -> long -> float -> double
              char -> int
```

强制转换可能丢失数据：

```java
double value = 3.99;
int number = (int) value; // 3，小数部分被截断

int large = 130;
byte small = (byte) large; // 溢出，结果不是 130
```

> [!warning] 浮点类型并不总比整数类型“精确”
> `long` 转 `float`、`double` 可能丢失有效数字。对精度有要求的金额、科学计算和标识符，应选择适当的数据类型。
