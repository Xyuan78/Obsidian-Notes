# JDBC 技术

> [!info] 资料来源
> 基于语雀《JavaSE核心技术》的 [JDBC技术](https://www.yuque.com/neuedu/campus/gsxdwk4z9961py1d) 整理。示例按 JDK 8 编写，数据库驱动信息按现代 MySQL 8 驱动说明。

## 1. JDBC 是什么

JDBC（Java Database Connectivity）是 Java 访问关系型数据库的标准 API。它定义了一套统一接口，具体数据库差异由各厂商提供的 JDBC 驱动实现。

JDBC 的核心价值是解耦：

- Java 程序面向 `java.sql` 标准接口编程。
- 更换数据库时，通常只需替换驱动和连接配置。
- SQL、事务和结果集处理方式保持一致。

## 2. 核心接口与类

| 类型                  | 作用                 |
| ------------------- | ------------------ |
| `Driver`            | 数据库驱动接口，由数据库厂商实现   |
| `DriverManager`     | 管理驱动并创建连接          |
| `Connection`        | 表示一次数据库连接和事务上下文    |
| `Statement`         | 执行静态 SQL           |
| `PreparedStatement` | 执行带参数的预编译 SQL，优先使用 |
| `CallableStatement` | 调用存储过程             |
| `ResultSet`         | 保存查询结果，提供行游标       |
| `SQLException`      | JDBC 操作异常          |

### 2.1 JDBC 驱动类型

1. **JDBC-ODBC 桥接驱动**：依赖 ODBC，已过时。
2. **本地 API 驱动**：调用数据库本地客户端库。
3. **网络协议驱动**：通过中间服务器转换协议。
4. **纯 Java 驱动**：直接与数据库通信，现代 JDBC 主要采用此方式。

现代项目通常不需要显式调用 `Class.forName`；只要驱动 JAR 位于运行时类路径，JDBC 4.0 之后可通过 SPI 自动发现驱动。传统教学代码显式加载驱动并非错误，但已不是必需步骤。

## 3. 标准执行流程

```text
加载/准备驱动
  -> 获取 Connection
  -> 创建 Statement / PreparedStatement
  -> 设置参数
  -> 执行 SQL
  -> 处理 ResultSet 或更新行数
  -> 提交或回滚事务
  -> 关闭资源
```

连接 MySQL 的现代 JDBC URL 示例：

```java
String url = "jdbc:mysql://127.0.0.1:3306/school"
        + "?useUnicode=true"
        + "&characterEncoding=UTF-8"
        + "&serverTimezone=Asia/Shanghai"
        + "&useSSL=false"
        + "&allowPublicKeyRetrieval=true";
String username = "root";
String password = "your-password";
```

> [!warning] 驱动坐标
> MySQL 8 使用 `com.mysql.cj.jdbc.Driver`，Maven 坐标通常为 `com.mysql:mysql-connector-j`。旧版课件中的 `com.mysql.jdbc.Driver` 和旧版本号只适用于旧驱动。

## 4. 建立连接

```java
import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.SQLException;

public class JdbcConnectionDemo {
    public static void main(String[] args) {
        String url = "jdbc:mysql://127.0.0.1:3306/school"
                + "?useUnicode=true&characterEncoding=UTF-8"
                + "&serverTimezone=Asia/Shanghai";
        try (Connection connection =
                     DriverManager.getConnection(url, "root", "your-password")) {
            System.out.println(connection.getCatalog());
        } catch (SQLException e) {
            e.printStackTrace();
        }
    }
}
```

生产代码不应把密码硬编码在源码中。可从环境变量、启动参数或受保护的配置系统读取。

## 5. Statement 与 PreparedStatement

### 5.1 静态 SQL

```java
try (Connection connection = DriverManager.getConnection(url, username, password);
     Statement statement = connection.createStatement();
     ResultSet resultSet =
             statement.executeQuery("SELECT id, name FROM student")) {

    while (resultSet.next()) {
        System.out.println(resultSet.getLong("id") + "\t"
                + resultSet.getString("name"));
    }
}
```

`Statement` 适合完全可信、没有外部参数的固定 SQL。只要 SQL 含用户输入，就应优先使用 `PreparedStatement`。

### 5.2 增删改

```java
String sql = "INSERT INTO student(student_no, name, age) VALUES (?, ?, ?)";

try (Connection connection = DriverManager.getConnection(url, username, password);
     PreparedStatement ps = connection.prepareStatement(sql)) {

    ps.setString(1, "2026001");
    ps.setString(2, "张三");
    ps.setInt(3, 18);

    int rows = ps.executeUpdate();
    System.out.println("影响行数：" + rows);
}
```

- `executeUpdate()` 用于 `INSERT`、`UPDATE`、`DELETE`，返回受影响行数。
- 参数下标从 1 开始。
- 参数值会作为数据处理，而不是拼接进 SQL 结构。

### 5.3 查询

```java
String sql = "SELECT student_no, name, age FROM student WHERE age >= ?";

try (Connection connection = DriverManager.getConnection(url, username, password);
     PreparedStatement ps = connection.prepareStatement(sql)) {

    ps.setInt(1, 18);

    try (ResultSet resultSet = ps.executeQuery()) {
        while (resultSet.next()) {
            String studentNo = resultSet.getString("student_no");
            String name = resultSet.getString("name");
            int age = resultSet.getInt("age");
            System.out.println(studentNo + "\t" + name + "\t" + age);
        }
    }
}
```

`ResultSet.next()` 将游标移动到下一行；返回 `false` 表示没有更多数据。默认结果集通常是只读、只进的。

读取 SQL `NULL` 时要区分“值为 0”和“值为空”：

```java
int age = resultSet.getInt("age");
if (resultSet.wasNull()) {
    // age 在数据库中为 NULL
}
```

## 6. SQL 注入与 PreparedStatement

危险写法：

```java
String sql = "SELECT * FROM users WHERE username = '"
        + username + "' AND password = '" + password + "'";
```

攻击者构造特殊输入后，可能改变 SQL 的判断逻辑。安全写法：

```java
String sql = "SELECT id, username FROM users "
        + "WHERE username = ? AND password_hash = ?";

try (Connection connection = DriverManager.getConnection(url, username, password);
     PreparedStatement ps = connection.prepareStatement(sql)) {

    ps.setString(1, loginName);
    ps.setString(2, passwordHash);

    try (ResultSet resultSet = ps.executeQuery()) {
        // 判断是否查询到用户
    }
}
```

> [!important] 参数不能代表 SQL 结构
> `PreparedStatement` 可以安全绑定值，但不能用参数占位表名、列名、`ORDER BY` 方向等 SQL 结构。此类动态结构必须从白名单中选择。

## 7. JDBC 类型与日期时间

| Java 类型 | SQL 类型示例 |
|---|---|
| `int` / `Integer` | `INT` |
| `long` / `Long` | `BIGINT` |
| `double` / `Double` | `DOUBLE` |
| `boolean` / `Boolean` | `BOOLEAN` |
| `String` | `VARCHAR`、`CHAR`、`TEXT` |
| `BigDecimal` | `DECIMAL`、`NUMERIC` |
| `java.sql.Date` | `DATE` |
| `java.sql.Time` | `TIME` |
| `java.sql.Timestamp` | `TIMESTAMP` |

Java 8 时间类型可以通过 JDBC 4.2 API 绑定和读取：

```java
LocalDate birthday = LocalDate.of(2000, 1, 1);
ps.setObject(1, birthday);

LocalDateTime createdAt = resultSet.getObject(
        "created_at", LocalDateTime.class);
```

不同数据库对类型映射和时区处理存在差异，生产代码必须明确数据库时区、JVM 时区和 JDBC 驱动版本。

## 8. JDBC 工具类与资源管理

资源关闭顺序应与创建顺序相反：

```text
ResultSet -> Statement / PreparedStatement -> Connection
```

`try-with-resources` 会自动按相反顺序关闭资源：

```java
public final class JdbcUtils {
    private JdbcUtils() {
    }

    public static Connection getConnection(
            String url, String username, String password) throws SQLException {
        return DriverManager.getConnection(url, username, password);
    }
}
```

更完整的配置可保存在 `db.properties` 中：

```properties
jdbc.driver=com.mysql.cj.jdbc.Driver
jdbc.url=jdbc:mysql://127.0.0.1:3306/school?serverTimezone=Asia/Shanghai
jdbc.username=root
jdbc.password=your-password
```

```java
Properties properties = new Properties();
try (InputStream input = JdbcUtils.class.getClassLoader()
        .getResourceAsStream("db.properties")) {

    if (input == null) {
        throw new IllegalStateException("找不到 db.properties");
    }

    properties.load(input);
    String url = properties.getProperty("jdbc.url");
    String username = properties.getProperty("jdbc.username");
    String password = properties.getProperty("jdbc.password");

    try (Connection connection =
                 DriverManager.getConnection(url, username, password)) {
        // 执行数据库操作
    }
}
```

> [!warning] 工具类不是连接池
> `DriverManager` 每次调用通常都会创建新的物理连接。学习原理时可以使用，实际服务应使用连接池。

## 9. 事务处理

事务就是把多条数据库操作作为一个整体执行，满足 ACID：

- 原子性（Atomicity）：要么全部成功，要么全部失败。
- 一致性（Consistency）：从一个合法状态转到另一个合法状态。
- 隔离性（Isolation）：并发事务之间按隔离级别相互影响。
- 持久性（Durability）：已提交结果应被可靠保存。

![JDBC 事务回滚示意](jdbc-transaction-rollback.png)

> 图源：语雀《JavaSE核心技术·JDBC技术》7.5.1。

```java
Connection connection = null;

try {
    connection = DriverManager.getConnection(url, username, password);
    connection.setAutoCommit(false);

    try (PreparedStatement out = connection.prepareStatement(
                 "UPDATE account SET balance = balance - ? WHERE id = ?");
         PreparedStatement in = connection.prepareStatement(
                 "UPDATE account SET balance = balance + ? WHERE id = ?")) {

        out.setBigDecimal(1, amount);
        out.setLong(2, fromId);
        out.executeUpdate();

        in.setBigDecimal(1, amount);
        in.setLong(2, toId);
        in.executeUpdate();
    }

    connection.commit();
} catch (SQLException e) {
    if (connection != null) {
        try {
            connection.rollback();
        } catch (SQLException rollbackError) {
            e.addSuppressed(rollbackError);
        }
    }
    throw new RuntimeException("转账失败", e);
} finally {
    if (connection != null) {
        try {
            connection.close();
        } catch (SQLException ignored) {
            // 真实项目应记录日志
        }
    }
}
```

要点：

- JDBC 连接默认自动提交，事务开始前应设置 `setAutoCommit(false)`。
- 所有操作成功后调用 `commit()`。
- 捕获异常后调用 `rollback()`。
- 连接池中归还连接前必须恢复自动提交状态，框架通常会处理。

## 10. 批处理

批量插入时，逐条执行会产生较多网络往返。`addBatch()` 和 `executeBatch()` 可以合并发送：

```java
String sql = "INSERT INTO student(student_no, name, age) VALUES (?, ?, ?)";

try (Connection connection = DriverManager.getConnection(url, username, password);
     PreparedStatement ps = connection.prepareStatement(sql)) {

    connection.setAutoCommit(false);

    for (Student student : students) {
        ps.setString(1, student.getStudentNo());
        ps.setString(2, student.getName());
        ps.setInt(3, student.getAge());
        ps.addBatch();
    }

    ps.executeBatch();
    connection.commit();
} catch (SQLException e) {
    throw new RuntimeException("批量写入失败", e);
}
```

批大小需要根据数据量、驱动和数据库限制调整，不能无限累积。

## 11. DAO 与 MVC

DAO（Data Access Object）把数据库访问封装在独立层中：

```text
Controller -> Service -> DAO -> JDBC -> Database
```

DAO 的职责：

- 提供按业务含义命名的数据访问方法。
- 封装 SQL、参数绑定、结果集转换和资源关闭。
- 不把 `ResultSet` 暴露给业务层。

```java
public interface StudentDao {
    Student findById(long id) throws SQLException;
    List<Student> findAll() throws SQLException;
    int insert(Student student) throws SQLException;
}
```

实现类可以将 `ResultSet` 转换为对象：

```java
private Student map(ResultSet rs) throws SQLException {
    Student student = new Student();
    student.setId(rs.getLong("id"));
    student.setStudentNo(rs.getString("student_no"));
    student.setName(rs.getString("name"));
    student.setAge(rs.getInt("age"));
    return student;
}
```

> [!tip] 不要过早手写 ORM
> 反射映射适合理解 DAO 和 ORM 原理。实际项目通常使用 MyBatis、JPA/Hibernate 或 Spring JDBC，但仍应理解连接、事务和资源生命周期。
>
> 本仓库已整理 MyBatis 专题笔记（MyBatis 正是封装 JDBC 的半自动 ORM），入口见 [[0.MyBatis总览]]。

## 12. 常见错误

- [ ] 占位符下标从 1 开始，却按 0 编写。
- [ ] 使用字符串拼接用户输入，造成 SQL 注入。
- [ ] 忘记设置参数、执行 SQL 或关闭资源。
- [ ] 使用 `getInt()` 读取可为空的数值后，没有调用 `wasNull()`。
- [ ] 在连接池环境中手动关闭连接后继续使用同一个连接。
- [ ] 事务中出现异常却没有回滚。
- [ ] 驱动类名、Maven 坐标和数据库版本不匹配。
- [ ] URL 中没有明确时区、字符集或必要的连接参数。
- [ ] 把数据库密码直接写入公开仓库。
