# Java 入门与流程控制

## 1. Java 程序的运行过程

Java 源文件扩展名为 `.java`，编译后生成 `.class` 字节码文件，再由 JVM 执行：

```text
HelloWorld.java
    --javac 编译-->
HelloWorld.class
    --java 运行-->
JVM 执行字节码
```

三个概念：

- **JVM**：Java 虚拟机，负责执行字节码，是实现跨平台的关键。
- **JRE**：Java 运行环境，包含 JVM 和运行所需类库。
- **JDK**：Java 开发工具包，包含 JRE、编译器和其他开发工具。

> [!tip] “一次编写，到处运行”
> Java 源代码先编译成平台无关的字节码，再由各平台自己的 JVM 执行，因此不需要为每个平台重新编译源代码。

## 2. 第一个 Java 程序

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("HelloWorld");
    }
}
```

执行结果：

```text
HelloWorld
```

### 2.1 类名规则

- 使用大驼峰命名法：`HelloWorld`、`StudentManager`。
- 可以由字母、数字、下划线 `_` 和美元符号 `$` 组成。
- 不能以数字开头。
- 不能使用 Java 关键字。
- 区分大小写。
- `public` 类名必须与文件名完全一致。

> [!warning] 常见错误
> 文件名为 `HelloWorld.java`，类名写成 `Helloworld`，会因为大小写不一致而编译失败。

### 2.2 main 方法

```java
public static void main(String[] args)
```

| 部分 | 含义 |
|---|---|
| `public` | 访问权限为公开 |
| `static` | 不需要创建对象即可由 JVM 调用 |
| `void` | 方法没有返回值 |
| `main` | JVM 约定的程序入口方法名 |
| `String[] args` | 命令行参数数组 |

### 2.3 注释

```java
// 单行注释

/*
   多行注释
*/

/**
 * 文档注释，可用于生成 API 文档。
 */
```

### 2.4 输出与转义字符

```java
System.out.println("输出后换行");
System.out.print("输出后不换行");

System.out.println("第一行\n第二行");
System.out.println("姓名\t年龄");
System.out.println("他说：\"你好\"");
System.out.println("路径：C:\\Java");
```

| 转义字符 | 作用 |
|---|---|
| `\n` | 换行 |
| `\t` | 制表位 |
| `\"` | 双引号 |
| `\'` | 单引号 |
| `\\` | 反斜杠 |

## 3. 变量、常量与数据类型

### 3.1 变量三要素

```java
int age = 18;
```

- 数据类型：`int`
- 变量名：`age`
- 初始值：`18`

变量必须先声明并赋值后使用，同一个作用域内不能重复声明同名变量。

### 3.2 基本类型

| 类型 | 占用 | 示例 | 默认值 |
|---|---:|---|---|
| `byte` | 1 字节 | `byte b = 100;` | `0` |
| `short` | 2 字节 | `short s = 1000;` | `0` |
| `int` | 4 字节 | `int n = 100000;` | `0` |
| `long` | 8 字节 | `long n = 100000L;` | `0L` |
| `float` | 4 字节 | `float f = 3.14F;` | `0.0F` |
| `double` | 8 字节 | `double d = 3.14;` | `0.0D` |
| `char` | 2 字节 | `char c = 'A';` | `'\u0000'` |
| `boolean` | 由 JVM 实现决定 | `boolean ok = true;` | `false` |

记忆要点：

- Java 默认的小数字面量是 `double`。
- 要写 `float`，必须在数字后加 `F` 或 `f`。
- 要写 `long`，建议在数字后加 `L`，避免超出 `int` 范围。
- `char` 用单引号且只能放一个字符；`String` 用双引号。

### 3.3 常量

```java
static final int MAX_COUNT = 100;
```

`final` 修饰的变量只能赋值一次，常量名通常全部大写，多个单词用下划线分隔。

## 4. 键盘输入

```java
import java.util.Scanner;

public class InputDemo {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.print("请输入年龄：");
        int age = input.nextInt();

        System.out.print("请输入姓名：");
        String name = input.next();

        System.out.println(name + "：" + age);
    }
}
```

常用方法：

| 方法 | 读取内容 |
|---|---|
| `nextInt()` | 整数 |
| `nextDouble()` | 小数 |
| `next()` | 一个不含空格的字符串 |
| `nextLine()` | 当前行剩余内容 |

> [!warning] 混用 `nextInt()` 与 `nextLine()`
> `nextInt()` 读取数字后会留下换行符，下一次调用 `nextLine()` 可能直接读到空字符串。需要时可在两者之间额外调用一次 `nextLine()` 消耗换行符。

## 5. 运算符

### 5.1 算术运算符

```java
int a = 7;
int b = 3;

System.out.println(a + b); // 10
System.out.println(a - b); // 4
System.out.println(a * b); // 21
System.out.println(a / b); // 2，整数除法
System.out.println(a % b); // 1，取余
System.out.println(a * 1.0 / b); // 2.333...
```

- 整数与整数相除，结果仍是整数。
- 想得到小数，至少让一个操作数为小数类型。
- `%` 可用于判断整除、提取个位数字、循环取范围等。

### 5.2 自增、自减与复合赋值

```java
int i = 1;
System.out.println(i++); // 先使用，再自增，输出 1
System.out.println(i);   // 2
System.out.println(++i); // 先自增，再使用，输出 3

int n = 10;
n += 5; // n = n + 5
```

复合赋值包含隐式强制转换：

```java
short s = 10;
s += 1;       // 合法，相当于 s = (short)(s + 1)
// s = s + 1; // 编译错误，右侧结果类型是 int
```

### 5.3 关系运算符

| 运算符 | 含义 |
|---|---|
| `==` | 是否相等 |
| `!=` | 是否不相等 |
| `>`、`>=` | 大于、大于等于 |
| `<`、`<=` | 小于、小于等于 |

关系表达式结果是 `boolean`。

### 5.4 逻辑运算符

```java
boolean a = true;
boolean b = false;

System.out.println(a & b);  // false，两边都计算
System.out.println(a | b);  // true，两边都计算
System.out.println(!a);     // false

System.out.println(a && b); // false，短路与
System.out.println(a || b); // true，短路或
```

- `&&`：左边为 `false` 时，右边不计算。
- `||`：左边为 `true` 时，右边不计算。
- `&`、`|` 也会计算两边；若操作数是整数，还可表示按位运算。

### 5.5 位运算符

位运算符按二进制位处理整数：

| 运算符 | 含义 | 示例 |
|---|---|---|
| `&` | 按位与 | `6 & 3` 结果为 `2` |
| `\|` | 按位或 | `6 \| 3` 结果为 `7` |
| `^` | 按位异或，相同为 0，不同为 1 | `6 ^ 3` 结果为 `5` |
| `~` | 按位取反 | `~0` 结果为 `-1` |
| `<<` | 左移 | `3 << 1` 结果为 `6` |
| `>>` | 有符号右移 | `-4 >> 1` 结果为 `-2` |
| `>>>` | 无符号右移 | 高位补 0 |

```java
int a = 6;  // 0000 0110
int b = 3;  // 0000 0011

System.out.println(a & b);  // 2
System.out.println(a | b);  // 7
System.out.println(a ^ b);  // 5
System.out.println(a << 1); // 12
```

位运算适合底层数据处理、权限标志和性能敏感场景。普通业务代码应优先保证可读性。

### 5.6 三元运算符

```java
int score = 80;
String result = score >= 60 ? "及格" : "不及格";
```

格式：

```java
条件表达式 ? 条件成立时的值 : 条件不成立时的值
```

### 5.7 运算符优先级

优先级较高的常见运算符：

```text
一元运算符 > 算术运算 > 移位 > 关系 > 相等 > 位运算 > 逻辑运算 > 三元 > 赋值
```

不确定时直接使用括号，不要依赖复杂优先级记忆。

## 6. 类型转换

### 6.1 隐式转换

```java
int i = 100;
double d = i;
```

小范围类型可以自动转换为大范围类型：

```text
byte -> short -> int -> long -> float -> double
                 char -> int
```

### 6.2 强制转换

```java
double d = 3.99;
int i = (int) d; // 3，小数部分被截断
```

> [!warning] 强制转换可能造成数据丢失或数值变化，必须确认业务上允许。

### 6.3 字符与字符串参与运算

```java
char c = 'a';
System.out.println((int) c); // 97

System.out.println(1 + 2 + "3");   // "33"
System.out.println("1" + 2 + 3);   // "123"
System.out.println('a' + 1);       // 98
System.out.println("a" + 1);       // "a1"
```

当 `+` 的一侧是字符串时，执行字符串拼接；连续 `+` 从左到右计算。

## 7. 选择结构

### 7.1 if

```java
if (score >= 90) {
    System.out.println("优秀");
} else if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}
```

### 7.2 switch

```java
int month = 4;
switch (month) {
    case 1:
    case 3:
    case 5:
    case 7:
    case 8:
    case 10:
    case 12:
        System.out.println("31天");
        break;
    case 4:
    case 6:
    case 9:
    case 11:
        System.out.println("30天");
        break;
    case 2:
        System.out.println("28或29天");
        break;
    default:
        System.out.println("月份错误");
}
```

课件适用版本为 JDK 8，`switch` 支持：

- `byte`、`short`、`char`、`int`
- 枚举
- `String`（Java 7 开始）

`case` 后必须是常量；忘记 `break` 会发生穿透，继续执行后续分支。

### 7.3 闰年判断

```java
boolean isLeapYear = year % 400 == 0
        || (year % 4 == 0 && year % 100 != 0);
```

## 8. 循环结构

### 8.1 while

```java
int i = 1;
while (i <= 5) {
    System.out.println(i);
    i++;
}
```

适合循环次数事先不确定的场景。

### 8.2 do-while

```java
int i = 1;
do {
    System.out.println(i);
    i++;
} while (i <= 5);
```

至少执行一次循环体。

### 8.3 for

```java
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
```

结构：

```java
for (初始化; 循环条件; 迭代语句) {
    循环体
}
```

### 8.4 嵌套循环

外层控制行，内层控制列：

```java
for (int i = 1; i <= 5; i++) {
    for (int j = 1; j <= i; j++) {
        System.out.print("*");
    }
    System.out.println();
}
```

### 8.5 break 与 continue

- `break`：立即结束当前循环或 `switch`。
- `continue`：跳过本次循环剩余语句，进入下一次迭代。

```java
for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        continue;
    }
    if (i == 8) {
        break;
    }
    System.out.println(i);
}
```

## 9. 典型循环练习

| 题目 | 核心思路 |
|---|---|
| 计算 `1 + 2 + ... + n` | 累加变量从 0 开始，循环更新 |
| 计算 `n!` | 累乘变量必须是 `long` 或 `BigInteger`，不能从 0 开始 |
| 倒序输出整数各位 | 通过 `n % 10` 取末位，再 `n /= 10` 缩小 |
| 判断素数 | 试除到 `sqrt(n)` 即可 |
| 打印乘法表 | 外层控制行，内层控制列 |
| 打印三角形 | 外层控制行，内层分别控制空格和星号 |
| 求最大公约数 | 辗转相除法 |
| 猴子吃桃 | 使用倒推，按题目规则反向计算 |
| 万年历 | 先计算已知日期到目标日期的总天数，再用总天数对 7 取余 |

## 11. Java 平台与运行过程

Java 技术体系通常分为：

| 名称 | 作用 |
|---|---|
| JVM | Java 虚拟机，执行字节码，屏蔽操作系统差异 |
| JRE | Java 运行环境，包含 JVM 和运行所需类库 |
| JDK | Java 开发工具包，包含 JRE、编译器和开发工具 |

源码到运行的流程：

```text
Demo.java --javac--> Demo.class --JVM--> 运行结果
```

- `javac` 编译源码为 JVM 字节码。
- `.class` 文件由 JVM 装载和执行。
- JVM 可以在不同平台运行同一份字节码，这是“一次编写，到处运行”的基础。
- Java 通常被描述为“编译成字节码，再由 JVM 解释或即时编译执行”，并不是纯粹的编译型或解释型语言。

## 12. 流程控制补充

### 12.1 switch 的注意点

```java
switch (day) {
    case 1:
    case 2:
    case 3:
    case 4:
    case 5:
        System.out.println("工作日");
        break;
    default:
        System.out.println("休息日");
}
```

- 忘记 `break` 会继续执行后续 `case`，称为穿透。
- 可以利用有意穿透合并相同逻辑的多个分支。
- `default` 可以放在任意位置，但通常放在最后。
- switch 只适合对离散值进行多分支判断，不适合复杂区间判断。

### 12.2 循环选择

| 结构 | 适用场景 |
|---|---|
| `for` | 已知循环次数或按索引遍历 |
| `while` | 次数未知，先判断条件再执行 |
| `do-while` | 至少执行一次，再判断条件 |

`break` 结束当前循环，`continue` 跳过本次剩余语句进入下一次迭代。嵌套循环中，标签可以明确指定要中断的外层循环，但可读性通常有限，应谨慎使用。

```java
outer:
for (int i = 0; i < 5; i++) {
    for (int j = 0; j < 5; j++) {
        if (i + j == 4) {
            break outer;
        }
    }
}
```
## 10. 易错清单

- [ ] `=` 是赋值，`==` 才是比较。
- [ ] 整数除法会丢弃小数，计算平均值时写成 `sum * 1.0 / count`。
- [ ] `for` 循环变量作用域只在循环内部。
- [ ] 循环条件必须在某次迭代后趋向结束，避免死循环。
- [ ] `switch` 分支忘记 `break` 会穿透。
- [ ] `print` 不换行，`println` 才换行。
- [ ] `String` 比较内容使用 `equals`，不要依赖 `==`。
