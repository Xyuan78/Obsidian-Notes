# 表单基础

## 表单的作用

表单用于收集用户输入，并将数据提交给服务器或交给 JavaScript 处理。

```html
<form action="/login" method="post">
  <!-- 表单控件 -->
</form>
```

- `action`：提交目标的 URL。
- `method`：常见值为 `get` 或 `post`。
- `get` 通常用于查询，参数会出现在 URL 中。
- `post` 通常用于创建、修改或提交敏感数据。

## label 与 input

```html
<div>
  <label for="username">用户名</label>
  <input id="username" name="username" type="text" required />
</div>
```

- `label` 的 `for` 要和控件的 `id` 对应。
- 点击文字时可以聚焦对应控件。
- `name` 决定提交时字段的名称。
- `required` 表示该字段必填。

也可以把控件嵌在 `label` 中：

```html
<label>
  邮箱
  <input type="email" name="email" />
</label>
```

## 常见 input 类型

```html
<input type="text" name="nickname" />
<input type="password" name="password" />
<input type="email" name="email" />
<input type="number" name="age" min="0" max="120" />
<input type="date" name="birthday" />
<input type="search" name="keyword" />
<input type="file" name="avatar" />
<input type="color" name="theme" />
```

正确的 `type` 可以启用移动端专用键盘和浏览器原生校验。

## 单选框与复选框

```html
<fieldset>
  <legend>选择学习方向</legend>

  <label>
    <input type="radio" name="direction" value="frontend" checked />
    前端
  </label>

  <label>
    <input type="radio" name="direction" value="backend" />
    后端
  </label>

  <label>
    <input type="checkbox" name="skills" value="html" />
    HTML
  </label>
</fieldset>
```

同一组单选框必须使用相同的 `name`。复选框可以多选。

## 下拉框与多行文本

```html
<label for="city">城市</label>
<select id="city" name="city">
  <option value="">请选择</option>
  <option value="beijing">北京</option>
  <option value="shanghai">上海</option>
</select>

<label for="message">留言</label>
<textarea id="message" name="message" rows="5"></textarea>
```

## 按钮

```html
<button type="submit">提交</button>
<button type="reset">重置</button>
<button type="button">普通按钮</button>
```

在表单中，按钮默认可能表现为提交按钮。需要明确写出 `type`，避免意外提交。

## 常用校验属性

```html
<input type="email" name="email" required />
<input type="text" name="code" minlength="6" maxlength="12" />
<input type="number" name="score" min="0" max="100" step="1" />
<input type="text" name="phone" pattern="[0-9]{11}" />
```

浏览器原生校验只能作为第一层校验，服务器端仍需再次验证。

## 可用性建议

- 每个输入框都应有可理解的标签。
- 必填项和错误信息要清晰可见。
- 不要只靠颜色表达状态。
- 相关控件使用 `fieldset` 和 `legend` 分组。
- 设置 `autocomplete` 可以帮助用户快速填写。
- 表单布局和交互应支持键盘操作。

### form 的常用属性

```html
<form action="/register" method="post" name="registerForm" enctype="multipart/form-data">
  <!-- 表单控件 -->
</form>
```

- `action`：数据提交到哪个服务器地址。
- `method`：提交方式，常见为 `get` 和 `post`。
- `name`：表单名称。
- `id`：页内唯一标识，便于 CSS 和 JavaScript 选择。
- `enctype`：提交数据编码；包含文件上传时通常使用 `multipart/form-data`。

### text 控件的常用属性

```html
<input
  type="text"
  name="username"
  value="默认值"
  placeholder="请输入用户名"
  size="30"
  maxlength="15"
  pattern="[1-9]\d{6,}"
  required
/>
```

- `value`：默认值。
- `placeholder`：未输入时的提示，不能代替 `label`。
- `size`：文本框大致显示长度。
- `maxlength`：允许输入的最大字符数。
- `pattern`：使用正则表达式限制输入格式。
- `required`：必填。
- `readonly`：只读，仍会提交。
- `disabled`：禁用，通常不会提交，也不能聚焦。

### 选择状态

```html
<input type="radio" name="gender" value="男" checked />
<input type="checkbox" name="hobby" value="HTML" checked />
<select name="education">
  <option value="1">专科</option>
  <option value="2" selected>本科</option>
</select>
```

- 单选框必须使用相同的 `name` 才能组成互斥组。
- 复选框可以使用相同的 `name` 收集多个值。
- `checked` 设置单选框或复选框默认选中。
- `selected` 设置下拉选项默认选中。

### fieldset 与 legend

```html
<fieldset>
  <legend>账号信息</legend>
  <label for="user">用户名</label>
  <input id="user" name="user" />
</fieldset>
```

`fieldset` 用于把相关控件分组，`legend` 是这一组的标题。

### datalist 输入建议

```html
<label for="site">网站</label>
<input id="site" name="site" list="site-list" />
<datalist id="site-list">
  <option value="www"></option>
  <option value="w3c"></option>
  <option value="MDN"></option>
</datalist>
```

`datalist` 提供可输入的建议列表，用户仍可以填写列表之外的内容。

### select 与 optgroup

```html
<select name="major">
  <optgroup label="理工类">
    <option value="se">软件工程</option>
    <option value="cs" selected>计算机科学与技术</option>
  </optgroup>
  <optgroup label="文史类">
    <option value="history">历史学</option>
  </optgroup>
</select>
```

`optgroup` 用于给下拉选项分组。

### 表单按钮

```html
<input type="submit" value="注册" />
<input type="reset" value="重写" />
<input type="button" value="普通按钮" />
<input type="image" src="./img/login.gif" alt="登录" />
<button type="submit">提交</button>
```

- `submit`：提交表单。
- `reset`：重置为初始值。
- `button` / `type="button"`：普通按钮，通常由 JavaScript 绑定行为。
- `image`：图片形式的提交按钮。
- `button` 元素必须明确写出 `type`，避免默认提交行为。

### data-* 自定义属性

```html
<input id="custom" type="text" data-aaa="自定义值" />

<script>
  const input = document.getElementById("custom");
  console.log(input.dataset.aaa);
</script>
```

- HTML 中自定义数据属性必须使用 `data-` 前缀。
- JavaScript 中通过 `dataset` 读取，例如 `data-aaa` 对应 `dataset.aaa`。
- 自定义属性适合保存与元素相关的小型数据，不应存放敏感信息。
