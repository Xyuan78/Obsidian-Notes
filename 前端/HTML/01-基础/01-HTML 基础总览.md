# HTML 基础总览

> [!abstract] 一句话理解
> HTML 负责描述页面“有什么内容”和“内容是什么含义”，不负责复杂的视觉样式与交互逻辑。

## HTML 是什么

HTML（HyperText Markup Language，超文本标记语言）通过标签为内容添加结构。例如：

- 标题使用 `<h1>` 到 `<h6>`。
- 段落使用 `<p>`。
- 链接使用 `<a>`。
- 图片使用 `<img>`。

浏览器读取 HTML 后，会把它解析为 DOM 树，再结合 CSS 和 JavaScript 完成展示与交互。

## 最小文档结构

```html
<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>我的第一个页面</title>
  </head>
  <body>
    <h1>你好，HTML</h1>
    <p>这是一个最小可运行的 HTML 页面。</p>
  </body>
</html>
```

各部分作用：

- `<!DOCTYPE html>`：声明使用 HTML5 标准。
- `<html>`：整个文档的根元素。
- `lang="zh-CN"`：告诉浏览器和辅助技术页面主要使用简体中文。
- `<head>`：保存页面元数据，不直接显示在页面主体中。
- `<meta charset="UTF-8">`：使用 UTF-8 编码，减少中文乱码。
- `<meta name="viewport">`：移动端布局的基础配置。
- `<title>`：浏览器标签页标题。
- `<body>`：用户实际看到的主要内容。

## 元素的组成

```html
<a href="https://example.com" target="_blank">访问示例网站</a>
```

- 开始标签：`<a>`
- 结束标签：`</a>`
- 元素内容：`访问示例网站`
- 属性名：`href`
- 属性值：`https://example.com`
- 布尔属性：例如 `disabled`，可以只写属性名。

没有内容、也不需要结束标签的元素称为空元素，例如：

```html
<img src="avatar.jpg" alt="用户头像" />
<br />
<hr />
<input type="text" />
```

## 注释与字符实体

HTML 注释：

```html
<!-- 这里是注释，不会显示在页面中 -->
```

部分字符有特殊含义，需要使用字符实体：

```html
<p>小于号：&lt;，大于号：&gt;，和号：&amp;</p>
```

## 基础编写规范

- 使用小写标签名和属性名。
- 属性值使用双引号，保持一致。
- 正确嵌套标签，不要交叉闭合。
- 使用有意义的标签表达内容含义。
- 图片提供 `alt`，表单控件提供 `label`。
- 缩进清晰，但不要为了视觉效果滥用 `<br>`。

## 常见错误

- 忘记 `<!DOCTYPE html>`。
- 中文页面未设置 UTF-8。
- 用多个 `<br>` 代替段落或布局。
- 用 `<div>` 包住所有内容，忽略语义化标签。
- 图片缺少 `alt` 属性。
- 标题层级跳级，例如从 `<h1>` 直接到 `<h4>`。

## 练习

1. 创建一个完整 HTML5 文档。
2. 页面中写一级标题、两个段落和一条水平线。
3. 添加一条注释和至少一个字符实体。
4. 使用浏览器开发者工具检查 DOM 结构。

### 静态网站与动态网站

- 静态网站：页面文件编辑完成后，内容通常不会因用户或服务器数据变化而改变。
- 动态网站：页面通过用户与服务器交互生成或返回不同内容，例如搜索、登录、购物车。
- 本课程阶段主要学习由 HTML、CSS、JavaScript 构成的静态网页。

### 开发环境与项目目录

- HTML 文件扩展名通常为 `.html`，也可以使用 `.htm`。
- 课程中使用 IDEA 或 HBuilderX 新建普通项目、基本 HTML 项目或静态网站项目。
- 常见课程目录会把网页统一放在 `html5` 文件夹中，再按页面、图片、样式和脚本分类。
- 编辑完成后可直接把 HTML 文件拖到浏览器中运行，也可以使用开发服务器打开。

### 编译执行与解释执行

- 编译执行：例如 Java，先编译源文件，再由虚拟机执行编译结果。
- 解释执行：HTML 由浏览器读取并逐项解释标签，通常不需要手动编译。
- HTML 代码由浏览器解析。遇到不合法内容时，不同浏览器可能会跳过、修正或继续解析。
- 现代页面应以 HTML 标准为准，不能依赖某个浏览器的容错行为。

### 标记语言与标签分类

HTML 不是编程语言，而是一种描述网页结构和含义的标记语言。

- 闭合标签：有开始标签和结束标签，例如 `<p>内容</p>`。
- 空元素：没有内容，通常不需要单独结束标签，例如 `<br />`、`<hr />`、`<input />`。
- 现代 HTML 中写 `<br>` 合法；课程示例使用 `<br />`，主要是沿用 XHTML 的自闭合风格，项目内保持一致即可。

### 语法要求

- 标签名和属性名在 HTML 中通常不区分大小写，但推荐全部小写。
- 属性值应始终使用引号，双引号最常用。
- 属性值内部包含双引号时，外层可以使用单引号。
- 不要依赖浏览器自动补齐结束标签，结构必须写完整。
- 标签要正确嵌套，不要交叉闭合。

```html
<p class="intro">推荐写法</p>
<input type="text" name="username" />
```

### 常用全局属性

```html
<p id="intro" class="text highlight" style="color: red;">内容</p>
```

- `id`：页面中的唯一标识。
- `class`：一个或多个类名，便于 CSS 和 JavaScript 选择。
- `style`：元素的行内样式，适合临时测试，项目中优先使用外部样式表。
- `title`：鼠标悬停时显示的补充说明，但不能替代可见标签。

### 查看源码与调试

- 编辑器可以查看项目源文件。
- 浏览器“查看网页源代码”看到的是服务器返回的原始 HTML。
- 按 `F12` 打开开发者工具，可以查看浏览器解析后的 DOM、样式和网络请求。
- 页面结构与 JavaScript 修改结果应以开发者工具中的 Elements 面板为准。

### 字符实体

某些字符在 HTML 中有特殊含义，需要使用字符实体：

| 显示结果 | 描述 | 实体名称 | 实体编号 |
| --- | --- | --- | --- |
| 空格 | 不换行空格 | `&nbsp;` | `&#160;` |
| `<` | 小于号 | `&lt;` | `&#60;` |
| `>` | 大于号 | `&gt;` | `&#62;` |
| `&` | 和号 | `&amp;` | `&#38;` |
| `"` | 双引号 | `&quot;` | `&#34;` |
| `'` | 撇号 | `&apos;` | `&#39;` |
| `©` | 版权 | `&copy;` | `&#169;` |
| `®` | 注册商标 | `&reg;` | `&#174;` |
| `×` | 乘号 | `&times;` | `&#215;` |
| `÷` | 除号 | `&divide;` | `&#247;` |

HTML 标签名不区分大小写，但字符实体名称区分大小写。
