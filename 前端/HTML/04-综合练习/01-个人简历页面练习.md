# 个人简历页面练习

> [!goal] 练习目标
> 只使用 HTML 完成一个结构清晰、语义正确、便于后续添加 CSS 的个人简历页面。

## 页面内容

至少包含：

- 姓名和个人简介。
- 联系方式或社交链接。
- 教育经历。
- 技能列表。
- 项目经历。
- 页脚版权信息。

## 推荐结构

```html
<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>张三的简历</title>
  </head>
  <body>
    <header>
      <h1>张三</h1>
      <p>前端开发学习者</p>
      <nav aria-label="简历章节">
        <a href="#about">简介</a>
        <a href="#skills">技能</a>
        <a href="#projects">项目</a>
      </nav>
    </header>

    <main>
      <section id="about">
        <h2>个人简介</h2>
        <p>正在系统学习 HTML、CSS 和 JavaScript。</p>
      </section>

      <section id="skills">
        <h2>技能</h2>
        <ul>
          <li>HTML 语义化</li>
          <li>CSS 基础布局</li>
        </ul>
      </section>

      <section id="projects">
        <h2>项目经历</h2>
        <article>
          <h3>个人主页</h3>
          <p>使用 HTML 和 CSS 完成的响应式个人介绍页面。</p>
        </article>
      </section>
    </main>

    <footer>
      <p>&copy; 2026 张三</p>
    </footer>
  </body>
</html>
```

## 自查清单

- [ ] 有完整的 HTML5 文档结构。
- [ ] 中文页面设置了 `lang="zh-CN"` 和 UTF-8。
- [ ] 标题层级连续且合理。
- [ ] 主要内容放在 `main` 中。
- [ ] 每个章节使用 `section` 和标题组织。
- [ ] 链接文字能说明目标。
- [ ] 图片有合理的 `alt`。
- [ ] 页面不依赖 CSS 也能读懂内容顺序。
