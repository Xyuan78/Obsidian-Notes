# 文本、列表、链接与图片

## 标题与段落

- `<h1>` 到 `<h6>` 表示六级标题，数字越小层级越高。
- 通常一个页面只保留一个主要 `<h1>`。
- 标题应按层级使用，不要只为改变字号而选择标题。
- `<p>` 表示一个段落，段落之间会自然分隔。
- `<br>` 只用于行内换行，例如地址、诗歌。
- `<hr>` 表示主题分隔，不再只是“画一条线”。

```html
<h1>前端学习笔记</h1>
<h2>HTML 基础</h2>
<p>HTML 负责组织页面内容。</p>
```

## 文本语义

```html
<p>使用 <strong>strong</strong> 表示重要内容。</p>
<p>使用 <em>em</em> 表示强调语气。</p>
<p><mark>mark</mark> 表示与上下文相关的标记。</p>
```

`<strong>` 和 `<em>` 表示语义，`<b>` 和 `<i>` 主要表示视觉区分。现代页面优先选择有明确含义的标签。

## 列表

无序列表：

```html
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>
```

有序列表：

```html
<ol>
  <li>编写结构</li>
  <li>添加样式</li>
  <li>实现交互</li>
</ol>
```

描述列表：

```html
<dl>
  <dt>HTML</dt>
  <dd>负责页面内容结构。</dd>
  <dt>CSS</dt>
  <dd>负责页面视觉表现。</dd>
</dl>
```

## 链接

```html
<a href="https://developer.mozilla.org/" target="_blank" rel="noopener noreferrer">
  访问 MDN
</a>
```

- `href` 指定跳转地址。
- `target="_blank"` 在新标签页打开。
- 使用 `target="_blank"` 时建议添加 `rel="noopener noreferrer"`。
- 页面内跳转可以使用锚点：

```html
<a href="#contact">联系我</a>
<h2 id="contact">联系方式</h2>
```

链接文字应描述目标内容，避免只写“点击这里”。

## 图片

```html
<img
  src="./images/avatar.jpg"
  alt="张三的个人头像"
  width="240"
  height="240"
/>
```

- `src`：图片地址。
- `alt`：图片无法显示时提供的替代文本，也是无障碍的重要信息。
- 装饰图片可以使用空替代文本 `alt=""`。
- 同时写明 `width` 和 `height` 有助于浏览器预留空间，减少布局跳动。

## 路径

```text
./            当前目录
../           上一级目录
/images/a.jpg 从网站根目录开始
```

优先使用相对路径，便于项目迁移。路径大小写是否敏感取决于服务器环境，代码中应保持完全一致。

## 表格基础

```html
<table>
  <caption>课程安排</caption>
  <thead>
    <tr>
      <th scope="col">课程</th>
      <th scope="col">时间</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">HTML</th>
      <td>周一</td>
    </tr>
  </tbody>
</table>
```

表格只用于展示二维数据，不用于页面布局。

## 语义化结构

```html
<body>
  <header>页头</header>
  <nav>导航</nav>
  <main>
    <article>独立文章内容</article>
    <aside>补充信息</aside>
  </main>
  <footer>页脚</footer>
</body>
```

- `header`：页面或区块的头部。
- `nav`：主要导航链接区域。
- `main`：页面唯一的主要内容区域。
- `section`：有主题的内容分组。
- `article`：可独立分发的内容。
- `aside`：与主内容相关但可独立的补充内容。
- `footer`：页面或区块的底部。

### 标题标签

```html
<h1>一级标题</h1>
<h2>二级标题</h2>
<h6>六级标题</h6>
```

- 标题有 `h1`–`h6` 六级。
- 默认字号依次减小，但不要只为了字号选择标题层级。
- 页面结构应按 `h1`、`h2`、`h3` 的逻辑层级组织。

### 超链接的三种类型

```html
<!-- 页面链接：相对路径 -->
<a href="./about.html">关于我们</a>

<!-- 页面链接：绝对路径 -->
<a href="https://www.example.com/">示例网站</a>

<!-- 邮件链接 -->
<a href="mailto:hello@example.com">联系我们</a>

<!-- 锚点链接 -->
<a href="#contact">跳到联系方式</a>
<h2 id="contact">联系方式</h2>
```

路径说明：

- 相对路径以当前页面为参照，例如 `./index.html`、`../index.html`。
- 绝对路径从协议、域名或磁盘根路径开始。
- `./` 表示当前目录，`../` 表示上一级目录。
- `target="_blank"` 可以在新标签页打开链接，外链建议同时设置 `rel="noopener noreferrer"`。
- 课程中的 `<a name="锚点名">` 是旧式锚点写法，现代 HTML 优先使用元素的 `id`。
- `href="#"` 是空链接，常用于尚未确定目标的原型页面。

### 图片属性

```html
<a href="#">
  <img
    src="./img/banner.png"
    width="800"
    title="一带一路"
    alt="一带一路总设计图"
  />
</a>
```

- `src`：图片路径。
- `width` / `height`：控制尺寸；等比例缩放时通常只设置一个尺寸。
- `title`：悬停提示。
- `alt`：图片无法显示时的替代文本，也是无障碍信息。
- `align` 属于旧式视觉属性，现代布局应使用 CSS。

### 文本格式化

```html
<p><b>加粗文本</b>、<i>斜体文本</i></p>
<p><code>console.log()</code></p>
<p>水：H<sub>2</sub>O，平方：3<sup>2</sup>=9</p>
<p><del>已删除内容</del></p>
```

- `b` / `i` 主要表示视觉样式。
- `strong` / `em` 表示重要性和强调语义，现代页面更推荐。
- `code` 表示代码片段。
- `sub` / `sup` 表示下标和上标。
- `del` 表示已删除内容。

### 列表扩展

```html
<ol type="I" start="5">
  <li>第五项</li>
  <li>第六项</li>
</ol>

<ul type="circle">
  <li>无序项</li>
  <li>
    嵌套列表
    <ul>
      <li>子项</li>
    </ul>
  </li>
</ul>
```

- `ol` 表示有序列表，`type` 可以设置编号样式，`start` 可以设置起点。
- `ul` 表示无序列表，`type` 可以设置项目符号。
- 方向控制、符号样式等视觉要求建议使用 CSS。
- `list-style: none` 可以隐藏项目符号，导航菜单中很常见。

### div 与 span

```html
<div class="card">
  <span class="label">标签：</span>
  <span>HTML</span>
</div>
```

- `div` 是块级容器，适合组合较完整的内容块。
- `span` 是行内容器，适合包裹一段文字中的局部内容。
- 两者默认没有语义。能使用 `header`、`nav`、`main`、`section`、`article` 等语义标签时，Priority 应优先使用语义标签。
