# 表格、容器与页面布局

> [!source] 课程对照
> `html.pdf` 第 14–22 页。

## 表格的基本结构

```html
<table>
  <caption>第一季度收支汇总</caption>
  <thead>
    <tr>
      <th scope="col">月份</th>
      <th scope="col">工资</th>
      <th scope="col">奖金</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">一月</th>
      <td>5000</td>
      <td>1000</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td>合计</td>
      <td>5000</td>
      <td>1000</td>
    </tr>
  </tfoot>
</table>
```

- `table`：表格。
- `caption`：表格标题。
- `thead`：表头区域。
- `tbody`：主体数据区域。
- `tfoot`：汇总或脚注区域。
- `tr`：表格行。
- `th`：表头单元格，通常居中加粗。
- `td`：普通数据单元格。

课程中可能使用 `<table border="1">` 等属性。`border`、`cellpadding`、`cellspacing` 属于旧式表现属性，现代页面应改用 CSS 控制边框、内边距和边框间距。

## 合并单元格

```html
<table>
  <tr>
    <td colspan="2">横向合并两列</td>
  </tr>
  <tr>
    <td rowspan="2">纵向合并两行</td>
    <td>内容一</td>
  </tr>
  <tr>
    <td>内容二</td>
  </tr>
</table>
```

- `colspan="n"`：横向跨 `n` 列。
- `rowspan="n"`：纵向跨 `n` 行。
- 合并后要减少对应行或列中的单元格，避免表格结构错位。

## 课程中的旧式表格属性

```html
<table border="1" cellpadding="20" cellspacing="10">
  <!-- 课程示例 -->
</table>
```

- `border`：旧式边框宽度属性。
- `cellpadding`：单元格内容与边框的距离。
- `cellspacing`：单元格之间的间距。
- `caption align="bottom"`：旧式标题位置属性。
- `width="100%"`：旧式宽度属性。

现代写法：

```css
table {
  width: 100%;
  border-collapse: collapse;
}

th,
td {
  padding: 12px;
  border: 1px solid #cbd5e1;
}

caption {
  caption-side: bottom;
}
```

## 嵌套表格

表格可以嵌套，但不建议频繁使用。嵌套层级过深会增加结构复杂度，也会让响应式适配变得困难。

## div、span 与容器

```html
<div class="product-card">
  <h2>无线鼠标</h2>
  <p><span class="price">￥99</span></p>
</div>
```

- `div` 是块级容器，用于组合多个元素或搭建结构。
- `span` 是行内容器，用于包裹一行文字中的局部内容。
- 两者没有语义。能使用 `header`、`nav`、`main`、`section`、`article` 时优先使用语义标签。
- 不要只用 `div` 搭建页面，也不要用表格承载普通页面布局。

## 课程提到的布局方式

### div + CSS 布局

现代页面最常用的方式。HTML 负责结构，CSS 使用 Flexbox、Grid 等完成布局。

```css
.layout {
  display: grid;
  grid-template-columns: 240px minmax(0, 1fr);
  gap: 24px;
}
```

### 表格布局

- 旧式网站常使用表格控制页面结构。
- 表格只适合呈现二维数据，不适合作为现代页面总布局。
- 对复杂页面，表格布局难以维护和响应式适配。

### 框架布局

- `frameset` 和 `frame` 用于把浏览器窗口切分成多个页面区域。
- 该方案已经过时，在现代项目中不应使用。
- 后端管理系统的局部区域可以少量使用 `iframe`，但必须考虑安全、可访问性和页面导航问题。
- 现代页面整体布局应优先使用 CSS Grid 或 Flexbox。

## 课程练习

使用 `dl`、`dt`、`dd` 制作图文混排的推广列表：

```html
<dl class="promotion">
  <dt><img src="./img/promote-1.jpg" alt="无线鼠标" /></dt>
  <dd><a href="#">无线鼠标</a></dd>
</dl>
```

`dl` 适合“名称—说明”或“图片—说明”成组出现的内容。
