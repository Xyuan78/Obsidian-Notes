# 元数据、地图与内嵌框架

> [!source] 课程对照

## head 中的页面元数据

`head` 中的内容通常不直接显示，但会影响浏览器、搜索引擎和辅助技术。

```html
<head>
  <meta charset="utf-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <meta name="description" content="免费在线教程" />
  <meta name="keywords" content="HTML,CSS,XML,JavaScript" />
  <meta name="author" content="runoob" />
  <title>菜鸟教程</title>
</head>
```

- `meta charset="utf-8"`：设置字符编码。
- `viewport`：移动端布局的基础设置。
- `description`：页面描述，搜索结果可能显示。
- `keywords`：旧式关键词声明，现代搜索引擎权重很低，不应作为 SEO 的核心手段。
- `author`：页面作者。
- `title`：浏览器标签页标题，也是搜索结果显示的重要文本。

## 链接样式表 link

```html
<link rel="stylesheet" href="./css/style.css" />
```

`link` 用于链接外部资源，最常见的是 CSS 样式表。

## 脚本 script

```html
<script src="./js/app.js" defer></script>
```

- `src`：外部 JavaScript 文件路径。
- `defer`：等 HTML 解析完成后再按顺序执行脚本。
- 较复杂的现代项目还可以使用 `type="module"`，通过模块机制加载脚本。
- 旧式写法可能把 `type="text/javascript"` 写在标签中，现代 HTML 通常可以省略。

## 样式 style

```html
<style>
  .notice {
    color: #b45309;
    background: #fffbeb;
  }
</style>
```

`style` 用于在文档中写内部样式。多个页面复用样式时，优先使用外部样式表。

## 图像地图 map 与 area

```html
<img src="planets.gif" width="145" height="126" alt="行星" usemap="#planetmap" />

<map name="planetmap">
  <area shape="rect" coords="0,0,82,126" alt="Sun" href="sun.html" />
  <area shape="circle" coords="90,58,3" alt="Mercury" href="mercury.html" />
  <area shape="circle" coords="124,58,8" alt="Venus" href="venus.html" />
</map>
```

- `usemap="#planetmap"`：把图片与地图关联。
- `map name="planetmap"`：定义地图名称。
- `area`：为图片中的某个区域设置链接。
- `shape="rect"`：矩形，坐标通常为 `x1,y1,x2,y2`。
- `shape="circle"`：圆形，坐标通常为 `圆心x,圆心y,半径`。
- `shape="poly"`：多边形，坐标由多组顶点构成。
- `shape="default"`：覆盖整个图片的默认区域。

图像地图较难维护和适配，现代项目中使用要谨慎，应确保替代文本和键盘操作可用。

## 内嵌框架 iframe

```html
<iframe
  src="./header.html"
  name="contentFrame"
  title="页面内容区域"
  width="100%"
  height="200"
  loading="lazy"
></iframe>
```

课程中常见属性：

- `src`：要显示的页面地址。
- `name`：框架名称，可被链接的 `target` 指向。
- `width` / `height`：尺寸。
- `frameborder`：旧式边框属性，现代优先使用 CSS。
- `scrolling`：旧式滚动条属性，现代浏览器中使用要谨慎。

现代项目应添加：

- `title`：说明框架内容，满足无障碍要求。
- `loading="lazy"`：延迟加载非首屏 iframe。
- `sandbox`：限制不可信 iframe 的能力。
- `referrerpolicy`：控制请求来源信息。

## 旧式框架集 frameset 与 frame

```html
<frameset rows="200,*,100">
  <frame src="header.html" />
  <frame src="main.html" />
  <frame src="footer.html" />
</frameset>
```

- `frameset` 不能写在 `body` 中。
- `frameset` / `frame` 已被淘汰，不应在新项目中使用。
- 需要嵌入独立页面时优先考虑 `iframe`；需要页面区域划分时使用 CSS Grid、Flexbox 和路由。
