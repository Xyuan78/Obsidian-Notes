## 阅读提醒

课程中的以下内容属于旧式方案，学习时可以理解，但新项目应优先使用现代写法：

- `frameset` / `frame`：不再用于新页面。
- 表格页面布局：只把表格用于数据展示。
- 行内样式和 HTML 表现属性：改用 CSS。
- `var`：现代代码优先使用 `let` / `const`。
- `document.write()`：现代项目不推荐。
- jQuery 1.8.3：版本过旧，新项目优先原生 API 或使用受支持的新安全版本。
- 手机号和邮箱的简化正则：不能覆盖所有现代合法格式，且必须配合服务器端验证。
