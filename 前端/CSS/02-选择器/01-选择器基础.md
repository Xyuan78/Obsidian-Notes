# 选择器基础

## 基础选择器

```css
* {
  box-sizing: border-box;
}

p {
  color: #333333;
}

.card {
  padding: 16px;
}

#site-title {
  font-size: 2rem;
}
```

- `*`：通用选择器，匹配所有元素。
- `p`：类型选择器，匹配所有 `p` 元素。
- `.card`：类选择器，最常用于组件和模块。
- `#site-title`：ID 选择器，优先级高，通常每页 ID 应唯一。

## 组合选择器

```css
/* 后代：.menu 内任意层级的 a */
.menu a {
  color: inherit;
}

/* 直接子元素 */
.menu > li {
  display: inline-block;
}

/* 相邻兄弟 */
h2 + p {
  margin-top: 0;
}

/* 后续兄弟 */
h2 ~ p {
  color: #666666;
}

/* 同时匹配多个选择器 */
h1,
h2,
h3 {
  line-height: 1.3;
}
```

## 属性选择器

```css
input[type="email"] {
  border-color: #2563eb;
}

a[href^="https://"] {
  color: green;
}

a[href$=".pdf"] {
  color: crimson;
}

[class~="featured"] {
  outline: 2px solid gold;
}
```

- `[attr]`：存在该属性。
- `[attr="value"]`：属性值完全相等。
- `[attr^="value"]`：以指定内容开头。
- `[attr$="value"]`：以指定内容结尾。
- `[attr*="value"]`：包含指定内容。

## 伪类

伪类用于描述元素的某种状态或位置。

```css
a:hover {
  color: #1d4ed8;
}

input:focus-visible {
  outline: 3px solid #2563eb;
  outline-offset: 2px;
}

li:first-child {
  margin-top: 0;
}

li:last-child {
  margin-bottom: 0;
}

li:nth-child(even) {
  background-color: #f8fafc;
}

input:disabled {
  cursor: not-allowed;
  opacity: 0.6;
}
```

表单状态：

```css
input:required {
  border-left: 3px solid orange;
}

input:invalid:not(:placeholder-shown) {
  border-color: red;
}
```

## 伪元素

伪元素用于创建或选择元素的一部分。

```css
.card::before {
  content: "";
  display: block;
  width: 48px;
  height: 4px;
  background-color: #2563eb;
}

.card::after {
  content: "→";
}

::selection {
  color: white;
  background-color: #2563eb;
}
```

`::before` 和 `::after` 必须设置 `content` 才会生成。

## 优先级

从高到低可简记为：

1. 行内样式
2. ID 选择器
3. 类、属性选择器、伪类
4. 元素、伪元素

权重可以粗略表示为：

```text
ID = 100
class / attribute / pseudo-class = 10
element / pseudo-element = 1
```

示例：

```css
p { color: black; }              /* 0-0-1 */
.text { color: blue; }           /* 0-1-0 */
#intro { color: red; }           /* 1-0-0 */
```

不要只靠增加选择器层级解决样式冲突。优先把选择器写得清晰、稳定、低耦合。

## 层叠顺序

优先级相同时，后出现的规则覆盖先出现的规则。

```css
.alert {
  color: orange;
}

.alert {
  color: red; /* 最终通常为红色 */
}
```

## 继承与初始值

可以继承的属性会从父元素传给后代：

```css
body {
  color: #333333;
  font-family: sans-serif;
}
```

不能继承的属性：

```css
.card {
  margin: 16px;
  border: 1px solid #dddddd;
}
```

## 练习

为博客文章列表设计 CSS 选择器，实现：

- 列表项之间统一间距。
- 偶数项背景色不同。
- 链接悬停时改变颜色。
- 输入框聚焦时显示可见轮廓。
- 卡片标题前生成一个小色块。
