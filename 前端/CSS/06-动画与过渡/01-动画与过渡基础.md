# 动画与过渡基础

## transition

`transition` 用于在两个状态之间平滑变化。

```css
.button {
  background-color: #2563eb;
  transition: background-color 180ms ease;
}

.button:hover {
  background-color: #1d4ed8;
}
```

完整写法：

```css
.card {
  transition:
    transform 200ms ease,
    box-shadow 200ms ease;
}

.card:hover {
  transform: translateY(-4px);
  box-shadow: 0 12px 24px rgb(15 23 42 / 15%);
}
```

常见缓动：

- `linear`
- `ease`
- `ease-in`
- `ease-out`
- `ease-in-out`
- `cubic-bezier(...)`

## transform

```css
.box {
  transform: translate(20px, 0);
  transform: scale(1.1);
  transform: rotate(45deg);
  transform: skewX(10deg);
}
```

可以组合：

```css
.badge {
  transform: translateY(-2px) scale(1.04);
}
```

`transform` 通常比修改 `top`、`left` 更适合做位移动画，性能通常也更好。

## animation 与关键帧

```css
@keyframes fade-in {
  from {
    opacity: 0;
    transform: translateY(12px);
  }

  to {
    opacity: 1;
    transform: translateY(0);
  }
}

.message {
  animation: fade-in 400ms ease-out both;
}
```

动画属性：

```css
.box {
  animation-name: fade-in;
  animation-duration: 400ms;
  animation-timing-function: ease-out;
  animation-delay: 100ms;
  animation-iteration-count: 1;
  animation-direction: normal;
  animation-fill-mode: both;
}
```

简写顺序没有强制固定，但建议保持团队一致。

## 性能建议

优先动画以下属性：

- `transform`
- `opacity`

避免频繁动画会触发布局的属性：

- `width`
- `height`
- `top`
- `left`
- `margin`

需要更强性能控制时可了解：

```css
.will-change {
  will-change: transform;
}
```

不要滥用 `will-change`，它可能消耗额外内存并创建新的合成层。

## 可访问性

必须考虑用户系统设置：

```css
@media (prefers-reduced-motion: reduce) {
  .animated {
    animation: none;
    transition: none;
  }
}
```

动画不能成为理解页面信息的唯一方式。重要状态变化应同时提供文字、图标或颜色以外的提示。

## 常见错误

- 动画时长过长，影响操作效率。
- 每个元素都加大量动画，造成视觉噪声。
- 用 `transition: all` 无差别扩散动画。
- 忽略键盘焦点状态。
- 忽略减少动态效果的偏好设置。
