# 盒模型基础

## 盒模型的四层结构

每个元素都可以视为一个矩形盒子：

```text
Margin（外边距）
┌──────────────────────────────┐
│ Border（边框）               │
│  ┌────────────────────────┐  │
│  │ Padding（内边距）      │  │
│  │  ┌──────────────────┐  │  │
│  │  │ Content（内容）  │  │  │
│  │  └──────────────────┘  │  │
│  └────────────────────────┘  │
└──────────────────────────────┘
```

- `content`：文字、图片等实际内容区域。
- `padding`：内容和边框之间的空间。
- `border`：盒子的边框。
- `margin`：盒子与其他元素之间的外部空间。

## 基础示例

```css
.card {
  width: 320px;
  padding: 16px;
  border: 1px solid #d1d5db;
  margin: 24px;
  background-color: white;
}
```

在默认 `content-box` 下，卡片实际占用宽度为：

```text
320px + 16px × 2 + 1px × 2 = 354px
```

## box-sizing

推荐在项目开始时统一设置：

```css
*,
*::before,
*::after {
  box-sizing: border-box;
}
```

- `content-box`：`width` 只表示内容宽度。
- `border-box`：`width` 包含内容、内边距和边框。

设置 `border-box` 后，上面的实际占用宽度就是 `320px`，更容易控制布局。

## 内边距与外边距

```css
.box {
  padding: 12px 20px;
  padding-block: 12px;
  padding-inline: 20px;

  margin: 16px auto;
  margin-block: 16px;
  margin-inline: auto;
}
```

简写方向通常按顺时针：

```css
margin: 上 右 下 左;
margin: 上下 左右;
margin: 上 左右 下;
margin: 四个方向;
```

推荐逐渐使用逻辑属性 `padding-block`、`padding-inline`、`margin-inline`，让布局更容易适应不同书写方向。

## 边框与圆角

```css
.panel {
  border: 1px solid #cbd5e1;
  border-radius: 12px;
}

.avatar {
  border: 3px solid white;
  border-radius: 50%;
}
```

## 尺寸与溢出

```css
.box {
  width: min(100%, 640px);
  min-height: 120px;
  max-width: 1200px;
  overflow: hidden;
}

.scroll-area {
  max-height: 320px;
  overflow-y: auto;
}
```

常见 `overflow`：

- `visible`：内容超出也显示，默认值。
- `hidden`：裁剪超出内容。
- `auto`：需要时出现滚动条。
- `scroll`：始终预留滚动区域。

使用 `overflow: hidden` 前要确认不会隐藏下拉菜单、焦点轮廓或提示内容。

## 外边距折叠

垂直方向相邻的块级元素外边距可能合并，只取较大值：

```css
.first {
  margin-bottom: 40px;
}

.second {
  margin-top: 24px; /* 两段间距通常为 40px，而不是 64px */
}
```

常见触发场景：

- 相邻兄弟元素。
- 父子元素之间，父元素没有边框、内边距或布局隔离。
- 空块元素。

可用的处理方式：

- 使用 Flexbox 或 Grid 的 `gap`。
- 给父元素添加 `padding`、`border` 或 `display: flow-root`。
- 统一使用单方向间距，减少复杂折叠。

## 显示类型

```css
span {
  display: inline;
}

.card {
  display: block;
}

.button {
  display: inline-block;
}

.container {
  display: flex;
  gap: 16px;
}
```

- `inline` 不独占一行，宽高通常不生效。
- `block` 独占一行，可设置宽高。
- `inline-block` 行内排列，同时可设置宽高。
- `flex` 和 `grid` 会建立新的布局上下文。

## 练习

创建两个卡片：

1. 所有元素使用 `border-box`。
2. 卡片有内容、内边距、边框、圆角和阴影。
3. 卡片在父容器中水平居中。
4. 两卡片之间使用 `gap`，不要依赖负外边距。

盒模型由 `margin`、`border`、`padding` 和内容区域组成。简写值按顺时针方向理解：

```css
p.ex1 {
  padding: 2cm; /* 上、右、下、左全部 2cm */
}

p.ex2 {
  padding: 0.5cm 3cm; /* 上下 0.5cm，左右 3cm */
}

p.ex3 {
  padding: 2cm 1cm 5cm; /* 上 2cm，左右 1cm，下 5cm */
}

p.ex4 {
  padding: 0.5cm 3cm 1cm 2cm; /* 上、右、下、左 */
}
```

课程使用 `cm` 演示盒模型的取值规律。实际网页布局更常使用 `px`、`rem`、`em`、`%` 等适合屏幕的单位。写法规律不变：

```css
margin: 上 右 下 左;
padding: 上 右 下 左;
```
