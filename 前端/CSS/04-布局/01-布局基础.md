# 布局基础

## 正常文档流

元素默认按文档流排列：

- 块级元素通常从上到下排列。
- 行内元素通常从左到右排列。
- 正常流是布局的基础，定位和浮动应谨慎使用。

```css
.container {
  display: flow-root;
}

.card {
  display: block;
}

.tag {
  display: inline-block;
}
```

## 定位

```css
.parent {
  position: relative;
}

.badge {
  position: absolute;
  top: 8px;
  right: 8px;
}
```

常见 `position`：

- `static`：默认值，参与正常文档流。
- `relative`：相对自身原位置偏移，原空间仍保留。
- `absolute`：脱离文档流，相对最近的非 `static` 定位祖先定位。
- `fixed`：相对视口定位，滚动时通常保持不动。
- `sticky`：在正常流中，当达到阈值后表现为粘性定位。

```css
.site-header {
  position: sticky;
  top: 0;
  z-index: 10;
}
```

`z-index` 只在参与层叠上下文且 `position` 不为 `static` 等常见条件下更容易按预期生效。

## Flexbox

Flexbox 适合一维布局：一行或一列。

```css
.toolbar {
  display: flex;
  align-items: center;
  gap: 12px;
}

.toolbar .spacer {
  margin-left: auto;
}
```

常见属性：

```css
.row {
  display: flex;
  flex-direction: row;
  justify-content: space-between;
  align-items: center;
  flex-wrap: wrap;
  gap: 16px;
}

.item {
  flex: 1 1 240px;
}
```

- `justify-content`：主轴对齐。
- `align-items`：交叉轴对齐。
- `gap`：项目间距。
- `flex-grow`：剩余空间如何分配。
- `flex-shrink`：空间不足时是否收缩。
- `flex-basis`：初始主轴尺寸。

## Grid

Grid 适合二维布局：同时控制行和列。

```css
.card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 20px;
}
```

固定列布局：

```css
.layout {
  display: grid;
  grid-template-columns: 240px minmax(0, 1fr);
  gap: 24px;
}
```

常见能力：

- `grid-template-columns`
- `grid-template-rows`
- `grid-column` / `grid-row`
- `grid-template-areas`
- `gap`
- `minmax()`
- `repeat()`
- `auto-fit` / `auto-fill`

## 如何选择布局方案

- 简单横向或纵向排列：优先 Flexbox。
- 规则的行列结构或页面大框架：优先 Grid。
- 需要覆盖元素时，再考虑定位。
- 能用正常流和 `gap` 解决时，不要使用绝对定位。

## 常见错误

- 所有布局都使用 `position: absolute`。
- 用固定高度承载可能增多的内容。
- 用大量 margin 拼布局，导致响应式困难。
- 忽略 `min-width: 0` 导致 Grid/Flex 子项无法收缩。
- 不清楚主轴和交叉轴就盲目写 Flex 属性。

## 练习

1. 用 Flexbox 制作顶部导航栏。
2. 用 Grid 制作自适应卡片列表。
3. 用 Grid 实现“侧边栏 + 内容区”两列布局。
4. 用 `position: sticky` 制作粘性页头。
