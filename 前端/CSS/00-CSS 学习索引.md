# CSS 学习索引

> [!tip] 记录约定
> 优先记录“属性为什么这样写”和“实际布局效果”，不要只抄属性清单。

## 01 基础

- [[01-CSS 基础总览]]：语法、引入方式、颜色、单位、字体、文本、层叠与继承。
- 后续补充：CSS 自定义属性、函数、浏览器兼容基础。

## 02 选择器

- [[01-选择器基础]]：基础选择器、组合选择器、属性选择器、伪类、伪元素和优先级。
- 后续补充：`:is()`、`:where()`、`:has()`、复杂选择器组织策略。

## 03 盒模型

- [[01-盒模型基础]]：内容、内边距、边框、外边距、`box-sizing`、溢出与边距折叠。
- 后续补充：逻辑属性、宽高约束、替换元素尺寸。

## 04 布局

- [[01-布局基础]]：文档流、定位、Flexbox、Grid 和布局方案选择。
- 后续补充：多列布局、层叠上下文、复杂页面布局。

## 05 响应式

- [[01-响应式基础]]：viewport、移动优先、断点、流式尺寸和容器查询。
- 后续补充：图片响应式、方向和分辨率查询。

## 06 动画与过渡

- [[01-动画与过渡基础]]：`transition`、`transform`、`@keyframes`、性能和可访问性。
- 后续补充：滚动驱动动画、视图过渡 API。

## 07 综合练习

- [[01-导航栏页面练习]]：Flexbox、状态样式和响应式导航练习。
- 后续补充：卡片列表、后台仪表盘、响应式落地页。
