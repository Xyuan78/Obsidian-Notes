综合使用 `Date`、函数、事件和定时器制作数字时钟。

## JavaScript 实现

```js
function pad(number) {
  return String(number).padStart(2, "0");
}

function updateClock() {
  const now = new Date();
  const time = [
    pad(now.getHours()),
    pad(now.getMinutes()),
    pad(now.getSeconds()),
  ].join(":");

  document.getElementById("clock").textContent = time;
}

updateClock();
setInterval(updateClock, 1000);
```

## 定时器

### setInterval

```js
const timerId = setInterval(updateClock, 1000);

clearInterval(timerId);
```

`setInterval()` 每隔指定毫秒重复执行一次函数。

### setTimeout

```js
const timerId = setTimeout(updateClock, 1000);

clearTimeout(timerId);
```

`setTimeout()` 只延迟执行一次，也可以在函数内部再次调用自己形成循环。

## 显示日期

```js
function formatDate(date) {
  const year = date.getFullYear();
  const month = date.getMonth() + 1;
  const day = date.getDate();
  const weekdays = ["星期日", "星期一", "星期二", "星期三", "星期四", "星期五", "星期六"];

  return `${year}年${month}月${day}日 ${weekdays[date.getDay()]}`;
}

console.log(formatDate(new Date()));
```

## 课程代码的问题与改进

- 课程使用 `setTimeout(showTime, 500)` 和自身调用实现循环；现代写法通常使用 `setInterval()`。
- 课程中的 `switch` 存在 `case 1` 和 `case 2` 都取 `weekdays[2]` 的复制错误，应仔细测试。
- 使用 `String(number).padStart(2, "0")` 比手写 `checkTime()` 更直接。
- 避免把 JavaScript 字符串传给 `setTimeout`；应传函数或函数引用。
