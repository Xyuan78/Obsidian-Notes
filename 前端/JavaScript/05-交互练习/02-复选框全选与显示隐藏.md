# 复选框全选与显示隐藏

## 复选框全选与取消全选

### HTML

```html
<form>
  <label><input type="checkbox" name="fruit" value="apple" />苹果</label>
  <label><input type="checkbox" name="fruit" value="pear" />梨</label>
  <label><input type="checkbox" name="fruit" value="peach" />桃</label>

  <button type="button" id="select-all">全选</button>
  <button type="button" id="clear-all">取消全选</button>
</form>
```

### JavaScript

```js
const fruitCheckboxes = document.querySelectorAll('input[name="fruit"]');
const selectAllButton = document.querySelector("#select-all");
const clearAllButton = document.querySelector("#clear-all");

selectAllButton.addEventListener("click", () => {
  fruitCheckboxes.forEach((checkbox) => {
    checkbox.checked = true;
  });
});

clearAllButton.addEventListener("click", () => {
  fruitCheckboxes.forEach((checkbox) => {
    checkbox.checked = false;
  });
});
```

课程中通过遍历所有 `input`，再判断 `type` 和 `name`。现代写法可以直接用属性选择器 `input[name="fruit"]` 精确选择，代码更清晰。

## 一个复选框控制全部

```js
const masterCheckbox = document.querySelector("#select-all-master");

masterCheckbox.addEventListener("change", () => {
  fruitCheckboxes.forEach((checkbox) => {
    checkbox.checked = masterCheckbox.checked;
  });
});
```

被其他复选框反选时，可以同步 `masterCheckbox.checked` 状态。

## 显示与隐藏元素

### HTML

```html
<button type="button" id="toggle-button">隐藏</button>
<div id="panel">需要显示或隐藏的内容</div>
```

### CSS

```css
.is-hidden {
  display: none;
}
```

### JavaScript

```js
const toggleButton = document.querySelector("#toggle-button");
const panel = document.querySelector("#panel");

toggleButton.addEventListener("click", () => {
  panel.classList.toggle("is-hidden");
  toggleButton.textContent = panel.classList.contains("is-hidden") ? "显示" : "隐藏";
});
```

## 为什么优先切换 class

- 样式规则保存在 CSS 中，职责更清晰。
- 可以同时切换多个样式属性。
- 方便处理过渡动画。
- JavaScript 不需要反复记忆具体颜色、尺寸或显示方式。
- 比直接写 `element.style.display` 更容易维护。

## 可访问性提醒

- 按钮应使用 `button` 元素，而不是只加点击事件的 `div`。
- 动态显示或隐藏内容时，可以同步 `aria-expanded`、`aria-controls` 等状态。
- 重要内容不应只依赖鼠标悬停显示。
