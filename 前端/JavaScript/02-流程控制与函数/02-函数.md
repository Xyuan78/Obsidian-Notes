# 函数

## 函数声明

```js
function greet(name) {
  return `你好，${name}`;
}

const message = greet("张三");
console.log(message);
```

- `function`：定义函数。
- `name`：参数名。
- `return`：返回结果并结束函数。
- 没有显式 `return` 时，函数返回 `undefined`。

## 函数表达式

```js
const add = function (a, b) {
  return a + b;
};

console.log(add(1, 2));
```

函数可以赋值给变量，也可以作为参数或返回值，这称为一等函数。

## 箭头函数

```js
const add = (a, b) => a + b;
const square = (number) => number * number;
```

箭头函数语法更简洁，但没有自己的 `this`、`arguments` 和 `super`。DOM 事件回调中需要特别注意 `this` 的含义。

## 默认参数

```js
function createUser(name, role = "visitor") {
  return { name, role };
}
```

未传入 `role` 时使用默认值 `"visitor"`。

## 作用域

```js
const globalValue = "全局";

function test() {
  const localValue = "局部";
  console.log(globalValue);
  console.log(localValue);
}
```

- 函数内部可以访问外层作用域。
- 外层不能直接访问函数内部的局部变量。
- `var` 是函数作用域，`let` / `const` 是块级作用域。
- 尽量缩小变量作用域，降低相互影响。

## 回调函数

```js
function runTask(callback) {
  callback();
}

runTask(function () {
  console.log("任务完成");
});
```

回调函数是作为参数传给其他函数、之后由其他函数调用的函数。事件处理、数组方法和异步操作中都很常见。

## 课程示例中的函数

```js
function checkTime(time) {
  if (time < 10) {
    return "0" + time;
  }

  return time;
}
```

这个函数把小于 10 的数字补成两位字符串，例如 `9` 变成 `"09"`。
