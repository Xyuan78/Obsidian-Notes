# 运算符、分支与循环

> [!source] 课程对照
> `html.pdf` 第 34–38 页。

## 比较运算符

```js
"5" == 5;   // true，只比较值，允许类型转换
"5" === 5;  // false，值和类型都要相同
"5" != 5;   // false
"5" !== 5;  // true
```

现代代码优先使用严格相等 `===` 和严格不等 `!==`，避免意外类型转换。

## 其他常用运算符

```js
let a = 10 + 5;
let b = 10 - 5;
let c = 10 * 5;
let d = 10 / 5;
let e = 10 % 3;

a += 1;
a++;
```

- `%`：取余。
- `&&`：逻辑与。
- `||`：逻辑或。
- `!`：逻辑非。
- `??`：空值合并。
- `?.`：可选链。

## if 与 if...else

```js
const score = 80;

if (score >= 90) {
  console.log("优秀");
} else if (score >= 60) {
  console.log("及格");
} else {
  console.log("不及格");
}
```

## switch

```js
const day = new Date().getDay();

switch (day) {
  case 0:
    console.log("星期天");
    break;
  case 6:
    console.log("星期六");
    break;
  default:
    console.log("工作日");
}
```

- `case` 后可以匹配数字或字符串。
- 每个分支通常使用 `break`，否则会继续向下执行。
- `default` 处理所有未匹配情况。

## for 循环

```js
for (let i = 0; i < 5; i++) {
  console.log(`数字 ${i}`);
}
```

执行顺序：

1. 初始化 `let i = 0`。
2. 判断条件 `i < 5`。
3. 执行循环体。
4. 执行更新 `i++`。
5. 重复条件和循环体，直到条件为假。

## for...in 与 for...of

```js
const person = { fname: "Bill", lname: "Gates", age: 56 };

for (const key in person) {
  console.log(key, person[key]);
}

const colors = ["red", "green", "blue"];

for (const color of colors) {
  console.log(color);
}
```

- `for...in` 通常用来遍历对象的键名。
- `for...of` 用来遍历可迭代对象的值，比使用 `for...in` 遍历数组更合适。

## while 与 do...while

```js
let i = 0;

while (i < 5) {
  console.log(i);
  i++;
}
```

`while` 先判断条件，条件为假时循环体可能一次都不执行。

```js
let j = 0;

do {
  console.log(j);
  j++;
} while (j < 5);
```

`do...while` 先执行一次循环体，再判断条件，因此至少执行一次。

## break 与 continue

```js
for (let i = 0; i < 10; i++) {
  if (i === 3) {
    break;
  }
  console.log(i);
}
```

```js
for (let i = 0; i <= 5; i++) {
  if (i === 3) {
    continue;
  }
  console.log(i);
}
```

- `break`：立刻结束整个循环或 `switch`。
- `continue`：跳过当前迭代，继续下一次循环。
- 标签语句可以控制嵌套循环，但可读性较差，实际项目中应谨慎使用。

## 代码风格

- 循环变量使用有意义的名称。
- 循环条件要保证最终会结束，避免死循环。
- 优先使用 `let` / `const`，减少 `var` 带来的作用域问题。
- 复杂条件应提取为有名称的变量或函数。
