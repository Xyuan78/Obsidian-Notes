# 变量、数据类型与类型转换

> [!source] 课程对照
> `html.pdf` 第 30、33、38–39 页。

## 变量声明

```js
var oldName = "旧式变量";
let count = 1;
const siteName = "Frontend Notes";
```

- `var`：课程常用写法，函数作用域，存在变量提升，现代项目通常不再优先使用。
- `let`：块级作用域，变量值可以重新赋值。
- `const`：块级作用域，声明后不能重新绑定；对象内部属性仍可修改。

现代 JavaScript 优先使用 `const`，确实需要重新赋值时使用 `let`。

```js
const user = { name: "张三" };
user.name = "李四"; // 可以修改对象属性

let score = 60;
score = 80; // 可以重新赋值
```

## 数据类型

常见原始类型：

- `string`：字符串。
- `number`：数字，包括整数、小数和 `NaN`。
- `boolean`：布尔值 `true` / `false`。
- `undefined`：声明但未赋值。
- `null`：主动表示“没有对象值”。
- `symbol`：唯一符号。
- `bigint`：大整数。

常见对象类型：

- `Object`：普通对象。
- `Array`：数组。
- `Date`：日期时间对象。
- `Function`：函数也是对象。

```js
const name = "HTML";
const count = 10;
const isReady = true;
const empty = null;
let notAssigned;
const colors = ["red", "green"];
const person = { name: "Bill", age: 56 };
```

## null 与 undefined

```js
let a;
console.log(a); // undefined

let list = ["ss", "nn"];
list = null; // 主动释放对象引用
```

- `undefined` 常表示变量已声明但还没有值。
- `null` 常表示程序主动设置的“空”。
- `typeof null` 的结果是 `"object"`，这是历史遗留行为。
- `typeof undefined` 的结果是 `"undefined"`。
- `NaN` 的类型是 `number`。
- 数组和日期的 `typeof` 结果都是 `"object"`。

## 字符串与数字转换

```js
parseInt("15.8");    // 15
parseFloat("15.8");  // 15.8
Number("15");        // 15
Number(true);        // 1
Number(false);       // 0
Number(null);        // 0
Number(undefined);   // NaN
```

- `parseInt()`：解析为整数。
- `parseFloat()`：解析为浮点数。
- `Number()`：按数字转换规则转换。
- 转换失败通常得到 `NaN`。
- 使用 `Number.isNaN(value)` 判断值是否为 `NaN`。

## 自动类型转换

```js
"5" + 1;     // "51"：数字转换为字符串
"5" - 1;     // 4：字符串转换为数字
"5" + null;  // "5null"
1 + true;    // 2
```

`+` 遇到字符串时通常会进行字符串拼接，其他算术运算符通常尝试转换为数字。不要依赖隐式转换，必要时显式使用 `Number()`、`String()`。

## 模板字符串

```js
const name = "张三";
const age = 18;

console.log(`${name} 今年 ${age} 岁`);
```

模板字符串使用反引号，可以通过 `${...}` 插入变量或表达式。
