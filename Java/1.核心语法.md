# Java 核心语法

## 1. 字面量

作用：告诉程序员数据在程序中的书写格式

| 类型 | 说明 | 写法 |
|------|------|------|
| 整数 | 不带小数点数字 | `666`, `-88` |
| 小数 | 带小数点数字 | `13.14` |
| 字符 | 必须使用单引号，有且仅能一个字符 | `'A'`, `'我'` |
| 字符串 | 必须使用双引号，内容可有可无 | `"HelloWorld"` |
| 布尔值 | 表示真假 | `true`, `false` |
| 空值 | 特殊的值，空置 | `null` |

## 2. 变量

### 2.1 什么是变量？

变量是在程序中临时存储数据的容器，但只能存一个值

### 2.2 变量的格式

```java
数据类型 变量名 = 数据值;
```

> [!warning] 注意
> 变量名不能重复，变量在使用之前要赋值

## 3. 数据类型

### 3.1 分类

- 基本数据类型
- 引用数据类型

### 3.2 基本数据类型的八类

| 数据类型 | 关键字 | 内存占用 | 取值范围 |
|----------|--------|----------|----------|
| 整数 | `byte` | 1 | $-2^{7} \sim 2^{7}-1$（-128~127） |
| | `short` | 2 | $-2^{15} \sim 2^{15}-1$（-32768~32767） |
| | `int` | 4 | $-2^{31} \sim 2^{31}-1$ |
| | `long` | 8 | $-2^{63} \sim 2^{63}-1$ |
| 浮点数 | `float` | 4 | $1.401298e^{-45} \sim 3.402823e^{38}$ |
| | `double` | 8 | $4.9000000e^{-324} \sim 1.797693e^{308}$ |
| 字符 | `char` | 2 | 0~65535 |
| 布尔 | `boolean` | 1 | `true`, `false` |

> [!tip] 取值范围大小
> `double` > `float` > `long` > `int` > `short` > `byte`

## 4. 标识符

一般遵循阿里巴巴的命名规则（见名知意）

- 必须由数字、字母、下划线 `_`、美元符号 `$` 组成
- 数字不能开头
- 不能是关键字
- 区分大小写

### 4.1 小驼峰命名法

适用于变量名和方法名

- 一个单词，全部小写
- 多个单词，从第二个单词开始首字母大写，如 `firstName`, `maxAge`

### 4.2 大驼峰命名法

适用于类名

- 一个单词，首字母大写，如 `Demo`
- 多个单词，每一个单词首字母都要大写，如 `HelloWorld`

## 5. 键盘录入

在 `Scanner` 这个类中

```java
// 1. 导包，找到 Scanner 这个类
import java.util.Scanner;

public class ScannerDemo1 {
    public static void main(String[] args) {
        // 2. 创建对象，申明准备使用 Scanner 类
        Scanner sc = new Scanner(System.in);
        // 3. 接收数据
        System.out.println("请输入一个数字");
        int i = sc.nextInt();
        System.out.println(i);
    }
}
```

## 6. 算术运算符

### `+` `-` `*` `/` `%`

- `/`：整数相除只能得到整数，想得到小数必须有小数参与
- `%`：取模，得到余数

## 7. 隐式转换

把一个取值范围小的数据或变量，赋值给另一个取值范围大的变量，程序自动完成

## 8. 强制转换

把一个取值范围大的数据或变量赋值给另一个取值范围小的变量，必须强制转换

```java
目标数据类型 变量名 = (目标数据类型) 被强转的数据;
```

要转为什么类型，就在小括号中写什么类型

## 9. 字符串 + 操作

- 当 `+` 操作中出现字符串时，此时是字符串的拼接，会拼接前后数据并产生一个新的字符串
- 当连续进行 `+` 操作时，从左到右逐个进行

## 10. 字符的 + 操作

当 `+` 操作中出现了字符，会拿着字符对应的 ASCII 码表中的数字进行计算

```java
char c = 'a';
int result = c + 0;
System.out.println(result); // 97
```

## 11. 自增自减运算符

- `++`：自增
- `--`：自减

放在变量前面：先 ++；放在变量后面：后 ++

## 12. 扩展运算符

`+=`、`-=`、`/=`、`%=`

```java
a += b   // 相当于 a = a + b
```

## 13. 关系运算符

| 符号 | 解释 |
|------|------|
| `==` | 判断左右是否相等，成立为 `true`，否则 `false` |
| `!=` | 判断左右是否不相等，成立为 `true`，否则 `false` |
| `>` | 判断左边是否大于右边 |
| `>=` | 判断左边是否大于等于右边 |
| `<` | 判断左边是否小于右边 |
| `<=` | 判断左边是否小于等于右边 |

## 14. 逻辑运算符

### `&` `|` `!` 的使用

- **`&`（逻辑与）**：两边都为真，结果才为真
- **`|`（逻辑或）**：两边都为假，结果才为假
- **`!`（取反 / 非）**：`false` 取反为 `true`

## 15. 三元运算符

```java
关系表达式 ? 表达式1 : 表达式2;
```

- 如果表达式为真，执行表达式 1
- 如果表达式为假，执行表达式 2
