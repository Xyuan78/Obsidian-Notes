# Python 数据库与 API

## 1. HTTP 基础

### 1.1 请求方法

| 方法 | 用途 | 说明 |
|------|------|------|
| `GET` | 获取数据 | 只读，参数放 URL |
| `POST` | 创建数据 | 数据放请求体 |
| `PUT` | 更新数据 | 整体替换 |
| `PATCH` | 部分更新 | 按需修改 |
| `DELETE` | 删除数据 | — |

### 1.2 状态码

| 状态码 | 含义 |
|--------|------|
| `200` | 成功 |
| `201` | 创建成功 |
| `204` | 无内容 |
| `400` | 请求错误 |
| `401` | 未认证 |
| `404` | 资源未找到 |
| `500` | 服务器内部错误 |

## 2. MongoDB 与 PyMongo

### 2.1 概念对照

| 关系型数据库（SQL） | MongoDB（NoSQL） |
|---------------------|------------------|
| 数据库 database | 数据库 database |
| 表 table | 集合 collection |
| 行 row | 文档 document |
| 列 column | 字段 field |

MongoDB 文档是 JSON 风格（BSON），**无需提前定义表结构**，字段可以灵活增减

### 2.2 连接与基本操作

```powershell
pip install pymongo dnspython
```

```python
import pymongo
from bson.objectid import ObjectId

client = pymongo.MongoClient('mongodb+srv://用户名:密码@集群地址/')
db = client['thirty_days_of_python']      # 访问（不存在会自动创建）
collection = db['students']               # 访问集合

# 增
collection.insert_one({'name': 'Asabeneh', 'country': 'Finland', 'age': 250})
collection.insert_many([{'name': 'David', 'age': 34}, {'name': 'John', 'age': 28}])

# 查
collection.find_one()                            # 第一条
collection.find_one({'_id': ObjectId('...')})    # 按 id
list(collection.find())                          # 全部（转列表）
collection.find_one({'name': 'David'})           # 条件

# 改
collection.update_one({'name': 'David'}, {'$set': {'age': 35}})
collection.update_many({'country': 'Finland'}, {'$set': {'city': 'Helsinki'}})

# 删
collection.delete_one({'name': 'David'})
collection.delete_many({'age': {'$lt': 20}})
collection.drop()                                # 删除整个集合
```

### 2.3 查询修饰符

```python
collection.find({'age': {'$gt': 25}})        # 大于
collection.find({'age': {'$gte': 25}})       # 大于等于
collection.find({'age': {'$lt': 30}})        # 小于
collection.find({'age': {'$in': [25, 28]}})  # 在列表中
collection.find({'name': {'$regex': '^A'}})  # 正则
collection.find().limit(5)                   # 限制条数
collection.find().sort('age', -1)            # 降序（1 升序）
collection.count_documents({})               # 文档数量
```

## 3. 用 Flask 构建 API

### 3.1 GET：返回 JSON

```python
from flask import Flask, Response
import json

app = Flask(__name__)

@app.route('/api/v1.0/students', methods=['GET'])
def students():
    student_list = [
        {'name': 'Asabeneh', 'country': 'Finland', 'age': 250},
        {'name': 'David', 'country': 'UK', 'age': 34},
    ]
    return Response(json.dumps(student_list), mimetype='application/json')

if __name__ == '__main__':
    app.run(debug=True, port=5000)
```

### 3.2 连接 MongoDB 的完整 CRUD

```python
from flask import Flask, request, Response
from bson.objectid import ObjectId
from bson.json_util import dumps   # 支持 ObjectId 序列化
import pymongo

app = Flask(__name__)
client = pymongo.MongoClient('mongodb+srv://用户名:密码@集群地址/')
collection = client['thirty_days_of_python']['students']

# 查询所有
@app.route('/api/v1.0/students', methods=['GET'])
def get_students():
    students = collection.find()
    return Response(dumps(students), mimetype='application/json')

# 按 ID 查询
@app.route('/api/v1.0/students/<id>', methods=['GET'])
def get_student(id):
    student = collection.find_one({'_id': ObjectId(id)})
    if student:
        return Response(dumps(student), mimetype='application/json')
    return {'message': '未找到'}, 404

# 创建
@app.route('/api/v1.0/students', methods=['POST'])
def create_student():
    data = request.json                  # 解析请求体 JSON
    result = collection.insert_one(data)
    return {'message': '创建成功', 'id': str(result.inserted_id)}, 201

# 更新
@app.route('/api/v1.0/students/<id>', methods=['PUT'])
def update_student(id):
    data = request.json
    result = collection.update_one({'_id': ObjectId(id)}, {'$set': data})
    if result.modified_count:
        return {'message': '更新成功'}
    return {'message': '未找到'}, 404

# 删除
@app.route('/api/v1.0/students/<id>', methods=['DELETE'])
def delete_student(id):
    result = collection.delete_one({'_id': ObjectId(id)})
    if result.deleted_count:
        return {'message': '删除成功'}
    return {'message': '未找到'}, 404

if __name__ == '__main__':
    app.run(debug=True, port=5000)
```

### 3.3 测试方式

- **GET**：浏览器直接访问 `http://localhost:5000/api/v1.0/students`
- **POST/PUT/DELETE**：用 [Postman](https://www.postman.com/) 选择方法、填 URL、Body 选 `raw + JSON` 发送
- 命令行测试：`curl -X POST -H "Content-Type: application/json" -d '{"name":"Tom"}' http://localhost:5000/api/v1.0/students`
