# Python 数据存储容器

数据容器可以容纳多份数据，容纳的每一份数据称之为一个元素。
分为：**列表（list）**、**字符串（str）**、**元组（tuple）**、**字典（dict）**、**集合（set）**

| 容器 | 是否有序 | 是否可变 | 是否可重复 | 语法 |
|------|----------|----------|------------|------|
| 列表 list | 有序 | 可变 | 可重复 | `[1, 2, 3]` |
| 字符串 str | 有序 | 不可变 | — | `'abc'` |
| 元组 tuple | 有序 | 不可变 | 可重复 | `(1, 2, 3)` |
| 字典 dict | 有序（3.7+） | 可变 | 键唯一 | `{'a': 1}` |
| 集合 set | 无序 | 可变 | 不重复 | `{1, 2, 3}` |

## 一、列表（list）

### 1. 定义

```python
列表名称 = [元素1, 元素2, 元素3, ...]
```

### 2. 特点

- 可以存储不同类型的元素
- 元素有序，可以重复，元素可以修改
- 从前向后，下标从 0 开始；从后往前，下标从 -1 开始

### 3. 切片

对数据截取其中一部分的操作。列表、字符串、元组都支持切片

```python
序列数据[开始索引:结束索引:步长]
```

- 不包含结束索引位置对应的元素
- 开始索引未指定默认为 0；结束索引未指定默认为列表长度；步长未指定默认为 1
- 索引采用正向、反向索引都可以
- 步长是选取间隔

```python
s = ['A', 'C', 'E', 'B', 'D', 'E', 'G']
s[0:5:1]   # ['A', 'C', 'E', 'B', 'D']
s[0:5:2]   # ['A', 'E', 'D']
```

### 4. 常用方法

| 方法 | 说明 | 示例 |
|------|------|------|
| `append()` | 在列表尾部追加元素 | `s.append(10086)` |
| `extend()` | 追加一个可迭代对象的所有元素 | `s.extend([1, 2])` |
| `insert()` | 在指定索引之前插入元素 | `s.insert(0, 82)` |
| `remove()` | 移除列表中第一个匹配的值 | `s.remove(75)` |
| `pop()` | 删除指定索引的元素，默认删最后一个 | `s.pop(2)` / `s.pop()` |
| `index()` | 查找元素第一次出现的下标 | `s.index(75)` |
| `count()` | 统计元素出现次数 | `s.count(75)` |
| `sort()` | 对列表排序（元素类型需一致） | `s.sort()` / `s.sort(reverse=True)` |
| `reverse()` | 反转列表元素 | `s.reverse()` |
| `copy()` | 复制列表（浅拷贝） | `s2 = s.copy()` |
| `clear()` | 清空列表 | `s.clear()` |

### 5. 遍历

```python
for 元素 in 列表:          # 遍历元素
    print(元素)

for i in range(len(列表)): # 按下标遍历
    print(i, 列表[i])
```

## 二、字符串（str）

### 1. 定义

- 字符串是字符的容器，一个字符串中可以存放任意数量的字符
- 特点：不可变性（无法修改）、有序性、可迭代性
- 字符串中的每个字符元素都有对应的下标（索引），可以获取对应的元素

### 2. 切片

```python
序列对象[开始索引:结束索引:步长]
```

- 不包含结束索引位置对应的元素
- 步长为 -1 表示从后往前

### 3. 常用方法

| 方法 | 说明 | 示例 |
|------|------|------|
| `find()` | 查找子串，返回第一次出现的索引，找不到返回 -1 | `s.find('Python')` |
| `index()` | 查找子串，找不到会报错 | `s.index('Python')` |
| `count()` | 统计子串出现的次数 | `s.count('H')` |
| `upper()` | 转换为大写 | `s.upper()` |
| `lower()` | 转换为小写 | `s.lower()` |
| `split()` | 按指定分隔符分割成列表 | `s.split(' ')` |
| `join()` | 用分隔符把列表连接成字符串 | `'-'.join(['a','b'])` → `'a-b'` |
| `strip()` | 去除两端空白字符或指定字符 | `s.strip()` / `s.strip('*')` |
| `replace()` | 将指定子串替换为新的子串 | `s.replace('H', 'C')` |
| `startswith()` | 检查是否以指定子串开头，返回布尔值 | `s.startswith('P')` |
| `endswith()` | 检查是否以指定子串结尾 | `s.endswith('n')` |
| `len()` | 字符串长度（内置函数） | `len(s)` |

> [!warning] 注意
> 字符串不可变：`s[0] = 'a'` 会报错；修改字符串实际是生成新字符串

## 三、元组（tuple）

### 1. 定义

```python
元组名称 = (元素1, 元素2, 元素3, ...)
```

```python
t1 = ()                  # 空元组
t2 = (1, 2, 3)           # 基本创建
t3 = (1,)                # 单个元素必须加逗号
t4 = tuple([1, 2, 3])    # 列表转元组
t5 = 1, 2, 3             # 省略括号也能创建元组
```

### 2. 特点

- **不可变**：创建后不能修改、添加、删除元素
- 有序，支持下标索引和切片（与列表相同）
- 可以存储不同类型的数据
- 比列表更安全，适合存储不允许修改的数据（如配置、坐标）

### 3. 访问与切片

```python
t = (10, 20, 30, 40, 50)
t[0]        # 10
t[-1]       # 50
t[1:4]      # (20, 30, 40)
'x' in t    # 成员判断
len(t)      # 5
```

### 4. 常用方法

| 方法 | 说明 | 示例 |
|------|------|------|
| `index(x)` | 查找元素下标 | `t.index(30)` → 2 |
| `count(x)` | 统计元素出现次数 | `t.count(20)` → 1 |

### 5. 元组与列表的转换

```python
t = (1, 2, 3)
lst = list(t)        # [1, 2, 3] 元组 → 列表
t2 = tuple(lst)      # (1, 2, 3) 列表 → 元组
```

### 6. 元组解包

```python
t = ('Asabeneh', 250)
name, age = t        # name='Asabeneh', age=250

# 星号解包
a, *rest = (1, 2, 3, 4)    # a=1, rest=[2, 3, 4]
```

> [!tip] 提示
> 元组中的元素不可变，但如果元素本身是可变对象（如列表），该元素内部仍可修改

## 四、字典（dict）

### 1. 定义

以**键值对（key-value）**存储数据，键必须唯一且不可变

```python
字典名称 = {键: 值, 键: 值, ...}
```

```python
person = {'name': 'Asabeneh', 'age': 250, 'city': 'Helsinki'}
empty = {}                              # 空字典
```

### 2. 特点

- 键唯一：重复键后面的值覆盖前面的
- 键必须不可变（字符串、数字、元组）；值可以是任意类型
- 通过键查找值，查询速度快

### 3. 常用操作

```python
person['name']            # 访问：Asabeneh（键不存在报 KeyError）
person.get('name')        # 安全访问：不存在返回 None
person.get('city', '未知') # 带默认值

person['email'] = 'a@b.com'   # 添加键值对
person['age'] = 251           # 修改值（键已存在则覆盖）

'name' in person          # True，判断键是否存在
len(person)               # 键值对数量

person.pop('email')       # 删除指定键并返回其值
person.popitem()          # 删除最后一个键值对
del person['age']         # 删除指定键
person.clear()            # 清空
```

### 4. 遍历与视图

```python
person.keys()      # dict_keys(['name', 'age', ...])
person.values()    # dict_values([...])
person.items()     # dict_items([('name', 'Asabeneh'), ...])

for key, value in person.items():
    print(key, value)
```

### 5. 嵌套字典

```python
student = {
    'name': 'Asabeneh',
    'address': {'city': 'Helsinki', 'zip': '02210'},
    'skills': ['Python', 'Flask']
}
student['address']['city']    # Helsinki
```
