# Python 网络爬虫

爬虫 = 用程序自动向网站发送 HTTP 请求、解析响应内容、提取并保存数据

## 1. 安装依赖

```powershell
pip install requests beautifulsoup4
```

## 2. requests 获取网页

```python
import requests

response = requests.get('https://example.com')

response.status_code          # 200 成功 / 404 未找到
response.ok                   # True/False
response.content              # 原始内容（字节）
response.text                 # 解码后的文本
response.url                  # 最终 URL
response.headers              # 响应头
response.json()               # 如果返回 JSON 直接解析
```

### 2.1 带参数和请求头

```python
# 查询参数
params = {'q': 'python', 'page': 2}
response = requests.get('https://example.com/search', params=params)

# 自定义请求头（模拟浏览器，绕过简单反爬）
headers = {'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36'}
response = requests.get('https://example.com', headers=headers)

# 超时设置（防止卡死）
response = requests.get('https://example.com', timeout=10)
```

## 3. BeautifulSoup 解析

```python
from bs4 import BeautifulSoup

soup = BeautifulSoup(response.content, 'html.parser')

soup.title                  # <title>...</title>
soup.title.get_text()       # 标题文本
soup.body                   # 整个 body
soup.p                      # 第一个 p 标签
```

### 3.1 查找方法

| 方法 | 说明 |
|------|------|
| `soup.find('h1')` | 第一个 h1 |
| `soup.find_all('a')` | 所有 a 标签（列表） |
| `soup.find_all('h2', limit=5)` | 限制数量 |
| `soup.find('div', class_='content')` | 按 class 查找（注意 class_） |
| `soup.find('table', {'cellpadding': '3'})` | 按属性查找 |
| `soup.select('.content a')` | CSS 选择器 |
| `soup.select_one('#title')` | 单个 CSS 选择器 |

### 3.2 提取内容

```python
# 获取文本和属性
tag = soup.find('a')
tag.get_text()              # 链接文本
tag.get('href')             # href 属性
tag['href']                 # 同上，不存在会报错
tag.attrs                   # 所有属性字典

# 提取表格
table = soup.find('table')
for tr in table.find_all('tr'):
    cells = [td.get_text().strip() for td in tr.find_all('td')]
    print(cells)

# 提取所有链接
links = [a.get('href') for a in soup.find_all('a') if a.get('href')]
```

## 4. 保存数据

```python
import json, csv

# 保存为 JSON
data = [{'title': t.get_text()} for t in soup.find_all('h2')]
with open('data.json', 'w', encoding='utf-8') as f:
    json.dump(data, f, indent=2, ensure_ascii=False)

# 保存为 CSV
with open('data.csv', 'w', newline='', encoding='utf-8') as f:
    writer = csv.writer(f)
    for item in data:
        writer.writerow([item['title']])
```

## 5. 完整小例子

```python
import requests
from bs4 import BeautifulSoup
import json

url = 'https://example.com'
response = requests.get(url, timeout=10)

if response.status_code == 200:
    soup = BeautifulSoup(response.content, 'html.parser')
    posts = []
    for h2 in soup.find_all('h2'):
        posts.append({'title': h2.get_text().strip()})
    with open('posts.json', 'w', encoding='utf-8') as f:
        json.dump(posts, f, indent=2, ensure_ascii=False)
    print(f'抓取到 {len(posts)} 条')
else:
    print(f'请求失败：{response.status_code}')
```

## 6. 爬虫礼仪与反爬

> [!warning] 注意
> - 遵守目标网站的 `robots.txt`（如 `https://example.com/robots.txt`）和用户协议
> - 控制请求频率：用 `time.sleep(1)` 间隔请求，避免给服务器造成压力
> - 尊重版权，抓取的数据仅用于学习
> - 网站可能返回 403/验证码/动态渲染（JavaScript），需要更复杂的技术（selenium 等）
