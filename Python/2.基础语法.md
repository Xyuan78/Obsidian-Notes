# Python 基础语法

## 1. 字面量

指程序中直接书写的固定值（数据），称为字面量

| 类型 | 说明 | 示例 |
|------|------|------|
| 整数 | 不带小数点的数字 | `10`, `18`, `-5` |
| 浮点数/小数 | 带小数点的数字 | `8.5`, `3.14` |
| 布尔 | 真或假 | `true`（-1）, `false`（0） |
| 字符串（str） | 描述文本的一种数据类型 | `"人生苦短"` |
| 空值 | 仅包含一个 `None` | `None` |
| 数据容器 | 存储多项数据的容器 | 列表/元组/集合/字典 |

## 2. 变量

程序中用来存储单个数据的容器，通常把常发生变化的数据存储在变量中

```python
变量名 = 变量的值
num = 1114.1
```

## 3. 标识符

为变量、函数、类等元素起的名字，一般遵循见名知意

- 必须由数字、字母、下划线 `_`、美元符号 `$` 组成
- 数字不能开头
- 不能是关键字
- 区分大小写

### 3.1 小驼峰命名法

适用于变量名和方法名

- 一个单词全部小写
- 多个单词从第二个单词开始首字母大写，如 `firstName`, `maxAge`

### 3.2 大驼峰命名法

适用于类名

- 一个单词首字母大写，如 `Demo`
- 多个单词每个单词首字母都要大写，如 `HelloWorld`

## 4. 数据类型

| 类型 | 说明 | 示例 |
|------|------|------|
| `int` | 整数 | `10`, `-5` |
| `float` | 浮点数 | `8.5`, `3.14` |
| `str` | 字符串（用引号引起来的都是字符串） | `"Python"` |
| `bool` | 布尔，表示真假 | `true`, `false` |
| `NoneType` | 空值，表示空或无值 | `None` |

> 通过 `type()` 来查看数据的类型

## 5. 字符串

字符：是文本世界的基本单位，一个字母、一个数字、一个标点符号、一个汉字等都是一个字符

### 5.1 字符串的定义

**双引号定义**

```python
s1 = "Hello"
```

**单引号定义**

```python
s2 = 'Python'
```

**三引号定义（多行字符串）**

```python
s3 = """
    尊敬的领导：
        感谢您
"""
```

**常见转义字符**

| 转义符 | 说明 |
|--------|------|
| `\\'` | 单引号 |
| `\\"` | 双引号 |
| `\\n` | 换行 |
| `\\t` | 制表符（Tab）缩进 |

### 5.2 字符串的拼接

```python
slogan = "黑马程序员" + "成就IT黑马"
print(slogan)
```

> [!warning] 注意
> `+` 号只能拼接两个字符串，无法将非字符串与字符串进行拼接

### 5.3 字符串的格式化

**通过占位符 `%` 的形式**

```python
s1 = '人生苦短'
s2 = '我用Python'
print("大家好：%s , %s" % (s1, s2))
```

**通过 `f` 前缀 + `{}` 表达式**

```python
name = "涛哥"
print(f"大家好，我是{name}，欢迎大家进入Python的课程学习")

s1 = "人生苦短"
s2 = "我用Python"
print(f"我是：{s1}, {s2}")
```

## 6. 输入输出

- `input()`：输入函数，获取键盘输入的数据
- `print()`：输出函数，将数据输出到控制台

> [!warning] 注意
> 无论输入的是什么，`input()` 返回的都是字符串类型

## 7. 运算符

### 7.1 算术运算符

| 运算符 | 说明 |
|--------|------|
| `+` | 加法 |
| `-` | 减法 |
| `*` | 乘法 |
| `/` | 除法 |
| `//` | 整除 |
| `%` | 取余 / 求模 |
| `**` | 幂指数 |

### 7.2 赋值运算符

| 运算符 | 说明 | 等效 |
|--------|------|------|
| `=` | 赋值 | |
| `+=` | 加法赋值 | `num += 2` 等效于 `num = num + 2` |
| `-=` | 减法赋值 | |
| `*=` | 乘法赋值 | |
| `/=` | 除法赋值 | |
| `%=` | 取模赋值 | |
| `//=` | 取整除赋值 | |
| `**=` | 幂赋值 | |

### 7.3 比较运算符

运算结果是布尔值

| 运算符 | 说明 |
|--------|------|
| `==` | 等于 |
| `!=` | 不等于 |
| `>` | 大于 |
| `>=` | 大于等于 |
| `<` | 小于 |
| `<=` | 小于等于 |

### 7.4 逻辑运算符

| 运算符 | 说明 |
|--------|------|
| `and` | 逻辑与（并且），同时成立才符合条件 |
| `or` | 逻辑或（或者），只要有一个符合条件即可 |
| `not` | 逻辑非（取反），`true` 变 `false` |
