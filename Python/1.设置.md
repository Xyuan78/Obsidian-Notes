# Python 开发环境设置

## 1. 环境安装与检查

```powershell
python --version     # 查看 Python 版本
pip --version        # 查看 pip 版本
python -c "print('hello')"   # 直接运行一行代码
```

> [!tip] 提示
> 命令行输入 `python` 进入交互式解释器（Python Shell），输入 `exit()` 退出

## 3. 字符串

- 用引号引起来的内容就是字符串：单引号 `'...'`、双引号 `"..."`、三引号 `'''...'''`（多行）
- 字符串是**不可变**的有序字符序列，支持下标索引和切片

```python
s1 = 'Hello'
s2 = "Python"
s3 = """多行
字符串"""
len(s1)        # 5
s1[0]          # 'H'
s1[-1]         # 'o'
```

## 4. 变量与常量

### 4.1 变量

程序中用来存储数据的容器，值可以随时改变

```python
变量名 = 变量的值
age = 20          # 数字
name = '小明'      # 字符串
age = 21          # 修改变量值
```

- 变量必须先赋值再使用，否则报 `NameError`
- `type(变量)` 可以查看变量的数据类型

### 4.2 常量

- Python **没有真正的常量**，约定用**全大写命名**表示"不要修改"的值
- 是一种编程规范，不是语法限制

```python
PI = 3.14159
MAX_COUNT = 100
```

### 4.3 变量与常量的区别

| 对比 | 变量 | 常量 |
|------|------|------|
| 命名规范 | 小写/小驼峰 | 全大写 |
| 值 | 可以修改 | 约定不修改 |
| 示例 | `age = 20` | `PI = 3.14` |

## 5. 标识符命名规则

- 只能包含：数字、字母、下划线，且不能以数字开头，不能包含空格
- 区分大小写（`Name` 和 `name` 是两个变量）
- 不能使用关键字（`if`、`for`、`class` 等）
- 尽量不要与内置函数重名（`print`、`len`、`type` 等）

> [!warning] 注意
> 查看关键字列表：`import keyword; keyword.kwlist`；遵守"见名知意"原则

## 6. 数据类型

### 6.1 Python 内置类型

| 类型 | 说明 | 示例 |
|------|------|------|
| `int` | 整数 | `10`, `-5` |
| `float` | 浮点数 | `3.14`, `8.5` |
| `str` | 字符串 | `'Python'` |
| `bool` | 布尔型 | `True`, `False` |
| `NoneType` | 空值 | `None` |
| `list` | 列表 | `[1, 2, 3]` |
| `tuple` | 元组 | `(1, 2)` |
| `dict` | 字典 | `{'a': 1}` |
| `set` | 集合 | `{1, 2}` |

```python
print(type(10))        # <class 'int'>
print(type('Python'))  # <class 'str'>
print(type([1, 2]))    # <class 'list'>
```

### 6.2 数据类型转换

| 函数 | 说明 | 示例 |
|------|------|------|
| `int(x)` | 转整数 | `int('10')` → 10 |
| `float(x)` | 转浮点数 | `float('3.14')` → 3.14 |
| `str(x)` | 转字符串 | `str(10)` → `'10'` |
| `bool(x)` | 转布尔 | `bool(1)` → True |
| `list(x)` | 转列表 | `list((1,2))` → `[1,2]` |
| `tuple(x)` | 转元组 | `tuple([1,2])` → `(1,2)` |
| `set(x)` | 转集合（去重） | `set([1,1,2])` → `{1,2}` |

> [!warning] 注意
> 字符串转数字：`int('abc')` 会报 `ValueError`；`int('10.5')` 会报错，需先 `float()`
