# Python Pandas

Pandas 是 Python 数据分析的核心库，提供 **Series**（一列数据）和 **DataFrame**（表格数据）两种结构

## 1. 安装与导入

```powershell
pip install pandas
```

```python
import pandas as pd
import numpy as np
```

## 2. Series（一列数据）

```python
s = pd.Series([1, 2, 3, 4, 5])                    # 默认索引 0-4
s = pd.Series([1, 2, 3], index=['a', 'b', 'c'])   # 自定义索引
s = pd.Series({'name': 'Asabeneh', 'age': 250})   # 字典 → 键为索引
s = pd.Series(10, index=[1, 2, 3])                # 常量序列
s = pd.Series(np.linspace(5, 20, 10))             # 均匀分布

print(s)            # 索引 + 值 + dtype
print(s.values)     # 值数组
print(s.index)      # 索引
print(s['a'])       # 按索引取值
print(s.mean())     # 序列也支持统计运算
```

## 3. DataFrame（表格）

### 3.1 创建 DataFrame

```python
# 从列表的列表
df = pd.DataFrame(
    [['Asabeneh', 'Finland', 'Helsinki'],
     ['David', 'UK', 'London']],
    columns=['Name', 'Country', 'City']
)

# 从字典（键是列名，值是整列）
data = {'Name': ['Asabeneh', 'David'],
        'Country': ['Finland', 'UK']}
df = pd.DataFrame(data)

# 从字典列表（每个字典是一行）
df = pd.DataFrame([{'Name': 'Asabeneh', 'Country': 'Finland'},
                   {'Name': 'David', 'Country': 'UK'}])
```

### 3.2 读取与保存文件

```python
df = pd.read_csv('data.csv')
df = pd.read_csv('data.csv', encoding='utf-8')
df = pd.read_excel('data.xlsx')
df = pd.read_json('data.json')

df.to_csv('out.csv', index=False)
df.to_excel('out.xlsx', index=False)
```

## 4. 数据探索

| 方法 | 说明 |
|------|------|
| `df.head(n)` | 前 n 行（默认 5） |
| `df.tail(n)` | 后 n 行 |
| `df.shape` | (行数, 列数) |
| `df.columns` | 列名 |
| `df.index` | 行索引 |
| `df.dtypes` | 每列数据类型 |
| `df.info()` | 列类型 + 缺失值概况 |
| `df.describe()` | 数值列统计摘要（count/mean/std/min/25%/50%/75%/max） |
| `df.isna().sum()` | 每列缺失值数量 |

```python
df.head(10)
df.describe()
df.info()
```

## 5. 数据选择

```python
df['Name']                 # 取一列（Series）
df[['Name', 'Age']]        # 取多列（DataFrame）
df['Age'].mean()           # 某一列的统计

# 按行位置取（iloc）
df.iloc[0]                 # 第一行
df.iloc[1:3]               # 第 2-3 行
df.iloc[0, 1]              # 第一行第二列

# 按索引标签取（loc）
df.set_index('Name', inplace=True)   # 设置索引列
df.loc['Asabeneh']         # 按索引取行
```

## 6. 布尔索引（条件筛选）

```python
df[df['Age'] > 30]                      # 年龄大于 30
df[df['Country'] == 'Finland']          # 等于
df[df['Age'].between(20, 40)]           # 区间
df[df['Name'].str.contains('A')]        # 字符串包含
combined = df[(df['Age'] > 20) & (df['Country'] == 'Finland')]   # 与
combined = df[(df['Age'] < 20) | (df['Age'] > 40)]               # 或
```

## 7. 修改数据

```python
df['NewCol'] = [...]                     # 添加新列
df['NewCol'] = df['Age'] * 2             # 由已有列计算
df['Name'] = df['Name'].str.upper()      # 格式化（字符串方法）
df['Age'] = df['Age'].astype(float)      # 转换类型
df = df.drop('NewCol', axis=1)           # 删除列
df = df.drop(0)                          # 删除行
df['Age'].fillna(0)                      # 填充缺失值
df = df.dropna()                         # 删除含缺失值的行
```

## 8. 分组聚合（groupby）

```python
# 按国家分组，统计各组的平均年龄
df.groupby('Country')['Age'].mean()

# 分组统计汇总
df.groupby('Country').agg({'Age': ['mean', 'max', 'count']})

# 排序
df.sort_values('Age', ascending=False)   # 按年龄降序
```

## 9. 完整小例子

```python
import pandas as pd

df = pd.read_csv('data.csv')
print(df.head())
print(df.info())

# 清洗：填充缺失值
df['Age'] = df['Age'].fillna(df['Age'].mean())

# 筛选：保留成年且芬兰的用户
adults_finland = df[(df['Age'] >= 18) & (df['Country'] == 'Finland')]

# 分析：各国平均年龄
print(df.groupby('Country')['Age'].mean())

# 保存
adults_finland.to_csv('adults_finland.csv', index=False)
```
