# Python 异常处理

## 1. 错误与异常

- **语法错误**：代码不符合语法，程序无法运行
- **异常**：语法正确但运行时出错（除零、下标越界、类型不匹配等），可用 try/except 捕获处理

## 2. 常见异常类型

| 异常 | 触发场景 |
|------|----------|
| `SyntaxError` | 语法错误，如 `print 'hi'` 少了括号 |
| `NameError` | 使用未定义的变量/函数名 |
| `IndexError` | 列表/元组下标越界 |
| `KeyError` | 字典访问不存在的键 |
| `TypeError` | 类型不匹配，如数字与字符串相加 |
| `ValueError` | 值不合法，如 `int('abc')` |
| `AttributeError` | 对象没有该属性/方法，如 `math.PI`（应为 `pi`） |
| `ModuleNotFoundError` | 导入不存在的模块 |
| `ImportError` | 导入失败 |
| `ZeroDivisionError` | 除零 |
| `FileNotFoundError` | 打开不存在的文件 |
| `StopIteration` | 迭代器没有更多元素 |

```python
# 常见触发示例
print('hello)                  # SyntaxError
print(x)                       # NameError
[1, 2][5]                      # IndexError
{'a': 1}['b']                  # KeyError
'1' + 1                        # TypeError
int('abc')                     # ValueError
```

## 3. try / except 结构

### 3.1 基本用法

```python
try:
    age = 2019 - int(input('出生年份：'))
except TypeError:
    print('类型错误')
except ValueError:
    print('值错误：年份必须是数字')
except Exception as e:      # 兜底，捕获其他所有异常
    print(f'发生错误：{e}')
else:
    print(f'你的年龄是 {age} 岁')   # 没有异常时执行
finally:
    print('无论是否异常都执行')      # 常用于关闭文件/释放资源
```

### 3.2 一个 except 捕获多种异常

```python
try:
    result = 10 / int(input('除数：'))
except (ValueError, ZeroDivisionError) as e:
    print(f'输入不合法：{e}')
```

### 3.3 获取异常信息

```python
try:
    lst = [1, 2]
    print(lst[5])
except IndexError as e:
    print(e)            # list index out of range
    print(e.args)       # ('list index out of range',)
```

## 4. 主动抛出异常 raise

```python
def set_age(age):
    if age < 0 or age > 150:
        raise ValueError(f'年龄不合法：{age}')
    return age

# 自定义异常
class AgeError(Exception):
    pass

raise AgeError('自定义错误信息')
```

## 5. 自定义异常类

```python
class CustomError(Exception):
    def __init__(self, message):
        self.message = message
        super().__init__(message)

try:
    raise CustomError('出错了')
except CustomError as e:
    print(e.message)     # 出错了
```

## 6. 常用配套函数

| 函数 | 说明 | 示例 |
|------|------|------|
| `enumerate(iterable, start=0)` | 同时取索引和元素 | `for i, v in enumerate(['a','b'])` → (0,'a') (1,'b') |
| `zip(*iterables)` | 并行打包多个序列 | `list(zip([1,2],[3,4]))` → `[(1,3),(2,4)]` |
| `*` 展开 | 合并列表 | `lst = [0, *lst1, *lst2]` |

```python
fruits = ['banana', 'orange', 'mango']
for index, item in enumerate(fruits):
    print(index, item)          # 0 banana / 1 orange / 2 mango

countries = ['Finland', 'Sweden', 'Norway']
capitals = ['Helsinki', 'Stockholm', 'Oslo']
for country, capital in zip(countries, capitals):
    print(f'{country} 的首都是 {capital}')
```
