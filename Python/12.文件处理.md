# Python 文件处理

## 1. 打开文件模式

```python
open('文件路径', 模式, encoding='utf-8')
```

| 模式 | 说明 |
|------|------|
| `r` | 只读（默认），文件不存在报错 |
| `w` | 写入，**清空原内容**，不存在则创建 |
| `a` | 追加，不存在则创建 |
| `x` | 新建写入，文件已存在报错 |
| `r+` | 读写（不会清空） |
| `b` | 二进制模式（配合使用：`rb`、`wb`） |

## 2. 读取文件

```python
f = open('file.txt', 'r', encoding='utf-8')
txt = f.read()          # 读取全部内容为字符串
f.close()               # 记得关闭！
```

```python
f.read(10)              # 只读前 10 个字符
f.readline()            # 读第一行
f.readlines()           # 读全部行，返回列表（含换行符）
f.read().splitlines()   # 读全部行，去掉换行符
```

### 2.1 推荐 with 写法（自动关闭）

```python
with open('file.txt', 'r', encoding='utf-8') as f:
    txt = f.read()
# 离开 with 块自动关闭，无需手动 close

with open('file.txt', encoding='utf-8') as f:
    for line in f:              # 逐行读取（大文件高效）
        print(line, end='')
```

## 3. 写入文件

```python
# 覆盖写入
with open('file.txt', 'w', encoding='utf-8') as f:
    f.write('第一行\n')
    f.write('第二行')

# 追加
with open('file.txt', 'a', encoding='utf-8') as f:
    f.write('\n追加的内容')

# 写入多行
with open('file.txt', 'w', encoding='utf-8') as f:
    f.writelines(['a\n', 'b\n', 'c\n'])
```

> [!warning] 注意
> - `w` 模式会清空原文件，重要文件先备份
> - 写中文务必指定 `encoding='utf-8'`，否则可能乱码

## 4. JSON 文件

JSON = 字符串化的字典/列表，是网络传输和配置文件的标准格式

```python
import json

person = {'name': 'Asabeneh', 'age': 250, 'skills': ['Python', 'Flask']}

# 字典 → JSON 字符串
json_str = json.dumps(person, indent=2, ensure_ascii=False)

# JSON 字符串 → 字典
data = json.loads(json_str)

# 字典 → 文件
with open('person.json', 'w', encoding='utf-8') as f:
    json.dump(person, f, indent=2, ensure_ascii=False)

# 文件 → 字典
with open('person.json', 'r', encoding='utf-8') as f:
    data = json.load(f)
```

> [!tip] 提示
> `ensure_ascii=False` 让中文以原文保存（否则变成 `\uXXXX` 转义）；`indent=2` 美化缩进

## 5. CSV 文件

```python
import csv

# 写入
with open('data.csv', 'w', newline='', encoding='utf-8') as f:
    writer = csv.writer(f)
    writer.writerow(['name', 'country', 'age'])
    writer.writerow(['Asabeneh', 'Finland', 250])

# 读取
with open('data.csv', 'r', encoding='utf-8') as f:
    for row in csv.reader(f):
        print(row)          # ['name', 'country', 'age'] ...

# 字典形式读写
with open('data.csv', 'w', newline='', encoding='utf-8') as f:
    writer = csv.DictWriter(f, fieldnames=['name', 'country'])
    writer.writeheader()
    writer.writerow({'name': 'Asabeneh', 'country': 'Finland'})

with open('data.csv', 'r', encoding='utf-8') as f:
    for row in csv.DictReader(f):
        print(row['name'], row['country'])
```

## 6. 目录与文件操作

```python
import os

os.getcwd()              # 当前目录
os.listdir('.')          # 列出目录内容
os.mkdir('new_dir')      # 创建目录（已存在报错）
os.makedirs('a/b/c')     # 递归创建
os.remove('file.txt')    # 删除文件（不存在报错）
os.rmdir('new_dir')      # 删除空目录

# 安全删除
if os.path.exists('file.txt'):
    os.remove('file.txt')
```

```python
# pathlib 更现代的方式
from pathlib import Path

p = Path('data/file.txt')
p.exists()               # 是否存在
p.read_text(encoding='utf-8')   # 读
p.write_text('内容', encoding='utf-8')  # 写
p.mkdir(parents=True, exist_ok=True)    # 创建目录
```
