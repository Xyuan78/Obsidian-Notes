# Python 推导式

推导式（comprehension）用一行表达式快速创建新序列，支持条件过滤和嵌套循环，比 for + append 更简洁高效

## 1. 列表推导式

```python
[表达式 for 变量 in 可迭代对象 if 条件]
```

### 1.1 基本用法

```python
numbers = [i for i in range(11)]                 # [0,1,2,...,10]
squares = [i * i for i in range(11)]             # [0,1,4,9,...]
doubled = [i * 2 for i in range(5)]              # [0,2,4,6,8]

# 对字符串操作
names = ['Asabeneh', 'David', 'John']
upper = [name.upper() for name in names]         # ['ASABENEH','DAVID','JOHN']
```

### 1.2 带条件过滤

```python
even = [i for i in range(21) if i % 2 == 0]      # 偶数
odd = [i for i in range(21) if i % 2 != 0]       # 奇数
positive_even = [i for i in range(21) if i % 2 == 0 and i > 0]
```

### 1.3 生成元组列表

```python
pairs = [(i, i * i) for i in range(5)]
# [(0, 0), (1, 1), (2, 4), (3, 9), (4, 16)]
```

### 1.4 嵌套循环（展平多维列表）

```python
list_of_lists = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
flat = [num for row in list_of_lists for num in row]
# [1, 2, 3, 4, 5, 6, 7, 8, 9]

# 两个循环交叉组合
combos = [(x, y) for x in [1, 2] for y in ['a', 'b']]
# [(1,'a'), (1,'b'), (2,'a'), (2,'b')]
```

> [!warning] 注意
> 嵌套推导式的顺序与普通循环一致：先写外层循环，再写内层循环

### 1.5 对比普通写法

```python
# 普通写法
squares = []
for i in range(10):
    squares.append(i * i)

# 推导式写法
squares = [i * i for i in range(10)]
```

## 2. 集合推导式

```python
{表达式 for 变量 in 可迭代对象 if 条件}
```

```python
s = {i for i in range(10) if i % 2 == 0}         # {0, 2, 4, 6, 8}
words = ['apple', 'banana', 'apple']
unique_len = {len(w) for w in words}             # {5, 6} 自动去重
```

## 3. 字典推导式

```python
{键表达式: 值表达式 for 变量 in 可迭代对象 if 条件}
```

```python
dct = {i: i * i for i in range(5)}               # {0:0, 1:1, 2:4, 3:9, 4:16}

# 由两个列表生成字典
keys = ['name', 'age']
values = ['Asabeneh', 250]
person = {k: v for k, v in zip(keys, values)}
# {'name': 'Asabeneh', 'age': 250}

# 条件过滤
even_square = {i: i * i for i in range(10) if i % 2 == 0}
```

## 4. 元组与生成器表达式

```python
# 注意：小括号生成的是生成器，不是元组
gen = (i * i for i in range(5))      # generator 对象，惰性求值
list(gen)                            # [0, 1, 4, 9, 16]

# 生成器优点：不一次性占用内存，适合大数据
total = sum(i * i for i in range(1000000))
```
