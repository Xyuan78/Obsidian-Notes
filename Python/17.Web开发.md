# Python Web 开发（Flask）

Flask 是 Python 的轻量级 Web 框架，适合快速搭建网站和 API

## 1. 项目准备

```powershell
python -m venv venv
venv\Scripts\activate
pip install Flask
```

项目结构（约定）：

```
项目目录/
├── app.py            # 主程序（入口）
├── static/           # 静态资源（CSS/JS/图片）
│   └── css/main.css
└── templates/        # HTML 模板
    ├── layout.html   # 公共布局
    ├── home.html
    └── about.html
```

## 2. 最小应用

```python
from flask import Flask
import os

app = Flask(__name__)

@app.route('/')                 # 路由装饰器：访问 / 时执行
def home():
    return '<h1>欢迎</h1>'

@app.route('/about')
def about():
    return '<h1>关于我们</h1>'

if __name__ == '__main__':
    port = int(os.environ.get('PORT', 5000))   # 部署时用环境变量端口
    app.run(debug=True, host='0.0.0.0', port=port)
```

运行 `python app.py`，浏览器访问 `http://localhost:5000`

> [!tip] 提示
> `debug=True` 修改代码自动重载并显示错误详情，生产环境必须关闭

## 3. 路由进阶

### 3.1 动态路由

```python
@app.route('/user/<name>')
def user(name):
    return f'<h1>你好，{name}</h1>'

@app.route('/post/<int:post_id>')      # 限定类型：int/float/path
def post(post_id):
    return f'文章 ID：{post_id}'
```

### 3.2 限定请求方法

```python
@app.route('/login', methods=['GET', 'POST'])
def login():
    return '登录页'
```

## 4. 渲染模板（Jinja2）

```python
from flask import Flask, render_template

app = Flask(__name__)

@app.route('/')
def home():
    techs = ['HTML', 'CSS', 'Flask', 'Python']
    name = '30 天 Python 挑战'
    return render_template('home.html', title='主页', name=name, techs=techs)
```

```html
<!-- templates/home.html -->
<!DOCTYPE html>
<html>
<head><title>{{ title }}</title></head>
<body>
  <h1>欢迎，{{ name }}</h1>
  <ul>
    {% for tech in techs %}
    <li>{{ tech }}</li>
    {% endfor %}
  </ul>
  {% if techs|length > 3 %}
    <p>技术栈很丰富！</p>
  {% endif %}
</body>
</html>
```

Jinja2 语法速记：`{{ 变量 }}` 输出、`{% 语句 %}` 控制流、`{# 注释 #}`

## 5. 模板继承（layout）

```html
<!-- templates/layout.html -->
<!DOCTYPE html>
<html>
<head><title>{% block title %}默认标题{% endblock %}</title></head>
<body>
  <nav>
    <a href="/">首页</a> | <a href="/about">关于</a>
  </nav>
  {% block content %}{% endblock %}
</body>
</html>
```

```html
<!-- templates/home.html -->
{% extends 'layout.html' %}

{% block title %}首页{% endblock %}

{% block content %}
<h1>主页内容</h1>
{% endblock %}
```

## 6. 表单处理

```python
from flask import Flask, render_template, request

@app.route('/post', methods=['GET', 'POST'])
def post():
    if request.method == 'POST':
        name = request.form['name']          # 表单字段
        return f'收到：{name}'
    return render_template('post.html')
```

```html
<!-- templates/post.html -->
<form method="POST">
  <input type="text" name="name" placeholder="输入姓名">
  <button type="submit">提交</button>
</form>
```

> [!tip] 提示
> - `request.form['字段']`：POST 表单数据
> - `request.args.get('key')`：URL 查询参数（`?key=value`）
> - `request.json`：POST 的 JSON 请求体
> - `request.path`：当前路径

## 7. 静态文件

```html
<!-- templates/layout.html 中引用 -->
<link rel="stylesheet" href="{{ url_for('static', filename='css/main.css') }}">
```

## 8. 重定向与错误页

```python
from flask import redirect, url_for, abort

@app.route('/old')
def old():
    return redirect(url_for('home'))    # 重定向到 home 函数

@app.route('/secret')
def secret():
    abort(404)                          # 返回 404

@app.errorhandler(404)
def not_found(e):
    return '页面不存在', 404
```
