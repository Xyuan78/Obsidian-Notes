# Python 数据分析（NumPy）

## 1. statistics 统计模块

```python
from statistics import mean, median, mode, stdev, variance

data = [1, 2, 3, 4, 5]
mean(data)        # 3.0 平均数
median(data)      # 3 中位数
mode(data)        # 众数（出现最多的值）
stdev(data)       # 标准差
variance(data)    # 方差
```

> [!tip] 提示
> 数据量大或需要数组运算时，用 NumPy/Pandas 替代 statistics

## 2. NumPy 数组

### 2.1 创建数组

```python
import numpy as np

arr = np.array([1, 2, 3, 4, 5])            # 列表 → 一维数组
arr2 = np.array([[1, 2, 3], [4, 5, 6]])    # 二维数组
arr_float = np.array([1, 2, 3], dtype=float)   # 指定类型 [1., 2., 3.]
arr_bool = np.array([0, 1, 0], dtype=bool)     # [False, True, False]
np.array((1, 2, 3))                        # 元组 → 数组

np.arange(10)              # [0 1 2 ... 9] 类似 range
np.arange(2, 10, 2)        # [2 4 6 8]
np.linspace(5, 20, 10)     # 5 到 20 均匀取 10 个点
np.zeros(5)                # [0. 0. 0. 0. 0.]
np.ones((2, 3))            # 2x3 全 1
np.random.rand(3)          # 3 个 0-1 随机数
np.random.randint(1, 100, 5)   # 5 个 1-99 随机整数
```

### 2.2 数组属性

```python
arr = np.array([[1, 2, 3], [4, 5, 6]])
arr.shape        # (2, 3) 行数、列数
arr.ndim         # 2 维度数
arr.size         # 6 元素个数
arr.dtype        # dtype('int64') 数据类型
arr.tolist()     # 转回 Python 列表
len(arr)         # 2 行数
```

## 3. 数组运算（向量化）

NumPy 无需循环即可对整个数组做数学运算，这也是它比列表快的原因

```python
arr = np.array([1, 2, 3, 4, 5])
arr + 2            # [3 4 5 6 7]
arr - 2            # [-1 0 1 2 3]
arr * 2            # [2 4 6 8 10]
arr / 2            # [0.5 1. 1.5 2. 2.5]
arr ** 2           # [1 4 9 16 25]
arr % 2            # [1 0 1 0 1]
arr1 + arr2        # 数组间逐元素运算（长度需相同）
```

```python
# 条件筛选
arr[arr > 3]       # array([4, 5]) 返回满足条件的元素
```

## 4. 索引与切片

```python
arr = np.array([10, 20, 30, 40, 50])
arr[0]          # 10
arr[-1]         # 50
arr[1:4]        # [20 30 40]
arr[::2]        # [10 30 50] 步长切片

arr2 = np.array([[1, 2, 3], [4, 5, 6]])
arr2[0]         # 第 0 行 [1 2 3]
arr2[0, 1]      # 第 0 行第 1 列 = 2
arr2[:, 1]      # 所有行第 1 列 [2 5]
arr2[1, :2]     # 第 1 行前两列 [4 5]
```

## 5. 常用统计函数

```python
arr = np.array([3, 1, 4, 1, 5, 9, 2, 6])
arr.min()          # 1 最小值
arr.max()          # 9 最大值
arr.sum()          # 31 总和
arr.mean()         # 3.875 平均值
np.median(arr)     # 3.5 中位数
np.std(arr)        # 标准差
np.var(arr)        # 方差
np.percentile(arr, 25)   # 25 分位数
np.percentile(arr, 90)   # 90 分位数
arr.argmax()       # 最大值的索引
arr.argmin()       # 最小值的索引
```

## 6. 拼接与变形

```python
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

np.concatenate([a, b])            # [1 2 3 4 5 6] 默认按行拼接
np.vstack([a, b])                 # 垂直堆叠 [[1 2 3],[4 5 6]]
np.hstack([a, b])                 # 水平拼接 [1 2 3 4 5 6]

arr = np.array([[1, 2, 3], [4, 5, 6]])
arr.reshape(3, 2)                 # 变形为 3 行 2 列
arr.flatten()                     # [1 2 3 4 5 6] 拉平为一维
```
