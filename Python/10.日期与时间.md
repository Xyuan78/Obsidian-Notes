# Python 日期与时间

## 1. datetime 模块

```python
from datetime import datetime, date, time, timedelta
```

| 类 | 说明 |
|----|------|
| `datetime` | 日期 + 时间 |
| `date` | 只有日期 |
| `time` | 只有时间 |
| `timedelta` | 时间差，用于计算 |
| `timezone` | 时区 |

## 2. 获取当前时间

```python
now = datetime.now()
print(now)                       # 2026-08-06 10:30:00.123456
print(now.year, now.month, now.day)        # 2026 8 6
print(now.hour, now.minute, now.second)    # 10 30 0
print(now.weekday())             # 0=周一 ... 6=周日
print(now.timestamp())           # 时间戳（1970 年以来的秒数）
```

## 3. 构造 datetime

```python
d = datetime(2020, 1, 1)                    # 2020-01-01 00:00:00
d = datetime(2020, 1, 1, 14, 30, 5)         # 2020-01-01 14:30:05

# 从时间戳转回
dt = datetime.fromtimestamp(1577836800)     # 2020-01-01 00:00:00
```

## 4. 格式化 strftime（时间 → 字符串）

```python
now = datetime.now()
now.strftime('%Y-%m-%d %H:%M:%S')     # 2026-08-06 10:30:00
now.strftime('%m/%d/%Y')              # 08/06/2026
now.strftime('%d %B, %Y')             # 06 August, 2026
```

### 4.1 常用格式符号

| 符号 | 说明 | 示例 |
|------|------|------|
| `%Y` | 四位年份 | 2026 |
| `%y` | 两位年份 | 26 |
| `%m` | 月份 01-12 | 08 |
| `%d` | 日 01-31 | 06 |
| `%H` | 24 小时制小时 00-23 | 10 |
| `%I` | 12 小时制小时 01-12 | 10 |
| `%M` | 分钟 00-59 | 30 |
| `%S` | 秒 00-59 | 00 |
| `%p` | AM/PM | AM |
| `%B` | 完整月份名 | August |
| `%b` | 缩写月份名 | Aug |
| `%A` | 完整星期名 | Thursday |
| `%a` | 缩写星期名 | Thu |
| `%j` | 一年中的第几天 001-366 | 218 |
| `%W` | 一年中的第几周 | 31 |

## 5. strptime（字符串 → 时间）

```python
date_str = '5 December, 2019'
date_obj = datetime.strptime(date_str, '%d %B, %Y')
# 2019-12-05 00:00:00

datetime.strptime('2026-08-06', '%Y-%m-%d')
datetime.strptime('10:30:00', '%H:%M:%S')
```

> [!warning] 注意
> `strptime` 的格式字符串必须与输入完全匹配，否则抛 `ValueError`

## 6. date 与 time 对象

```python
from datetime import date, time

d = date(2020, 1, 1)
today = date.today()
print(today.year, today.month, today.day)   # 2026 8 6
print(today.isoformat())                    # '2026-08-06'
print(today.weekday())                      # 3（周四）

t = time(10, 30, 50)          # 10:30:50
t = time(hour=10, minute=30, second=50, microsecond=200555)
print(t)                      # 10:30:50.200555
```

## 7. timedelta 时间差

```python
from datetime import datetime, timedelta

t1 = datetime(2019, 12, 5)
t2 = datetime(2020, 1, 1)
diff = t2 - t1
print(diff)                   # 27 days, 0:00:00
print(diff.days)              # 27
print(diff.total_seconds())   # 2332800.0

# 时间加减
today = datetime.now()
print(today + timedelta(days=7))          # 一周后
print(today - timedelta(hours=3))         # 三小时前
print(today + timedelta(weeks=1, days=2, hours=4, minutes=30))
```

```python
# 构建 timedelta
td = timedelta(weeks=12, days=10, hours=4, seconds=20)
print(td)                     # 94 days, 4:00:20
```

## 8. 实战示例

```python
# 计算年龄
def calc_age(birth_year):
    return date.today().year - birth_year

print(calc_age(2000))         # 26

# 距离新年的天数
now = datetime.now()
new_year = datetime(now.year + 1, 1, 1)
print(f'距离新年还有 {new_year - now}')

# 日期格式化输出
print(f"今天是 {now.strftime('%Y年%m月%d日')} 星期{'一二三四五六日'[now.weekday()]}")
```
