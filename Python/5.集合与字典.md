# Python 集合与字典

## 1. 集合（set）

### 1.1 什么是集合

集合是**无序、不重复**的元素集合。集合的元素必须是不可变类型（数字、字符串、元组），不能是列表或字典。

- 无序：没有下标索引，不能用索引访问
- 唯一：自动去重，重复元素只保留一个
- 用途：去重、成员判断、数学集合运算（并集/交集/差集）

### 1.2 创建集合

```python
st = set()                              # 空集合
fruits = {'banana', 'orange', 'mango'}  # 直接创建

# 从列表/元组创建（自动去重）
lst = [1, 2, 2, 3, 3, 3]
st = set(lst)          # {1, 2, 3}

# 字符串转集合（拆成字符）
set('hello')           # {'h', 'e', 'l', 'o'}
```

> [!warning] 注意
> 空集合必须用 `set()` 创建；`{}` 创建的是空字典

### 1.3 常用方法

| 方法 | 说明 | 示例 |
|------|------|------|
| `add(x)` | 添加单个元素 | `st.add('item5')` |
| `update(iterable)` | 批量添加（列表/元组/集合/字符串） | `st.update(['a','b'])` |
| `remove(x)` | 移除元素，**不存在会报 KeyError** | `st.remove('a')` |
| `discard(x)` | 移除元素，**不存在不报错** | `st.discard('a')` |
| `pop()` | 随机移除并返回一个元素 | `st.pop()` |
| `clear()` | 清空集合 | `st.clear()` |
| `copy()` | 复制集合 | `st2 = st.copy()` |
| `del st` | 删除整个集合 | — |

```python
fruits = {'banana', 'orange', 'mango'}
fruits.add('lime')                       # 添加单个
fruits.update(['apple', 'grape'])        # 批量添加
fruits.remove('apple')                   # 移除（存在才安全）
fruits.discard('不存在的元素')            # 不报错
```

### 1.4 集合运算

| 运算 | 方法 | 运算符 | 说明 |
|------|------|--------|------|
| 并集 | `s1.union(s2)` | `s1 \| s2` | 合并全部元素 |
| 交集 | `s1.intersection(s2)` | `s1 & s2` | 共有元素 |
| 差集 | `s1.difference(s2)` | `s1 - s2` | 在 s1 但不在 s2 |
| 对称差集 | `s1.symmetric_difference(s2)` | `s1 ^ s2` | (A\B) ∪ (B\A) |
| 子集 | `s1.issubset(s2)` | `s1 <= s2` | s1 是 s2 的子集 |
| 超集 | `s1.issuperset(s2)` | `s1 >= s2` | s1 包含 s2 |
| 不相交 | `s1.isdisjoint(s2)` | — | 无共同元素返回 True |

```python
python = {'p', 'y', 't', 'h', 'o', 'n'}
dragon = {'d', 'r', 'a', 'g', 'o', 'n'}

python.union(dragon)                # {'p','y','t','h','o','n','d','r','a','g'}
python.intersection(dragon)         # {'o', 'n'}
python.difference(dragon)           # {'p', 'y', 't', 'h'}
python.symmetric_difference(dragon) # {'p','y','t','h','d','r','a','g'}
python.isdisjoint(dragon)           # False（有共同元素）
```

### 1.5 成员判断与去重

```python
'mango' in fruits          # True，in 判断成员
'apple' not in fruits      # True

# 经典去重写法
words = ['apple', 'banana', 'apple', 'orange', 'banana']
unique = list(set(words))  # ['apple', 'banana', 'orange']
```

> [!tip] 提示
> 去重后再排序：`sorted(set(words))` 保证结果顺序稳定

## 2. 字典（dict）

### 2.1 什么是字典

字典是**无序、可变**的键值对（key-value）集合，键必须**唯一且不可变**（字符串、数字、元组），值可以是任意类型。

### 2.2 创建字典

```python
dct = {}                                          # 空字典
dct = {'key1': 'value1', 'key2': 'value2'}        # 字面量
dct = dict(name='Asabeneh', age=250)              # 关键字创建
dct = dict([('name', 'Asabeneh'), ('age', 250)])  # 由键值对列表创建
dct = dict.fromkeys(['a', 'b', 'c'], 0)           # 统一默认值 {'a':0,'b':0,'c':0}
```

复杂示例（值可以是任意类型，可嵌套）：

```python
person = {
    'name': 'Asabeneh',
    'age': 250,
    'skills': ['Python', 'Flask'],      # 列表
    'address': {                        # 嵌套字典
        'city': 'Helsinki',
        'zipcode': '02210'
    }
}
```

### 2.3 访问字典

```python
person['name']                 # Asabeneh，键不存在报 KeyError
person['address']['city']      # Helsinki，嵌套访问
person.get('name')             # Asabeneh，不存在返回 None
person.get('city', '未知')      # 不存在返回默认值 '未知'
person.setdefault('age', 0)    # 键存在返回值，不存在则插入默认值
```

### 2.4 添加与修改

```python
person['email'] = 'asabeneh@gmail.com'   # 键不存在 → 添加
person['age'] = 251                      # 键存在 → 修改（覆盖）
person.update({'city': 'Espoo', 'age': 252})   # 批量添加/修改
```

### 2.5 删除

| 操作 | 写法 | 说明 |
|------|------|------|
| 删除指定键 | `dct.pop('key')` | 返回被删的值，键不存在报错 |
| 安全删除 | `dct.pop('key', 默认值)` | 键不存在返回默认值 |
| 删除最后一项 | `dct.popitem()` | 删除并返回最后插入的键值对 |
| 删除键 | `del dct['key']` | — |
| 清空 | `dct.clear()` | 保留空字典 |
| 删除整个字典 | `del dct` | — |
| 复制 | `dct.copy()` | 浅拷贝，避免影响原字典 |

### 2.6 遍历与视图

```python
dct.keys()      # dict_keys(['key1','key2',...])  所有键
dct.values()    # dict_values([...])              所有值
dct.items()     # dict_items([('key1','value1'),...])  键值对

# 常用遍历方式
for key in dct:                  # 遍历键
    print(key)

for key, value in dct.items():   # 同时遍历键和值
    print(key, value)
```

### 2.7 合并字典（Python 3.9+）

```python
d1 = {'a': 1, 'b': 2}
d2 = {'b': 3, 'c': 4}
merged = d1 | d2          # {'a': 1, 'b': 3, 'c': 4}，后者覆盖
```

### 2.8 字典常用方法速查

| 方法 | 说明 |
|------|------|
| `len(dct)` | 键值对数量 |
| `'key' in dct` | 键是否存在 |
| `dct.get(key, default)` | 安全取值 |
| `dct.setdefault(key, default)` | 取值，不存在则设置默认值 |
| `dct.update(other)` | 合并其他字典 |
| `dct.copy()` | 浅拷贝 |
| `dct.pop(key)` / `dct.popitem()` | 删除 |
| `dct.clear()` | 清空 |
| `dct.keys()` / `dct.values()` / `dct.items()` | 视图 |

> [!warning] 注意
> `copy()` 是浅拷贝：嵌套的可变对象（列表/字典）仍共享引用，修改会影响原字典
