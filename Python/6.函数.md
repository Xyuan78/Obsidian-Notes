# Python 函数

## 1. 函数基础

### 1.1 定义与调用

```python
def 函数名(参数1, 参数2):
    # 函数体
    return 返回值    # 没有 return 默认返回 None
```

```python
def add_two_numbers(num1, num2):
    return num1 + num2

print(add_two_numbers(2, 3))   # 5
print(add_two_numbers)         # <function add_two_numbers at 0x...> 函数本身是对象
```

> [!tip] 提示
> 函数必须先定义再调用；没有 `return` 的函数返回 `None`

### 1.2 return 的细节

```python
# 返回多个值（实际是返回元组）
def swap(a, b):
    return b, a

x, y = swap(1, 2)      # 解包接收，x=2, y=1

# return 会立即结束函数
def is_even(n):
    if n % 2 == 0:
        return True    # 执行到这里直接返回
    return False
```

## 2. 参数传递

| 方式 | 写法 | 说明 |
|------|------|------|
| 位置参数 | `f(1, 2)` | 按顺序传参 |
| 关键字参数 | `f(num2=2, num1=1)` | 键值对传参，顺序无关 |
| 默认参数 | `def f(name='Asabeneh')` | 不传参时用默认值 |
| 可变参数 | `def f(*args)` | 打包为元组，任意数量 |
| 关键字可变参数 | `def f(**kwargs)` | 打包为字典 |

### 2.1 位置与关键字参数

```python
def generate_full_name(first_name, last_name):
    return f'{first_name} {last_name}'

generate_full_name('Asabeneh', 'Yetayeh')            # 位置传参
generate_full_name(last_name='Yetayeh', first_name='Asabeneh')  # 关键字传参
```

### 2.2 默认参数

```python
def greet(name='陌生人'):
    return f'你好，{name}'

greet()              # 你好，陌生人
greet('小明')        # 你好，小明
```

> [!warning] 注意
> 默认参数必须写在非默认参数之后：`def f(a, b=1)` 正确，`def f(a=1, b)` 报错

### 2.3 可变参数 *args / **kwargs

```python
def sum_all(*args):
    return sum(args)

sum_all(1, 2, 3)            # 6
sum_all(1, 2, 3, 4, 5)      # 15

def person_info(**kwargs):
    for k, v in kwargs.items():
        print(f'{k} = {v}')

person_info(name='Asabeneh', age=250, country='Finland')
```

### 2.4 解包（unpacking）

```python
# 列表/元组解包为位置参数
lst = [1, 2, 3, 4, 5]
sum_all(*lst)

# 字典解包为关键字参数
dct = {'a': 1, 'b': 2}
def add(a, b):
    return a + b
add(**dct)                  # 3

# 星号赋值解包
one, *middle, last = [1, 2, 3, 4, 5]
print(one, middle, last)    # 1 [2, 3, 4] 5

# 展开合并列表
lst1, lst2 = [1, 2], [3, 4]
lst = [0, *lst1, *lst2]     # [0, 1, 2, 3, 4]
```

## 3. 匿名函数 lambda

单表达式匿名函数，**隐式返回表达式结果**，不能写多行

```python
add = lambda a, b: a + b
print(add(2, 3))                # 5

square = lambda x: x ** 2
print(square(3))                # 9

# 立即调用
print((lambda a, b: a + b)(2, 3))   # 5

# 函数返回 lambda
def power(x):
    return lambda n: x ** n

print(power(2)(3))              # 8
```

> [!tip] 提示
> lambda 最适合作为 `map`/`filter`/`sorted` 等函数的临时函数参数，不要滥用

## 4. 高阶函数

把函数当作**参数**或**返回值**的函数

```python
# 函数作为参数
def apply(func, x):
    return func(x)

apply(square, 5)        # 25

# 函数作为返回值
def choose(type):
    if type == 'square':
        return lambda x: x ** 2
    elif type == 'cube':
        return lambda x: x ** 3

result = choose('cube')
print(result(3))        # 27
```

### 4.1 map / filter / reduce

| 函数 | 说明 | 示例 |
|------|------|------|
| `map(func, iterable)` | 对每个元素应用函数，返回新结果 | `list(map(lambda x: x*x, [1,2,3]))` → `[1,4,9]` |
| `filter(func, iterable)` | 保留函数返回 True 的元素 | `list(filter(lambda x: x%2==0, range(10)))` → `[0,2,4,6,8]` |
| `reduce(func, iterable)` | 累计归约 | `reduce(lambda a,b: a+b, [1,2,3,4])` → `10` |

```python
from functools import reduce

# map 配合多个可迭代对象
list(map(lambda x, y: x + y, [1, 2, 3], [10, 20, 30]))   # [11, 22, 33]

# filter 提取正偶数
nums = [-8, -3, 0, 2, 4, 7]
list(filter(lambda x: x > 0 and x % 2 == 0, nums))       # [2, 4]

# reduce 计算阶乘
reduce(lambda a, b: a * b, range(1, 6))                  # 120
```

## 5. 闭包

**闭包**：内部函数引用外部函数的变量，外部函数返回内部函数，被引用的变量随内部函数保留

```python
def add_ten():
    ten = 10
    def add(num):
        return num + ten    # 引用外部变量 ten
    return add

closure_result = add_ten()
print(closure_result(5))    # 15
print(closure_result(10))   # 20
```

## 6. 装饰器

**装饰器**：在不修改原函数代码的前提下，给函数添加新功能（闭包的应用）

### 6.1 基本装饰器

```python
def uppercase_decorator(function):
    def wrapper():
        func = function()
        return func.upper()
    return wrapper

@uppercase_decorator        # 等价于 greeting = uppercase_decorator(greeting)
def greeting():
    return 'Welcome to Python'

print(greeting())           # WELCOME TO PYTHON
```

### 6.2 带参数的函数使用装饰器

```python
def decorator(func):
    def wrapper(*args, **kwargs):
        print('调用前')
        result = func(*args, **kwargs)
        print('调用后')
        return result
    return wrapper

@decorator
def add(a, b):
    return a + b

print(add(2, 3))            # 调用前 / 调用后 / 5
```

### 6.3 多个装饰器（顺序很重要）

```python
def uppercase_decorator(function):
    def wrapper():
        return function().upper()
    return wrapper

def split_decorator(function):
    def wrapper():
        return function().split()
    return wrapper

@split_decorator            # 先执行（离函数最近的先装饰）
@uppercase_decorator
def greeting():
    return 'Welcome to Python'

print(greeting())           # ['WELCOME', 'TO', 'PYTHON']
```
