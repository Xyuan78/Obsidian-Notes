# Python 流程控制

## 1. `if` 语句

### 基本格式

```python
if 要判断的条件:
    条件成立时，执行操作1
else:
    条件不成立时，执行操作2
```

### 进阶语句

```python
if 条件1:
    条件1成立时，执行操作1
elif 条件2:
    条件2成立时，执行操作2
else:
    所有条件都不成立时，执行操作3
```

## 2. `match` 模式匹配（类似其他语言的 `switch`）

用清晰的模板去精准匹配数据的结果和内容，匹配成功则执行相应操作

```python
day = input("请输入星期几（1-7）：")
match day:
    case 1:
        print("星期一")
    case 2:
        print("星期二")
    case 3 if 条件表达式:
        print("星期三（带条件）")
    case 4:
        print("星期四")
    case 5:
        print("星期五")
    case 6 | 7:
        print("周末")
    case _:
        print("输入错误")
```

## 3. `while` 循环

重复执行某一件事

```python
while 条件表达式:
    循环体代码1
    循环体代码2
else:
    条件为 False，循环正常结束时执行
```

## 4. `for` 循环

```python
for 元素 in 待处理数据集:
    循环体代码（对元素进行处理）
else:
    循环结束时执行的代码
```

### `range()` 语句

- `range(end)`：获取一个从 0 开始到 end 结束的数字序列（不含 end 本身）
- `range(start, end)`：获取从 start 到 end 的数字序列（不含 end 本身）
- `range(start, end, step)`：获取从 start 到 end 的数字序列，步长为 step（不含 end 本身）

## 5. 嵌套循环

```python
for 元素1 in 待处理数据集1:
    # 外部循环体
    for 元素2 in 待处理数据集2:
        # 内部循环体
        ...
```
