# Python 面向对象

面向对象编程（OOP）把数据（属性）和操作（方法）封装成**类**，由类创建**对象**（实例）

## 1. 类与对象基础

### 1.1 定义类与创建对象

```python
class Person:            # 类名用大驼峰命名（CamelCase）
    pass                 # 空类

p = Person()             # 创建对象（实例化）
print(type(p))           # <class '__main__.Person'>
```

### 1.2 构造函数 `__init__` 与 `self`

`__init__` 在创建对象时自动执行，`self` 指向当前实例

```python
class Person:
    def __init__(self, firstname, lastname, age):
        self.firstname = firstname     # 实例属性
        self.lastname = lastname
        self.age = age

p = Person('Asabeneh', 'Yetayeh', 250)
print(p.firstname, p.age)   # Asabeneh 250
```

### 1.3 对象方法

```python
class Person:
    def __init__(self, firstname='Asabeneh', lastname='Yetayeh', age=250):
        self.firstname = firstname
        self.lastname = lastname
        self.age = age
        self.skills = []               # 属性默认值

    def person_info(self):             # 对象方法，第一个参数必须是 self
        return f'{self.firstname} {self.lastname} 今年 {self.age} 岁'

    def add_skill(self, skill):
        self.skills.append(skill)

p1 = Person()
print(p1.person_info())                # Asabeneh Yetayeh 今年 250 岁
p1.add_skill('Python')
p1.add_skill('Flask')
print(p1.skills)                       # ['Python', 'Flask']

p2 = Person('John', 'Doe', 30)         # 覆盖默认值
print(p2.skills)                       # [] 每个实例独立
```

> [!tip] 提示
> 构造函数参数给默认值，可以避免不传参时报错；`self.xxx` 属性每个实例各自独立

## 2. 继承

子类继承父类的属性和方法，实现代码复用

```python
class Student(Person):                 # 括号里是父类
    def __init__(self, firstname, lastname, age, gender):
        super().__init__(firstname, lastname, age)   # 调用父类构造函数
        self.gender = gender

    def person_info(self):             # 方法重写（覆盖父类）
        return f'{self.firstname} 是学生（{self.gender}）'

s = Student('Asabeneh', 'Yetayeh', 250, '男')
print(s.person_info())                 # Asabeneh 是学生（男）
print(s.add_skill)                     # 继承的方法仍可用
```

### 2.1 isinstance 判断

```python
print(isinstance(s, Student))   # True
print(isinstance(s, Person))    # True（Student 是 Person 的子类）
```

## 3. 封装与私有属性

Python 用命名约定表示私有：`_x`（约定私有）、`__x`（名称改写，实际私有）

```python
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.__balance = balance       # 双下划线：外部不能直接访问

    def deposit(self, amount):
        self.__balance += amount

    def get_balance(self):
        return self.__balance

acct = BankAccount('Asabeneh', 100)
acct.deposit(50)
print(acct.get_balance())       # 150
# print(acct.__balance)         # AttributeError
```

## 4. 魔术方法（双下划线方法）

| 方法 | 作用 | 示例 |
|------|------|------|
| `__init__(self, ...)` | 构造函数 | 初始化属性 |
| `__str__(self)` | `print()` / `str()` 显示内容 | 自定义可读描述 |
| `__repr__(self)` | 解释器中的表示 | 调试用 |
| `__len__(self)` | `len(对象)` | 返回长度 |
| `__eq__(self, other)` | `==` 比较 | 自定义相等逻辑 |
| `__add__(self, other)` | `+` 运算 | 自定义加法 |

```python
class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __str__(self):
        return f'Point({self.x}, {self.y})'

    def __add__(self, other):
        return Point(self.x + other.x, self.y + other.y)

    def __eq__(self, other):
        return self.x == other.x and self.y == other.y

p1, p2 = Point(1, 2), Point(3, 4)
print(p1)               # Point(1, 2)
print(p1 + p2)          # Point(4, 6)
print(p1 == Point(1, 2))  # True
```

## 5. 类属性与类方法

```python
class Dog:
    species = 'Canis familiaris'      # 类属性（所有实例共享）

    def __init__(self, name):
        self.name = name              # 实例属性

    @classmethod
    def get_species(cls):             # 类方法，第一个参数是 cls
        return cls.species

    @staticmethod
    def bark():                       # 静态方法，不需要 self/cls
        return '汪汪'

d = Dog('旺财')
print(d.species, Dog.species)         # 类属性共享
print(Dog.get_species())              # Canis familiaris
print(Dog.bark())                     # 汪汪
```
