# Python 模块与包

## 1. 模块（module）

### 1.1 什么是模块

一个 `.py` 文件就是一个模块。把功能拆分成多个模块，便于组织、复用和维护代码。

### 1.2 创建与导入模块

```python
# mymodule.py（自定义模块）
PI = 3.14

def add(a, b):
    return a + b

def area_of_circle(r):
    return PI * r ** 2
```

```python
# 在其他文件中使用
import mymodule
mymodule.add(2, 3)                  # 5
mymodule.PI                         # 3.14

from mymodule import add, PI        # 只导入指定内容
add(2, 3)

from mymodule import add as a       # 重命名
a(2, 3)

from mymodule import *              # 导入全部（不推荐，可能覆盖同名变量）
```

| 导入写法 | 调用方式 |
|----------|----------|
| `import 模块名` | `模块名.函数()` |
| `from 模块名 import 函数` | 直接 `函数()` |
| `from 模块名 import 函数 as 别名` | `别名()` |
| `import 模块1, 模块2` | 一次导入多个 |

### 1.3 `__name__` 与 `if __name__ == '__main__'`

```python
# 直接运行时 __name__ 为 '__main__'；被导入时为模块名
if __name__ == '__main__':
    print('只有直接运行时才执行')
```

> [!tip] 提示
> 测试代码放进 `if __name__ == '__main__':` 里，被导入时不会执行

## 2. 常用内置模块

| 模块 | 常用函数/常量 | 说明 |
|------|----------------|------|
| `os` | `getcwd()`、`mkdir()`、`listdir()`、`remove()`、`environ` | 操作系统接口 |
| `sys` | `argv`、`version`、`path` | 解释器与命令行参数 |
| `math` | `pi`、`sqrt()`、`ceil()`、`floor()`、`pow()` | 数学运算 |
| `statistics` | `mean()`、`median()`、`mode()`、`stdev()` | 统计 |
| `random` | `random()`、`randint(a,b)`、`choice()`、`shuffle()` | 随机数 |
| `string` | `ascii_letters`、`digits`、`punctuation` | 字符串常量 |
| `datetime` | `datetime`、`date`、`timedelta` | 日期时间，见 [[10.日期与时间]] |
| `re` | `findall()`、`sub()`、`split()` | 正则，见 [[11.正则表达式]] |

```python
import os, sys, math, random, statistics

os.getcwd()                        # 当前工作目录
sys.argv                           # 命令行参数列表
math.sqrt(16)                      # 4.0
statistics.mean([1, 2, 3, 4, 5])   # 3
random.randint(1, 6)               # 1-6 随机整数（模拟骰子）
random.choice(['a', 'b', 'c'])     # 随机取一个
```

## 3. 包（package）

**包** = 包含 `__init__.py` 的目录，`__init__.py` 可以为空

```
mypackage/
├── __init__.py     # 包标识，可写导入逻辑
├── arithmetic.py
└── greet.py
```

```python
import mypackage.arithmetic
from mypackage import arithmetic
from mypackage.arithmetic import add
```

## 4. pip 包管理

### 4.1 常用命令

| 命令 | 说明 |
|------|------|
| `pip --version` | 查看 pip 版本 |
| `pip install 包名` | 安装包 |
| `pip install 包名==1.2.3` | 安装指定版本 |
| `pip install -U 包名` | 升级包 |
| `pip uninstall 包名` | 卸载包 |

| `pip install -r requirements.txt` | 按清单安装 |

## 5. 虚拟环境（venv）

### 5.1 为什么需要

不同项目依赖不同版本，虚拟环境把每个项目的依赖隔离，避免版本冲突，也让 `requirements.txt` 干净可控

### 5.2 使用流程

```powershell
# 创建虚拟环境（目录名习惯用 venv）
python -m venv venv

# 激活（Windows PowerShell）
venv\Scripts\activate

# 激活（macOS / Linux）
source venv/bin/activate

# 安装依赖
pip install flask

# 记录依赖
pip freeze > requirements.txt

# 退出虚拟环境
deactivate
```

> [!warning] 注意
> - 激活后命令行前缀出现 `(venv)` 表示已生效
> - `venv` 目录体积大且可重建，必须加入 `.gitignore`
> - 换电脑/部署时：`pip install -r requirements.txt` 一键恢复环境
