# Python 正则表达式

正则表达式（RegEx）是用模式字符串匹配文本的工具，常用于校验、提取、替换、分割

## 1. re 模块常用方法

| 方法 | 说明 |
|------|------|
| `re.match(pattern, text)` | 从**开头**匹配，返回 Match 对象或 None |
| `re.search(pattern, text)` | 搜索**第一个**匹配 |
| `re.findall(pattern, text)` | 返回所有匹配的**列表** |
| `re.finditer(pattern, text)` | 返回迭代器（大文本更省内存） |
| `re.sub(pattern, repl, text, flags)` | 替换匹配内容 |
| `re.split(pattern, text)` | 按模式分割 |
| `re.fullmatch(pattern, text)` | 整个字符串完全匹配 |

```python
import re

txt = 'I love Python, Python is great.'
re.findall(r'Python', txt)              # ['Python', 'Python']
re.search(r'love', txt).group()         # 'love'
re.sub(r'Python', 'Java', txt)          # I love Java, Java is great.
re.split(r',', txt)                     # ['I love Python', ' Python is great.']
re.match(r'I', txt)                     # 开头匹配成功
```

> [!tip] 提示
> 模式用 `r'...'` 原始字符串，反斜杠不会被转义；`re.I` 忽略大小写

### 1.1 匹配对象的使用

```python
m = re.search(r'(\d+)-(\d+)', '号码 010-12345678')
m.group()        # '010-12345678' 整个匹配
m.group(1)       # '010' 第一组
m.group(2)       # '12345678' 第二组
m.start(), m.end()   # 匹配位置
```

## 2. 常用元字符

| 元字符 | 说明 | 示例 |
|--------|------|------|
| `.` | 任意单个字符（除换行） | `a.c` 匹配 `abc` |
| `^` | 字符串开头 | `^Python` |
| `$` | 字符串结尾 | `Python$` |
| `*` | 前面字符出现 0 次或多次 | `ab*c` 匹配 `ac`、`abc` |
| `+` | 出现 1 次或多次 | `\d+` |
| `?` | 出现 0 次或 1 次 | `colou?r` 匹配 color/colour |
| `{n}` | 恰好 n 次 | `\d{4}` |
| `{n,m}` | n 到 m 次 | `\d{2,4}` |
| `\|` | 或 | `cat\|dog` |
| `\d` | 数字 `[0-9]` | `\d+` |
| `\w` | 字母数字下划线 | `\w+` |
| `\s` | 空白（空格/Tab/换行） | `\s+` |
| `\D` `\W` `\S` | 对应取反 | — |
| `\b` | 单词边界 | `\bcat\b` |
| `\\` | 匹配反斜杠本身 | `\\d` |

## 3. 字符类（方括号）

```python
[Pp]ython        # Python 或 python
[a-z]            # 任意小写字母
[0-9]            # 任意数字
[a-zA-Z0-9]      # 字母和数字
[^0-9]           # 非数字（^ 在方括号内表示取反）
[aeiou]          # 任意元音字母
```

## 4. 分组与捕获

```python
# 分组提取
re.findall(r'(\d{4})-(\d{2})-(\d{2})', '2026-08-06')
# [('2026', '08', '06')]

# 非捕获分组 (?:...)
re.findall(r'(?:cat|dog)s?', 'cats and dogs')    # ['cats', 'dogs']
```

## 5. 常用标志 flags

| 标志 | 说明 |
|------|------|
| `re.I` | 忽略大小写 |
| `re.M` | 多行模式，`^`/`$` 匹配每行 |
| `re.S` | 让 `.` 匹配换行 |

```python
re.findall(r'apple', 'Apple APPLE apple', re.I)   # ['Apple', 'APPLE', 'apple']
```

## 6. 实战常用模式

```python
# 邮箱
email_pattern = r'^[\w\.-]+@[\w\.-]+\.\w+$'
re.fullmatch(email_pattern, 'user@example.com')   # 匹配成功

# 手机号（11 位，1 开头）
phone_pattern = r'^1[3-9]\d{9}$'
re.fullmatch(phone_pattern, '13812345678')

# 提取所有数字
re.findall(r'\d+', 'December 6, 2019 and July 8, 2021')   # ['6', '2019', '8', '2021']

# 清洗文本中的特殊字符
re.sub(r'[%$#@]', '', '%I a%m teacher$')          # 'I am teacher'

# 中文匹配
re.findall(r'[\u4e00-\u9fa5]+', 'hello 世界 world 你好')   # ['世界', '你好']
```
